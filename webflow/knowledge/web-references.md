# Web references — free, licence-checked starting points

> Verified starting points for a zero-build static site. **Checked 2026-11-06**
> from repository metadata; re-check quarterly
> ([MAINTENANCE.md](../MAINTENANCE.md)) and re-run the
> [reuse-first.md](reuse-first.md) §3 scorecard at the moment of use. A reference
> can be many — **one site picks ONE base** (§5).

## 1. The trap this catalogue avoids

"Free web UI" is five different markets. Only the first two fit a static,
phone-first study/utility site:

- ✅ Classless CSS (drop-in typography), small component CSS, one icon set.
- ❌ Admin dashboards, landing-page templates, animation showcase libraries,
  paid "free" tiers, anything that requires a build step or a CDN.

## 2. Classless and minimal CSS (best fit for content sites)

| Reference | Licence | Use for |
|---|---|---|
| [picocss/pico](https://github.com/picocss/pico) | MIT | Semantic HTML that looks deliberate with no classes; small, themeable via custom properties |
| [kevquirk/simple.css](https://github.com/kevquirk/simple.css) | MIT | One-file, readable, dark-mode-aware base for text-heavy pages |
| [andybrewer/mvp](https://github.com/andybrewer/mvp) | MIT | Tiny, very plain — a starting point to override, not to keep |
| [oxalorg/sakura](https://github.com/oxalorg/sakura) | MIT | Old but minimal; study-grade |

## 3. Component CSS and design tokens

| Reference | Licence | Note |
|---|---|---|
| [open-props/open-props](https://github.com/ArgyleInk/open-props) | MIT | A large, well-organised custom-property token set (colours, sizes, easings) — ADAPT the naming, don't import it all |
| [saadeghi/daisyui](https://github.com/saadeghi/daisyui) | MIT | Semantic component classes; usable from a CDN-free build only with Tailwind — a recorded exception, not the default |
| [twbs/bootstrap](https://github.com/twbs/bootstrap) | MIT | Fine framework, instantly generic result, large payload for one site; usually REJECT |
| [W3C/WAI APG](https://www.w3.org/WAI/ARIA/apg/patterns/) | W3C document | The authority for tabs, dialogs, disclosure, combobox behaviour — ADAPT patterns, keep the semantics |

## 4. Icons, fonts, images

| Reference | Licence | Note |
|---|---|---|
| [lucide-icons/lucide](https://github.com/lucide-icons/lucide) | ISC (verify per file) | Consistent stroke icons; inline the SVGs you use or ship one sprite |
| [tailwindlabs/heroicons](https://github.com/tailwindlabs/heroicons) | MIT | Same idea, filled/outline variants |
| [google/material-design-icons](https://github.com/google/material-design-icons) | Apache-2.0 | Large; take only the glyphs used |
| [fontsource/fontsource](https://github.com/fontsource/fontsource) | MIT (per family) | Self-hosted fonts — never a font CDN, which breaks offline and privacy claims |
| [system font stack](https://modernfontstacks.com/) | n/a | Default choice: zero bytes, instant render |

## 5. Stack options (plan chat picks ONE, records it DECIDE-ONCE)

| Option | Stack | Speed | Risk |
|---|---|---|---|
| **A · DEFAULT** | Hand-written HTML + one CSS token file + one classless base (Pico or Simple.css), vanilla ES modules, inline SVG sprite | Fast, zero build, fully controllable | Requires discipline; no component library to lean on |
| **B · Component classes** | Plain HTML + daisyUI/Tailwind **built ahead of time** and committed as one CSS file | Fast once built | Introduces a build step and a large generated file; must be regenerated by hand on a phone |
| **C · Study-only** | Read APG patterns + one UI kit for layout ideas, implement in A | Slowest | Temptation to half-adopt a kit's markup |

A site may *study* screens from other tiers (STUDY), but the site itself is
built with the one chosen option. Switching mid-design is a design-direction
change, not a tweak.

## 6. Avoid for this purpose

- Admin/dashboard templates and landing-page kits — wrong skeleton, heavy JS.
- Animation showcase libraries — motion with no states.
- Anything loaded from a CDN at runtime: it breaks the offline claim, adds a
  third-party request, and can change under you.
- Icon fonts — unreadable at small sizes, inaccessible without care, extra
  request.
- "Free" tiers that become paid (Tailwind Plus, MUI X, Flowbite Pro) and Figma
  kits with paid upsells.
- No verifiable licence file — reuse-first §3: no licence = no permission.

## 7. Official references worth bookmarking

- [MDN Web Docs](https://developer.mozilla.org/) — the language reference.
- [web.dev](https://web.dev/) — performance, PWA, and Core Web Vitals guidance.
- [WCAG 2.2 quick reference](https://www.w3.org/WAI/WCAG22/quickref/) — the
  accessibility floor, in checklist form.
- [GitHub Pages docs](https://docs.github.com/en/pages) — project paths,
  custom domains, HTTPS.
- [Can I use](https://caniuse.com/) — support floor checks before promising a
  feature.
