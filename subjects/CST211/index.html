CST211 — Computer Programming Lab in C

Practical course. Source: Revised 2022 syllabus, p.14. Listed areas are transcribed tasks, not completed solutions.

  • Familiarisation with the programming environment (editor, compiler)
  • Formatted input and output (number formats, justification, specifiers)
  • Decision making and branching programs
  • Loop programs (GCD, LCM, series, patterns, primes, Armstrong numbers)
  • Arrays and strings (search, sort, matrices, vowels, standard string functions, palindrome)
  • Functions and parameter passing (nCr, series, factorial, call by value/reference, recursion)
  • Pointers and dynamic memory allocation (arrays, strings, structures, linked list, stack, queue)
