Computer Programming Lab in C

Practical course. Source: Revised 2022 syllabus, p.14. Credits 2; L-T-P 0-0-2; 2 hours per week; 30 contact hours.

Syllabus assessment fields: internal 60, external 40.

Supports the Computer Programming in C theory course.

Practical areas listed in the syllabus

These are transcribed task areas. Nothing here is a completed solution, a worked output or a claim that the task was performed.

  • Familiarisation with the programming environment (editor, compiler)
  • Formatted input and output (number formats, justification, specifiers)
  • Decision making and branching programs
  • Loop programs (GCD, LCM, series, patterns, primes, Armstrong numbers)
  • Arrays and strings (search, sort, matrices, vowels, standard string functions, palindrome)
  • Functions and parameter passing (nCr, series, factorial, call by value/reference, recursion)
  • Pointers and dynamic memory allocation (arrays, strings, structures, linked list, stack, queue)

Keep a dated record of the programs you actually write yourself; the site cannot do the practical for you.
