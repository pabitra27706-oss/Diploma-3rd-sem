About This Course

Course Aim

To develop the concept of how a computer works internally, covering architecture, microprocessors, and interfacing. Students will understand how hardware components are organized and how the CPU executes instructions at the micro-level.

Course Objectives

  • Understand the basic structure and operation of a digital computer
  • Analyze computational designs and control unit implementations
  • Study the Intel 8086 microprocessor architecture in detail
  • Write and trace 8086 assembly language programs
  • Interface memory and I/O devices with the 8086

Learning Outcomes

  • Explain Von-Neumann architecture and bus structures
  • Implement Booth's algorithm and pipelining concepts
  • Describe 8086 registers, segmentation, and interrupts
  • Write assembly programs and interface memory with 8086
  • Explain cache mapping and virtual memory techniques

Prerequisites

Basic knowledge of computer system components and digital logic gates (AND, OR, NOT, XOR). Familiarity with binary number systems and Boolean algebra is helpful.

Important Exam Tips
  • Unit 2 (20 hrs) carries the highest weightage — Booth's algorithm and pipelining are most frequently asked.
  • Numerical problems on Hamming code, pipeline speedup, cache mapping, and virtual memory are common.
  • For 6-mark answers, include block diagrams, step-by-step derivations, and trace tables.
  • Assembly programs must have correct syntax, proper segment structure, and initialization of DS.
  • Physical address calculation (Segment × 10H + Offset) is asked in almost every exam.
