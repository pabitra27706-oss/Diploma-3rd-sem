8086 Assembly Program Structure

Every 8086 assembly program typically follows this structure:

; Data Segment DATA SEGMENT ; Variable declarations (DB, DW) DATA ENDS ; Code Segment CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX ; Initialize DS ; Your program logic here MOV AH, 4CH INT 21H ; Terminate program CODE ENDS END START

Simple Programs

Program 1: Data Transfer Between Registers

Objective

Move a 16-bit value from one register to another and from memory to register.

8086 Assembly Code
DATA SEGMENT NUM1 DW 1234H ; 16-bit number in memory NUM2 DW ? ; Destination variable DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX ; Initialize DS MOV AX, NUM1 ; AX ← 1234H (memory to register) MOV BX, AX ; BX ← AX (register to register) MOV NUM2, BX ; NUM2 ← BX (register to memory) MOV AH, 4CH INT 21H ; Exit to DOS CODE ENDS END START

Program 2: 16-bit Addition of Two Numbers

8086 Assembly Code
DATA SEGMENT NUM1 DW 1234H NUM2 DW 5678H SUM DW ? DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX MOV AX, NUM1 ; AX = 1234H ADD AX, NUM2 ; AX = 1234H + 5678H = 68ACH MOV SUM, AX ; Store result in SUM MOV AH, 4CH INT 21H CODE ENDS END START

Program 3: 16-bit Subtraction

8086 Assembly Code
DATA SEGMENT NUM1 DW 5678H NUM2 DW 1234H DIFF DW ? DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX MOV AX, NUM1 ; AX = 5678H SUB AX, NUM2 ; AX = 5678H - 1234H = 4444H MOV DIFF, AX ; Store result MOV AH, 4CH INT 21H CODE ENDS END START

Program 4: 32-bit Addition (Multi-precision)

Concept

A 32-bit number is stored as two 16-bit words (low word first). Add low words with ADD, then add high words with ADC (Add with Carry) to include any carry from the low-word addition.

8086 Assembly Code
DATA SEGMENT NUM1_LO DW 0FFFFH ; Low word of NUM1 NUM1_HI DW 0001H ; High word: NUM1 = 0001FFFFH NUM2_LO DW 0002H ; Low word of NUM2 NUM2_HI DW 0003H ; High word: NUM2 = 00030002H SUM_LO DW ? SUM_HI DW ? DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX MOV AX, NUM1_LO ; AX = FFFFH ADD AX, NUM2_LO ; AX = FFFFH+0002H = 0001H, CF=1 MOV SUM_LO, AX MOV AX, NUM1_HI ; AX = 0001H ADC AX, NUM2_HI ; AX = 0001H+0003H+CF = 0005H MOV SUM_HI, AX ; Result = 00050001H MOV AH, 4CH INT 21H CODE ENDS END START

Logical Programs

Program 5: Logical AND, OR, XOR Operations

8086 Assembly Code
DATA SEGMENT VAL1 DW 0F0FH VAL2 DW 00FFH AND_RES DW ? OR_RES DW ? XOR_RES DW ? DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX ; AND operation: 0F0FH AND 00FFH = 000FH MOV AX, VAL1 AND AX, VAL2 MOV AND_RES, AX ; 000FH ; OR operation: 0F0FH OR 00FFH = 0FFFH MOV AX, VAL1 OR AX, VAL2 MOV OR_RES, AX ; 0FFFH ; XOR operation: 0F0FH XOR 00FFH = 0FF0H MOV AX, VAL1 XOR AX, VAL2 MOV XOR_RES, AX ; 0FF0H MOV AH, 4CH INT 21H CODE ENDS END START

Program 6: Masking — Extract Lower Nibble

Concept

Masking uses AND to isolate specific bits. AND with 0FH extracts the lower 4 bits (lower nibble) of a byte, clearing the upper nibble to 0.

8086 Assembly Code
MOV AL, 5AH ; AL = 0101 1010 = 5AH AND AL, 0FH ; AL = 0000 1010 = 0AH ; Lower nibble = AH (0AH), upper nibble cleared

Program 7: Set and Clear Specific Bits

8086 Assembly Code
; SET bit 3 of AL (OR with mask) MOV AL, 00H OR AL, 08H ; AL = 00001000 = 08H (bit 3 set) ; CLEAR bit 3 of AL (AND with inverted mask) MOV AL, 0FFH AND AL, 0F7H ; AL = 11110111 AND 11111111 = F7H (bit 3 cleared) ; TOGGLE bit 5 of AL (XOR with mask) MOV AL, 0A0H XOR AL, 20H ; Bit 5 toggled: A0H XOR 20H = 80H

Branch & Call Instructions

Program 8: Find Larger of Two Numbers

8086 Assembly Code
DATA SEGMENT NUM1 DW 0050H NUM2 DW 0030H LARGER DW ? DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX MOV AX, NUM1 ; AX = 0050H CMP AX, NUM2 ; Compare AX with NUM2 JGE STORE ; If AX >= NUM2, jump MOV AX, NUM2 ; Else AX = NUM2 STORE: MOV LARGER, AX ; Store larger value MOV AH, 4CH INT 21H CODE ENDS END START

Program 9: Sum of Array Elements Using LOOP

8086 Assembly Code
DATA SEGMENT ARR DW 10H, 20H, 30H, 40H, 50H ; 5-element array SUM DW ? CNT DW 05H ; Count = 5 DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX LEA SI, ARR ; SI points to start of array MOV CX, CNT ; CX = 5 (loop counter) XOR AX, AX ; AX = 0 (accumulator for sum) NEXT: ADD AX, [SI] ; Add current element to AX ADD SI, 02H ; Move to next word (DW = 2 bytes) LOOP NEXT ; CX--, if CX!=0 goto NEXT MOV SUM, AX ; Store sum (10+20+30+40+50 = F0H) MOV AH, 4CH INT 21H CODE ENDS END START

Program 10: Subroutine Call (CALL / RET)

Concept

CALL pushes IP (return address) onto the stack and jumps to the subroutine. RET pops IP from the stack and returns execution to the caller.

8086 Assembly Code
CODE SEGMENT ASSUME CS:CODE START: MOV AX, 000AH ; AX = 10 MOV BX, 0014H ; BX = 20 CALL ADD_SUB ; Call subroutine ; After CALL: CX has result MOV AH, 4CH INT 21H ; ---- Subroutine: ADD two numbers ---- ADD_SUB PROC NEAR MOV CX, AX ; CX = AX ADD CX, BX ; CX = AX + BX = 30 RET ; Return to caller ADD_SUB ENDP CODE ENDS END START

Sorting (Bubble Sort)

Bubble Sort Algorithm

Bubble sort repeatedly compares adjacent elements and swaps them if they are in the wrong order. After each pass, the largest unsorted element "bubbles" to the end. For n elements, n−1 passes are needed.

Steps
  1. Set pass counter = n − 1 (outer loop).
  2. For each pass, compare adjacent elements from start.
  3. If current > next (ascending), swap them using XCHG.
  4. After each pass, the largest element is at the end.
  5. Reduce comparison count by 1 each pass.
  6. Repeat until all passes complete.

Program 11: Bubble Sort (Ascending Order)

8086 Assembly Code
DATA SEGMENT ARR DW 50H, 10H, 40H, 20H, 30H ; 5 unsorted elements N DW 05H ; Number of elements DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX MOV DX, N DEC DX ; DX = n-1 = 4 (outer passes) OUTER: LEA SI, ARR ; SI → start of array MOV CX, DX ; CX = comparisons in this pass INNER: MOV AX, [SI] ; AX = current element CMP AX, [SI+2] ; Compare with next element JLE NOSWAP ; If current <= next, no swap ; Swap [SI] and [SI+2] MOV BX, [SI+2] MOV [SI], BX MOV [SI+2], AX NOSWAP: ADD SI, 02H ; Move to next pair LOOP INNER ; Repeat inner loop DEC DX ; One less pass needed JNZ OUTER ; If DX != 0, next pass MOV AH, 4CH INT 21H CODE ENDS END START ; Result: ARR = 10H, 20H, 30H, 40H, 50H (sorted ascending)

Evaluation of Arithmetic Expressions

Approach

Arithmetic expressions are evaluated by breaking them into individual operations, following operator precedence (multiply/divide first, then add/subtract), and using registers as temporary storage. For complex expressions, the intermediate results are stored in memory or stack.

Program 12: Evaluate Z = (A + B) × (C − D)

8086 Assembly Code
DATA SEGMENT A DW 000AH ; A = 10 B DW 0005H ; B = 5 C DW 000FH ; C = 15 D DW 0003H ; D = 3 Z DW ? DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX ; Step 1: Calculate (A + B) MOV AX, A ADD AX, B ; AX = A + B = 15 ; Step 2: Calculate (C - D) MOV BX, C SUB BX, D ; BX = C - D = 12 ; Step 3: Multiply (A+B) × (C-D) MUL BX ; DX:AX = AX × BX = 15 × 12 = 180 ; Step 4: Store result MOV Z, AX ; Z = 00B4H = 180 MOV AH, 4CH INT 21H CODE ENDS END START

Program 13: Evaluate Y = A² + B² (Sum of Squares)

8086 Assembly Code
DATA SEGMENT A DW 0004H ; A = 4 B DW 0003H ; B = 3 Y DW ? DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX MOV AX, A ; AX = 4 MUL AX ; DX:AX = 4 × 4 = 16 MOV BX, AX ; BX = A² = 16 MOV AX, B ; AX = 3 MUL AX ; DX:AX = 3 × 3 = 9 ADD AX, BX ; AX = 9 + 16 = 25 MOV Y, AX ; Y = 0019H = 25 MOV AH, 4CH INT 21H CODE ENDS END START

String Manipulation

String Instructions in 8086

The 8086 provides powerful string instructions that operate on sequences of bytes or words. They use specific register conventions:

  • SI → Source index (points to source string in DS segment)
  • DI → Destination index (points to destination in ES segment)
  • CX → Counter for REP prefix
  • DF (Direction Flag): 0 = auto-increment (CLD), 1 = auto-decrement (STD)

Program 14: Copy a String (Move String)

8086 Assembly Code
DATA SEGMENT SRC DB 'HELLO$' DST DB 6 DUP('$') ; Destination of same size DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA, ES:DATA START: MOV AX, DATA MOV DS, AX MOV ES, AX ; ES = DS (same segment) CLD ; DF=0, auto-increment SI/DI LEA SI, SRC ; SI → source string LEA DI, DST ; DI → destination string MOV CX, 06H ; CX = 6 bytes to copy REP MOVSB ; Copy CX bytes from DS:SI to ES:DI MOV AH, 4CH INT 21H CODE ENDS END START

Program 15: Search for a Character in String (SCASB)

8086 Assembly Code
DATA SEGMENT STR1 DB 'ASSEMBLY$' LEN DW 08H ; Length of string POS DW ? ; Position found DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA, ES:DATA START: MOV AX, DATA MOV DS, AX MOV ES, AX CLD ; Forward direction LEA DI, STR1 ; DI → string MOV CX, LEN ; CX = string length MOV AL, 'M' ; Character to search REPNE SCASB ; Scan until AL = ES:DI or CX=0 JNZ NOT_FOUND ; If ZF=0, not found ; Found: DI now points to byte AFTER match DEC DI LEA AX, STR1 SUB DI, AX ; DI = position (0-indexed) MOV POS, DI NOT_FOUND: MOV AH, 4CH INT 21H CODE ENDS END START

Assembler Directives

What Are Assembler Directives?

Assembler directives are instructions to the assembler (not to the CPU). They do not generate machine code but control how the assembler organizes the program, allocates memory, and defines constants. They are also called pseudo-operations.

DirectiveSyntaxDescriptionExample
DB name DB value Define Byte — allocates 1 byte NUM DB 25H
DW name DW value Define Word — allocates 2 bytes (16-bit) VAL DW 1234H
DD name DD value Define Double Word — allocates 4 bytes (32-bit) BIG DD 12345678H
DUP count DUP(value) Duplicate — repeat initial value count times ARR DB 10 DUP(0)
ASSUME ASSUME CS:seg, DS:seg Tells assembler which segment register maps to which segment ASSUME CS:CODE, DS:DATA
SEGMENT / ENDS name SEGMENT...ENDS Define a segment block DATA SEGMENT...DATA ENDS
END END label End of program. Label = starting execution point. END START
EQU name EQU value Define a constant (no memory allocated) MAX EQU 100
ORG ORG address Set origin — next byte at specified address ORG 100H
PROC / ENDP name PROC...ENDP Define a procedure (subroutine) ADD_NUM PROC NEAR...ENDP
DB vs DW — Key Difference

DB (Define Byte) allocates 1 byte per value. DW (Define Word) allocates 2 bytes per value. When traversing an array: for DB array, increment pointer by 1 (INC SI); for DW array, increment by 2 (ADD SI, 2).

Procedures & Macros

Procedures

A procedure (subroutine) is a reusable block of code defined between PROC and ENDP directives. Called using CALL, returns with RET.

  • NEAR Procedure: Caller and procedure in the same code segment. CALL pushes only IP. RET pops only IP.
  • FAR Procedure: Caller and procedure in different code segments. CALL pushes CS and IP. RETF pops both.
Procedure Syntax
MULTIPLY PROC NEAR MUL BX ; DX:AX = AX × BX RET MULTIPLY ENDP ; Calling: MOV AX, 05H MOV BX, 03H CALL MULTIPLY ; After: DX:AX = 15
Macros

A macro is a named block of code defined once and expanded in-place wherever it is invoked. Unlike a procedure, a macro is substituted (expanded) by the assembler at each call site — no CALL/RET overhead.

  • Defined using MACRO...ENDM.
  • Can accept parameters.
  • No stack overhead — faster than procedures.
  • Code is duplicated at each call site → larger executable.
Macro Syntax
; Macro definition ADD_TWO MACRO P1, P2 MOV AX, P1 ADD AX, P2 ENDM ; Macro invocation (usage) ADD_TWO NUM1, NUM2 ; Expands to: MOV AX, NUM1 / ADD AX, NUM2 ADD_TWO VAL1, VAL2 ; Expands again — separate copy

Syntax Reference & Key Rules

MOV Instruction Rules

MOV dst, src — copies src into dst. Restrictions:

  • Cannot MOV memory to memory directly: MOV [2000H], [3000H] ❌
  • Cannot MOV immediate to segment register: MOV DS, 1000H ❌ → use AX as bridge
  • Cannot MOV CS directly: CS is read-only in MOV.
  • Both operands must be same size (8-bit or 16-bit).
MUL / DIV Register Usage

8-bit MUL: MUL src8 → AX = AL × src8

16-bit MUL: MUL src16 → DX:AX = AX × src16

8-bit DIV: DIV src8 → AL = AX ÷ src8, AH = remainder

16-bit DIV: DIV src16 → AX = DX:AX ÷ src16, DX = remainder

LOOP Instruction

LOOP label → CX ← CX − 1; if CX ≠ 0, jump to label

LOOPE label → CX ← CX − 1; if CX ≠ 0 AND ZF = 1, jump

LOOPNE label → CX ← CX − 1; if CX ≠ 0 AND ZF = 0, jump

String Instruction Setup

Before any string operation:

1. CLD → clear DF (forward direction, SI/DI auto-increment)

2. LEA SI, source → SI points to source

3. LEA DI, dest → DI points to destination

4. MOV CX, count → set repeat count

5. REP MOVSB → execute string operation

Stack Operations

PUSH AX → SP ← SP − 2; [SS:SP] ← AX

POP AX → AX ← [SS:SP]; SP ← SP + 2

Stack grows downward (SP decrements on PUSH).

Last In First Out (LIFO) — last pushed is first popped.

Array Pointer Increment
DB array (bytes): ADD SI, 1 or INC SI
DW array (words): ADD SI, 2
Bubble Sort Passes
Number of passes = N − 1
Comparisons in pass i = N − i

Total comparisons = N(N−1)/2 in worst case.

Key Definitions

Assembler Directive

An instruction to the assembler (not to the CPU) that controls how the assembler processes the source code. Directives define memory segments, allocate storage, define constants, and mark the start/end of the program. They generate no machine code.

Procedure (Subroutine)

A named, reusable block of assembly code defined between PROC and ENDP directives. Invoked using the CALL instruction and returns using RET. The CPU automatically saves the return address (IP) on the stack during CALL.

Macro

A named block of assembly instructions defined using MACRO...ENDM directives. When invoked, the assembler replaces the macro call with the actual instructions in-place (inline expansion). Unlike procedures, macros have no CALL/RET overhead but produce duplicate code at each invocation.

DB (Define Byte)

An assembler directive that allocates one byte of memory per value and optionally initializes it. Used for 8-bit variables, character strings, and byte arrays.

DW (Define Word)

An assembler directive that allocates two bytes (one 16-bit word) of memory per value and optionally initializes it. Used for 16-bit variables, addresses, and word arrays.

ASSUME Directive

An assembler directive that informs the assembler which segment register is associated with which segment. It does not actually load segment registers — the programmer must initialize them with MOV instructions at runtime.

REP Prefix

A string instruction prefix that repeats the following string operation CX times, decrementing CX each time until CX = 0. REPE repeats while equal (ZF=1), REPNE repeats while not equal (ZF=0).

Bubble Sort

A simple sorting algorithm that repeatedly compares adjacent elements and swaps them if they are in wrong order. Requires N−1 passes for N elements. Time complexity O(N²) in worst case.

Multiple Choice Questions

Q 1

Which instruction is used for multi-precision addition where the carry from a previous addition must be included?

  • a. ADD
  • b. ADC
  • c. INC
  • d. SBB
Answer: b. ADC

ADC (Add with Carry) computes: dst ← dst + src + CF. It includes the carry flag from a previous ADD, making it essential for 32-bit or larger addition using 16-bit registers.

Q 2

What is the result of executing XOR AX, AX?

  • a. AX = FFFFH
  • b. AX = 0001H
  • c. AX = 0000H
  • d. AX is unchanged
Answer: c. AX = 0000H

XOR of any value with itself always gives 0. This is the most efficient way to clear a register — it is shorter and faster than MOV AX, 0 on 8086.

Q 3

Which assembler directive allocates 2 bytes of memory?

  • a. DB
  • b. DD
  • c. DW
  • d. DQ
Answer: c. DW

DW (Define Word) allocates 2 bytes (16 bits) per value. DB = 1 byte, DD = 4 bytes (double word), DQ = 8 bytes (quad word).

Q 4

In bubble sort with 5 elements, how many passes are needed to guarantee sorted order?

  • a. 5
  • b. 3
  • c. 4
  • d. 10
Answer: c. 4

Bubble sort requires N−1 passes for N elements. For N=5: 5−1=4 passes. Total comparisons in worst case = N(N−1)/2 = 10.

Q 5

The LOOP instruction in 8086 uses which register as the counter?

  • a. AX
  • b. BX
  • c. DX
  • d. CX
Answer: d. CX

LOOP automatically decrements CX and jumps to the label if CX ≠ 0. CX is the dedicated counter register of the 8086.

Q 6

Which string instruction copies a byte from DS:SI to ES:DI?

  • a. SCASB
  • b. CMPSB
  • c. MOVSB
  • d. STOSB
Answer: c. MOVSB

MOVSB (Move String Byte) copies one byte from DS:SI to ES:DI, then auto-increments or decrements both SI and DI based on the DF flag. Used with REP prefix for block copy.

Q 7

What does the ASSUME directive do in 8086 assembly?

  • a. Loads values into segment registers
  • b. Tells the assembler which segment register maps to which segment
  • c. Allocates memory for variables
  • d. Marks end of program
Answer: b. Tells the assembler which segment register maps to which segment

ASSUME is an assembler directive (not a CPU instruction) that tells the assembler how segments are mapped. The programmer must still initialize segment registers with MOV instructions at runtime.

Q 8

Which prefix repeats a string operation while CX ≠ 0 AND the zero flag is clear?

  • a. REP
  • b. REPE
  • c. REPNE
  • d. REPZ
Answer: c. REPNE

REPNE (Repeat while Not Equal) continues while CX ≠ 0 AND ZF = 0. Used with SCASB to scan for a character — stops when character is found (ZF=1) or CX reaches 0.

Q 9

After executing MUL BX where AX=0050H and BX=0003H, the result is stored in:

  • a. AX only
  • b. BX:AX
  • c. DX:AX
  • d. CX:AX
Answer: c. DX:AX

For 16-bit MUL: DX:AX = AX × src. Result = 0050H × 0003H = 00F0H. DX=0000H, AX=00F0H. The 32-bit result is split with high word in DX and low word in AX.

Q 10

What is the main advantage of a macro over a procedure?

  • a. Uses less memory
  • b. Can be recursive
  • c. No CALL/RET overhead — faster execution
  • d. Supports more parameters
Answer: c. No CALL/RET overhead — faster execution

Macros expand inline so there is no CALL/RET instruction overhead and no stack push/pop. This makes macros faster. The tradeoff is that code is duplicated at each invocation, using more memory.

Q 11

Which instruction is used to load the effective address (offset) of a memory variable into a register?

  • a. MOV BX, [VAR]
  • b. LEA BX, VAR
  • c. LDS BX, VAR
  • d. XCHG BX, VAR
Answer: b. LEA BX, VAR

LEA (Load Effective Address) loads the offset address of VAR into BX — not the data at VAR. MOV BX, [VAR] loads the actual data. LEA is used to set up pointer registers for memory access.

Q 12

The CLD instruction in 8086 is used to:

  • a. Clear the carry flag
  • b. Clear the direction flag to set forward string processing
  • c. Clear the zero flag
  • d. Clear all flags
Answer: b. Clear the direction flag to set forward string processing

CLD clears DF=0, causing string instructions (MOVSB, SCASB etc.) to auto-increment SI and DI after each operation (forward direction). STD sets DF=1 for backward direction.

Q 13

In a NEAR procedure call, which value is pushed onto the stack by CALL?

  • a. CS and IP
  • b. FLAGS only
  • c. IP only
  • d. CS, IP, and FLAGS
Answer: c. IP only

CALL NEAR pushes only the IP (return address — offset of next instruction) onto the stack. FAR CALL pushes CS then IP. INT pushes FLAGS, CS, then IP.

Q 14

What does ARR DB 5 DUP(0) do?

  • a. Defines a word array of 5 elements
  • b. Defines 5 bytes all initialized to 0
  • c. Defines 5 double words
  • d. Reserves 5 bytes without initialization
Answer: b. Defines 5 bytes all initialized to 0

DB 5 DUP(0) allocates 5 bytes, each initialized to 0. DUP is the duplicate operator. It creates repeated initial values. Total memory = 5 × 1 = 5 bytes.

Q 15

Which instruction compares two strings byte by byte and sets flags without modifying either string?

  • a. MOVSB
  • b. STOSB
  • c. LODSB
  • d. CMPSB
Answer: d. CMPSB

CMPSB (Compare String Byte) subtracts ES:DI from DS:SI and sets flags (ZF, CF, SF) but does not store the result. Used with REPE prefix to compare strings until a difference is found.

Short Answer Questions

Q 1

What is the difference between ADD and ADC instructions?

ADD dst, src: dst ← dst + src. Simple addition. Does not include carry flag. Used for first word of multi-precision addition.

ADC dst, src: dst ← dst + src + CF. Add with Carry — includes carry flag from previous ADD. Used for higher words in multi-precision (32-bit, 64-bit) addition on 16-bit processor.

Q 2

What is an assembler directive? Give two examples.

An assembler directive is an instruction to the assembler, not to the CPU. It controls how the assembler organizes and processes the source code. Directives do not produce machine code.

Examples: DB (Define Byte — allocates 1 byte of memory) and ASSUME (tells assembler which segment register maps to which segment).

Q 3

Why must ES be initialized before using string instructions like MOVSB?

String destination instructions (MOVSB, STOSB, CMPSB) use ES:DI as the destination segment:offset pair. The destination is always accessed via ES (Extra Segment). If ES is not initialized to point to the correct data segment, the destination write will go to the wrong memory location. Therefore ES must be explicitly loaded (usually MOV AX, DATA / MOV ES, AX) before string operations.

Q 4

What is the role of the CX register in the LOOP and REP instructions?

CX acts as the automatic counter in both instructions:

  • LOOP label: CX is decremented by 1; if CX ≠ 0, jump to label. When CX reaches 0, loop exits.
  • REP MOVSB: Repeats MOVSB, decrementing CX each time, until CX = 0.

Both use CX implicitly — programmer sets CX to the desired count before the loop/string instruction.

Q 5

How do you swap two memory words in 8086 assembly without using XCHG directly?

To swap [SI] and [SI+2] using registers:

MOV AX, [SI] ; AX = first element MOV BX, [SI+2] ; BX = second element MOV [SI], BX ; First ← second MOV [SI+2], AX ; Second ← first

This uses two registers as temporary storage to accomplish the swap without XCHG.

Q 6

What is the difference between MOVSB and STOSB?

MOVSB: Copies byte from DS:SI to ES:DI. Both SI and DI are updated (incremented/decremented). Used for block memory copy.

STOSB: Stores AL into ES:DI. Only DI is updated. SI is not used. Used for filling a memory block with a constant value (e.g., clearing memory with REP STOSB).

Q 7

Write a sequence of instructions to load DS with the value 2000H.

DS cannot be loaded directly with an immediate value. A register must be used as a bridge:

MOV AX, 2000H ; Load 2000H into AX first MOV DS, AX ; Then transfer AX to DS

This is required because 8086 does not allow direct immediate-to-segment-register transfers.

Q 8

What is the purpose of the END directive and the END START statement?

The END directive marks the physical end of the assembly source file. The assembler stops processing after this point.

END START additionally tells the assembler (and linker) that execution should begin at the label START. When the program is loaded, the IP is set to the address of START. Without the label, the linker does not know where to begin execution.

Q 1

Write a complete 8086 assembly program to implement bubble sort on an array of 5 words in ascending order. Trace the first pass on the array [50H, 10H, 40H, 20H, 30H].

Complete Bubble Sort Program
DATA SEGMENT ARR DW 50H, 10H, 40H, 20H, 30H N DW 05H DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX MOV DX, N DEC DX OUTER: LEA SI, ARR MOV CX, DX INNER: MOV AX, [SI] CMP AX, [SI+2] JLE NOSWAP MOV BX, [SI+2] MOV [SI], BX MOV [SI+2], AX NOSWAP: ADD SI, 02H LOOP INNER DEC DX JNZ OUTER MOV AH, 4CH INT 21H CODE ENDS END START
First Pass Trace on [50H, 10H, 40H, 20H, 30H]

Compare 50H, 10H: 50H > 10H → swap → [10H, 50H, 40H, 20H, 30H]

Compare 50H, 40H: 50H > 40H → swap → [10H, 40H, 50H, 20H, 30H]

Compare 50H, 20H: 50H > 20H → swap → [10H, 40H, 20H, 50H, 30H]

Compare 50H, 30H: 50H > 30H → swap → [10H, 40H, 20H, 30H, 50H]

After Pass 1: [10H, 40H, 20H, 30H, 50H] — largest element (50H) is in place.

Q 2

Write a complete 8086 assembly program to copy a string from source to destination using string instructions. Explain each instruction used.

String Copy Program
DATA SEGMENT SRC DB 'HELLO WORLD$' DST DB 12 DUP('$') DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA, ES:DATA START: MOV AX, DATA MOV DS, AX ; DS = source segment MOV ES, AX ; ES = destination segment CLD ; DF=0: forward (increment SI, DI) LEA SI, SRC ; SI → source string LEA DI, DST ; DI → destination string MOV CX, 12 ; CX = 12 bytes to copy REP MOVSB ; Copy CX bytes DS:SI→ES:DI MOV AH, 4CH INT 21H CODE ENDS END START
Instruction Explanation
  • MOV DS, AX / MOV ES, AX: Initialize segment registers. ES needed because MOVSB writes to ES:DI.
  • CLD: Clear Direction Flag → SI and DI auto-increment after each byte copied (forward direction).
  • LEA SI, SRC: Load offset address of SRC into SI. SI is the source pointer.
  • LEA DI, DST: Load offset address of DST into DI. DI is the destination pointer.
  • MOV CX, 12: Set counter to 12 (number of bytes to copy).
  • REP MOVSB: Repeats MOVSB 12 times. Each iteration: copies byte DS:SI→ES:DI, increments SI and DI, decrements CX. Stops when CX=0.

Q 3

Explain procedures and macros in 8086 assembly. Write a program using a procedure to find the factorial of a number.

Procedure: Reusable code block. Invoked with CALL, returns with RET. Single copy in memory. Stack used for return address.

Macro: Inline code expansion. Faster (no CALL overhead). Code duplicated at each use. Defined with MACRO...ENDM.

Factorial Using Procedure (Iterative)
DATA SEGMENT NUM DW 0005H ; Find 5! RESULT DW ? DATA ENDS CODE SEGMENT ASSUME CS:CODE, DS:DATA START: MOV AX, DATA MOV DS, AX MOV AX, NUM CALL FACT MOV RESULT, AX ; AX = 5! = 120 = 78H MOV AH, 4CH INT 21H ; Procedure: Compute factorial of AX ; Input: AX = n. Output: AX = n! FACT PROC NEAR MOV CX, AX MOV AX, 0001H ; AX = 1 (result) MULT_LOOP: MUL CX ; AX = AX × CX DEC CX JNZ MULT_LOOP ; Repeat until CX=0 RET FACT ENDP CODE ENDS END START ; 5! = 5×4×3×2×1 = 120 = 0078H

Revision & Quick Summary

Quick Revision Points
  • Every 8086 program: DATA SEGMENT...DATA ENDS, CODE SEGMENT...CODE ENDS, ASSUME CS:CODE, DS:DATA, initialize DS at start, end with INT 21H (AH=4CH).
  • DS cannot be loaded with immediate: use MOV AX, DATA / MOV DS, AX.
  • ADD = simple add. ADC = add with carry (for multi-precision). SUB = subtract. SBB = subtract with borrow.
  • AND = mask/clear bits. OR = set bits. XOR = toggle bits. XOR AX,AX = clear AX.
  • CMP sets flags but does NOT store result. Used before conditional jumps.
  • TEST = AND without storing. Used to check specific bits.
  • JGE = jump if greater or equal (signed). JLE = jump if less or equal. JA/JB = unsigned above/below.
  • LOOP = decrement CX, jump if CX≠0. Must initialize CX before loop.
  • Bubble sort: N−1 passes, each pass uses LOOP and CMP + swap.
  • For DW arrays: increment pointer by 2 (ADD SI, 2). For DB arrays: by 1 (INC SI).
  • MUL BX (16-bit): result in DX:AX. DIV BX: quotient in AX, remainder in DX. Clear DX=0 before DIV.
  • String instructions use: SI=source (DS:SI), DI=destination (ES:DI), CX=count.
  • CLD = clear DF → auto-increment SI/DI (forward). STD = set DF → auto-decrement (backward).
  • MOVSB=copy byte, STOSB=store AL, CMPSB=compare bytes, SCASB=scan for AL.
  • REP = repeat CX times. REPE = while equal (ZF=1). REPNE = while not equal (ZF=0).
  • DB=1 byte, DW=2 bytes, DD=4 bytes. DUP = repeat.
  • ASSUME = assembler directive (not CPU instruction) — does not load registers.
  • EQU = constant, no memory. ORG = set current address.
  • PROC NEAR: CALL pushes IP only. PROC FAR: CALL pushes CS then IP.
  • Macro = inline expansion (faster, more code). Procedure = CALL/RET (slower, less code).
  • To reverse string: push all chars onto stack, pop into destination.
  • Terminate DOS program: MOV AH, 4CH / INT 21H.
Must Remember for Exam
  • Bubble sort passes = N − 1. Total worst-case comparisons = N(N−1)/2.
  • 16-bit MUL result: DX:AX. Always clear DX=0 before 16-bit DIV.
  • String ops: SI=source in DS, DI=destination in ES. ES must be initialized.
  • CLD before string copy (forward). REPNE SCASB to search for character.
  • ASSUME is for assembler only — does NOT load segment registers.
  • Macro: MACRO...ENDM. Procedure: PROC...ENDP.
  • Program termination: MOV AH, 4CH / INT 21H.
  • XOR reg, reg = fastest way to clear a register to 0.
Common Mistakes to Avoid
  • ❌ MOV DS, 1000H — cannot load segment register directly with immediate. Use MOV AX, 1000H / MOV DS, AX.
  • ❌ Forgetting to initialize ES before using MOVSB/STOSB — MOVSB writes to ES:DI.
  • ❌ Using ADD SI, 1 for DW array — must use ADD SI, 2 for word arrays.
  • ❌ Forgetting XOR DX, DX before DIV — DX must be 0 for correct 16-bit division.
  • ❌ Confusing MOVSB (copy DS:SI→ES:DI) with STOSB (store AL→ES:DI, SI not used).
  • ❌ Confusing REPE (repeat while ZF=1) with REPNE (repeat while ZF=0).
  • ❌ Saying ASSUME loads segment registers — it only informs the assembler.
  • ❌ Forgetting that LOOP uses CX exclusively — do not use CX for other purposes inside loop.
  • ❌ Confusing CMP and SUB — CMP does not modify operands, SUB stores result in destination.
  • ❌ Bubble sort: outer loop count = N−1, not N. Using N causes one unnecessary pass.
