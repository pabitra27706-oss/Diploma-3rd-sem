Microprogrammed Control

What is a Control Unit?

The Control Unit (CU) is the part of the CPU that directs the operation of all other units. It generates control signals that activate specific hardware components at the right time to execute each instruction. There are two ways to implement a control unit:

  • Hardwired Control: Logic circuits are directly wired to produce control signals. Fast but inflexible.
  • Microprogrammed Control: Control signals are generated by executing micro-instructions stored in a special memory called Control Memory.
Control Memory

Control memory (also called control store or microprogram memory) is a special read-only memory inside the CPU that stores micro-instructions. Each micro-instruction specifies the control signals to be activated during one clock cycle.

  • Micro-instruction: A binary word stored in control memory. Each bit (or field) corresponds to a control signal or a group of control signals.
  • Microprogram: A sequence of micro-instructions that together implement one machine instruction.
  • Control Address Register (CAR): Holds the address of the next micro-instruction to be fetched from control memory.
  • Control Data Register (CDR): Holds the micro-instruction fetched from control memory.
  • Subroutine Register (SBR): Stores return address during micro-subroutine calls.
Control Memory vs Main Memory

Control memory is much faster (typically ROM or fast RAM inside the CPU), much smaller (holds only microprogram), and is accessed by the control unit — not by the programmer. Main memory is accessed by user programs.

Address Sequencing

Address sequencing refers to how the next micro-instruction address is determined. The Control Address Register (CAR) must be updated after each micro-instruction. There are four ways:

Methods of Address Sequencing
  1. Incrementing CAR: CAR ← CAR + 1. Sequential execution of micro-instructions, similar to PC increment.
  2. Unconditional Branch: A branch address field in the micro-instruction directly specifies the next CAR value.
  3. Conditional Branch: Next address depends on a status bit (carry, zero, overflow). If condition true, branch; else increment.
  4. Mapping from Instruction: The opcode of the machine instruction is mapped (through a mapping ROM or logic) to the starting address of its corresponding microprogram in control memory.

Micro-instruction Formats

There are two main formats for encoding control information in a micro-instruction:

  • Horizontal Micro-instruction: Each bit directly controls one microoperation. Wide word (many bits). Allows parallel micro-operations. Less encoding, faster execution.
  • Vertical Micro-instruction: Encoded fields — a decoder converts the field to control signals. Narrow word (fewer bits). Only one or few micro-operations per cycle. More encoding, slower.
Exam Point

Horizontal micro-instructions are wider (more bits) but faster. Vertical micro-instructions are narrower (fewer bits, encoded) but slower. CISC CPUs like Intel x86 use microprogrammed control internally.

Computer Arithmetic

Addition & Subtraction Using 2's Complement

Modern computers perform both addition and subtraction using 2's complement representation, which allows subtraction to be done using an adder circuit.

2's Complement Subtraction Rule

A − B = A + (2's complement of B) = A + B̄ + 1

  1. Find 2's complement of B (invert all bits, add 1).
  2. Add A and (2's complement of B) using binary addition.
  3. If there is a carry out of MSB, discard it (for unsigned). For signed, check overflow.
  4. The result is in 2's complement if negative.
Overflow Detection
Overflow = Cn XOR Cn-1

where Cₙ = carry out of MSB, Cₙ₋₁ = carry into MSB. Overflow occurs when signs of both operands are same but result sign differs.

Example: 7 − 3 using 8-bit 2's complement

A = 7 = 00000111

B = 3 = 00000011 → 2's comp of B = 11111101

A + (−B):   00000111 + 11111101

              1 00000100 → Carry discarded

Result = 00000100 = +4 ✅

Booth's Multiplication Algorithm

Booth's algorithm multiplies two signed binary numbers in 2's complement form. It reduces the number of additions required by examining pairs of bits in the multiplier.

Booth's Algorithm Steps
  1. Initialize: A = 0 (Accumulator), Q = Multiplier, M = Multiplicand, Q₋₁ = 0, count = n (number of bits).
  2. Examine the last bit of Q (Q₀) and Q₋₁:
    • If Q₀ Q₋₁ = 10: A ← A − M (subtract multiplicand)
    • If Q₀ Q₋₁ = 01: A ← A + M (add multiplicand)
    • If Q₀ Q₋₁ = 00 or 11: No operation
  3. Arithmetic right shift the combined register [A, Q, Q₋₁] by 1 bit.
  4. Decrement count by 1.
  5. If count ≠ 0, go to step 2. Else stop.
  6. Result = [A, Q] (combined 2n-bit product).
Booth's Example: Multiply (+3) × (−2) using 4-bit

M = +3 = 0011, Q = −2 = 1110, −M = 1101, A = 0000, Q₋₁ = 0, Count = 4

Why Booth's Algorithm?
  • Works correctly for both positive and negative multipliers in 2's complement.
  • Reduces number of additions when the multiplier has runs of 1s (consecutive 1s require only 1 add and 1 subtract instead of multiple additions).
  • Efficient for hardware implementation.
Restoring Division Algorithm

Restoring division performs binary division by repeatedly shifting and subtracting the divisor. It is called "restoring" because if the subtraction result is negative, the divisor is added back (restored) to the partial remainder.

Restoring Division Steps
  1. Initialize: A (Accumulator) = 0, Q = Dividend, M = Divisor, Count = n.
  2. Left shift [A, Q] by 1 bit.
  3. A ← A − M (subtract divisor from A).
  4. If A ≥ 0 (MSB of A = 0): Set Q₀ = 1 (quotient bit = 1). Partial remainder is valid.
  5. If A < 0 (MSB of A = 1): Set Q₀ = 0 (quotient bit = 0). Restore: A ← A + M.
  6. Decrement count. If count ≠ 0, go to step 2.
  7. Quotient = Q. Remainder = A.
Non-Restoring Division Algorithm

Non-restoring division avoids the restore step. Instead of restoring when result is negative, it directly adds or subtracts in the next step based on the sign of the current partial remainder. This makes it faster than restoring division.

Non-Restoring Division Steps
  1. Initialize: A = 0, Q = Dividend, M = Divisor, Count = n.
  2. Left shift [A, Q] by 1.
  3. If A is positive (MSB = 0): A ← A − M, set Q₀ = 1.
  4. If A is negative (MSB = 1): A ← A + M, set Q₀ = 0.
  5. Decrement count. If count ≠ 0, go to step 2.
  6. If final A is negative, restore: A ← A + M.
  7. Quotient = Q, Remainder = A.

Floating-Point Arithmetic Operations

Floating-point arithmetic is more complex than integer arithmetic because the exponents must be aligned before operations and the result must be normalized afterward.

Floating-Point Addition / Subtraction Steps
  1. Check for zeros: If either operand is zero, return the other operand.
  2. Align exponents: Find the difference of exponents. Shift the mantissa of the smaller exponent right by the difference. Update its exponent to match the larger.
  3. Add or subtract mantissas: Perform addition or subtraction on the aligned mantissas.
  4. Normalize result: Adjust mantissa and exponent so the result is in normalized form (leading 1 before binary point for IEEE 754).
  5. Round: Apply rounding to fit within the mantissa bit width.
  6. Check for overflow/underflow: Verify exponent is within valid range.
Floating-Point Multiplication Steps
  1. Multiply the mantissas.
  2. Add the exponents: E_result = E₁ + E₂ − Bias.
  3. Determine sign: XOR of the two sign bits.
  4. Normalize and round the result.
Floating-Point Division Steps
  1. Divide the mantissas.
  2. Subtract the exponents: E_result = E₁ − E₂ + Bias.
  3. Determine sign: XOR of the two sign bits.
  4. Normalize and round the result.
Special Cases in Floating-Point
  • Overflow: Exponent exceeds maximum value → ±Infinity result.
  • Underflow: Exponent below minimum value → result becomes denormalized or zero.
  • NaN (Not a Number): Result of 0/0, ∞/∞, or similar undefined operations.
  • Catastrophic Cancellation: Subtracting two nearly equal numbers causes significant loss of precision.

Pipelining

What is Pipelining?

Pipelining is a technique of implementing instruction-level parallelism by overlapping the execution of multiple instructions. Like an assembly line in a factory, different stages of different instructions are processed simultaneously. Each stage handles one part of instruction processing.

Pipeline Speedup
Speedup = n × k / (k + n − 1)

n = number of instructions, k = number of pipeline stages. As n→∞, Speedup → k (ideal speedup = number of stages).

Pipeline Throughput & Efficiency
Throughput = n / (k + n − 1) × Tclk
Efficiency = Speedup / k

Pipeline Hazards

Hazards are situations that prevent the next instruction from executing in its designated clock cycle:

  • Structural Hazard: Hardware resource conflict — two instructions need the same hardware unit simultaneously.
  • Data Hazard: Instruction depends on result of a previous instruction still in the pipeline (RAW — Read After Write is most common).
  • Control Hazard (Branch Hazard): Branch instruction changes PC — the instructions already fetched may be wrong.

Solutions:

  • Stalling (Bubbles): Insert NOP cycles to wait for data.
  • Forwarding (Bypassing): Route result directly from EX stage to next instruction without waiting for WB.
  • Branch Prediction: Predict branch direction and speculatively execute instructions.
  • Delayed Branching: Execute one instruction after branch regardless (RISC technique).
RISC Pipeline

RISC (Reduced Instruction Set Computer) processors are specifically designed to be pipelined efficiently. Key features that enable clean pipelining:

  • Fixed instruction length: All instructions are the same size (e.g., 32 bits), making IF stage uniform.
  • Load-Store architecture: Only LOAD and STORE access memory. All arithmetic uses registers, eliminating memory-EX hazards.
  • Simple addressing modes: Reduces decode complexity.
  • Large register file: Reduces memory accesses, keeping data in registers.
  • Hardwired control: No microprogram lookup — faster decode.

Vector Processing & Array Processors

Vector Processing (SIMD)

Vector processing performs the same operation on multiple data elements simultaneously. This is also called SIMD — Single Instruction Multiple Data.

  • Vector: A one-dimensional array of numbers (e.g., [1, 2, 3, 4]).
  • Vector Instruction: A single instruction that operates on all elements of a vector at once.
  • Vector Registers: Special wide registers that hold multiple data elements (e.g., 128-bit register holds four 32-bit floats).
  • Example: Instead of adding 8 pairs of numbers with 8 ADD instructions, a vector ADD instruction adds all 8 pairs in one instruction.
Vector Operation Example
C[i] = A[i] + B[i]   for i = 0 to n−1

Scalar: n ADD instructions. Vector: 1 VADD instruction processes all n elements.

Real-World Examples

Intel SSE/AVX instructions, ARM NEON, GPU shader cores — all use SIMD/vector processing. Used heavily in graphics, scientific simulation, machine learning.

Array Processors

An array processor consists of multiple processing elements (PEs) that operate in parallel under the control of a single control unit. All PEs execute the same instruction simultaneously but on different data.

  • SIMD Architecture: Single Instruction, Multiple Data — all PEs get the same instruction, different data.
  • Interconnection Network: PEs are connected through a network that allows data sharing.
  • Master Control Unit: Broadcasts instructions to all PEs. Handles branching and I/O.
  • Applications: Matrix operations, image processing, weather simulation, neural networks.

Key Definitions

Microprogrammed Control

A method of implementing the control unit where each machine instruction is executed by a sequence of micro-instructions stored in a special control memory. The control signals are generated by reading these micro-instructions.

Micro-instruction

A binary word stored in control memory that specifies a set of micro-operations to be performed during one clock cycle. It contains control signal bits, a next address field, and possibly a condition field.

Booth's Algorithm

A signed binary multiplication algorithm that examines pairs of consecutive bits in the multiplier to determine whether to add, subtract, or do nothing, reducing the number of partial product additions required.

Pipelining

A technique for implementing instruction-level parallelism by dividing instruction processing into stages and overlapping the execution of multiple instructions such that different instructions occupy different stages simultaneously.

Pipeline Hazard

A condition that prevents the next instruction in the pipeline from executing in its designated clock cycle. Types: structural hazard (resource conflict), data hazard (data dependency), and control hazard (branch).

SIMD (Single Instruction Multiple Data)

A parallel computing model where a single instruction operates on multiple data elements simultaneously. Used in vector processors and GPU architectures for data-parallel computations.

Restoring Division

A binary division algorithm where if the partial remainder becomes negative after subtraction of the divisor, the divisor is added back (restored) to the partial remainder and a quotient bit of 0 is recorded.

Control Memory (Microprogram Store)

A high-speed memory (typically ROM) inside the CPU that stores the microprograms. Each address in control memory contains one micro-instruction that specifies operations for one clock cycle.

Multiple Choice Questions

Q 1

In Booth's algorithm, if the current bit Q₀ and previous bit Q₋₁ are 1 and 0 respectively (Q₀Q₋₁ = 10), what operation is performed?

  • a. Add multiplicand to accumulator
  • b. Subtract multiplicand from accumulator
  • c. No operation
  • d. Shift only
Answer: b. Subtract multiplicand from accumulator

In Booth's algorithm: Q₀Q₋₁ = 10 → A ← A − M. Q₀Q₋₁ = 01 → A ← A + M. 00 or 11 → no operation.

Q 2

Which type of control unit is used in RISC processors?

  • a. Microprogrammed control
  • b. Hardwired control
  • c. Stored program control
  • d. ROM-based control
Answer: b. Hardwired control

RISC processors use hardwired control because they have simple, fixed-length instructions. Hardwired control is faster and suits RISC's streamlined design. CISC uses microprogrammed control.

Q 3

In a 4-stage pipeline, 10 instructions are to be executed. What is the total number of clock cycles needed?

  • a. 40
  • b. 10
  • c. 13
  • d. 14
Answer: c. 13

Using formula: k + n − 1 = 4 + 10 − 1 = 13 clock cycles. Without pipeline: 4 × 10 = 40 cycles. Speedup = 40/13 ≈ 3.07.

Q 4

Which hazard occurs when two instructions need the same hardware resource at the same time in a pipeline?

  • a. Data hazard
  • b. Control hazard
  • c. Structural hazard
  • d. Branch hazard
Answer: c. Structural hazard

Structural hazard = resource conflict. Two instructions need the same hardware simultaneously (e.g., one memory for both instruction fetch and data access). Solved by adding separate instruction and data caches.

Q 5

In restoring division, what happens when the partial remainder becomes negative after subtraction?

  • a. Quotient bit set to 1
  • b. Division terminates
  • c. Divisor is subtracted again
  • d. Divisor is added back and quotient bit set to 0
Answer: d. Divisor is added back and quotient bit set to 0

In restoring division, a negative partial remainder means the divisor was too large. The divisor is restored (added back), quotient bit = 0, and the process continues.

Q 6

What is the primary advantage of microprogrammed control over hardwired control?

  • a. Faster execution speed
  • b. Less hardware required
  • c. Easier to modify and implement complex instructions
  • d. Smaller control memory needed
Answer: c. Easier to modify and implement complex instructions

Microprogrammed control stores micro-instructions in ROM. Adding new instructions only requires updating the microprogram, not redesigning hardware. This makes complex ISAs (like x86) much easier to implement.

Q 7

SIMD stands for:

  • a. Single Instruction Multiple Data
  • b. Single Instruction Multiple Devices
  • c. Sequential Instruction Multiple Data
  • d. Simultaneous Instruction Memory Data
Answer: a. Single Instruction Multiple Data

SIMD is the parallelism model used in vector processors and GPUs where one instruction performs the same operation on multiple data elements simultaneously.

Q 8

In floating-point multiplication, the result exponent is computed as:

  • a. E₁ − E₂ + Bias
  • b. E₁ + E₂ + Bias
  • c. E₁ + E₂ − Bias
  • d. E₁ × E₂ − Bias
Answer: c. E₁ + E₂ − Bias

For FP multiplication: E_result = E₁ + E₂ − Bias (subtract bias once because both stored exponents already include it). For division: E_result = E₁ − E₂ + Bias.

Q 9

Which technique routes the ALU result directly to the next instruction's input without waiting for the write-back stage?

  • a. Branch prediction
  • b. Stalling
  • c. Operand forwarding (bypassing)
  • d. Delayed branching
Answer: c. Operand forwarding (bypassing)

Forwarding (bypassing) solves data hazards by providing the computed result directly from the EX stage output to the next instruction's EX stage input, bypassing the register file write-back.

Q 10

In Booth's algorithm, what is the initial value of Q₋₁?

  • a. 1
  • b. Same as MSB of multiplier
  • c. 0
  • d. Same as LSB of multiplier
Answer: c. 0

In Booth's algorithm initialization: Accumulator A = 0, Q = multiplier, Q₋₁ = 0 (initially zero, as there is no previous bit before the LSB of Q).

Q 11

The speedup of an ideal k-stage pipeline with very large number of instructions approaches:

  • a. 1
  • b. n (number of instructions)
  • c. k (number of stages)
  • d. k × n
Answer: c. k (number of stages)

As n→∞, Speedup = n×k/(k+n−1) → k. The maximum theoretical speedup of a pipeline equals the number of stages. In practice, hazards reduce this.

Q 12

Which of the following is NOT a feature of RISC architecture?

  • a. Fixed instruction length
  • b. Load-Store architecture
  • c. Microprogrammed control unit
  • d. Large register file
Answer: c. Microprogrammed control unit

RISC uses hardwired control (not microprogrammed). Microprogrammed control is a feature of CISC processors. RISC has fixed instruction length, load-store architecture, and large register files.

Q 13

In floating-point addition, before adding the mantissas, what must be done first?

  • a. Multiply the mantissas
  • b. Align the exponents
  • c. Normalize the result
  • d. Find the sign of the result
Answer: b. Align the exponents

Before adding or subtracting floating-point mantissas, exponents must be equalized. The mantissa of the smaller exponent is right-shifted until both exponents match.

Q 14

The register that holds the address of the next micro-instruction in microprogrammed control is called:

  • a. Program Counter
  • b. Instruction Register
  • c. Control Address Register (CAR)
  • d. Memory Address Register
Answer: c. Control Address Register (CAR)

CAR (Control Address Register) in microprogrammed control is analogous to the PC in normal instruction execution. It holds the address of the next micro-instruction to be fetched from control memory.

Q 15

A control hazard in a pipeline is caused by:

  • a. Two instructions needing the same register
  • b. Memory latency
  • c. Branch instructions changing the program counter
  • d. ALU overflow
Answer: c. Branch instructions changing the program counter

Control hazards occur because branch instructions change the PC, making already-fetched instructions (after the branch) potentially wrong. Solved by branch prediction, delayed branching, or flushing the pipeline.

Short Answer Questions

Q 1

What is control memory and what does it store?

Control memory is a high-speed ROM inside the CPU used in microprogrammed control units. It stores micro-instructions — binary words where each bit or field represents a control signal or group of signals that activate specific hardware operations during one clock cycle.

Q 2

State the four rules of Booth's algorithm for deciding the operation based on Q₀ and Q₋₁.

Booth's algorithm rules based on Q₀Q₋₁:

  • 00: No operation (shift only)
  • 01: A ← A + M (add multiplicand)
  • 10: A ← A − M (subtract multiplicand)
  • 11: No operation (shift only)

After each step, arithmetic right shift [A, Q, Q₋₁] by 1 bit.

Q 3

What is a pipeline hazard? Name its three types.

A pipeline hazard is a condition that prevents the next instruction from executing in its designated clock cycle, causing a pipeline stall. Three types:

  • Structural Hazard: Resource conflict between two instructions.
  • Data Hazard: Instruction depends on result of a previous instruction still in pipeline.
  • Control Hazard: Branch instruction causes uncertainty about next instruction to fetch.

Q 4

What is the difference between horizontal and vertical micro-instructions?

Horizontal micro-instruction: Each bit directly controls one micro-operation. Wide word, allows parallel operations, less encoding overhead, faster. Used when speed is priority.

Vertical micro-instruction: Encoded fields — a decoder converts to control signals. Narrower word, one or few operations per cycle, more encoding. Saves control memory space but slower.

Q 5

What is operand forwarding and which hazard does it solve?

Operand forwarding (bypassing) is a technique that routes the result of an ALU operation directly from the output of the Execute stage to the input of the next instruction's Execute stage, without waiting for the result to be written back to the register file. It solves RAW (Read After Write) data hazards in pipelines.

Q 6

Why is RISC architecture more suitable for pipelining than CISC?

RISC is more pipeline-friendly because: (1) Fixed-length instructions make IF stage uniform. (2) Load-Store architecture eliminates memory hazards in EX stage. (3) Simple addressing modes speed up decode. (4) Hardwired control is faster than microprogram lookup. (5) Large register files keep data available without memory access.

Q 7

What is vector processing? Give one real-world application.

Vector processing performs the same operation on multiple data elements simultaneously using a single instruction (SIMD — Single Instruction Multiple Data). Instead of using a loop with scalar operations, one vector instruction processes all elements at once. Real-world application: 3D graphics rendering — GPU cores process thousands of pixel color values simultaneously using vector/SIMD operations.

Q 8

What is the difference between arithmetic pipeline and instruction pipeline?

Arithmetic pipeline breaks a complex arithmetic operation (like floating-point addition) into stages so multiple arithmetic operations can overlap. The stages are parts of the computation (e.g., align exponents → add mantissas → normalize).

Instruction pipeline overlaps the fetch, decode, and execute stages of multiple different instructions. The stages are parts of the instruction execution process (IF → ID → EX → WB).

Q 9

What are the steps in floating-point addition?

Steps in floating-point addition:

  1. Check for zero operands.
  2. Align exponents (shift mantissa of smaller exponent right).
  3. Add or subtract the mantissas.
  4. Normalize the result.
  5. Round to fit mantissa precision.
  6. Check for exponent overflow/underflow.

Q 10

What is address sequencing in microprogrammed control?

Address sequencing is the process of determining the address of the next micro-instruction to execute in the control memory. Methods include: (1) Incrementing the CAR by 1 for sequential execution, (2) Unconditional branching using address field, (3) Conditional branching based on status flags, and (4) Mapping from the opcode of a machine instruction to the start address of its microprogram.

Long Answer Questions

Q 1

Explain Booth's multiplication algorithm with a complete example. Multiply (−5) × (+3) using 4-bit 2's complement representation.

Q 2

Explain microprogrammed control unit with a neat diagram description. Compare horizontal and vertical micro-instructions with examples.

Microprogrammed Control Unit Structure:

  • Control Memory: ROM that stores all microprograms. Each address contains one micro-instruction.
  • Control Address Register (CAR): Points to the current micro-instruction address in control memory.
  • Micro-instruction Register (MIR/CDR): Holds the micro-instruction fetched from control memory.
  • Sequencer: Determines the next CAR value (increment, branch, or map from opcode).
  • Subroutine Register (SBR): Saves return address during micro-subroutine calls.
Microprogrammed Control Operation
  1. Machine instruction fetched → opcode extracted.
  2. Opcode mapped to starting address in control memory (via mapping ROM).
  3. CAR loaded with this start address.
  4. Micro-instruction fetched from control memory into CDR.
  5. CDR activates control signals → performs micro-operations.
  6. Sequencer computes next CAR. Go to step 4 until microprogram complete.

WidthWide (one bit per signal)Narrow (encoded fields)
DecodingNone neededDecoder required
ParallelismHigh (many ops at once)Low (one op per cycle)
Control memory sizeLargeSmall
SpeedFasterSlower

Q 3

Calculate the speedup, efficiency, and total execution time with and without a 5-stage pipeline for 100 instructions. Each stage takes 10 ns.

Given: k = 5 stages, n = 100 instructions, t = 10 ns per stage.

Without Pipeline
T_seq = n × k × t = 100 × 5 × 10 = 5000 ns
With Pipeline
T_pipe = (k + n − 1) × t = (5 + 100 − 1) × 10 = 104 × 10 = 1040 ns
Speedup
Speedup = T_seq / T_pipe = 5000 / 1040 ≈ 4.81

Or using formula: n×k/(k+n−1) = 500/104 ≈ 4.81

Efficiency
Efficiency = Speedup / k = 4.81 / 5 = 0.962 = 96.2%

The pipeline achieves 96.2% efficiency, very close to the ideal 100% because n >> k.

Q 4

Explain pipeline hazards in detail. What is a RAW hazard and how does forwarding solve it? Give an example.

Pipeline Hazards prevent ideal pipeline execution. Three types:

  • Structural: Resource conflict — two instructions need same unit. Solution: Duplicate hardware (separate I-cache and D-cache).
  • Data: Dependency between instructions. Three sub-types: RAW (Read After Write), WAR (Write After Read), WAW (Write After Write). RAW is most critical.
  • Control: Branch changes PC. Solution: Branch prediction, delayed branching.
RAW Hazard Example

I1: ADD R1, R2, R3    (R1 ← R2 + R3)

I2: SUB R4, R1, R5    (R4 ← R1 − R5) ← needs R1 from I1!

Without forwarding: I2 must wait until I1 completes WB (2 stall cycles needed).

With Forwarding: After I1 completes EX stage, R1 result is sent directly to I2's EX stage input. No stall needed. I2 uses the value immediately from the pipeline register, not the register file.

Load-Use Hazard

Even with forwarding, a LOAD followed immediately by an instruction using the loaded value requires 1 stall cycle because the loaded value is only available after the MEM stage, which is too late for the next instruction's EX stage.

Q 5

Identify and classify the hazard in the following instruction sequence in a 5-stage pipeline. Suggest a solution.

I1: LOAD R1, [100]
I2: ADD R2, R1, R3
I3: SUB R4, R2, R5

Hazard Analysis:

  • I1 → I2: LOAD-USE hazard (a data hazard). I2 needs R1 which is loaded by I1. LOAD's result is available after MEM stage — too late for I2's EX stage even with forwarding. Requires 1 stall cycle.
  • I2 → I3: RAW data hazard. I3 needs R2 computed by I2. With forwarding, this can be resolved without stalling (EX→EX forwarding works).
Solutions
  • For LOAD-USE (I1→I2): Insert 1 NOP (stall/bubble) between I1 and I2. Or compiler reorders instructions (move an independent instruction between LOAD and ADD).
  • For I2→I3 RAW: Operand forwarding resolves this with no stall.

Revision & Quick Summary

Quick Revision Points
  • Hardwired control: Logic gates, fast, rigid. Used in RISC.
  • Microprogrammed control: Control memory stores micro-instructions. Flexible. Used in CISC (x86).
  • CAR (Control Address Register) = address of current micro-instruction. Like PC but for microprograms.
  • Address sequencing: 4 methods — increment, unconditional branch, conditional branch, opcode mapping.
  • Horizontal micro-instruction: Wide word, direct control bits, parallel, no decode needed, fast.
  • Vertical micro-instruction: Narrow word, encoded, needs decoder, serial, slower.
  • 2's complement subtraction: A − B = A + B̄ + 1 (add 2's complement of B).
  • Overflow detection: V = Cₙ ⊕ Cₙ₋₁ (carry out XOR carry into MSB).
  • Booth's algorithm: Signed multiplication. Q₀Q₋₁=10 → subtract M. 01 → add M. 00/11 → nothing. Then arithmetic right shift. Repeat n times.
  • Restoring division: Subtract M. If negative, restore (add M back), Q₀=0. If positive, Q₀=1. Repeat n times.
  • Non-restoring division: No restore. If A positive → subtract M next. If A negative → add M next. Faster.
  • Floating-point addition: Align exponents → add mantissas → normalize → round.
  • FP multiplication exponent: E₁ + E₂ − Bias. Division: E₁ − E₂ + Bias.
  • Pipeline speedup formula: n×k / (k+n−1). Approaches k as n→∞.
  • Pipeline efficiency: Speedup / k.
  • Three hazard types: Structural (resource conflict), Data (RAW/WAR/WAW), Control (branch).
  • RAW hazard solution: Forwarding (bypassing). Load-use hazard needs 1 stall even with forwarding.
  • RISC pipeline: 5 stages (IF, RD, ALU, MEM, WB). Fixed instruction length, load-store architecture.
  • SIMD / Vector processing: One instruction operates on multiple data elements. Example: Intel AVX, GPU.
  • Array processor: Multiple PEs with one control unit. SIMD architecture. Used in matrix operations.
Must Remember for Exam
  • Booth's rules: 10 → subtract, 01 → add, 00/11 → nothing + arithmetic right shift each step.
  • Pipeline clock cycles with pipeline = k + n − 1. Without = n × k.
  • Ideal speedup of k-stage pipeline with n→∞ instructions = k.
  • RISC → Hardwired control. CISC → Microprogrammed control.
  • Restoring division restores when negative. Non-restoring does NOT restore.
  • FP addition must align exponents first before adding mantissas.
  • Forwarding solves RAW hazards. Load-use still needs 1 stall cycle.
  • CAR in microprogrammed control ≡ PC in normal execution.
  • Horizontal micro-instruction: wide, fast, parallel. Vertical: narrow, encoded, slower.
  • Overflow V = Cₙ ⊕ Cₙ₋₁ — this formula is frequently asked.
Common Mistakes to Avoid
  • ❌ In Booth's algorithm, forgetting that Q₋₁ starts at 0, not Q's LSB.
  • ❌ Confusing arithmetic right shift with logical right shift — Booth's uses arithmetic right shift (sign bit replicated).
  • ❌ Using n × k for pipelined execution — correct formula is (k + n − 1) × t.
  • ❌ Forgetting to subtract Bias in FP multiplication exponent: E₁ + E₂ − Bias (not just E₁ + E₂).
  • ❌ Confusing restoring and non-restoring division — restoring adds M back when negative; non-restoring does NOT restore.
  • ❌ Thinking forwarding eliminates ALL data hazards — Load-Use hazard still needs 1 stall even with forwarding.
  • ❌ Confusing control hazard (branch) with data hazard (dependency) — they have different causes and solutions.
  • ❌ In floating-point addition, forgetting to normalize the result after adding mantissas.
  • ❌ Confusing CAR with PC — CAR addresses control memory, PC addresses main memory.
  • ❌ Saying RISC uses microprogrammed control — RISC uses hardwired control for speed.
