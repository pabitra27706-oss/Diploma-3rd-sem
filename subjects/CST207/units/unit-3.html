Overview

What This Unit Covers

This unit introduces the Intel 8086 microprocessor — the foundation of all modern x86 processors. We study its internal architecture, register structure, memory segmentation model, interrupt handling, addressing modes, and instruction set. Understanding the 8086 is essential for writing assembly language programs in Unit 4.

Historical Context

The Intel 8086 was introduced in 1978 as a 16-bit microprocessor. It has a 16-bit data bus and a 20-bit address bus (1 MB addressable memory). It is the ancestor of all modern Intel/AMD x86 processors. The 8088 variant (used in IBM PC) had an 8-bit external data bus but same 16-bit internal architecture.

8086 Block Diagram & Pin Functions

Internal Architecture — Two Units

The 8086 is divided internally into two independent and parallel-working units:

  • BIU (Bus Interface Unit): Handles all bus operations — fetches instructions from memory, reads/writes data. Contains the instruction queue (prefetch buffer), segment registers, IP (Instruction Pointer), and the address generation logic.
  • EU (Execution Unit): Executes instructions. Contains the ALU, general-purpose registers, flag register, and the control unit. Receives instructions from the BIU's queue and executes them.
Pipelining in 8086

The BIU and EU operate in parallel — while the EU executes one instruction, the BIU prefetches the next instructions into the 6-byte instruction queue. This is a basic form of pipelining that improves throughput.

BIU — Bus Interface Unit Details
  • Instruction Queue: 6-byte FIFO buffer that holds prefetched instruction bytes. EU reads from this queue, BIU fills it from memory.
  • Segment Registers: CS, DS, SS, ES — hold the base address (shifted left 4 bits) of the four memory segments.
  • Instruction Pointer (IP): Holds the offset of the next instruction within the Code Segment.
  • Address Adder: Computes 20-bit physical address from 16-bit segment register and 16-bit offset.
  • Internal Bus: 16-bit internal bus connecting BIU to EU.
EU — Execution Unit Details
  • ALU: 16-bit arithmetic and logic operations.
  • General Purpose Registers: AX, BX, CX, DX (each 16-bit, dividable into two 8-bit halves).
  • Pointer & Index Registers: SP, BP, SI, DI.
  • Flag Register: 16-bit register holding status flags (CF, ZF, SF, OF, etc.).
  • Control Unit: Decodes instructions received from BIU queue and generates micro-operations.

Multiplexed Bus

The 8086 uses a multiplexed address/data bus on pins AD0–AD15. During T1 (first clock cycle of bus cycle), these pins carry the address. During T2 and T3, they carry data. The ALE signal is used to latch the address into an external latch (like 74LS373) before it disappears.

Status vs Control Flags

Status flags (CF, PF, AF, ZF, SF, OF) are set/cleared automatically by arithmetic and logic instructions to reflect the result. Control flags (TF, IF, DF) are set/cleared by the programmer to control CPU behavior.

Memory Segmentation

Why Segmentation?

The 8086 has 16-bit registers but a 20-bit address bus. To address 1 MB (2²⁰ bytes) of memory using 16-bit registers, Intel introduced the segmented memory model. Memory is divided into logical segments, each up to 64 KB.

Physical Address Calculation
Physical Address = Segment Register × 16 + Offset
= (Segment Register << 4) + Offset

The segment register value is shifted left by 4 bits (multiplied by 16 = 10H) and added to the 16-bit offset to produce a 20-bit physical address.

Code Segment
CS : IP
Stores program instructions. IP holds offset of next instruction to execute.
Data Segment
DS : offset
Stores data variables. BX, SI, DI used as offsets for addressing.
Stack Segment
SS : SP / BP
Stores the stack. SP points to top; BP accesses stack frame parameters.
Extra Segment
ES : DI
Extra data segment. DI used as destination in string operations (MOVS, STOS).

CS = 1000H, IP = 0200H
Physical Address = 1000H × 10H + 0200H
= 10000H + 0200H = 10200H
DS = 2000H, Offset = 0050H
Physical Address = 2000H × 10H + 0050H
= 20000H + 0050H = 20050H
Segment Overlap

Segments can overlap in memory. Two different segment:offset pairs can point to the same physical address. The same physical address can have multiple logical addresses (segment aliasing). Maximum segment size is 64 KB (FFFFH offset).

Interrupt Mechanism

What is an Interrupt?

An interrupt is a signal that temporarily suspends the normal execution of a program and transfers control to a special routine called an Interrupt Service Routine (ISR). After the ISR completes, the original program resumes from where it was interrupted.

Interrupt Processing Steps
  1. CPU completes current instruction.
  2. CPU saves state: pushes FLAGS, CS, and IP onto the stack.
  3. Clears IF and TF flags (to disable further interrupts during ISR).
  4. Fetches interrupt vector from Interrupt Vector Table (IVT) at address 0000:0000.
  5. Jumps to ISR (loads CS:IP from vector table).
  6. ISR executes, handles the interrupt.
  7. IRET instruction: pops IP, CS, FLAGS from stack → resumes original program.
Interrupt Vector Table (IVT)

The IVT occupies the first 1 KB of memory (addresses 0000:0000 to 0000:03FF). It has 256 entries, each 4 bytes (2 bytes for IP + 2 bytes for CS of ISR).

IVT Address Calculation
IVT Address = Interrupt Type × 4

Example: INT 21H → IVT address = 21H × 4 = 84H. CS:IP of ISR stored at 0000:0084H.

Maskable vs Non-Maskable
  • Maskable (INTR): Can be enabled/disabled using STI (Set Interrupt Flag) and CLI (Clear Interrupt Flag) instructions. When IF=0, INTR is ignored.
  • Non-Maskable (NMI): Cannot be disabled by software. Always responded to. Used for critical hardware events (power failure, memory error).

Addressing Modes

What are Addressing Modes?

An addressing mode defines how the operand of an instruction is specified — where to find the data needed for the instruction. The 8086 supports a rich set of addressing modes providing flexibility in accessing data.

Physical Address = DS × 10H + EA   (for data accesses)

Base registers: BX, BP. Index registers: SI, DI. Displacement: 8-bit or 16-bit constant in instruction.

  • BX, SI, DI → default segment = DS
  • BP → default segment = SS
  • IP → always uses CS
  • SP → always uses SS
  • Segment override prefix can change the default (e.g., ES:[BX])

Key Formulas

Physical Address Calculation
Physical Address = Segment Register × 10H + Offset

Segment register is shifted left by 4 bits (×16). Both segment and offset are 16-bit. Result is 20-bit.

Maximum Addressable Memory
Memory = 2²⁰ = 1 MB = 1,048,576 bytes

20-bit address bus → 2²⁰ unique addresses. Each address selects 1 byte.

IVT Entry Address
IVT Address = Interrupt Type Number × 4

Each IVT entry = 4 bytes (2 for IP + 2 for CS). Total IVT = 256 × 4 = 1024 bytes = 1 KB at 0000:0000.

Effective Address (EA)
EA = Base Register + Index Register + Displacement
Physical = DS:EA (default for data) or CS:IP (for code)
Maximum Segment Size
Max Segment Size = 2¹⁶ = 64 KB = 65,536 bytes

Since offset is 16-bit, maximum offset = FFFFH = 65535. So each segment can be at most 64 KB.

Key Definitions

BIU (Bus Interface Unit)

The unit in the 8086 that handles all external bus operations including instruction prefetching, memory reads/writes, and I/O operations. It contains the instruction queue, segment registers, IP, and address generation logic.

EU (Execution Unit)

The unit in the 8086 that executes instructions received from the BIU's instruction queue. It contains the ALU, general-purpose registers, flag register, and control unit. It operates in parallel with the BIU.

Segmentation

A memory management technique used by the 8086 where the 1 MB address space is divided into logical segments of up to 64 KB each. A 20-bit physical address is formed by combining a 16-bit segment register value (shifted left 4 bits) with a 16-bit offset.

Interrupt Vector Table (IVT)

A table stored in the first 1 KB of memory (0000:0000 to 0000:03FF) containing 256 entries, each 4 bytes (CS:IP address of the ISR). The CPU uses this table to find the starting address of the Interrupt Service Routine for each interrupt type.

Addressing Mode

A method of specifying the location of an operand in an instruction. The 8086 supports multiple addressing modes including immediate, register, direct, register indirect, based indexed, and relative modes.

Effective Address (EA)

The 16-bit offset address within a segment used to locate an operand in memory. EA = Base Register + Index Register + Displacement. The physical address is then computed as Segment × 10H + EA.

NMI (Non-Maskable Interrupt)

A hardware interrupt that cannot be disabled by software (cannot be masked using the IF flag). It has the highest priority among external interrupts and is used for critical events like power failure or memory parity errors.

Instruction Queue

A 6-byte FIFO buffer in the BIU that holds prefetched instruction bytes fetched from memory. The EU reads instructions from this queue while the BIU simultaneously fetches ahead, implementing basic pipelining.

Multiple Choice Questions

Q 1

The 8086 microprocessor has how many address lines and what is its maximum addressable memory?

  • a. 16 address lines, 64 KB
  • b. 20 address lines, 1 MB
  • c. 24 address lines, 16 MB
  • d. 32 address lines, 4 GB
Answer: b. 20 address lines, 1 MB

The 8086 has a 20-bit address bus (A0–A19) giving 2²⁰ = 1,048,576 = 1 MB of addressable memory. Data bus is 16-bit.

Q 2

Which unit of the 8086 is responsible for prefetching instructions from memory?

  • a. Execution Unit (EU)
  • b. Arithmetic Logic Unit (ALU)
  • c. Bus Interface Unit (BIU)
  • d. Control Unit (CU)
Answer: c. Bus Interface Unit (BIU)

The BIU handles all bus operations including fetching instructions from memory into the 6-byte instruction queue. The EU reads from this queue and executes instructions.

Q 3

If CS = 2000H and IP = 0300H, what is the physical address of the next instruction?

  • a. 2300H
  • b. 20300H
  • c. 23000H
  • d. 2030H
Answer: b. 20300H

Physical Address = CS × 10H + IP = 2000H × 10H + 0300H = 20000H + 0300H = 20300H.

Q 4

Which register is used as a loop counter in 8086 assembly language?

  • a. AX
  • b. BX
  • c. CX
  • d. DX
Answer: c. CX

CX is the Counter register. The LOOP instruction automatically decrements CX and jumps if CX ≠ 0. CL also holds the shift count for SHL/SHR instructions.

Q 5

The instruction MOV AX, 1234H uses which addressing mode?

  • a. Register addressing
  • b. Direct addressing
  • c. Immediate addressing
  • d. Indirect addressing
Answer: c. Immediate addressing

In immediate addressing, the operand (1234H) is directly specified in the instruction itself. No memory access needed to fetch the operand.

Q 6

Which flag is used to enable or disable the maskable hardware interrupt (INTR)?

  • a. TF (Trap Flag)
  • b. SF (Sign Flag)
  • c. DF (Direction Flag)
  • d. IF (Interrupt Flag)
Answer: d. IF (Interrupt Flag)

IF=1 (set by STI instruction) enables INTR. IF=0 (cleared by CLI instruction) disables INTR. NMI cannot be masked and is always responded to regardless of IF.

Q 7

The Interrupt Vector Table (IVT) in 8086 occupies:

  • a. First 256 bytes of memory
  • b. First 512 bytes of memory
  • c. First 1 KB of memory
  • d. First 4 KB of memory
Answer: c. First 1 KB of memory

256 interrupt types × 4 bytes each (2 for IP + 2 for CS) = 1024 bytes = 1 KB. Located at physical addresses 00000H to 003FFH.

Q 8

Which segment register is used by default for stack operations (PUSH/POP)?

  • a. CS
  • b. DS
  • c. ES
  • d. SS
Answer: d. SS

Stack operations (PUSH, POP, CALL, RET) always use the Stack Segment (SS) register. SP points to the current top of stack within SS.

Q 9

What does the ALE (Address Latch Enable) pin signal indicate?

  • a. Data is valid on the bus
  • b. A valid address is present on AD0–AD15
  • c. CPU is in reset state
  • d. Interrupt is being acknowledged
Answer: b. A valid address is present on AD0–AD15

ALE goes HIGH during T1 clock cycle when the address is valid on the multiplexed AD0–AD15 pins. External logic (latch like 74LS373) uses ALE to latch the address before the bus switches to data mode.

Q 10

The instruction LEA BX, [SI+100H] loads into BX:

  • a. The data at address SI+100H
  • b. The value 100H
  • c. The effective address SI+100H
  • d. The physical address DS:SI+100H
Answer: c. The effective address SI+100H

LEA (Load Effective Address) loads the computed offset address (SI+100H) into BX — not the data at that address and not the physical address. No memory access occurs.

Q 11

After execution of XOR AX, AX, what is the value of AX?

  • a. FFFFH
  • b. Unchanged
  • c. 0000H
  • d. 0001H
Answer: c. 0000H

XOR of any value with itself = 0. XOR AX, AX is a common and efficient way to clear a register to zero. It also clears CF and OF flags.

Q 12

Which instruction returns from an interrupt service routine?

  • a. RET
  • b. RETF
  • c. IRET
  • d. POP IP
Answer: c. IRET

IRET (Interrupt Return) pops IP, CS, and FLAGS from the stack to restore the state saved when the interrupt was accepted. RET only pops IP (and CS for far calls) but not FLAGS.

Q 13

In the 8086, which register pair is used to hold the result of a 16-bit multiplication?

  • a. AX and BX
  • b. DX and AX
  • c. CX and AX
  • d. AX only
Answer: b. DX and AX

For 16-bit × 16-bit multiplication (MUL/IMUL), the 32-bit result is stored in DX:AX (DX = high word, AX = low word). For 8-bit × 8-bit, result is in AX.

Q 14

The LOOP instruction in 8086 automatically:

  • a. Increments CX and jumps if CX ≠ 0
  • b. Decrements CX and jumps if CX ≠ 0
  • c. Decrements CX and jumps if CX = 0
  • d. Checks ZF and jumps accordingly
Answer: b. Decrements CX and jumps if CX ≠ 0

LOOP decrements CX by 1. If CX ≠ 0 after decrement, it jumps to the label. If CX becomes 0, execution falls through to the next instruction.

Q 15

What is the size of the instruction prefetch queue in the 8086?

  • a. 4 bytes
  • b. 6 bytes
  • c. 8 bytes
  • d. 16 bytes
Answer: b. 6 bytes

The 8086 BIU has a 6-byte instruction prefetch queue (FIFO). The 8088 has a 4-byte queue. The BIU fills this queue whenever the bus is free and the queue is not full.

Short Answer Questions

Q 1

What are the two functional units of the 8086 and what does each do?

The 8086 has two functional units:

  • BIU (Bus Interface Unit): Handles all external bus operations — fetches instructions into the 6-byte queue, reads/writes memory and I/O, generates 20-bit physical addresses from segment:offset pairs.
  • EU (Execution Unit): Executes instructions fetched by BIU. Contains ALU, GPRs (AX, BX, CX, DX), pointer/index registers, and flag register. Both units operate in parallel for pipelining.

Calculate the physical address when DS = 3000H and offset = 0250H.

Q 3

What is the purpose of the ALE pin in the 8086?

ALE (Address Latch Enable) goes HIGH during T1 of the bus cycle when the address is valid on the multiplexed AD0–AD15 pins. External hardware (like 74LS373 latch) uses the falling edge of ALE to latch and hold the address, because AD0–AD15 will be used for data in the next clock cycle.

Q 4

Differentiate between NMI and INTR interrupts.

NMI (Non-Maskable Interrupt): Cannot be disabled by software. Always responded to. Edge-triggered. Fixed type 2. Used for critical events (power failure).

INTR (Maskable Interrupt): Can be enabled/disabled using STI/CLI instructions (IF flag). Level-triggered. Type number supplied by 8259 PIC. Used for keyboard, timer, I/O devices.

Q 5

What is the function of the flag register? Name any four flags.

The flag register is a 16-bit register that reflects the status of the last arithmetic/logic operation and controls certain CPU behaviors. Four important flags:

  • ZF (Zero Flag): Set when result = 0.
  • CF (Carry Flag): Set on unsigned overflow/carry out.
  • SF (Sign Flag): Set when result is negative (MSB=1).
  • IF (Interrupt Flag): Controls maskable interrupts (STI sets, CLI clears).

Q 6

What is the difference between MOV AX, [BX] and MOV AX, BX?

MOV AX, BX: Register addressing. Copies the 16-bit content of BX directly into AX. No memory access. AX ← BX.

MOV AX, [BX]: Register indirect addressing. Treats BX as a memory address (pointer). Reads the 16-bit data at memory location DS:BX into AX. AX ← Memory[DS:BX].

Q 7

What happens during an IRET instruction?

IRET (Interrupt Return) pops three values from the stack in this order: first IP (restores instruction pointer), then CS (restores code segment), then FLAGS (restores all flags including IF and TF). This completely restores the processor state to what it was just before the interrupt occurred, resuming the interrupted program exactly where it left off.

Q 8

What is the purpose of the CMP instruction? Does it modify any registers?

CMP (Compare) subtracts the source from the destination operand and sets the flags (ZF, CF, SF, OF) based on the result, but does NOT store the result — neither operand is modified. It is used before conditional jump instructions (JZ, JNZ, JA, JB, etc.) to compare two values and then branch based on the comparison result.

Long Answer Questions

Q 1

Draw and explain the internal block diagram of the Intel 8086 microprocessor. Describe the function of BIU and EU in detail.

The 8086 is internally divided into two independently operating units:

BIU (Bus Interface Unit)

Components:

  • 6-byte Instruction Queue (FIFO prefetch buffer)
  • Segment Registers: CS, DS, SS, ES
  • Instruction Pointer (IP)
  • Address Adder: computes Physical = Segment×10H + Offset
  • Internal 16-bit bus to EU

Function: Fetches instructions from memory into queue whenever queue has space and bus is free. Handles all memory read/write requests from EU. Generates 20-bit physical addresses.

EU (Execution Unit)

Components:

  • 16-bit ALU
  • General Purpose Registers: AX, BX, CX, DX
  • Pointer/Index Registers: SP, BP, SI, DI
  • Flag Register (16-bit)
  • Control Unit (instruction decoder)

Function: Reads instructions from BIU queue, decodes them, executes using ALU, updates flags, and requests BIU for memory operand access when needed.

Parallel Operation

BIU and EU work simultaneously — while EU executes instruction N, BIU prefetches instruction N+1, N+2 into the queue. This overlap improves throughput and is the 8086's basic pipeline mechanism.

Q 2

Explain the memory segmentation in 8086. How is the physical address calculated? Give three numerical examples.

Why Segmentation: 8086 has 16-bit registers but 20-bit address bus. Segmentation allows 16-bit registers to address 1 MB by dividing memory into logical segments.

Four Segments:

  • CS:IP — Code Segment: holds instructions
  • DS:offset — Data Segment: holds data variables
  • SS:SP/BP — Stack Segment: holds the stack
  • ES:DI — Extra Segment: for string destinations
Formula
Physical Address = Segment × 10H + Offset

Example 1:

CS = 1200H, IP = 0500H → PA = 12000H + 0500H = 12500H

Example 2:

DS = 4000H, Offset = 0100H → PA = 40000H + 0100H = 40100H

Example 3:

SS = 5000H, SP = 00FEH → PA = 50000H + 00FEH = 500FEH
Key Points
  • Max segment size = 64 KB (16-bit offset → max FFFFH).
  • Segments can overlap in physical memory.
  • Same physical address can have multiple segment:offset representations.

Q 3

Explain the interrupt mechanism of the 8086. Describe the steps that occur when an INTR interrupt is accepted. What is the role of the IVT?

Interrupt Mechanism: An interrupt suspends the current program and transfers control to an ISR. The 8086 supports hardware interrupts (NMI, INTR) and software interrupts (INT n).

Steps When INTR is Accepted
  1. Device asserts INTR pin HIGH. CPU checks IF flag.
  2. If IF=1, CPU completes current instruction.
  3. CPU sends INTA (Interrupt Acknowledge) signal to 8259 PIC.
  4. 8259 PIC sends the interrupt type number on data bus.
  5. CPU pushes FLAGS onto stack (saves status).
  6. CPU clears IF and TF (disables further interrupts).
  7. CPU pushes CS onto stack (saves code segment).
  8. CPU pushes IP onto stack (saves return address).
  9. CPU reads IVT at address = type × 4. Gets ISR CS:IP.
  10. CPU loads CS:IP from IVT — jumps to ISR.
  11. ISR executes and services the interrupt.
  12. IRET: pops IP, CS, FLAGS from stack. Resumes original program.
IVT (Interrupt Vector Table)

Located at 0000:0000 to 0000:03FF (first 1 KB). 256 entries × 4 bytes each. Each entry = 2 bytes IP + 2 bytes CS of the ISR. Example: INT 21H ISR address found at physical address 21H × 4 = 84H.

Q 4

Explain any five addressing modes of the 8086 with examples and effective address calculation for each.

ModeExampleEA CalculationPhysical Address (DS=2000H)

Why Multiple Modes?

Different modes suit different tasks. Immediate = constants. Register = fastest, no memory. Direct = fixed addresses. Indirect = pointers. Based+Displacement = structure/record fields. Based+Indexed = 2D arrays.

Q 5

Describe the register structure of the 8086. Explain the role of each register group with examples.

The 8086 has 14 registers organized in four groups:

Group 1: General Purpose Registers

AX (Accumulator), BX (Base), CX (Counter), DX (Data). Each 16-bit, splittable into AH/AL etc.

  • AX: primary for arithmetic/IO — ADD AX, BX
  • BX: memory base address — MOV AX, [BX]
  • CX: loop counter — LOOP label uses CX
  • DX: I/O port address, MUL/DIV extension — MUL BX → result in DX:AX
Group 2: Segment Registers

CS (Code), DS (Data), SS (Stack), ES (Extra). Hold base addresses of memory segments. Combined with 16-bit offset to form 20-bit physical address.

Group 3: Pointer & Index Registers

SP (Stack Pointer — top of stack in SS), BP (Base Pointer — stack frame access), SI (Source Index — string source in DS), DI (Destination Index — string destination in ES).

Group 4: Control Registers

IP (Instruction Pointer — offset of next instruction in CS, auto-incremented after fetch), FLAGS (16-bit — CF, PF, AF, ZF, SF, OF, TF, IF, DF).

(a) CS = 1500H, IP = 0200H
(b) DS = 3800H, BX = 0050H

PA = 1500H × 10H + 0200H = 15000H + 0200H = 15200H

(b) DS = 3800H, BX = 0050H:

PA = 3800H × 10H + 0050H = 38000H + 0050H = 38050H

(c) SS = 2200H, SP = 00FEH:

PA = 2200H × 10H + 00FEH = 22000H + 00FEH = 220FEH

Q 2

Identify the addressing mode used in each of the following 8086 instructions:

(a) MOV AX, 0FFH
(b) MOV AX, [BX+SI]
(c) MOV AX, CX
(d) MOV AX, [1200H]
(e) MOV AX, [BP+10H]

  • (a) MOV AX, 0FFH → Immediate Addressing (operand 0FFH is in the instruction)
  • (b) MOV AX, [BX+SI] → Based Indexed Addressing (EA = BX + SI)
  • (c) MOV AX, CX → Register Addressing (both operands are registers)
  • (d) MOV AX, [1200H] → Direct Addressing (EA = 1200H directly specified)
  • (e) MOV AX, [BP+10H] → Register + Displacement Addressing (EA = BP + 10H; uses SS segment since BP)

Q 4

Trace what happens step by step when the 8086 executes INT 21H. Assume stack is at SS=5000H, SP=0100H.

INT 21H Execution Trace

1. CPU fetches and decodes INT 21H instruction.

2. SP ← SP − 2 = 00FEH. Stack PA = 5000H×10H+00FEH = 500FEH.

   FLAGS pushed → Memory[500FEH] ← FLAGS

3. IF ← 0, TF ← 0 (interrupts disabled during ISR).

4. SP ← SP − 2 = 00FCH.

   CS pushed → Memory[500FCH] ← CS

5. SP ← SP − 2 = 00FAH.

   IP pushed → Memory[500FAH] ← IP (return address)

6. IVT address = 21H × 4 = 84H.

   New IP ← Memory[0000:0084H]

   New CS ← Memory[0000:0086H]

7. CPU jumps to CS:IP = ISR for INT 21H (DOS service handler).

8. ISR executes DOS service.

9. IRET: IP ← [stack], CS ← [stack], FLAGS ← [stack]. SP += 6.

10. Program resumes after INT 21H instruction.

Q 5

For the instruction MOV AX, [BX+SI+0100H], if BX=1000H, SI=0200H, DS=4000H, calculate the Effective Address and Physical Address.

Addressing Mode: Based Indexed with Displacement

Effective Address
EA = BX + SI + Displacement
EA = 1000H + 0200H + 0100H = 1300H
Physical Address
PA = DS × 10H + EA
PA = 4000H × 10H + 1300H
PA = 40000H + 1300H = 41300H

The 16-bit word at physical address 41300H is loaded into AX.

Revision & Quick Summary

Quick Revision Points
  • 8086: 16-bit data bus, 20-bit address bus, 1 MB addressable memory, 40-pin DIP.
  • Two internal units: BIU (fetches instructions, handles bus) and EU (executes instructions) — work in parallel.
  • BIU has 6-byte instruction queue (8088 has 4-byte). This provides basic pipelining.
  • Physical Address = Segment × 10H + Offset (20-bit result).
  • Four segments: CS:IP (code), DS:offset (data), SS:SP/BP (stack), ES:DI (extra).
  • Max segment size = 64 KB (16-bit offset).
  • GPRs: AX, BX, CX, DX — each 16-bit, divisible into AH/AL, BH/BL, CH/CL, DH/DL.
  • CX = counter (LOOP), AX = accumulator (arithmetic/IO), BX = base (memory), DX = data (MUL/DIV/IO).
  • Flag register: CF, PF, AF, ZF, SF, OF (status) + TF, IF, DF (control).
  • IF=1 enables INTR (STI sets it). IF=0 disables INTR (CLI clears it). NMI cannot be masked.
  • IVT: 256 entries × 4 bytes = 1 KB at 0000:0000 to 0000:03FF. Entry address = type × 4.
  • Interrupt response: push FLAGS → clear IF,TF → push CS → push IP → fetch ISR from IVT → jump to ISR.
  • IRET: pops IP, CS, FLAGS (in that order from stack).
  • INT n → software interrupt. NMI → non-maskable hardware. INTR → maskable hardware.
  • Addressing modes: Immediate (in instruction), Register (register to register), Direct (fixed address), Indirect ([BX]), Based+Disp ([BX+disp]), Based Indexed ([BX+SI]).
  • LEA loads address, MOV [addr] loads data at that address.
  • XOR AX,AX = fastest way to clear AX to 0.
  • CMP sets flags without storing result. TEST = AND without storing result.
  • MUL BX → 16-bit: result in DX:AX. DIV BX → quotient in AX, remainder in DX.
  • LOOP decrements CX and jumps if CX≠0. CALL pushes IP/CS, RET pops them.
  • AD0–AD15: multiplexed — address during T1 (ALE high), data during T2/T3.
  • After RESET: 8086 starts executing from FFFF0H (CS=FFFFH, IP=0000H).
Must Remember for Exam
  • Physical Address formula: Segment × 10H + Offset — most asked numerical.
  • 8086: 16-bit data bus, 20-bit address bus, 1 MB memory, 6-byte queue.
  • IVT entry address = Type × 4. Each entry = 4 bytes (IP low, IP high, CS low, CS high).
  • NMI = non-maskable (type 2, edge-triggered). INTR = maskable (IF flag, level-triggered).
  • IRET pops: IP then CS then FLAGS (reverse of what INT pushed).
  • Instruction prefetch queue: 8086 = 6 bytes, 8088 = 4 bytes.
  • Default segments: BX/SI/DI → DS, BP/SP → SS, IP → CS, DI in string ops → ES.
  • MUL result: 8×8 → AX. 16×16 → DX:AX. DIV: quotient → AX, remainder → DX.
Common Mistakes to Avoid
  • ❌ Multiplying segment by 16 (decimal) not 10H — both are the same but write × 10H in hex context.
  • ❌ Confusing LEA (loads address/offset) with MOV (loads data at address).
  • ❌ Saying NMI can be disabled — NMI is always non-maskable. Only INTR is maskable via IF.
  • ❌ Confusing IRET with RET — IRET pops FLAGS too. RET only pops IP (and CS for far).
  • ❌ Confusing BIU and EU roles — BIU handles the bus and prefetch, EU handles execution.
  • ❌ Saying 8086 has separate address and data buses — AD0–AD15 is multiplexed (time-shared).
  • ❌ Forgetting that INC/DEC do NOT affect CF (Carry Flag). All other arithmetic ops do.
  • ❌ Confusing CMP with SUB — CMP does not store result, only sets flags. SUB stores result.
  • ❌ Using wrong default segment — BP uses SS by default, not DS like BX/SI/DI.
  • ❌ Saying 8086 starts at address 0 after reset — it starts at FFFF0H (CS=FFFFH, IP=0000H).
