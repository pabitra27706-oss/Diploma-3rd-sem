One-Dimensional Arrays

What is an Array?

An array is a collection of a fixed number of elements of the same data type stored in contiguous (adjacent) memory locations. Each element is accessed using an index (subscript), starting from 0.

Without arrays, to store marks of 50 students you would need 50 separate variables: m1, m2, m3 ... m50. With an array: marks[50] — one declaration handles all 50.

Advantages of Arrays
  • Efficient storage — Multiple values stored under one name.
  • Random access — Any element accessed directly using its index in O(1) time.
  • Easy traversal — Loop through all elements with a single for loop.
  • Sorting & searching — Arrays are the standard structure for these operations.
  • Reduced code — No need to declare separate variables for each value.
  • Passed to functions — Arrays can be passed to functions for processing.
Declaration and Initialization
Syntax
data_type array_name[size];
data_type array_name[size] = {val1, val2, val3, ...};
Declaration and Initialization Examples
/* Declaration only */
int marks[5];                    /* 5 integers, uninitialized */
float salary[100];               /* 100 floats */
char grade[10];                  /* 10 characters */

/* Declaration with initialization */
int marks[5] = {85, 90, 78, 92, 88};
float pi_vals[3] = {3.14, 3.141, 3.1415};

/* Partial initialization — rest are set to 0 */
int arr[5] = {1, 2};            /* arr = {1, 2, 0, 0, 0} */

/* Size inferred from initializer */
int nums[] = {10, 20, 30, 40};  /* size = 4 (auto-calculated) */

/* All elements set to 0 */
int zeros[10] = {0};
Memory Representation of a 1D Array

For int marks[5] = {85, 90, 78, 92, 88}; on a system where int = 4 bytes:

marks[0]
90
marks[1]
78
marks[2]

Address Formula
Address of marks[i] = Base Address + (i × sizeof(data_type))
Example: If base = 1000, sizeof(int) = 4 → marks[3] is at 1000 + (3×4) = 1012
Index Rules
  • Valid indices: 0 to size-1. For int arr[5], valid indices are 0, 1, 2, 3, 4.
  • C does NOT check for out-of-bounds access — accessing arr[5] or arr[-1] is undefined behavior (may crash or corrupt data).
Complete 1D Array Example — Input, Display, Find Max/Min
#include <stdio.h>
int main() {
    int arr[10], n, i;
    int max, min;

    printf("Enter number of elements (max 10): ");
    scanf("%d", &n);

    /* Input */
    printf("Enter %d elements:\n", n);
    for (i = 0; i < n; i++) {
        printf("arr[%d] = ", i);
        scanf("%d", &arr[i]);
    }

    /* Initialize max and min */
    max = arr[0];
    min = arr[0];

    /* Find max and min */
    for (i = 1; i < n; i++) {
        if (arr[i] > max) max = arr[i];
        if (arr[i] < min) min = arr[i];
    }

    /* Display */
    printf("Array: ");
    for (i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\nMaximum = %d\nMinimum = %d\n", max, min);

    return 0;
}
Sorting a 1D Array (Bubble Sort)
Sort Array in Ascending Order
#include <stdio.h>
int main() {
    int arr[] = {64, 25, 12, 22, 11};
    int n = 5, temp;

    /* Bubble Sort */
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j+1]) {
                temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;
            }
        }
    }

    printf("Sorted array: ");
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    return 0;
}
/* Output: 11 12 22 25 64 */

Two-Dimensional Arrays (Matrices)

What is a 2D Array?

A two-dimensional array is an array of arrays — essentially a matrix with rows and columns. It is used to represent tabular data, matrices for mathematical operations, grids, and game boards. Elements are accessed using two indices: row index and column index.

Declaration and Initialization Syntax
data_type array_name[rows][columns];
data_type array_name[rows][columns] = {{r0c0,r0c1,...},{r1c0,r1c1,...}, ...};
2D Array Declaration Examples
/* Declaration only */
int matrix[3][3];          /* 3×3 matrix of integers */
float table[4][5];         /* 4 rows, 5 columns */

/* With initialization */
int mat[2][3] = {
    {1, 2, 3},             /* row 0 */
    {4, 5, 6}              /* row 1 */
};

/* Alternative flat initialization */
int mat2[2][3] = {1, 2, 3, 4, 5, 6};

/* Access: mat[row][col] */
printf("%d", mat[1][2]);   /* row 1, col 2 = 6 */
Memory Layout of a 2D Array

For int mat[2][3], stored in row-major order in memory:

1
mat[0][0]
2
mat[0][1]
3
mat[0][2]
4
mat[1][0]
5
mat[1][1]
6
mat[1][2]
Address Formula (Row-Major)
Address of mat[i][j] = Base + (i × num_cols + j) × sizeof(type)
Example: mat[1][2] at Base=2000, cols=3, int=4: 2000 + (1×3+2)×4 = 2000+20 = 2020
Matrix Input, Display and Addition
#include <stdio.h>
int main() {
    int A[3][3], B[3][3], C[3][3];
    int i, j;

    /* Input Matrix A */
    printf("Enter elements of Matrix A (3x3):\n");
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            scanf("%d", &A[i][j]);

    /* Input Matrix B */
    printf("Enter elements of Matrix B (3x3):\n");
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            scanf("%d", &B[i][j]);

    /* Addition */
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            C[i][j] = A[i][j] + B[i][j];

    /* Display result */
    printf("\nMatrix C = A + B:\n");
    for (i = 0; i < 3; i++) {
        for (j = 0; j < 3; j++)
            printf("%5d", C[i][j]);
        printf("\n");
    }
    return 0;
}
Matrix Multiplication
#include <stdio.h>
int main() {
    int A[3][3] = {{1,2,3},{4,5,6},{7,8,9}};
    int B[3][3] = {{9,8,7},{6,5,4},{3,2,1}};
    int C[3][3] = {0};  /* initialize result to 0 */

    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            for (int k = 0; k < 3; k++) {
                C[i][j] += A[i][k] * B[k][j];
            }
        }
    }

    printf("Product Matrix:\n");
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++)
            printf("%5d", C[i][j]);
        printf("\n");
    }
    return 0;
}

Multidimensional Arrays

Multidimensional Arrays (Idea)

C allows arrays with more than two dimensions. A 3D array can be thought of as a collection of 2D matrices — like multiple pages of a spreadsheet stacked together.

3D Array Syntax
data_type array_name[depth][rows][columns];

/* Example: 3D array of 2 pages, each 3×3 */
int cube[2][3][3];

/* Access element at page 1, row 2, column 0 */
cube[1][2][0] = 50;

/* Total elements = 2 × 3 × 3 = 18 integers */
Total Elements Formula
Total Elements = d1 × d2 × d3 × ... × dn
Example: int arr[2][3][4] → 2×3×4 = 24 elements, size = 24×4 = 96 bytes
Exam Note

The syllabus says "idea only" for multidimensional arrays. You only need to know the declaration syntax, element access, and total element count formula. You will not be asked to write complete programs with 3D arrays.

Strings (Character Arrays)

What is a String in C?

In C, a string is a one-dimensional array of characters terminated by a special character called the null character ('\0'). The null character signals the end of the string. C has no built-in string data type — strings are always character arrays.

String Memory Representation

For char str[] = "HELLO";:

'H'
str[0]
'E'
str[1]
'L'
str[2]
'L'
str[3]
'O'
str[4]
'\0'
str[5]

The string "HELLO" requires 6 bytes — 5 for characters + 1 for '\0'.

String Declaration and Initialization
/* Method 1: With string literal (auto adds '\0') */
char str1[] = "Hello";           /* size = 6 (5 chars + '\0') */
char str2[10] = "Hello";         /* size = 10, rest filled with '\0' */

/* Method 2: Character by character */
char str3[] = {'H','e','l','l','o','\0'};  /* must add '\0' manually */

/* Method 3: Using pointer (string literal in read-only memory) */
char *str4 = "Hello";            /* pointer to string literal */

/* Reading string from user */
char name[50];
scanf("%s", name);               /* reads until whitespace, NO & needed */
printf("%s", name);              /* prints the string */

/* Reading string with spaces using fgets */
fgets(name, 50, stdin);          /* reads full line including spaces */
Critical String Rules
  • Always declare string size at least 1 more than the expected string length (for '\0').
  • scanf("%s", name) does NOT need & because array name is already a pointer.
  • scanf("%s") stops at whitespace — use fgets() for strings with spaces.
  • Strings cannot be compared with == — use strcmp().
  • Strings cannot be assigned with = after declaration — use strcpy().
Accessing Individual Characters of a String
#include <stdio.h>
#include <string.h>
int main() {
    char str[] = "DIPLOMA";
    int len = strlen(str);

    /* Access characters using index */
    printf("First char : %c\n", str[0]);    /* D */
    printf("Last char  : %c\n", str[len-1]); /* A */

    /* Print character by character */
    printf("Characters: ");
    for (int i = 0; str[i] != '\0'; i++) {
        printf("%c ", str[i]);
    }
    printf("\n");

    /* Count vowels */
    int vowels = 0;
    for (int i = 0; str[i] != '\0'; i++) {
        char c = str[i];
        if (c=='A'||c=='E'||c=='I'||c=='O'||c=='U'||
            c=='a'||c=='e'||c=='i'||c=='o'||c=='u')
            vowels++;
    }
    printf("Vowels in '%s': %d\n", str, vowels);
    return 0;
}

String Handling Functions (<string.h>)

Including string.h

All standard string functions require: #include <string.h> at the top of your program.

1. strlen() — String Length

Returns the number of characters in a string, excluding the null terminator '\0'.

Syntax
size_t strlen(const char *str);
/* Returns: integer — number of characters (not including '\0') */
strlen() Example
#include <stdio.h>
#include <string.h>
int main() {
    char str1[] = "Hello";
    char str2[] = "Computer";
    char str3[] = "";          /* empty string */

    printf("Length of '%s' = %lu\n", str1, strlen(str1)); /* 5 */
    printf("Length of '%s' = %lu\n", str2, strlen(str2)); /* 8 */
    printf("Length of '' = %lu\n", strlen(str3));          /* 0 */

    /* Note: sizeof vs strlen */
    char arr[20] = "Hello";
    printf("strlen = %lu\n", strlen(arr));   /* 5 */
    printf("sizeof = %lu\n", sizeof(arr));   /* 20 (array size, not string length) */
    return 0;
}
strlen vs sizeof

strlen(arr) returns the string length (up to '\0'). sizeof(arr) returns the total array size in bytes. These are DIFFERENT. For char arr[20] = "Hello": strlen = 5, sizeof = 20.

2. strcpy() — String Copy

Copies the contents of the source string into the destination string, including the null terminator. The destination must have enough space.

Syntax
char *strcpy(char *destination, const char *source);
/* Copies source into destination. Returns pointer to destination. */
strcpy() Example
#include <stdio.h>
#include <string.h>
int main() {
    char src[] = "Hello World";
    char dest[20];

    strcpy(dest, src);            /* copies src into dest */
    printf("dest = %s\n", dest);  /* Hello World */

    /* String assignment using strcpy */
    char name[20];
    strcpy(name, "Diploma");
    printf("name = %s\n", name);  /* Diploma */

    /* WRONG: name = "Diploma";  — This does NOT work after declaration */
    return 0;
}
Buffer Overflow Risk

If the destination array is smaller than the source string, strcpy() causes a buffer overflow — a critical security vulnerability. Always ensure sizeof(dest) > strlen(src) + 1. Use strncpy() for safer copying.

3. strcat() — String Concatenation

Appends (joins) the source string to the end of the destination string. The null terminator of destination is overwritten and a new one added at the end.

Syntax
char *strcat(char *destination, const char *source);
/* Appends source to end of destination. Returns pointer to destination. */
strcat() Example
#include <stdio.h>
#include <string.h>
int main() {
    char first[30] = "Hello";
    char second[] = " World";

    printf("Before strcat: '%s'\n", first);   /* Hello */
    strcat(first, second);                     /* append second to first */
    printf("After strcat:  '%s'\n", first);   /* Hello World */

    /* Concatenating multiple strings */
    char result[50] = "West";
    strcat(result, " Bengal");
    strcat(result, " State");
    printf("%s\n", result);   /* West Bengal State */
    return 0;
}
4. strcmp() — String Comparison

Compares two strings lexicographically (dictionary order) character by character. Returns an integer based on the comparison.

Syntax
int strcmp(const char *str1, const char *str2);
/* Returns:
   0       — if str1 == str2 (strings are identical)
   < 0     — if str1 < str2 (str1 comes before str2 in dictionary)
   > 0     — if str1 > str2 (str1 comes after str2 in dictionary)
*/
strcmp() Example
#include <stdio.h>
#include <string.h>
int main() {
    char s1[] = "apple";
    char s2[] = "apple";
    char s3[] = "banana";
    char s4[] = "Apple";   /* uppercase A */

    printf("%d\n", strcmp(s1, s2));  /* 0 — equal */
    printf("%d\n", strcmp(s1, s3));  /* negative — apple < banana */
    printf("%d\n", strcmp(s3, s1));  /* positive — banana > apple */
    printf("%d\n", strcmp(s1, s4));  /* positive — 'a'(97) > 'A'(65) */

    /* Practical use: Password check */
    char password[20];
    printf("Enter password: ");
    scanf("%s", password);
    if (strcmp(password, "secret123") == 0) {
        printf("Access granted!\n");
    } else {
        printf("Wrong password!\n");
    }
    return 0;
}
Never Compare Strings with ==

In C, str1 == str2 compares the memory addresses of the strings, not their contents. This will almost always give wrong results. Always use strcmp() to compare string contents.

String Applications

Application 1 — Palindrome Check
#include <stdio.h>
#include <string.h>
int main() {
    char str[100], rev[100];
    printf("Enter a string: ");
    scanf("%s", str);

    strcpy(rev, str);
    int len = strlen(rev);

    /* Reverse the string */
    for (int i = 0; i < len / 2; i++) {
        char temp = rev[i];
        rev[i] = rev[len - 1 - i];
        rev[len - 1 - i] = temp;
    }

    if (strcmp(str, rev) == 0)
        printf("'%s' is a Palindrome.\n", str);
    else
        printf("'%s' is NOT a Palindrome.\n", str);
    return 0;
}
/* "MADAM" → reversed = "MADAM" → strcmp = 0 → Palindrome */
Application 2 — Extract Substring
#include <stdio.h>
#include <string.h>
/* Extract substring from position 'start' of length 'len' */
void extractSubstring(char *src, char *dest, int start, int len) {
    int i;
    for (i = 0; i < len && src[start + i] != '\0'; i++) {
        dest[i] = src[start + i];
    }
    dest[i] = '\0';   /* null terminate */
}

int main() {
    char str[] = "Computer Programming";
    char sub[20];

    /* Extract "Programming" (starts at index 9, length 11) */
    extractSubstring(str, sub, 9, 11);
    printf("Substring: %s\n", sub);    /* Programming */

    /* Extract first 8 chars "Computer" */
    extractSubstring(str, sub, 0, 8);
    printf("Left 8: %s\n", sub);       /* Computer */

    return 0;
}
Application 3 — Count Vowels and Consonants
#include <stdio.h>
#include <string.h>
#include <ctype.h>
int main() {
    char str[100];
    int vowels = 0, consonants = 0;
    printf("Enter a string: ");
    scanf("%s", str);

    for (int i = 0; str[i] != '\0'; i++) {
        char c = tolower(str[i]);   /* convert to lowercase for easy check */
        if (c >= 'a' && c <= 'z') {
            if (c=='a'||c=='e'||c=='i'||c=='o'||c=='u')
                vowels++;
            else
                consonants++;
        }
    }
    printf("Vowels = %d, Consonants = %d\n", vowels, consonants);
    return 0;
}
Application 4 — Replace Character in String
#include <stdio.h>
int main() {
    char str[] = "Hello World Hello";
    char find = 'l', replace = 'L';

    printf("Before: %s\n", str);
    for (int i = 0; str[i] != '\0'; i++) {
        if (str[i] == find)
            str[i] = replace;
    }
    printf("After:  %s\n", str);
    /* Output: HeLLo WorLd HeLLo */
    return 0;
}

Key Definitions

Array

A collection of a fixed number of elements of the same data type stored in contiguous memory locations, each identified by an index starting from 0.

Subscript / Index

The integer value used to identify and access a specific element of an array. Valid range is 0 to size-1.

String

A one-dimensional array of characters terminated by the null character '\0'. In C there is no separate string data type — strings are character arrays.

Null Terminator ('\0')

A special character with ASCII value 0 that marks the end of a string in C. All standard string functions rely on '\0' to determine string boundaries.

Row-Major Order

The memory storage order for 2D arrays in C where elements are stored row by row — all elements of row 0 first, then all of row 1, and so on.

strlen()

A standard library function in <string.h> that returns the number of characters in a string, excluding the null terminator '\0'.

Buffer Overflow

A security vulnerability that occurs when data written to a buffer (array) exceeds its allocated size, overwriting adjacent memory. Common with strcpy() when destination is too small.

Multiple Choice Questions

Q 1

What is the valid index range for an array declared as int arr[10]?

  • a. 1 to 10
  • b. 0 to 10
  • c. 0 to 9
  • d. 1 to 9
Answer: c. 0 to 9

Array indices in C always start from 0. For an array of size 10, valid indices are 0 through 9 (size-1). Accessing arr[10] is out-of-bounds and causes undefined behavior.

Q 2

What is the output of: char s[]="Hello"; printf("%lu", strlen(s));

  • a. 6
  • b. 5
  • c. 4
  • d. Compile error
Answer: b. 5

strlen() returns the number of characters EXCLUDING the null terminator '\0'. "Hello" has 5 characters (H,e,l,l,o), so strlen returns 5. The array size is 6 (5 + '\0') but strlen is 5.

Q 3

Which function is used to copy one string into another in C?

  • a. strdup()
  • b. strcopy()
  • c. strcpy()
  • d. strcp()
Answer: c. strcpy()

strcpy(destination, source) is the standard library function in <string.h> for copying strings. strcopy() and strcp() do not exist. strdup() is non-standard (POSIX).

Q 4

What does strcmp("apple", "apple") return?

  • a. 1
  • b. -1
  • c. 0
  • d. True
Answer: c. 0

strcmp() returns 0 when both strings are identical. It returns a negative value if the first string comes before the second lexicographically, and a positive value if after. It does NOT return true/false.

Q 5

How many bytes does char str[10] = "Hello"; occupy in memory?

  • a. 5 bytes
  • b. 6 bytes
  • c. 10 bytes
  • d. 11 bytes
Answer: c. 10 bytes

The array is declared with size 10, so it occupies 10 bytes regardless of the string length. The string "Hello" (5 chars + '\0') occupies 6 of those bytes; the remaining 4 are filled with '\0'.

Q 6

Which of the following correctly accesses element at row 2, column 3 of a 2D array mat?

  • a. mat[3][2]
  • b. mat[2,3]
  • c. mat[2][3]
  • d. mat(2)(3)
Answer: c. mat[2][3]

2D array elements are accessed using two separate square brackets: mat[row][col]. mat[2,3] is invalid syntax in C (comma operator would make it mat[3]). Parentheses are not used for array access.

Q 7

What character terminates every string in C?

  • a. '$'
  • b. '#'
  • c. '\n'
  • d. '\0'
Answer: d. '\0'

The null character '\0' (ASCII value 0) terminates every string in C. All standard string functions like strlen(), strcpy(), strcmp() rely on this character to determine where the string ends.

Q 8

What is the total number of elements in int arr[3][4]?

  • a. 7
  • b. 12
  • c. 34
  • d. 3
Answer: b. 12

Total elements in a 2D array = rows × columns = 3 × 4 = 12. Total memory = 12 × sizeof(int) = 12 × 4 = 48 bytes on a 32-bit system.

Q 9

Which function appends one string to the end of another?

  • a. strcpy()
  • b. strcat()
  • c. strcmp()
  • d. strlen()
Answer: b. strcat()

strcat(destination, source) appends the source string to the end of the destination string. strcpy copies, strcmp compares, strlen measures length.

Q 10

What is the output of: int arr[] = {1,2,3,4,5}; printf("%d", arr[2]);

  • a. 1
  • b. 2
  • c. 3
  • d. 4
Answer: c. 3

Array index 2 gives the third element (indices start at 0). arr[0]=1, arr[1]=2, arr[2]=3, arr[3]=4, arr[4]=5. So arr[2] = 3.

Q 11

What happens if you use == to compare two strings in C?

  • a. It compares string contents correctly
  • b. It compares memory addresses, not contents
  • c. Compile error
  • d. It compares only first characters
Answer: b. It compares memory addresses, not contents

In C, array names are pointers to the first element. Using == compares the addresses (pointers), not the actual string contents. Always use strcmp() to compare string contents.

Q 12

Which of the following is an incorrect way to initialize a string in C?

  • a. char s[] = "Hello";
  • b. char s[6] = "Hello";
  • c. char s[] = {'H','e','l','l','o','\0'};
  • d. char s[5] = "Hello";
Answer: d. char s[5] = "Hello";

This is incorrect because "Hello" requires 6 bytes (5 chars + '\0'). Declaring size as 5 leaves no room for the null terminator, causing undefined behavior. The size must be at least 6.

Short Answer Questions

Q 1

What is an array? List any four advantages of using arrays.

An array is a collection of a fixed number of elements of the same data type stored in contiguous memory locations, accessed using an index. Advantages: (1) Efficient storage — multiple values under one name; (2) Random access — any element in O(1) using index; (3) Easy traversal — single loop processes all elements; (4) Sorting/searching — standard operations easily applied.

Q 2

What is the difference between strlen() and sizeof() for character arrays?

strlen() is a function that returns the number of characters in the string content, excluding '\0'. sizeof() is an operator that returns the total memory size of the array in bytes. For char arr[20] = "Hello": strlen(arr) = 5 but sizeof(arr) = 20.

Q 3

Why is the null character '\0' important in C strings?

The null character '\0' (ASCII 0) marks the end of a string in C. Since C has no built-in string type, all string functions (strlen, strcpy, strcmp, printf with %s) rely on '\0' to know where the string ends. Without '\0', these functions would read past the end of the string, causing undefined behavior or crashes.

Q 4

What is the output of strcmp("Banana", "Apple") and why?

The output is a positive value. strcmp compares strings lexicographically. 'B' has ASCII value 66 and 'A' has 65. Since 'B' > 'A', "Banana" > "Apple", so strcmp returns a positive value (typically 1 or the difference of ASCII values).

Q 5

What is the difference between a 1D array and a 2D array? Give one example of each.

A 1D array is a linear list of elements accessed by a single index: int marks[5] — stores 5 marks. A 2D array is a matrix of elements arranged in rows and columns, accessed by two indices: int mat[3][3] — stores a 3×3 matrix. 2D arrays are used for tabular and matrix data.

Q 6

What is row-major order? How are elements of a 2D array stored in memory?

Row-major order means 2D array elements are stored in memory row by row. For int mat[2][3], the storage order is: mat[0][0], mat[0][1], mat[0][2], mat[1][0], mat[1][1], mat[1][2]. C uses row-major order (unlike FORTRAN which uses column-major order).

Q 7

What is the minimum size of an array to store the string "DIPLOMA"?

The string "DIPLOMA" has 7 characters. In C, every string must end with '\0', so the minimum array size is 8: char str[8]. Declaration: char str[8] = "DIPLOMA"; or char str[] = "DIPLOMA"; (auto-sizes to 8).

Q 8

Why can't we use = to assign a string to a character array after declaration?

After declaration, the array name is a constant pointer — it cannot be reassigned. The statement str = "Hello" tries to change the pointer (address), which is not allowed. The correct way to assign a string after declaration is to use strcpy(str, "Hello"), which copies characters one by one.

Q 1

Explain one-dimensional arrays in C with declaration, initialization, memory representation, and a complete program to find the largest and smallest elements.

A one-dimensional array is a linear sequence of elements of the same type stored contiguously in memory. Each element is accessed by a single integer index starting from 0.

Declaration: data_type name[size]; Example: int marks[5];

Initialization: int marks[5] = {85, 90, 78, 92, 88};

Memory: For int arr[5] at base address 1000 (int=4 bytes):

  • arr[0] at 1000, arr[1] at 1004, arr[2] at 1008, arr[3] at 1012, arr[4] at 1016
  • Formula: Address of arr[i] = 1000 + i × 4
Find Largest and Smallest
#include <stdio.h>
int main() {
    int arr[10], n, max, min;
    printf("Enter n: ");
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &arr[i]);

    max = min = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) max = arr[i];
        if (arr[i] < min) min = arr[i];
    }
    printf("Max = %d, Min = %d\n", max, min);
    return 0;
}

Q 3

Explain two-dimensional arrays in C. Write a program to perform matrix multiplication of two 3×3 matrices.

A two-dimensional array is an array of arrays representing a matrix. Elements are accessed with two indices: mat[row][col]. Stored in memory in row-major order.

Declaration: int mat[3][3]; — 3 rows, 3 columns, 9 elements.

Matrix Multiplication Rule: C[i][j] = sum of A[i][k] × B[k][j] for all k.

Matrix Multiplication
#include <stdio.h>
int main() {
    int A[3][3], B[3][3], C[3][3] = {0};

    printf("Enter Matrix A (3x3):\n");
    for(int i=0;i<3;i++) for(int j=0;j<3;j++) scanf("%d",&A[i][j]);

    printf("Enter Matrix B (3x3):\n");
    for(int i=0;i<3;i++) for(int j=0;j<3;j++) scanf("%d",&B[i][j]);

    /* Multiplication */
    for(int i=0;i<3;i++)
        for(int j=0;j<3;j++)
            for(int k=0;k<3;k++)
                C[i][j] += A[i][k] * B[k][j];

    printf("\nResult Matrix C = A×B:\n");
    for(int i=0;i<3;i++){
        for(int j=0;j<3;j++) printf("%6d", C[i][j]);
        printf("\n");
    }
    return 0;
}

Condition for multiplication: Columns of A must equal rows of B. For 3×3 matrices this is always satisfied.

Practice Problems

Q 1

Write a C program to reverse an array of n integers entered by the user and display the reversed array.

Solution
#include <stdio.h>
int main() {
    int arr[100], n, temp;
    printf("Enter n: ");
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &arr[i]);

    /* Reverse using two-pointer technique */
    int left = 0, right = n - 1;
    while (left < right) {
        temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;
        left++;
        right--;
    }

    printf("Reversed: ");
    for (int i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");
    return 0;
}

Q 2

Write a C program to check whether a string entered by the user is a palindrome or not (without using string library functions).

Solution
#include <stdio.h>
int main() {
    char str[100];
    int len = 0, isPalin = 1;

    printf("Enter a string: ");
    scanf("%s", str);

    /* Find length manually */
    while (str[len] != '\0') len++;

    /* Check palindrome */
    for (int i = 0; i < len / 2; i++) {
        if (str[i] != str[len - 1 - i]) {
            isPalin = 0;
            break;
        }
    }

    if (isPalin)
        printf("'%s' IS a palindrome.\n", str);
    else
        printf("'%s' is NOT a palindrome.\n", str);
    return 0;
}
/* "MADAM" → palindrome, "HELLO" → not palindrome */

Q 3

Write a C program to find the transpose of a 3×3 matrix.

Solution
#include <stdio.h>
int main() {
    int mat[3][3], trans[3][3];

    printf("Enter 3x3 matrix:\n");
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++)
            scanf("%d", &mat[i][j]);

    /* Transpose: swap row and column */
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++)
            trans[j][i] = mat[i][j];

    printf("\nOriginal Matrix:\n");
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) printf("%5d", mat[i][j]);
        printf("\n");
    }

    printf("\nTranspose Matrix:\n");
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) printf("%5d", trans[i][j]);
        printf("\n");
    }
    return 0;
}

Q 4

Write a C program to count the number of words, vowels, and consonants in a string entered by the user.

Solution
#include <stdio.h>
#include <ctype.h>
int main() {
    char str[200];
    int words = 0, vowels = 0, consonants = 0;
    int inWord = 0;

    printf("Enter a sentence: ");
    fgets(str, 200, stdin);

    for (int i = 0; str[i] != '\0'; i++) {
        char c = tolower(str[i]);

        /* Count words */
        if (c != ' ' && c != '\n' && c != '\t') {
            if (!inWord) { words++; inWord = 1; }
        } else {
            inWord = 0;
        }

        /* Count vowels and consonants */
        if (c >= 'a' && c <= 'z') {
            if (c=='a'||c=='e'||c=='i'||c=='o'||c=='u')
                vowels++;
            else
                consonants++;
        }
    }

    printf("Words = %d\nVowels = %d\nConsonants = %d\n",
           words, vowels, consonants);
    return 0;
}

Q 5

Write a C program to implement linear search on an array of integers. Display the index if found, or "Not found" if absent.

Solution
#include <stdio.h>
int linearSearch(int arr[], int n, int key) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == key) return i;   /* found at index i */
    }
    return -1;   /* not found */
}

int main() {
    int arr[100], n, key, result;
    printf("Enter n: ");
    scanf("%d", &n);
    printf("Enter %d elements: ", n);
    for (int i = 0; i < n; i++) scanf("%d", &arr[i]);

    scanf("%d", &key);

    if (result != -1)
        printf("%d found at index %d\n", key, result);
    else
        printf("%d not found in array\n", key);
    return 0;
}

Quick Revision Points — Unit 3
  • Array = collection of same type elements in contiguous memory.
  • Array index starts at 0, valid range is 0 to size-1.
  • C does NOT check bounds — out-of-bounds access = undefined behavior.
  • Address of arr[i] = Base + (i × sizeof(type)).
  • 2D array element: mat[row][col]. Total elements = rows × cols.
  • 2D arrays stored in row-major order in C.
  • String = char array terminated by '\0' (null character).
  • Array size for string must be at least length + 1 for '\0'.
  • scanf("%s", name) — no & needed for arrays.
  • strlen(s) — length excluding '\0'. sizeof(arr) — total array bytes.
  • strcpy(dest, src) — copies src to dest (dest must be large enough).
  • strcat(dest, src) — appends src to end of dest.
  • strcmp(s1, s2) — 0 if equal, <0 if s1<s2, >0 if s1>s2.
  • Cannot use == to compare strings — compares addresses, not content.
  • Cannot use = to assign string after declaration — use strcpy().
  • All string functions require #include <string.h>.
Must Remember for Exam
  • Array index starts at 0 — extremely common MCQ trap (choosing 1 to n instead of 0 to n-1).
  • String must end with '\0' — always allocate one extra byte for it.
  • strcmp returns 0 for equal strings — NOT 1 or true.
  • strlen does NOT count '\0' — this distinction is asked every year.
  • Address formula for 1D array and 2D array — asked in numerical questions.
  • Matrix multiplication condition: columns of A must equal rows of B.
  • Row-major order — C stores 2D arrays row by row (column-major is Fortran).
  • All 4 string functions: strlen, strcpy, strcat, strcmp — their purpose and return type.
Common Mistakes in Exams
  • Writing array size exactly equal to string length — missing space for '\0'.
  • Using &arr[i] for 2D arrays in scanf — correct is &mat[i][j].
  • Using scanf("%s", &name) instead of scanf("%s", name) — & not needed for arrays.
  • Thinking strcmp("abc","abc") returns 1 (true) — it returns 0.
  • Confusing strlen (5) with sizeof (6) for "Hello".
  • Accessing arr[n] instead of arr[n-1] for the last element.
  • Forgetting to initialize result matrix to 0 in matrix multiplication.
  • Using str1 == str2 to compare strings — always use strcmp().
