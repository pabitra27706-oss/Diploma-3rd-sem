Introduction to C & File Types

History and Evolution of C

C was developed by Dennis Ritchie at Bell Laboratories between 1969 and 1973. It was originally developed along with the UNIX operating system. C evolved from the earlier language B, which in turn came from BCPL. In 1989, the American National Standards Institute (ANSI) standardized C, creating ANSI C (C89). Later versions include C99, C11, and C17.

  • 1960s — BCPL created by Martin Richards
  • 1970 — B language created by Ken Thompson
  • 1972 — C language created by Dennis Ritchie
  • 1978 — "The C Programming Language" book published (K&R C)
  • 1989 — ANSI C standardized (C89/C90)
  • 1999 — C99 standard released
Advantages of Structured Programming

C is a structured programming language, which means programs are divided into well-defined functions/blocks. Advantages include:

  • Modularity — Program is divided into functions/modules, each solving one task.
  • Reusability — Functions can be called multiple times from different places.
  • Easier Debugging — Each module can be tested independently.
  • Easier Maintenance — Changes in one module do not affect others.
  • Readability — Structured code is easier to understand and follow.
Key Characteristics of C
  • Middle-Level Language — Combines features of both high-level and low-level languages.
  • Case-Sensitive — main and Main are different.
  • Efficient and Fast — Compiled directly to machine code.
  • Portable — Code written on one system can run on another with minimal changes.
  • Rich in Operators — Provides a wide variety of operators for complex expressions.
  • Structured — Supports functions, loops, and conditional statements.
  • Extensible — Can be extended by adding new features through libraries.

C Program Compilation Process

The journey from source code to executable involves four steps:

  1. Preprocessing — Handles directives like #include and #define. Produces expanded source code.
  2. Compilation — Converts preprocessed source code into assembly language. Checks for syntax errors.
  3. Assembly — Converts assembly code into machine code object files (.o / .obj).
  4. Linking — Combines object files and library files to produce the final executable (.exe).

Type Conversion and Typecasting

What is Type Conversion?

Type conversion is the process of converting one data type to another. In C, this happens in two ways: implicitly (automatically by the compiler) and explicitly (manually by the programmer).

Implicit Type Conversion (Type Promotion)

The compiler automatically converts a lower data type to a higher data type to avoid data loss. This follows the hierarchy:

Type Promotion Hierarchy
char → int → long → float → double → long double
Implicit Conversion Example
#include <stdio.h>
int main() {
    int i = 10;
    float f;
    f = i;          /* int automatically promoted to float */
    printf("%f\n", f);   /* Output: 10.000000 */

    int a = 5, b = 2;
    float result;
    result = a / b;      /* Integer division happens first! */
    printf("%f\n", result); /* Output: 2.000000 (NOT 2.5) */
    return 0;
}
Explicit Type Conversion (Typecasting)

The programmer manually forces the conversion of one data type to another using the cast operator.

Typecasting Syntax
(target_data_type) expression
Typecasting Example
#include <stdio.h>
int main() {
    int a = 5, b = 2;
    float result;

    /* Without typecast: integer division */
    result = a / b;
    printf("Without typecast: %f\n", result);  /* 2.000000 */

    /* With typecast: float division */
    result = (float) a / b;
    printf("With typecast: %f\n", result);     /* 2.500000 */

    /* Another example */
    float x = 9.7;
    int y = (int) x;   /* Truncates decimal part */
    printf("Typecasted: %d\n", y);             /* 9 */

    return 0;
}
Important Note

Typecasting does not round. It truncates the decimal part. So (int)9.9 gives 9, not 10.

Always use the address-of operator (&) before variable names in scanf(). Forgetting it is one of the most common bugs in C.

Key Definitions

Token

A token is the smallest individual meaningful unit in a C program. Examples: keywords, identifiers, constants, operators.

Identifier

An identifier is a user-defined name given to a variable, function, array, or any user-defined entity. Must start with a letter or underscore, and cannot be a keyword.

Keyword

A keyword is a reserved word in C that has a predefined meaning and cannot be used as an identifier. C has 32 keywords (e.g., int, float, if, for, return).

Constant

A constant is a value that does not change during the execution of a program. Types: integer constants, floating-point constants, character constants, string constants.

Operator Precedence

Operator precedence defines the order in which operators are evaluated in an expression. Operators with higher precedence are evaluated before operators with lower precedence.

Associativity

Associativity defines the order of evaluation when two operators have the same precedence. It can be Left-to-Right or Right-to-Left.

Typecasting

Typecasting (explicit type conversion) is the process of manually converting a value of one data type into another using the cast operator, written as (type) value.

Structured Programming

Structured programming is a programming paradigm that uses functions, loops, and conditionals to create clear, modular, and readable code. It avoids the use of goto statements.

Multiple Choice Questions

Q 1

C language was developed by:

  • a. James Gosling
  • b. Dennis Ritchie
  • c. Bjarne Stroustrup
  • d. Ken Thompson
Answer: b. Dennis Ritchie

C was developed by Dennis Ritchie at Bell Laboratories between 1969–1973. Ken Thompson developed B, and James Gosling developed Java.

Q 2

Which of the following is NOT a valid C keyword?

  • a. float
  • b. extern
  • c. integer
  • d. static
Answer: c. integer

integer is not a C keyword. The correct keyword is int. All others — float, extern, static — are valid C keywords.

Q 3

What is the output of the following code?
int a = 5; printf("%d", a++);

  • a. 6
  • b. 5
  • c. 4
  • d. Compile error
Answer: b. 5

Post-increment (a++) uses the current value (5) first in the expression, then increments. So printf prints 5, and after that a becomes 6.

Q 4

What is the result of (float) 7 / 2 in C?

  • a. 3
  • b. 3.0
  • c. 3.5
  • d. Error
Answer: c. 3.5

The typecast (float) converts 7 to 7.0 before division. So 7.0 / 2 = 3.5. Without typecast, 7 / 2 = 3 (integer division).

Q 5

Which format specifier is used to print a hexadecimal value in C?

  • a. %h
  • b. %o
  • c. %x
  • d. %b
Answer: c. %x

%x prints lowercase hexadecimal, %X prints uppercase hexadecimal. %o prints octal. C does not have a %b specifier for binary.

Q 6

What does the sizeof() operator return for int on a 32-bit system?

  • a. 1
  • b. 2
  • c. 4
  • d. 8
Answer: c. 4

On a 32-bit system, sizeof(int) = 4 bytes. On older 16-bit systems it was 2 bytes. sizeof(char) = 1, sizeof(double) = 8.

Q 7

The result of 12 & 10 (bitwise AND) is:

  • a. 22
  • b. 8
  • c. 14
  • d. 2
Answer: b. 8

12 = 1100₂, 10 = 1010₂. Bitwise AND: 1100 & 1010 = 1000₂ = 8 in decimal.

Q 8

Which of the following is the correct way to read an integer using scanf()?

  • a. scanf("%d", num);
  • b. scanf("%d", &num);
  • c. scanf(num);
  • d. scanf("%i" num);
Answer: b. scanf("%d", &num);

scanf() requires the address of the variable using the & operator. Without &, undefined behavior occurs as scanf won't know where to store the input.

Q 9

What is the value of 5 << 2?

  • a. 10
  • b. 20
  • c. 40
  • d. 80
Answer: b. 20

Left shift by n positions = multiply by 2ⁿ. So 5 << 2 = 5 × 2² = 5 × 4 = 20. Binary: 101 becomes 10100 = 20.

Q 10

Which file type contains function prototypes and macro definitions in C?

  • a. .c file
  • b. .obj file
  • c. .h file
  • d. .exe file
Answer: c. .h file

Header files (.h) contain function prototypes, macro definitions, and constants. They are included using the #include directive. For example, stdio.h contains the printf() and scanf() prototypes.

Short Answer Questions

Q 1

What is a token in C? Name any four types of tokens.

A token is the smallest meaningful unit in a C program that the compiler can recognize. The four types of tokens are: Keywords (int, float), Identifiers (variable names), Constants (25, 3.14), and Operators (+, -, *, /).

Q 2

What is the difference between = and == in C?

= is the assignment operator — it assigns the value on the right to the variable on the left (e.g., a = 5). == is the equality/relational operator — it compares two values and returns 1 (true) or 0 (false) (e.g., a == 5). Using = instead of == in a condition is a common and dangerous bug.

Q 3

What is type casting in C? Give one example.

Typecasting is the explicit (manual) conversion of one data type to another using the cast operator. Syntax: (type) expression. Example: float result = (float)5 / 2; gives 2.5 instead of 2 (which integer division would give).

Q 4

What is the modulus operator and on what data types does it work?

The modulus operator % returns the remainder after integer division. For example, 10 % 3 = 1 (since 10 = 3×3 + 1). It works only on integer data types (int, long, char). Using % with float or double causes a compile-time error.

Q 5

Name the four types of files used in a C program and their extensions.

The four file types are: Source file (.c) — contains the C source code; Header file (.h) — contains prototypes and macros; Object file (.o or .obj) — machine code produced by compiler; Executable file (.exe) — final runnable program produced by the linker.

Q 6

What is the difference between a pre-increment (++a) and post-increment (a++) operator?

In pre-increment (++a), the variable is incremented first and then the new value is used in the expression. In post-increment (a++), the current value is used in the expression first, and then the variable is incremented. Example: If a=5, then b = ++a gives b=6, a=6; but b = a++ gives b=5, a=6.

Q 7

Why is the & operator required in scanf()? What happens if it is omitted?

The & (address-of) operator is required in scanf() because scanf() needs to know the memory address of the variable where the input should be stored. If & is omitted, the variable's value (not its address) is passed to scanf(), causing a runtime error or undefined behavior (the program may crash or produce wrong results).

Q 8

What are the advantages of structured programming?

Advantages of structured programming: (1) Modularity — program divided into functions; (2) Reusability — functions can be reused; (3) Easier debugging — each module tested independently; (4) Better readability — code is clear and organized; (5) Easier maintenance — changes in one module don't affect others.

Long Answer Questions (6 Marks)

Q 1

Explain all the operator types available in C with examples for each. Include arithmetic, relational, logical, assignment, increment/decrement, bitwise, ternary, and special operators.

C provides a rich set of operators. Here is a summary of each type:

1. Arithmetic Operators (+, -, *, /, %):
Used for mathematical calculations. Example: a + b, a % b. Note: % works only on integers.

2. Relational Operators (==, !=, <, >, <=, >=):
Compare two values and return 0 or 1. Example: 5 > 3 returns 1.

3. Logical Operators (&&, ||, !):
Combine conditions. Example: (a>0 && b>0) is true only if both are positive.

4. Assignment Operators (=, +=, -=, etc.):
Assign values. Example: a += 5 is same as a = a + 5.

5. Increment/Decrement (++, --):
Increase or decrease by 1. Pre (++a) increments first; Post (a++) uses value first.

6. Bitwise Operators (&, |, ^, ~, <<, >>):
Work on individual bits. Example: 12 & 10 = 8 (1100 & 1010 = 1000).

7. Ternary Operator (?:):
Shorthand for if-else. Example: max = (a>b) ? a : b;

8. Special Operators (sizeof, comma, &, *):
sizeof returns byte size of a type. Comma evaluates multiple expressions. & gives address, * dereferences.

Complete Example
#include <stdio.h>
int main() {
    int a = 10, b = 3;
    printf("Arithmetic: %d %d %d %d %d\n", a+b, a-b, a*b, a/b, a%b);
    printf("Relational: %d %d\n", a==b, a>b);
    printf("Logical: %d %d\n", (a>0 && b>0), !0);
    printf("Ternary: %d\n", (a>b) ? a : b);
    printf("Bitwise AND: %d\n", a & b);
    printf("Sizeof int: %lu\n", sizeof(int));
    return 0;
}

Q 2

Explain the C compilation process from source code to executable. Describe each step with the file types involved. Also explain the different file types (.c, .h, .o, .exe) used in C programming.

The compilation process in C involves four stages:

Step 1: Preprocessing
The preprocessor handles all directives starting with #. It expands #include files, replaces #define macros, and removes comments. The output is an expanded source file with .i extension.

Step 2: Compilation
The compiler converts preprocessed code into assembly language. This stage checks for syntax errors. Output: .s file (assembly code).

Step 3: Assembly
The assembler converts assembly code into machine code (binary). Output: .o or .obj (object file). Object files are not yet executable.

Step 4: Linking
The linker combines one or more object files with library files (like stdio library) to produce the final executable. Output: .exe (Windows) or no extension (Linux/Mac).

StageInputOutputTool
Preprocessing.c file.i filecpp (C Preprocessor)
Compilation.i file.s filecc1 (Compiler)
Assembly.s file.o / .obj fileas (Assembler)
Linking.o + libraries.exe fileld (Linker)

File Types in C:

  • .c (Source File) — Contains the actual C program written by the programmer.
  • .h (Header File) — Contains function prototypes, macros, and type definitions. Included using #include.
  • .o / .obj (Object File) — Machine code produced by the compiler. Not directly executable. Needs to be linked.
  • .exe (Executable File) — The final ready-to-run program produced by the linker.

Q 3

Explain implicit and explicit type conversion in C with examples. What are the rules of type promotion in C? What are the risks of type mismatch?

Type Conversion is the process of converting a value from one data type to another. C supports two types:

1. Implicit Type Conversion (Type Promotion):
Performed automatically by the compiler without any instruction from the programmer. It converts a "lower" type to a "higher" type to prevent data loss.

Type Promotion Order
char → int → long → float → double → long double
Implicit Conversion
int i = 10;
float f = i;     /* int promoted to float: f = 10.0 */
double d = f;    /* float promoted to double */

/* Danger: */
int a = 5, b = 2;
float result = a / b;   /* Integer division FIRST: result = 2.0 NOT 2.5 */

2. Explicit Type Conversion (Typecasting):
The programmer manually specifies the conversion using the cast operator (type).

Explicit Conversion (Typecasting)
int a = 5, b = 2;
float result = (float)a / b;  /* 5.0 / 2 = 2.5 — correct! */

float x = 9.99;
int y = (int)x;               /* Truncation: y = 9 (NOT rounded) */

char c = 'A';
int ascii = (int)c;           /* ASCII value: 65 */

Risks of Type Mismatch:

  • Data Loss — Converting float to int loses the decimal part.
  • Overflow — Assigning a large value to a smaller type causes unexpected results.
  • Wrong Calculations — Integer division when float result is expected.
  • Sign Issues — Converting signed to unsigned can produce large unexpected positive numbers.

Practice Problems

Q 1

Write a C program that takes two integers as input from the user, then displays: their sum, difference, product, quotient, and remainder. Also display the average as a float.

Solution
#include <stdio.h>
int main() {
    int a, b;
    printf("Enter two integers: ");
    scanf("%d %d", &a, &b);

    printf("Sum        = %d\n", a + b);
    printf("Difference = %d\n", a - b);
    printf("Product    = %d\n", a * b);
    printf("Quotient   = %d\n", a / b);
    printf("Remainder  = %d\n", a % b);
    printf("Average    = %.2f\n", (float)(a + b) / 2);

    return 0;
}

Key concept used: Typecasting with (float) to get decimal average.

Q 2

Write a C program to demonstrate the size of all primary data types using the sizeof() operator. Also demonstrate pre-increment and post-increment operators.

Solution
#include <stdio.h>
int main() {
    /* Sizes of data types */
    printf("=== Size of Data Types ===\n");
    printf("Size of char   : %lu bytes\n", sizeof(char));
    printf("Size of int    : %lu bytes\n", sizeof(int));
    printf("Size of float  : %lu bytes\n", sizeof(float));
    printf("Size of double : %lu bytes\n", sizeof(double));
    printf("Size of long   : %lu bytes\n", sizeof(long));

    /* Increment operators */
    printf("\n=== Increment Operators ===\n");
    int x = 10, y;

    y = ++x;  /* Pre-increment */
    printf("Pre-increment:  x = %d, y = %d\n", x, y);

    x = 10;   /* Reset */
    y = x++;  /* Post-increment */
    printf("Post-increment: x = %d, y = %d\n", x, y);

    return 0;
}

Q 3

Write a C program to find the maximum of three numbers entered by the user using the ternary operator.

Solution
#include <stdio.h>
int main() {
    int a, b, c, max;

    printf("Enter three integers: ");
    scanf("%d %d %d", &a, &b, &c);

    /* Find max of a and b first */
    max = (a > b) ? a : b;

    /* Compare max with c */
    max = (max > c) ? max : c;

    printf("Maximum of %d, %d, %d = %d\n", a, b, c, max);
    return 0;
}

Concept: Nested ternary operator usage for multi-value comparison.

Quick Revision

Quick Revision Points — Unit 1
  • C was developed by Dennis Ritchie at Bell Labs in 1972.
  • C is a middle-level, case-sensitive, structured programming language.
  • C has 32 keywords — they cannot be used as identifiers.
  • A token is the smallest unit: keywords, identifiers, constants, operators, string literals, punctuators.
  • The four file types: .c (source), .h (header), .o/.obj (object), .exe (executable).
  • Compilation stages: Preprocessing → Compilation → Assembly → Linking.
  • Primary data types: int (4 bytes), float (4 bytes), double (8 bytes), char (1 byte).
  • Format specifiers: %d (int), %f (float), %c (char), %s (string), %x (hex), %o (octal).
  • Implicit conversion = automatic by compiler (lower to higher type).
  • Explicit conversion = manual typecasting using (type).
  • Pre-increment (++a): increment first, use later. Post-increment (a++): use first, increment later.
  • Ternary operator: condition ? true_value : false_value. Only 3-operand operator in C.
  • Left shift << n = multiply by 2ⁿ. Right shift >> n = divide by 2ⁿ.
  • scanf() requires & before variable names (except arrays/strings).
  • Modulus operator % works only with integers.
Must Remember for Exam
  • C was developed by Dennis Ritchie — this is asked in almost every exam.
  • 32 keywords in C — int, float, char, double, void, if, else, for, while, do, switch, case, break, continue, return, goto, struct, union, enum, typedef, static, extern, auto, register, const, volatile, signed, unsigned, short, long, sizeof, default.
  • Post-increment vs Pre-increment — a very common 2-mark and MCQ topic.
  • Operator precedence — unary > arithmetic > relational > logical > assignment.
  • scanf with & — always required for scalar variables. One of the most tested topics.
  • 5 / 2 = 2 (integer division) but (float)5 / 2 = 2.5 — typecasting changes behavior.
  • sizeof(int) = 4 bytes on 32-bit/64-bit; sizeof(char) = 1 byte always.
Common Mistakes in Exams
  • Writing integer instead of int — integer is NOT a C keyword.
  • Forgetting & in scanf() calls — a classic bug.
  • Confusing = (assignment) with == (comparison) in conditions.
  • Using % with float — it only works with integers in C.
  • Thinking (int)9.9 = 10 — wrong! Typecasting truncates, it does NOT round. Answer is 9.
  • Confusing pre and post increment: b = ++a and b = a++ give different results when a=5.
  • Thinking left shift always doubles — it only works for unsigned values; signed overflow is undefined.
  • Writing printf("%d", a, b); with two values but only one format specifier — only a will be printed.
