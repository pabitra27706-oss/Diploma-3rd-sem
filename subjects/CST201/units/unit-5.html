What You Will Learn

Unit 5 is the most critical and most difficult unit in C programming. Pointers are variables that store memory addresses rather than values. They are the foundation of dynamic memory allocation, efficient array handling, call by reference, and data structures like linked lists and trees. Mastering pointers is essential for systems programming, embedded programming, and technical interviews. Pointers are powerful but dangerous. A small mistake with pointers can cause: segmentation faults (crashes), memory leaks (wasted memory), dangling pointers (pointing to freed memory), and undefined behavior. Understanding pointers requires visualizing memory addresses and indirection. Practice is absolutely essential.

Understanding Pointers

What is a Pointer?

A pointer is a variable that stores the memory address of another variable. Instead of storing a value like 10 or 'A', a pointer stores the location in memory where that value is stored. Pointers allow indirect access to data and enable powerful programming techniques like dynamic memory allocation and efficient array manipulation.

Memory Address Visualization

Every variable in a C program is stored at a specific memory location. Each location has a unique numeric address. Think of memory as a large apartment building where each apartment has a number (address) and contains a value.

Address: 1000
int x
Value: 50
Address: 2000
int *p
Value: 1000

p stores the address 1000, which is where x lives. We say p points to x.

Why Use Pointers?
  • Call by Reference — Modify original variables inside functions.
  • Dynamic Memory — Allocate memory at runtime using malloc/calloc.
  • Efficient Array Handling — Traverse arrays without copying.
  • Data Structures — Essential for linked lists, trees, graphs.
  • String Manipulation — Efficient processing of character arrays.
  • Return Multiple Values — Functions can modify multiple variables via pointers.
  • Low-Level Control — Direct memory access for systems programming.

Declaring and Accessing Pointers

The Two Critical Operators

Complete Pointer Example — Declaration, Assignment, Access
#include <stdio.h>
int main() {
    int x = 50;         /* normal variable */
    int *p;             /* pointer to int — declared but uninitialized */

    p = &x;             /* p now stores the ADDRESS of x */

    printf("Value of x        : %d\n", x);      /* 50 */
    printf("Address of x      : %p\n", &x);     /* e.g., 0x7ffd5e3c */
    printf("Value of p (addr) : %p\n", p);      /* same as &x */
    printf("Value at *p       : %d\n", *p);     /* 50 — dereferenced */

    /* Modify x through pointer */
    *p = 100;           /* changes the value at address stored in p */
    printf("\nAfter *p = 100:\n");
    printf("Value of x        : %d\n", x);      /* 100 — changed! */
    printf("Value at *p       : %d\n", *p);     /* 100 */

    return 0;
}
Memory Trace

Common Pointer Mistakes
  • Uninitialized Pointer — Using a pointer before assigning it an address causes undefined behavior (crash). 
    int *p;   /* p contains garbage address */
*p = 10;  /* DANGER — writes to random memory! */
  • Confusing * in declaration vs usage — int *p; declares a pointer. *p = 10; uses dereference.
  • Forgetting & when assigning — p = x; is wrong. Correct: p = &x;.

Types of Pointers

1. Null Pointer

A null pointer is a pointer that points to nothing — it does not hold any valid memory address. It is represented by the macro NULL (defined as 0 or (void*)0 in <stdio.h>).

Null Pointer Usage
#include <stdio.h>
int main() {
    int *p = NULL;      /* p initialized to null — safe */

    if (p == NULL) {
        printf("Pointer is null — not pointing anywhere\n");
    }

    /* NEVER dereference a null pointer */
    /* *p = 10;  — CRASH! Segmentation fault */

    int x = 50;
    p = &x;             /* now p points to valid memory */

    if (p != NULL) {
        printf("Now safe to use: *p = %d\n", *p);  /* 50 */
    }
    return 0;
}
Best Practice

Always initialize pointers to NULL if you don't have a valid address yet. Always check if (p != NULL) before dereferencing in production code to prevent crashes.

2. Void Pointer (Generic Pointer)

A void pointer is a special pointer type that can point to any data type. Declared as void *ptr. It cannot be dereferenced directly — it must be typecast to a specific type first.

Void Pointer Example
#include <stdio.h>
int main() {
    int x = 10;
    float f = 3.14;
    char c = 'A';

    void *ptr;          /* generic pointer */

    ptr = &x;           /* points to int */
    printf("Int value: %d\n", *(int*)ptr);  /* must typecast */

    ptr = &f;           /* now points to float */
    printf("Float value: %.2f\n", *(float*)ptr);

    ptr = &c;           /* now points to char */
    printf("Char value: %c\n", *(char*)ptr);

    /* Cannot do: printf("%d", *ptr);  — ERROR: void* cannot be dereferenced */
    return 0;
}
Use Cases of Void Pointers
  • Generic functions like malloc(), memcpy(), qsort() return void*.
  • Callback functions that accept any data type.
  • Implementing generic data structures.

#include <stdio.h>
int main() {
    int x = 10, y = 20;

    /* Pointer to constant */
    const int *p1 = &x;
    /* *p1 = 50;  — ERROR: cannot modify value */
    p1 = &y;       /* OK — can change where it points */

    *p2 = 50;      /* OK — can modify value */
    /* p2 = &y;   — ERROR: cannot change pointer address */

    /* Constant pointer to constant */
    const int *const p3 = &x;
    /* *p3 = 50;  — ERROR */
    /* p3 = &y;   — ERROR */

    return 0;
}

Pointer Arithmetic

What is Pointer Arithmetic?

Pointer arithmetic allows you to perform mathematical operations on pointers. When you increment a pointer, it moves to the next element of its type, not the next byte. The pointer moves by sizeof(data_type) bytes.

Valid Pointer Arithmetic Operations
  • Increment — ptr++ or ++ptr → moves to next element
  • Decrement — ptr-- or --ptr → moves to previous element
  • Addition — ptr + n → moves n elements forward
  • Subtraction — ptr - n → moves n elements backward
  • Difference — ptr2 - ptr1 → number of elements between two pointers
  • Comparison — ptr1 == ptr2, ptr1 < ptr2, etc.
Invalid Operations

You cannot: multiply pointers (ptr * 2), divide pointers (ptr / 2), or add two pointers (ptr1 + ptr2).

Pointer Arithmetic Example
#include <stdio.h>
int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int *p = arr;      /* p points to arr[0] */

    printf("Initial: *p = %d, address = %p\n", *p, p);  /* 10, e.g., 1000 */

    p++;               /* moves to next int (4 bytes forward) */
    printf("After p++: *p = %d, address = %p\n", *p, p); /* 20, 1004 */

    p += 2;            /* moves 2 ints forward (8 bytes) */
    printf("After p+=2: *p = %d, address = %p\n", *p, p); /* 40, 1012 */

    p--;               /* moves 1 int backward */
    printf("After p--: *p = %d, address = %p\n", *p, p); /* 30, 1008 */

    /* Pointer difference */
    int *start = &arr[0];
    int *end = &arr[4];
    printf("\nDifference: %ld elements\n", end - start); /* 4 */

    return 0;
}
Pointer Arithmetic Formula
New Address = Current Address + (n × sizeof(data_type))
Example: int *p at 1000, p+3 → 1000 + (3×4) = 1012

Pointers and Functions

Passing Pointers to Functions

Passing pointers to functions enables call by reference — the function can modify the original variables in the calling function. This is the only way in C to have a function modify multiple variables or modify an array.

Call by Reference — Swap Function
#include <stdio.h>

void swap(int *a, int *b) {     /* receives addresses */
    int temp = *a;
    *a = *b;                     /* modify original via pointers */
    *b = temp;
}

int main() {
    int x = 10, y = 20;
    printf("Before swap: x = %d, y = %d\n", x, y);  /* 10, 20 */
    swap(&x, &y);                /* pass addresses */
    printf("After swap:  x = %d, y = %d\n", x, y);  /* 20, 10 */
    return 0;
}
Function Modifying Multiple Values via Pointers
#include <stdio.h>

void calculate(int a, int b, int *sum, int *diff, int *prod) {
    *sum = a + b;
    *diff = a - b;
    *prod = a * b;
}

int main() {
    int s, d, p;
    calculate(20, 5, &s, &d, &p);  /* pass addresses */
    printf("Sum = %d, Diff = %d, Product = %d\n", s, d, p);
    /* Sum = 25, Diff = 15, Product = 100 */
    return 0;
}
Returning Pointer to Local Variable — DANGER!
WRONG — Dangling Pointer
int* badFunction() {
    int x = 10;     /* local variable on stack */
    return &x;       /* DANGER — x destroyed after return */
}

int main() {
    int *p = badFunction();
    printf("%d", *p);  /* UNDEFINED BEHAVIOR — x no longer exists */
    return 0;
}

Why it's wrong: Local variable x is destroyed when the function returns. The pointer points to freed memory (dangling pointer). Dereferencing it causes undefined behavior — may crash or print garbage.

Correct Solutions
  • Return pointer to dynamically allocated memory using malloc().
  • Return pointer to static variable (lifetime = program).
  • Return pointer to global variable.
  • Have the caller pass a pointer to modify.

Pointers and Arrays

Array Name is a Pointer

In C, the array name is a constant pointer to the first element of the array. For int arr[5];, the name arr is equivalent to &arr[0] — both give the address of the first element.

Array-Pointer Equivalences
Array NotationPointer NotationMeaning
arr&arr[0]Address of first element
arr[i]*(arr + i)Value at index i
&arr[i](arr + i)Address of element at index i
arr[0]*arrFirst element value
Array Access via Pointers
#include <stdio.h>
int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int *p = arr;       /* p points to arr[0] */

    /* Array notation vs Pointer notation */
    printf("arr[0] = %d,  *arr = %d\n", arr[0], *arr);       /* 10, 10 */
    printf("arr[2] = %d,  *(arr+2) = %d\n", arr[2], *(arr+2)); /* 30, 30 */

    /* Traversing array using pointer */
    printf("\nUsing pointer to traverse:\n");
    for (int i = 0; i < 5; i++) {
        printf("arr[%d] = %d = *(p+%d) = %d\n", i, arr[i], i, *(p+i));
    }

    /* Pointer arithmetic */
    printf("\nPointer arithmetic:\n");
    printf("*p     = %d\n", *p);      /* 10 */
    printf("*(p+1) = %d\n", *(p+1));  /* 20 */
    printf("*(p+4) = %d\n", *(p+4));  /* 50 */

    return 0;
}
Passing Array to Function (Always Call by Reference)
#include <stdio.h>

/* Arrays are ALWAYS passed by reference (as pointers) */
void modifyArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        arr[i] *= 2;    /* modifies original array */
    }
}

/* Equivalent declaration using pointer notation */
void modifyArray2(int *arr, int n) {
    for (int i = 0; i < n; i++) {
        *(arr + i) *= 2;
    }
}

int main() {
    int nums[] = {1, 2, 3, 4, 5};

    printf("Before: ");
    for (int i = 0; i < 5; i++) printf("%d ", nums[i]);

    modifyArray(nums, 5);   /* array name is a pointer */

    printf("\nAfter:  ");
    for (int i = 0; i < 5; i++) printf("%d ", nums[i]);
    printf("\n");
    /* Output: 2 4 6 8 10 — original array modified */

    return 0;
}
Key Difference: Array Name vs Pointer Variable
  • Array name (arr) is a constant pointer — you cannot do arr++ or arr = &x.
  • Pointer variable (int *p) can be reassigned — you can do p++, p = arr, etc.
Demonstration
int arr[5] = {1,2,3,4,5};
int *p = arr;

p++;        /* OK — pointer variable can be modified */
/* arr++;   ERROR — array name is constant pointer */

Pointers and Strings

Strings are Character Arrays

In C, strings are character arrays terminated by '\0'. A character pointer char *p can point to a string. String literals are stored in read-only memory.

String Declaration: Array vs Pointer
#include <stdio.h>
int main() {
    /* Method 1: Character array */
    char str1[] = "Hello";      /* Array — modifiable, stack */
    str1[0] = 'h';               /* OK — can modify */

    /* Method 2: Character pointer */
    char *str2 = "World";        /* Pointer to string literal — read-only */
    /* str2[0] = 'w';  — DANGER — may crash (segfault) */

    printf("%s\n", str1);        /* hello */
    printf("%s\n", str2);        /* World */

    return 0;
}
Array vs Pointer for Strings
Featurechar str[] = "Hi";char *str = "Hi";
StorageStack (local array)Pointer to read-only memory
Modifiable?YesNo (undefined behavior)
Can reassign?No (array name constant)Yes (pointer variable)
Memory6 bytes for "Hi\0"Pointer size (4 or 8 bytes)
Traversing String Using Pointer
#include <stdio.h>
int main() {
    char str[] = "DIPLOMA";
    char *p = str;

    /* Traverse using pointer */
    printf("Characters: ");
    while (*p != '\0') {
        printf("%c ", *p);
        p++;                /* move to next character */
    }
    printf("\n");

    /* Another method */
    p = str;                /* reset pointer */
    for (p = str; *p != '\0'; p++) {
        printf("%c", *p);
    }
    printf("\n");

    return 0;
}
Custom strlen() Using Pointer
#include <stdio.h>

int myStrlen(char *s) {
    int len = 0;
    while (*s != '\0') {
        len++;
        s++;
    }
    return len;
}

int main() {
    char name[] = "Computer";
    printf("Length of '%s' = %d\n", name, myStrlen(name));  /* 8 */
    return 0;
}

Array of Pointers

What is an Array of Pointers?

An array of pointers is an array where each element is a pointer. Most commonly used for storing multiple strings efficiently.

Declaration Syntax
data_type *array_name[size];

/* Example */
int *ptr_arr[5];        /* array of 5 pointers to int */
char *names[10];        /* array of 10 pointers to char (strings) */
Array of Pointers — Storing Strings
#include <stdio.h>
int main() {
    /* Array of pointers to strings */
    char *days[] = {
        "Monday",
        "Tuesday",
        "Wednesday",
        "Thursday",
        "Friday",
        "Saturday",
        "Sunday"
    };

    printf("Days of the week:\n");
    for (int i = 0; i < 7; i++) {
        printf("%d. %s\n", i+1, days[i]);
    }

    /* Access individual characters */
    printf("\nFirst char of Wednesday: %c\n", days[2][0]);  /* W */
    printf("Third char of Friday: %c\n", days[4][2]);       /* i */

    return 0;
}
Memory Layout of Array of Pointers

For char *names[] = {"Alice", "Bob", "Charlie"};

names[0] → pointer → "Alice\0" (stored in read-only memory) names[1] → pointer → "Bob\0" (stored in read-only memory) names[2] → pointer → "Charlie\0" (stored in read-only memory) Each pointer (4 or 8 bytes) points to the first character of each string. The strings themselves are stored separately in memory.
Array of Integer Pointers
#include <stdio.h>
int main() {
    int a = 10, b = 20, c = 30, d = 40;
    int *ptr[4];        /* array of 4 int pointers */

    ptr[0] = &a;
    ptr[1] = &b;
    ptr[2] = &c;
    ptr[3] = &d;

    printf("Values using array of pointers:\n");
    for (int i = 0; i < 4; i++) {
        printf("*ptr[%d] = %d\n", i, *ptr[i]);
    }

    /* Modify through pointers */
    *ptr[0] = 100;      /* changes a to 100 */
    printf("\nAfter modification: a = %d\n", a);  /* 100 */

    return 0;
}

Function Pointers

What is a Function Pointer?

A function pointer is a pointer that stores the address of a function. It can be used to call the function indirectly. Useful for callback functions, implementing function tables, and polymorphism.

Function Pointer Syntax
return_type (*pointer_name)(parameter_types);

/* Example */
int (*func_ptr)(int, int);    /* pointer to function taking 2 ints, returning int */
void (*callback)(char*);      /* pointer to function taking char*, returning void */
Function Pointer Example
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}

int multiply(int a, int b) {
    return a * b;
}

int main() {
    int (*operation)(int, int);   /* function pointer declaration */

    /* Point to add function */
    operation = add;              /* or operation = &add; */
    printf("10 + 5 = %d\n", operation(10, 5));  /* 15 */

    /* Point to subtract function */
    operation = subtract;
    printf("10 - 5 = %d\n", operation(10, 5));  /* 5 */

    /* Point to multiply function */
    operation = multiply;
    printf("10 * 5 = %d\n", operation(10, 5));  /* 50 */

    return 0;
}
Array of Function Pointers (Calculator)
#include <stdio.h>

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }
int dvd(int a, int b) { return a / b; }

int main() {
    /* Array of function pointers */
    int (*operations[4])(int, int) = {add, sub, mul, dvd};
    char *symbols[] = {"+", "-", "*", "/"};

    int a = 20, b = 5;

    printf("Calculator using function pointers:\n");
    for (int i = 0; i < 4; i++) {
        printf("%d %s %d = %d\n", a, symbols[i], b, operations[i](a, b));
    }

    return 0;
}
/* Output:
   20 + 5 = 25
   20 - 5 = 15
   20 * 5 = 100
   20 / 5 = 4
*/

Pointer to Pointer (Double Pointer)

What is a Pointer to Pointer?

A pointer to pointer (double pointer) is a pointer that stores the address of another pointer. Declared with **. Used in dynamic 2D arrays, command line arguments, and modifying pointer values inside functions.

Syntax
data_type **pointer_name;

/* Example */
int **pp;      /* pointer to pointer to int */
char **argv;   /* pointer to pointer to char (used in main) */
Pointer to Pointer Example
#include <stdio.h>
int main() {
    int x = 50;
    int *p = &x;        /* p points to x */
    int **pp = &p;      /* pp points to p */

    printf("Value of x:        %d\n", x);       /* 50 */
    printf("Value using *p:    %d\n", *p);      /* 50 */
    printf("Value using **pp:  %d\n", **pp);    /* 50 */

    printf("\nAddress of x:     %p\n", &x);
    printf("Value of p (addr): %p\n", p);       /* same as &x */
    printf("Value of pp:       %p\n", pp);      /* address of p */

    /* Modify x through double pointer */
    **pp = 100;
    printf("\nAfter **pp = 100:\n");
    printf("x = %d\n", x);                       /* 100 */

    return 0;
}
Memory Visualization
Variable Address Value ──────────────────────────────── x 1000 50 p 2000 1000 (points to x) pp 3000 2000 (points to p) Access chains: x → 50 *p → value at 1000 → 50 **pp → value at (value at 3000) → value at 2000 → value at 1000 → 50
Pointer to Pointer — Modify Pointer Inside Function
#include <stdio.h>
#include <stdlib.h>

void allocate(int **ptr, int value) {
    *ptr = (int*)malloc(sizeof(int));  /* allocate memory */
    **ptr = value;                      /* set value */
}

int main() {
    int *p = NULL;

    allocate(&p, 99);   /* pass address of pointer */

    if (p != NULL) {
        printf("Value allocated: %d\n", *p);  /* 99 */
        free(p);
    }

    return 0;
}

Dynamic Memory Allocation

What is Dynamic Memory Allocation?

Dynamic memory allocation allows you to allocate memory at runtime from the heap instead of compile-time from the stack. Size can be determined during execution. Essential for data structures like linked lists, trees, and graphs. Requires manual deallocation using free().

Stack vs Heap Memory
FeatureStack MemoryHeap Memory
AllocationCompile-time (automatic)Runtime (manual using malloc/calloc)
DeallocationAutomatic when function returnsManual using free()
SizeFixed at compile timeCan be determined at runtime
LifetimeFunction scope onlyUntil explicitly freed
Access speedFasterSlower
Size limitSmall (typically 1-8 MB)Large (limited by system RAM)
RiskStack overflowMemory leak if not freed
malloc() — Memory Allocation

Allocates a block of memory of specified size in bytes. Does NOT initialize the memory — contains garbage values. Returns void* which must be typecast. Returns NULL if allocation fails.

Syntax
void* malloc(size_t size);

/* Usage */
int *ptr = (int*) malloc(n * sizeof(int));
char *str = (char*) malloc(100 * sizeof(char));
malloc() Example
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;
    printf("Enter number of elements: ");
    scanf("%d", &n);

    /* Allocate memory for n integers */
    int *arr = (int*) malloc(n * sizeof(int));

    if (arr == NULL) {
        printf("Memory allocation failed!\n");
        return 1;
    }

    /* Use the allocated memory */
    printf("Enter %d elements:\n", n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }

    printf("You entered: ");
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    /* Free the allocated memory */
    free(arr);
    arr = NULL;     /* good practice — avoid dangling pointer */

    return 0;
}
calloc() — Contiguous Allocation

Allocates memory for an array of elements and initializes all bytes to zero. Takes two arguments: number of elements and size of each element.

Syntax
void* calloc(size_t num_elements, size_t element_size);

/* Usage */
int *ptr = (int*) calloc(n, sizeof(int));  /* n ints, all initialized to 0 */
calloc() Example
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *arr = (int*) calloc(5, sizeof(int));

    if (arr == NULL) {
        printf("Allocation failed!\n");
        return 1;
    }

    printf("Array initialized by calloc:\n");
    for (int i = 0; i < 5; i++) {
        printf("arr[%d] = %d\n", i, arr[i]);  /* All 0s */
    }

    free(arr);
    return 0;
}
realloc() — Resize Allocated Memory

Changes the size of previously allocated memory block. Can expand or shrink. Preserves existing data. May move the block to a new location if needed.

Syntax
void* realloc(void *ptr, size_t new_size);

/* Usage */
ptr = (int*) realloc(ptr, new_size * sizeof(int));
realloc() Example
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *arr = (int*) malloc(3 * sizeof(int));

    arr[0] = 10; arr[1] = 20; arr[2] = 30;

    printf("Original array: %d %d %d\n", arr[0], arr[1], arr[2]);

    /* Resize to hold 5 elements */
    arr = (int*) realloc(arr, 5 * sizeof(int));

    if (arr == NULL) {
        printf("Reallocation failed!\n");
        return 1;
    }

    arr[3] = 40; arr[4] = 50;

    printf("After realloc:  ");
    for (int i = 0; i < 5; i++) printf("%d ", arr[i]);
    printf("\n");

    free(arr);
    return 0;
}
free() — Deallocate Memory

Key Definitions

Pointer

A variable that stores the memory address of another variable rather than a data value. Declared with * operator.

Dereference

The operation of accessing the value at the address stored in a pointer using the * operator. Also called indirection.

Null Pointer

A pointer that does not point to any valid memory location. Initialized with NULL (defined as 0). Dereferencing a null pointer causes a crash.

Void Pointer

A generic pointer type (void*) that can point to any data type. Cannot be dereferenced directly — must be typecast first. Used by malloc/calloc.

Dangling Pointer

A pointer that points to memory that has been freed or deallocated. Dereferencing it causes undefined behavior. Set pointers to NULL after free() to avoid this.

Memory Leak

A situation where dynamically allocated memory is not freed using free(), causing the program to waste memory that cannot be reclaimed until the program ends.

Dynamic Memory Allocation

The process of allocating memory at runtime from the heap using malloc(), calloc(), or realloc(). Memory must be manually freed using free().

Pointer Arithmetic

Mathematical operations (increment, decrement, addition, subtraction) performed on pointers. The pointer moves by multiples of sizeof(data_type), not bytes.

Double Pointer

A pointer to a pointer (declared with **). Stores the address of another pointer. Used in dynamic 2D arrays and modifying pointers inside functions.

Function Pointer

A pointer that stores the address of a function. Can be used to call the function indirectly. Useful for callbacks and implementing function tables.

Multiple Choice Questions

Q 1

What does the & operator do in C?

  • a. Multiplies two numbers
  • b. Returns the memory address of a variable
  • c. Returns the value at an address
  • d. Performs bitwise AND
Answer: b. Returns the memory address of a variable

The & (address-of) operator returns the memory address of a variable. Example: &x gives the address where x is stored. Option d is partially correct (& is also bitwise AND) but in pointer context, it's the address-of operator.

Q 2

What is the output of: int x=10; int *p=&x; printf("%d", *p);?

  • a. Address of x
  • b. 10
  • c. Address of p
  • d. Garbage value
Answer: b. 10

*p dereferences the pointer p, which returns the value stored at the address p holds. Since p points to x, *p gives the value of x, which is 10.

Q 3

If int *p points to an integer at address 1000, what will p+2 point to (assuming int size is 4 bytes)?

  • a. 1002
  • b. 1004
  • c. 1008
  • d. 2000
Answer: c. 1008

Pointer arithmetic: p+2 moves 2 elements forward = 1000 + (2 × 4) = 1008. The pointer moves by sizeof(int) × 2, not by 2 bytes.

Q 4

Which function is used to allocate memory and initialize it to zero?

  • a. malloc()
  • b. calloc()
  • c. realloc()
  • d. alloc()
Answer: b. calloc()

calloc() allocates memory and initializes all bytes to zero. malloc() allocates but does NOT initialize (contains garbage). realloc() resizes already allocated memory. alloc() does not exist in standard C.

Q 5

What is a null pointer?

  • a. A pointer that points to address 0
  • b. A pointer with garbage value
  • c. A pointer that does not point to any valid memory
  • d. Both a and c
Answer: d. Both a and c

A null pointer is initialized with NULL (which is defined as 0 or (void*)0). It represents a pointer that points to nothing/nowhere. Dereferencing it causes a crash.

Q 6

What happens if you forget to call free() after malloc()?

  • a. Compile error
  • b. Runtime crash
  • c. Memory leak
  • d. Nothing
Answer: c. Memory leak

Not calling free() causes a memory leak — the allocated memory is never returned to the system. Over time, repeated leaks can exhaust available memory. The OS reclaims it only when the program terminates.

Q 7

What is the size of a pointer variable on a 64-bit system?

  • a. 2 bytes
  • b. 4 bytes
  • c. 8 bytes
  • d. Depends on the data type it points to
Answer: c. 8 bytes

On a 64-bit system, all pointers are 8 bytes regardless of the type they point to. On 32-bit systems, pointers are 4 bytes. The size is determined by the system architecture, not the pointed-to type.

Q 8

Which of the following is equivalent to arr[3] in C?

  • a. *(arr + 3)
  • b. *arr + 3
  • c. &arr[3]
  • d. arr + 3
Answer: a. *(arr + 3)

arr[3] is exactly equivalent to *(arr + 3). Both access the element at index 3. Option b (*arr + 3) adds 3 to the first element's value. Option c gives the address. Option d gives a pointer, not the value.

Q 9

What type of pointer can point to any data type?

  • a. int*
  • b. char*
  • c. void*
  • d. double*
Answer: c. void*

void* is a generic pointer that can point to any data type. It must be typecast before dereferencing. malloc() and calloc() return void* for this reason.

Q 10

What is a dangling pointer?

  • a. A pointer with NULL value
  • b. A pointer pointing to freed memory
  • c. A pointer to a pointer
  • d. An uninitialized pointer
Answer: b. A pointer pointing to freed memory

A dangling pointer points to memory that has been freed or deallocated. Dereferencing it causes undefined behavior. To avoid, set pointers to NULL after calling free().

Q 11

Which function is used to resize dynamically allocated memory?

  • a. malloc()
  • b. calloc()
  • c. realloc()
  • d. resize()
Answer: c. realloc()

realloc() changes the size of a previously allocated memory block. It can expand or shrink the block. If expansion is needed, it may move the block to a new location and copy existing data.

Q 12

What is the correct way to declare a pointer to a pointer to an integer?

  • a. int *p;
  • b. int **p;
  • c. int ***p;
  • d. int p**;
Answer: b. int **p;

int **p declares a pointer to a pointer to an integer (double pointer). The ** indicates two levels of indirection. Used for dynamic 2D arrays and modifying pointers inside functions.

Q 13

What does malloc() return if memory allocation fails?

  • a. 0
  • b. NULL
  • c. -1
  • d. Garbage value
Answer: b. NULL

If malloc() or calloc() cannot allocate the requested memory (e.g., not enough RAM), they return NULL. Always check if the returned pointer is NULL before using it to prevent crashes.

Q 14

Which operator is used to access structure members through a pointer?

  • a. .
  • b. ->
  • c. ::
  • d. *
Answer: b. ->

The -> operator is used to access structure members through a pointer. If s is a pointer to a structure, s->member is equivalent to (*s).member. The . operator is used for direct structure access.

Q 15

What is the difference between int *p[5] and int (*p)[5]?

  • a. No difference
  • b. First is array of pointers, second is pointer to array
  • c. First is pointer to array, second is array of pointers
  • d. Both are invalid
Answer: b. First is array of pointers, second is pointer to array

int *p[5] is an array of 5 pointers to int. int (*p)[5] is a pointer to an array of 5 integers. Parentheses change the precedence: [] binds before * in the first case.

Short Answer Questions

Q 1

What is a pointer? How is it different from a normal variable?

A pointer is a variable that stores the memory address of another variable instead of a data value. Declared with * operator. A normal variable stores a value (like 10, 'A'), while a pointer stores an address (like 1000, 2004). Pointers allow indirect access to data and enable dynamic memory allocation.

Q 2

What are the & and * operators? Explain with an example.

& (address-of) — Returns the memory address of a variable. Example: int x=10; &x gives the address where x is stored.

* (dereference/indirection) — Accesses the value at the address stored in a pointer. Example: int *p=&x; *p gives the value 10.

Together: p = &x; makes p point to x. *p = 20; changes x to 20.

Q 3

What is pointer arithmetic? Explain with an example.

Pointer arithmetic allows mathematical operations on pointers. When you increment a pointer, it moves to the next element of its type, not the next byte. The pointer moves by sizeof(data_type) bytes.

Example: int arr[] = {10,20,30}; int *p = arr;
p points to arr[0] at address 1000. p++ moves to arr[1] at 1004 (4 bytes forward). p+2 points to arr[2] at 1008.

Q 4

What is a null pointer? Why is it used?

A null pointer is a pointer that points to nothing, initialized with NULL (defined as 0). It is used to: (1) initialize pointers when no valid address is available yet; (2) check if a pointer has been assigned; (3) avoid accidental dereferencing of uninitialized pointers. Dereferencing a null pointer causes a segmentation fault (crash).

Q 5

What is dynamic memory allocation? Name the functions used for it.

Dynamic memory allocation is the process of allocating memory at runtime from the heap instead of compile-time from the stack. The size can be determined during program execution. Functions used: malloc() — allocate memory; calloc() — allocate and initialize to zero; realloc() — resize allocated memory; free() — deallocate memory.

Q 6

What is the difference between malloc() and calloc()?

malloc() — Takes 1 argument (total bytes); does NOT initialize memory (contains garbage); faster. Syntax: malloc(n * sizeof(type)).

calloc() — Takes 2 arguments (count, size each); initializes all bytes to zero; slower due to initialization. Syntax: calloc(n, sizeof(type)).

Use calloc() when you need zero-initialized memory; use malloc() otherwise for speed.

Q 7

What is a dangling pointer? How can you avoid it?

A dangling pointer is a pointer that points to memory that has been freed or deallocated. Dereferencing it causes undefined behavior (crash or garbage data). To avoid: (1) Set pointer to NULL after calling free(); (2) Never return address of local variables from functions; (3) Always check if pointer is NULL before dereferencing.

Q 8

What is a void pointer? When is it used?

A void pointer (void*) is a generic pointer that can point to any data type. It cannot be dereferenced directly — must be typecast first. Used by: (1) malloc() and calloc() which return void*; (2) Generic functions that accept any pointer type; (3) Implementing generic data structures.

Q 9

What is the relationship between arrays and pointers in C?

In C, the array name is a constant pointer to the first element. For int arr[5];, arr is equivalent to &arr[0]. Key relationships: arr[i] = *(arr+i); &arr[i] = (arr+i). Arrays are always passed to functions as pointers (call by reference). The difference: array name cannot be reassigned; pointer variables can.

Q 10

What is a memory leak? How can it be prevented?

A memory leak occurs when dynamically allocated memory is not freed using free(), causing the program to waste memory that cannot be reclaimed. Over time, this can exhaust available RAM. Prevention: (1) Always call free() for every malloc()/calloc(); (2) Set pointers to NULL after freeing; (3) Use tools like Valgrind to detect leaks.

Q 1

Explain pointers in C with declaration, initialization, and a complete program demonstrating pointer usage with variables and arrays.

A pointer is a variable that stores the memory address of another variable. It enables indirect access to data and is essential for dynamic memory allocation and efficient programming.

Declaration: data_type *pointer_name; Example: int *p;

Initialization: p = &variable; assigns the address of variable to p.

Dereferencing: *p accesses the value at the address stored in p.

int main() {

    printf("Value in p = %p\n", p);      /* same as &x */
    printf("Value at *p = %d\n", *p);    /* 50 */

    *p = 100;           /* modify x through pointer */
    printf("After *p=100, x = %d\n", x); /* 100 */

    /* Pointer with array */
    int arr[] = {10, 20, 30, 40};
    int *ptr = arr;     /* ptr points to arr[0] */

    printf("\nArray elements:\n");
    for (int i = 0; i < 4; i++) {
        printf("arr[%d] = %d = *(ptr+%d) = %d\n", 
               i, arr[i], i, *(ptr+i));
    }

Q 2

Explain dynamic memory allocation in C. Describe malloc(), calloc(), realloc(), and free() with syntax and examples.

Dynamic Memory Allocation allows allocating memory at runtime from the heap. All functions are in <stdlib.h>.

1. malloc() — Allocates memory of specified size; does NOT initialize.

malloc() Example
int *p = (int*) malloc(5 * sizeof(int));
if (p == NULL) { printf("Failed\n"); return 1; }
for (int i=0; i<5; i++) p[i] = i*10;
free(p);

2. calloc() — Allocates and initializes to zero.

calloc() Example
int *p = (int*) calloc(5, sizeof(int));
/* All 5 elements are 0 */

3. realloc() — Resizes previously allocated memory.

realloc() Example
int *p = malloc(3 * sizeof(int));
p = (int*) realloc(p, 6 * sizeof(int));  /* now 6 elements */

4. free() — Releases allocated memory.

free(p);
p = NULL;  /* prevent dangling pointer */

Common mistakes: Memory leak (not calling free), dangling pointer (using after free), double free.

Q 3

Explain pointer arithmetic in C with examples. Show how pointers are used to traverse an array.

Pointer arithmetic allows increment, decrement, addition, subtraction, and comparison operations on pointers. When a pointer is incremented, it moves to the next element of its type, not the next byte.

Formula: New Address = Current Address + (n × sizeof(data_type))

Pointer Arithmetic Example
#include <stdio.h>
int main() {
    int arr[] = {100, 200, 300, 400, 500};
    int *p = arr;

    printf("Initial: *p = %d, address = %p\n", *p, p);

    p++;  /* move to next int */
    printf("After p++: *p = %d, address = %p\n", *p, p);

    p += 2;  /* move 2 ints forward */
    printf("After p+=2: *p = %d\n", *p);  /* 400 */

    /* Traverse array using pointer */
    p = arr;  /* reset */
    printf("\nTraversing array:\n");
    for (int i = 0; i < 5; i++) {
        printf("*(p+%d) = %d\n", i, *(p+i));
    }

    /* Using pointer increment */
    p = arr;
    while (p < arr + 5) {
        printf("%d ", *p);
        p++;
    }
    printf("\n");

    return 0;
}
