Understanding Pointers

What a Pointer Is, and What & and * Do

A pointer is a variable whose value is a memory address. A normal variable stores data; a pointer stores where that data lives. &x gives you that address and *p follows it to read or write the cell at the other end — they undo each other, so *&x is just x. That one indirection buys call by reference, runtime-sized arrays and every data structure built from links.

Writing Through a Pointer, and the Two Increment Forms
#include <stdio.h>

int main(void)
{
    int x = 42;
    int *p = &x;                  /* p holds the address of x  */
    int arr[3] = {10, 20, 30};
    int *q = arr;                 /* array name decays to &arr[0] */

    printf("x = %d, *p = %d\n", x, *p);
    *p = 7;                       /* write through the pointer */
    printf("after *p = 7, x = %d\n", x);

    printf("(*q)++ returns %d", (*q)++);   /* value, then cell   */
    printf(", arr[0] now %d\n", arr[0]);

    printf("*q++ returns %d", *q++);       /* cell, then pointer */
    printf(", q now points at %d\n", *q);
    return 0;
}
/* x = 42, *p = 42
   after *p = 7, x = 7
   (*q)++ returns 10, arr[0] now 11
   *q++ returns 11, q now points at 20 */
*q++, (*q)++ and *++q

++ binds tighter than *, so *q++ means *(q++): read the current cell, then advance the pointer. (*q)++ increments the value and leaves the pointer alone. *++q advances first and reads the next cell.

Declaring and Accessing Pointers

Pointers: Type Checking, Scale Factor and *p++ Evaluation Order

The declaration is data_type *name; — the * belongs to the variable, not the type, which is why int *a, b; declares one pointer and one plain int. & yields an address; unary * yields the value at one.

Declare, Assign, Dereference
#include <stdio.h>

int main(void)
{
    int x = 50;
    int *p;                 /* declared, points at nothing yet */
    p = &x;                 /* now p stores the address of x   */

    printf("%d %d\n", x, *p);      /* 50 50 - two routes to one cell */
    *p = 100;                      /* write through the pointer      */
    printf("%d %d\n", x, *p);      /* 100 100 - x really changed     */

    int y = 7, *q = &y, z = 9;    /* q is a pointer, z is an int    */
    printf("%d %d\n", *q, z);      /* 7 9                            */
    return 0;
}
/* 50 50
   100 100
   7 9 */

Base-Type Compatibility Is Not Optional

int *p may only hold the address of an int; putting a float * in it makes the compiler read sizeof(int) bytes at the target and misinterpret half a float. That is why void * exists — it is the one pointer type with no width, so malloc can return it for every caller.

Pointer Arithmetic and the Scale Factor

Adding 1 to a pointer adds sizeof(*p), not 1, so it lands exactly on the next element of its own type: addr(p + k) = addr(p) + k * sizeof(*p). For a 4-byte int, p + 5 from 1000 gives 1020; where int is 2 bytes the same expression gives 1010. Pointers and Arrays runs this over a real array.

a[i] Is Literally *(a + i)

The compiler rewrites subscripting as pointer offset before generating code, which is why a[i], *(a + i) and even i[a] are the same expression. The difference is that a is a non-modifiable lvalue — a++ will not compile, p++ will.

Types of Pointers

NULL, void *, Wild and Dangling

Four pointer states account for almost every crash, and the table in Declaring and Accessing Pointers already lists how each one fails. Two of them are worth writing out as programmes because the compiler will not warn you: the void * cast, and the check that keeps a malloc result safe.

NULL as a Guard, and void * as a Generic Handle
#include <stdio.h>

int main(void)
{
    int x = 10, y = 0;
    void *v;                      /* holds any address, knows no type */

    v = &x;
    printf("%d\n", *(int *)v);    /* 10 - cast before dereferencing   */

    v = &y;
    *(int *)v = 99;               /* writes through the same handle   */
    printf("%d\n", y);            /* 99                               */

    int *p = NULL;
    if (p == NULL)                /* never dereference it here        */
        printf("p is null, refusing to read\n");
    return 0;
}
/* 10
   99
   p is null, refusing to read */
void * Does Not Mean "Any Type"

It means "an address whose target type has been forgotten". The compiler cannot compute *v + 1 because it does not know the width, so it refuses — that refusal is the feature. Cast to the real type first, and the scale factor comes back. This is precisely why malloc can return void * for every caller.

Pointer Arithmetic

The mechanics are covered under Pointers: Type Checking, Scale Factor and *p++ Evaluation Order — step size, the legal/illegal table and the 1000 → 1020 worked examples all live there, next to the memory diagram. Two exam-specific consequences are worth keeping separately.

Difference Gives Elements, Not Bytes

&a[4] - &a[0] is 4, not 16, because the compiler divides by sizeof(int) for you. If a question asks how many bytes separate two int pointers four elements apart, the answer is 4 × 4 = 16 — but the expression itself yields the element count. Mixing the two up is the most common lost mark in this subsection.

Every Exam Arithmetic Question in One Sentence

Multiply the step by sizeof(*p), add it to the starting address, and only then answer — and remember that subtracting two pointers of the same array cancels that multiplication again.

Pointers and Functions

Call by Reference — and Why Returning &local Fails

Passing an address is the only way a C function can modify its caller's variables. Inside the function the parameter is a copy of the address, so writing through it reaches the original cell.

Swap, and Three Results From One Function
#include <stdio.h>

void swap(int *a, int *b)
{
    int t = *a;  *a = *b;  *b = t;     /* writes to the caller's cells */
}

void stats(int a, int b, int *sum, int *diff)
{
    *sum = a + b;  *diff = a - b;
}

int main(void)
{
    int x = 10, y = 20, s = 0, d = 0;

    swap(&x, &y);                       /* pass addresses, not values */
    printf("x = %d, y = %d\n", x, y);    /* 20, 10                     */

    stats(20, 5, &s, &d);
    printf("sum = %d, diff = %d\n", s, d);   /* 25, 15 */
    return 0;
}
/* x = 20, y = 10
   sum = 25, diff = 15 */

Never Return the Address of a Local

int *make(void) { int t = 5; return &t; } compiles with a warning and then hands back a dangling pointer: t lives in the frame that the return destroys, so the caller reads whatever overwrites it next. Return one of three things instead — a pointer the caller passed in, a static variable (whose lifetime is the whole program), or a malloc block (which the caller must free).

Pointers and Arrays

Accessing and Summing Arrays Using Pointers

An array name decays to the address of its first element, so int *p = a; needs no &. From then on a[i], *(a + i) and p[i] are three spellings of one expression. The programme below is the one the paper asks for: display every element through the pointer, then sum them the same way.

The four equivalences worth memorising

a&a[0]Address of the first element
a[i]*(a + i)The value at index i
&a[i]a + iThe address of index i
a[i][j]*(*(a + i) + j)Row i, column j of a 2D array
Add Two Numbers, Then Traverse and Sum a 1D Array
#include <stdio.h>

int add(int *a, int *b) { return *a + *b; }

int sum(int *p, int n)
{
    int s = 0, i;
    for (i = 0; i < n; i++)
        s += *(p + i);          /* pointer form of a[i] */
    return s;
}

int main(void)
{
    int x = 12, y = 30;
    int a[5] = {10, 20, 30, 40, 50};
    int i, *p = a;

    printf("%d\n", add(&x, &y));        /* 42                    */

    for (i = 0; i < 5; i++)
        printf("%d ", *(a + i));         /* 10 20 30 40 50        */
    printf("\n");

    printf("sum = %d\n", sum(a, 5));     /* 150                   */
    printf("p[2] = %d, *p = %d\n", p[2], *p);
    return 0;
}
/* 42
   10 20 30 40 50
   sum = 150
   p[2] = 30, *p = 10 */
The Array Name Is Not a Variable

a is a non-modifiable lvalue: a++ and a = p are both compile errors, and sizeof(a) is the whole array (20 bytes) rather than a pointer size. Once you copy the address into p, all three change — p++ moves, p = a is legal, and sizeof(p) is 8. That single swap is what makes pointer traversal possible.

Pointers and Strings

A string literal lives in read-only memory and has type char[]. Assign it to an array and you get a private, writable copy; assign it to a pointer and you get a name for the original, which must not be written to.

char s[] = "Hi";char *s = "Hi";

One Arrow-Loop Over a String
#include <stdio.h>

int main(void)
{
    char s[] = "DIPLOMA";
    const char *p = s;      /* read-only view of the array */
    int n = 0;

    while (*p != '\0') {    /* stop at the terminator      */
        printf("%c", *p++); /* print, then advance         */
        n++;
    }
    printf("  (%d chars)\n", n);
    return 0;
}
/* DIPLOMA  (7 chars) */

Array of Pointers

char *names[3] is an array of three pointers, each pointing at a string stored elsewhere. That is why the rows may have different lengths — the array holds addresses, not characters. Brackets bind tighter than *, so char *names[3] and char (*names)[3] are different animals.

Ragged Strings, and the Parenthesis Trap
#include <stdio.h>

int main(void)
{
    const char *days[] = {"Mon", "Tuesday", "Wed"};
    int grid[2][3] = {{1,2,3},{4,5,6}};
    int (*row)[3] = grid;      /* ONE pointer to an array of 3 ints */

    printf("%d %d %d\n", days[0][0], days[1][1], days[2][2]);
    printf("%d pointers, %d bytes each\n",
           (int)(sizeof days / sizeof days[0]), (int)sizeof days[0]);
    printf("%d %d\n", row[1][0], (*row)[2]);
    return 0;
}
/* 77 117 100
   3 pointers, 8 bytes each
   4 3 */
*p[5] versus (*p)[5]

int *p[5] is five pointers to int, so sizeof p is five pointer-widths. int (*p)[5] is one pointer to an array of five ints. Parentheses override the rule that [] wins, and the second form is how a whole row of a 2D array travels as one argument.

Function Pointers

A function has an address too, so a pointer can hold it. The declaration mirrors the function's prototype with the name in parentheses: int (*op)(int, int). Calling through the pointer is identical to calling the function, and op(3, 4) and (*op)(3, 4) mean the same thing.

A Callback in Six Lines
#include <stdio.h>

int add(int x, int y) { return x + y; }
int apply(int (*op)(int, int), int x, int y) { return op(x, y); }

int main(void)
{
    int (*fp)(int, int) = add;      /* point at the function */

    printf("%d\n", fp(3, 4));       /* 7 - call through it   */
    printf("%d\n", (*fp)(3, 4));    /* 7 - the * is optional */
    printf("%d\n", apply(add, 5, 6));   /* 11 - passed as a value */
    return 0;
}
/* 7
   7
   11 */

Pointer to Pointer, Structures and Unions

Pointers to Structures and Unions Memory Size

int **pp = &p; holds the address of a pointer, so reaching the value takes two dereferences. The same ** is what a function needs when it must change a pointer in its caller. Structures add a shortcut: sp->x means (*sp).x, and the arrow is never optional when sp is a pointer.

Double Indirection, ->, and Why a Union Is One Size
#include <stdio.h>

struct point { int x; int y; };

union u { int i; char c; double d; };   /* members share storage */

int main(void)
{
    int x = 50;
    int *p = &x;
    int **pp = &p;

    printf("%d %d %d\n", x, *p, **pp);       /* 50 50 50        */
    **pp = 100;                             /* writes through both */
    printf("%d\n", x);                      /* 100             */

    struct point pt = {3, 4};
    struct point *sp = &pt;

    printf("%d %d\n", sp->x, (*sp).x);      /* 3 3 - same field */
    sp->x = 30;
    printf("%d\n", pt.x);                   /* 30 - it is the struct */

    printf("%d %d\n", (int)sizeof(struct point), (int)sizeof(union u));
    return 0;
}
/* 50 50 50
   100
   3 3
   30
   8 8 */
struct versus union — the one-mark answer
structunion
Storage per memberEvery member gets its own bytesAll members overlap the same bytes
Total sizeSum of members, plus paddingSize of the largest member, plus padding
Setting one fieldLeaves the others untouchedOverwrites the shared bytes — only one is valid at a time
Examplestruct point = 4 + 4 = 8union u = max(4, 1, 8) = 8
Why the Union Total Is the Largest Member

A union reserves one block big enough for its widest member; every member is just a different reading of those same bytes. That is why sizeof(union u) above is 8 (the double) and not 4 + 1 + 8 = 13. It is also why a union is the classic way to store "one of several" values without wasting space.

Dynamic Memory Allocation

malloc, calloc, realloc and free

Automatic variables live on the stack and die when their function returns. Arrays whose size is only known at runtime live on the heap, which you ask for explicitly and must give back by hand. `` provides exactly four calls for that, and this subsection is the single largest source of marks in the unit.

The Full Lifecycle: malloc → realloc → free
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 3, i;
    int *p = malloc(n * sizeof *p);        /* uninitialised block */

    if (p == NULL) {                        /* always check        */
        printf("allocation failed\n");
        return 1;
    }
    for (i = 0; i < n; i++) p[i] = (i + 1) * 10;

    int *q = realloc(p, 5 * sizeof *p);     /* grow to 5 elements  */
    if (q == NULL) { free(p); return 1; }   /* old block still live */
    p = q;                                   /* adopt the new block */

    for (i = 3; i < 5; i++) p[i] = (i + 1) * 10;
    for (i = 0; i < 5; i++) printf("%d ", p[i]);
    printf("\n");

    free(p);
    p = NULL;                                /* no dangling pointer */
    printf("freed: p = %s\n", p == NULL ? "NULL" : "dangling");
    return 0;
}
/* 10 20 30 40 50
   freed: p = NULL */
calloc Zeroes, malloc Does Not
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int i;
    int *a = calloc(4, sizeof *a);        /* zero-filled */
    int *b = malloc(4 * sizeof *b);       /* garbage     */

    for (i = 0; i < 4; i++) b[i] = 1;     /* make b usable */
    printf("calloc: %d %d %d %d\n", a[0], a[1], a[2], a[3]);
    printf("malloc after writing 1s: %d\n", b[0]);
    free(a);
    free(b);
    return 0;
}
/* calloc: 0 0 0 0
   malloc after writing 1s: 1 */
The Four Dynamic-Memory Mistakes
  • No NULL check. malloc returns NULL on failure; dereferencing it crashes.
  • Leak. Losing the only pointer without free — the block stays reserved for the life of the process.
  • Double free. Calling free twice on the same address corrupts the allocator; set the pointer to NULL after the first call.
  • Overwriting realloc's original. p = realloc(p, n) leaks the old block when it returns NULL — always assign through a temporary, as above.

Key Formulas and Syntax

The Four Formulas

Address step — addr(p + k) = addr(p) + k * sizeof(*p)
Element distance — p2 - p1 = elements between, ((char*)p2 - (char*)p1) / sizeof(*p1) = bytes
Subscript — a[i] ≡ *(a + i) and &a[i] ≡ (a + i)
Allocation size — malloc(n * sizeof *p) or calloc(n, sizeof *p); a string of L characters needs L + 1

Pointer Size Is a Property of the Machine

sizeof(p) is 4 on a 32-bit build and 8 on a 64-bit build — regardless of whether p points at a char or a double. It stores an address, and every address is the same width.

Key Definitions

Ten Terms, One Line Each
  • Pointer — a variable holding the address of another variable, declared with *.
  • Dereference — reading the value at an address, with unary *; also called indirection.
  • Null pointer — holds NULL and points at nothing; dereferencing it crashes.
  • Void pointer — void *, holds any address but must be cast before use; what malloc returns.
  • Wild pointer — declared but never given an address, so it holds garbage.
  • Dangling pointer — still holds an address whose memory has been freed.
  • Memory leak — a heap block that is still reserved but no longer reachable.
  • Dynamic memory allocation — reserving heap memory at runtime, and releasing it with free.
  • Double pointer — **pp, an address that leads to another address; needed to modify a pointer inside a function.
  • Function pointer — stores a function's entry address, used for callbacks and dispatch tables.

Multiple Choice Questions

Q 1

What does the & operator do in C?

  • a. Multiplies two numbers
  • b. Returns the memory address of a variable
  • c. Returns the value at an address
  • d. Performs bitwise AND
Answer: b. Returns the memory address of a variable

The & (address-of) operator returns the memory address of a variable. Example: &x gives the address where x is stored. Option d is partially correct (& is also bitwise AND) but in pointer context, it's the address-of operator.

Q 2

If int *p points to an integer at address 1000, what will p+2 point to (assuming int size is 4 bytes)?

  • a. 1002
  • b. 1004
  • c. 1008
  • d. 2000
Answer: c. 1008

Pointer arithmetic: p+2 moves 2 elements forward = 1000 + (2 × 4) = 1008. The pointer moves by sizeof(int) × 2, not by 2 bytes.

Q 3

Which function is used to allocate memory and initialize it to zero?

  • a. malloc()
  • b. calloc()
  • c. realloc()
  • d. alloc()
Answer: b. calloc()

calloc() allocates memory and initializes all bytes to zero. malloc() allocates but does NOT initialize (contains garbage). realloc() resizes already allocated memory. alloc() does not exist in standard C.

Q 4

What happens if you forget to call free() after malloc()?

  • a. Compile error
  • b. Runtime crash
  • c. Memory leak
  • d. Nothing
Answer: c. Memory leak

Not calling free() causes a memory leak — the allocated memory is never returned to the system. Over time, repeated leaks can exhaust available memory. The OS reclaims it only when the program terminates.

Q 5

Which of the following is equivalent to arr[3] in C?

  • a. *(arr + 3)
  • b. *arr + 3
  • c. &arr[3]
  • d. arr + 3
Answer: a. *(arr + 3)

arr[3] is exactly equivalent to *(arr + 3). Both access the element at index 3. Option b (*arr + 3) adds 3 to the first element's value. Option c gives the address. Option d gives a pointer, not the value.

Q 6

What type of pointer can point to any data type?

  • a. int*
  • b. char*
  • c. void*
  • d. double*
Answer: c. void*

void* is a generic pointer that can point to any data type. It must be typecast before dereferencing. malloc() and calloc() return void* for this reason.

Q 7

Which function is used to resize dynamically allocated memory?

  • a. malloc()
  • b. calloc()
  • c. realloc()
  • d. resize()
Answer: c. realloc()

realloc() changes the size of a previously allocated memory block. It can expand or shrink the block. If expansion is needed, it may move the block to a new location and copy existing data.

Q 8

What is the difference between int *p[5] and int (*p)[5]?

  • a. No difference
  • b. First is array of pointers, second is pointer to array
  • c. First is pointer to array, second is array of pointers
  • d. Both are invalid
Answer: b. First is array of pointers, second is pointer to array

int *p[5] is an array of 5 pointers to int. int (*p)[5] is a pointer to an array of 5 integers. Parentheses change the precedence: [] binds before * in the first case.

Short Answer Questions

Q 1

What are the & and * operators? Explain with an example.

& (address-of) — Returns the memory address of a variable. Example: int x=10; &x gives the address where x is stored.

* (dereference/indirection) — Accesses the value at the address stored in a pointer. Example: int *p=&x; *p gives the value 10.

Together: p = &x; makes p point to x. *p = 20; changes x to 20.

Q 2

What is a null pointer? Why is it used?

A null pointer is a pointer that points to nothing, initialized with NULL (defined as 0). It is used to: (1) initialize pointers when no valid address is available yet; (2) check if a pointer has been assigned; (3) avoid accidental dereferencing of uninitialized pointers. Dereferencing a null pointer causes a segmentation fault (crash).

Q 3

What is the difference between malloc() and calloc()?

malloc() — Takes 1 argument (total bytes); does NOT initialize memory (contains garbage); faster. Syntax: malloc(n * sizeof(type)).

calloc() — Takes 2 arguments (count, size each); initializes all bytes to zero; slower due to initialization. Syntax: calloc(n, sizeof(type)).

Use calloc() when you need zero-initialized memory; use malloc() otherwise for speed.

Q 4

What is the relationship between arrays and pointers in C?

In C, the array name is a constant pointer to the first element. For int arr[5];, arr is equivalent to &arr[0]. Key relationships: arr[i] = *(arr+i); &arr[i] = (arr+i). Arrays are always passed to functions as pointers (call by reference). The difference: array name cannot be reassigned; pointer variables can.

Long Answer Questions (6 Marks)

Q 1

Explain pointers in C with declaration, initialization, and a complete program demonstrating pointer usage with variables and arrays.

A pointer is a variable that stores the memory address of another variable. It enables indirect access to data and is essential for dynamic memory allocation and efficient programming.

Declaration: data_type *pointer_name; Example: int *p;

Initialization: p = &variable; assigns the address of variable to p.

Dereferencing: *p accesses the value at the address stored in p.

Complete Pointer Program
#include <stdio.h>
int main() {
    int x = 50;
    int *p = &x;        /* p points to x */

    printf("x = %d\n", x);
    printf("Address of x (&x) = %p\n", &x);
    printf("Value in p = %p\n", p);      /* same as &x */
    printf("Value at *p = %d\n", *p);    /* 50 */

    *p = 100;           /* modify x through pointer */
    printf("After *p=100, x = %d\n", x); /* 100 */

    /* Pointer with array */
    int arr[] = {10, 20, 30, 40};
    int *ptr = arr;     /* ptr points to arr[0] */

    printf("\nArray elements:\n");
    for (int i = 0; i < 4; i++) {
        printf("arr[%d] = %d = *(ptr+%d) = %d\n", 
               i, arr[i], i, *(ptr+i));
    }

    return 0;
}

Q 2

Explain dynamic memory allocation in C. Describe malloc(), calloc(), realloc(), and free() with syntax and examples.

Dynamic Memory Allocation allows allocating memory at runtime from the heap. All functions are in <stdlib.h>.

1. malloc() — Allocates memory of specified size; does NOT initialize.

malloc() Example
int *p = (int*) malloc(5 * sizeof(int));
if (p == NULL) { printf("Failed\n"); return 1; }
for (int i=0; i<5; i++) p[i] = i*10;
free(p);

2. calloc() — Allocates and initializes to zero.

calloc() Example
int *p = (int*) calloc(5, sizeof(int));
/* All 5 elements are 0 */

3. realloc() — Resizes previously allocated memory.

realloc() Example
int *p = malloc(3 * sizeof(int));
p = (int*) realloc(p, 6 * sizeof(int));  /* now 6 elements */

4. free() — Releases allocated memory.

free(p);
p = NULL;  /* prevent dangling pointer */

Common mistakes: Memory leak (not calling free), dangling pointer (using after free), double free.

Q 3

Explain pointers to structures and unions. Why does sizeof(union) equal its largest member, and how does the -> operator differ from (*sp).x?

Structure pointer. struct point *sp = &pt; stores the address of the whole structure. Both sp->x and (*sp).x read the same member — the arrow is simply shorter notation for "dereference, then select", and it binds so that no parentheses are needed. sp->x = 30 writes through to pt.x, because the pointer names the original object.

Union size. A struct gives every member its own bytes, so its size is the sum of the members plus padding. A union gives every member the same bytes, so it only needs room for the widest one: for union u { int i; char c; double d; }; that is the 8-byte double, not 4 + 1 + 8 = 13. Writing one member therefore overwrites the others, which is why only one field is valid at a time.

sizeof(struct point) where point holds two ints is 8; sizeof(union u) above is also 8 — but for the opposite reason.

Practice Problems

Q 1

Write a C program using pointers to swap two numbers. Use call by reference.

Swap Using Pointers
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 10, y = 20;
    printf("Before swap: x = %d, y = %d\n", x, y);
    swap(&x, &y);
    printf("After swap:  x = %d, y = %d\n", x, y);
    return 0;
}

Q 2

Write a C program to dynamically allocate memory for n integers using malloc(), read values, find the largest, and free the memory.

Dynamic Array — Find Max
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n, *arr, max;

    printf("Enter n: ");
    scanf("%d", &n);

    arr = (int*) malloc(n * sizeof(int));
    if (arr == NULL) {
        printf("Memory allocation failed!\n");
        return 1;
    }

    printf("Enter %d elements:\n", n);
    for (int i = 0; i < n; i++) scanf("%d", &arr[i]);

    max = arr[0];
    for (int i = 1; i < n; i++)
        if (arr[i] > max) max = arr[i];

    printf("Largest = %d\n", max);

    free(arr);
    arr = NULL;
    return 0;
}

Q 3

Write a C program using pointers to reverse a string without using string library functions.

Reverse String Using Pointers
#include <stdio.h>

int main() {
    char str[100], temp;
    char *start, *end;

    printf("Enter a string: ");
    scanf("%s", str);

    start = str;
    end = str;

    /* Find end of string */
    while (*end != '\0') end++;
    end--;  /* move back from '\0' to last char */

    /* Swap characters */
    while (start < end) {
        temp = *start;
        *start = *end;
        *end = temp;
        start++;
        end--;
    }

    printf("Reversed: %s\n", str);
    return 0;
}

Q 4

Write a C program that allocates an array of n integers with calloc, filled from the keyboard, prints the elements and their sum through a pointer, then resizes the block with realloc and frees it.

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n, i, sum = 0;
    int *p;

    printf("n: ");
    if (scanf("%d", &n) != 1 || n < 1) return 1;

    p = calloc(n, sizeof *p);          /* zero-filled, n elements */
    if (p == NULL) return 1;

    for (i = 0; i < n; i++)
        if (scanf("%d", p + i) != 1) { free(p); return 1; }

    for (i = 0; i < n; i++)
        sum += *(p + i);               /* pointer form of p[i]    */

    int *q = realloc(p, (n + 1) * sizeof *p);
    if (q == NULL) { free(p); return 1; }
    p = q;
    p[n] = sum;                        /* keep the total in the new cell */

    printf("sum = %d, last cell = %d\n", sum, p[n]);
    free(p);
    p = NULL;
    return 0;
}

Say the three things the examiner looks for: calloc zeroes the block, realloc goes through a temporary so a failure cannot lose the original, and free is followed by p = NULL.

Quick Revision

Unit 5 in Twelve Lines
  • &x yields an address; *p yields the value there. They undo each other.
  • int *p may only hold the address of an int; void * holds any address but cannot be dereferenced uncast.
  • Null, wild, dangling and leaked pointers are four failures of one rule: point at something valid.
  • addr(p + k) = addr(p) + k * sizeof(*p) — the scale factor, not one byte per step.
  • p2 - p1 counts elements, never bytes.
  • a[i] ≡ *(a + i); a is a non-modifiable lvalue, p is not.
  • *q++ advances the pointer; (*q)++ increments the value.
  • Arrays are always passed as pointers — there is no copy.
  • malloc leaves garbage; calloc zeroes; realloc resizes; free releases.
  • Check every allocation for NULL, and set the pointer to NULL after free.
  • sp->x means (*sp).x; a union is as big as its largest member.
  • A pointer is 4 bytes on a 32-bit build and 8 on a 64-bit build, whatever it points at.
Seven Marks Lost Every Year
  • Writing p + n adds n bytes — it adds n × sizeof(*p).
  • Saying strlen-style byte counts for p2 - p1, which counts elements.
  • Using malloc where the question wants zero-initialised memory (calloc).
  • Forgetting the NULL check after allocation.
  • free(p) without p = NULL — the pointer is now dangling.
  • Assuming sizeof(union) is the sum of its members.
  • Confusing int *p[5] (five pointers) with int (*p)[5] (one pointer to five ints).
