Graph Definition

A Graph G = (V, E) consists of:

  • V — A set of vertices (nodes).
  • E — A set of edges connecting pairs of vertices.

Paths, Cycles, and Connectivity
  • Path: A sequence of vertices v₁, v₂, ..., vₖ where each consecutive pair has an edge. Length = number of edges in the path.
  • Simple Path: A path where no vertex is repeated.
  • Cycle: A path where the first and last vertices are the same (v₁ = vₖ, k ≥ 3).
  • Acyclic Graph: A graph with no cycles.
  • Connected Graph: Every pair of vertices has a path between them (for undirected graphs).
  • Strongly Connected: In a directed graph, every vertex can reach every other vertex.
Spanning Tree

A spanning tree of a connected graph G is a subgraph that:

  • Is a tree (connected + acyclic).
  • Contains all V vertices of G.
  • Contains exactly V − 1 edges.

A graph can have many spanning trees. Among all possible spanning trees of a weighted graph, the one with minimum total edge weight is called the Minimum Spanning Tree (MST).

DAGs & Topological Sorting

DAG Definition

A Directed Acyclic Graph (DAG) is a directed graph with no directed cycles. Every DAG has at least one topological ordering.

Examples: Task dependency graphs, course prerequisites, build systems, Git commit history.

Topological Sort

Topological Sort is a linear ordering of vertices of a DAG such that for every directed edge (u → v), vertex u appears before vertex v in the ordering.

Topological sort is only possible for DAGs (no cycles). If the graph has a cycle, topological sort is impossible.

Algorithm 1: Kahn's Algorithm (BFS-based)
Pseudocode
KAHN-TOPOLOGICAL-SORT(G)
  Compute in-degree for each vertex
  queue Q ← all vertices with in-degree 0
  result = []
  while Q is not empty
    u = Q.dequeue()
    result.append(u)
    for each neighbour v of u
      in-degree[v] -= 1
      if in-degree[v] == 0
        Q.enqueue(v)
  if |result| != |V|: "Graph has a cycle"
  return result
Algorithm 2: DFS-based Topological Sort
Pseudocode
DFS-TOPOLOGICAL-SORT(G)
  stack S = []
  visited = {all false}
  for each vertex u in V
    if not visited[u]
      DFS-VISIT(u, visited, S)
  return S (reversed)

DFS-VISIT(u, visited, S)
  visited[u] = true
  for each neighbour v of u
    if not visited[v]
      DFS-VISIT(v, visited, S)
  S.push(u)    // push after all descendants

Complexity: Topological Sort
  • Time: O(V + E) — both Kahn's and DFS-based.
  • Space: O(V) — for in-degree array/visited array + queue/stack.
  • Prerequisite: Graph must be a DAG. If cycle exists, Kahn's detects it (result size < V).
Real-World Applications
  • Build systems: Compile files in dependency order (Makefile, Gradle).
  • Task scheduling: Schedule tasks with prerequisites.
  • Course prerequisites: Order courses so all prereqs come first.
  • Package managers: Install dependencies in correct order (npm, pip).

Minimum Spanning Tree (MST)

MST Definition

The Minimum Spanning Tree of a connected, weighted, undirected graph G is a spanning tree (V−1 edges connecting all V vertices) with the minimum total edge weight.

Properties:

  • Contains exactly V − 1 edges.
  • Connects all V vertices.
  • Has no cycles.
  • Has minimum total weight among all spanning trees.
  • May not be unique if multiple edges have the same weight.

1. Prim's Algorithm

Concept

Prim's algorithm grows the MST one vertex at a time, starting from any vertex. At each step, it adds the cheapest edge connecting a vertex already in the MST to a vertex not yet in the MST.

Paradigm: Greedy Method.

Pseudocode: Prim's Algorithm
PRIM(G, start)
  key[v] = ∞ for all v    // min weight edge to v
  key[start] = 0
  parent[v] = NIL for all v
  inMST[v] = false for all v

  repeat V times:
    u = vertex with minimum key[] not in MST
    inMST[u] = true
    for each neighbour v of u with weight w:
      if not inMST[v] and w < key[v]:
        key[v] = w
        parent[v] = u

  MST edges = {(parent[v], v) for all v ≠ start}

Complexity: Prim's
  • With adjacency matrix: O(V²) — suitable for dense graphs.
  • With min-heap + adjacency list: O(E log V) — suitable for sparse graphs.
  • Space: O(V + E).

2. Kruskal's Algorithm

Concept

Kruskal's algorithm builds the MST one edge at a time. It sorts all edges by weight and adds them greedily, skipping any edge that would create a cycle. Uses Union-Find (Disjoint Set Union) data structure to detect cycles efficiently.

Paradigm: Greedy Method.

Pseudocode: Kruskal's Algorithm
KRUSKAL(G)
  Sort all edges E by weight (ascending)
  MST = {}
  Initialize Union-Find for V vertices

  for each edge (u, v, w) in sorted order:
    if FIND(u) ≠ FIND(v):     // u and v in different sets (no cycle)
      MST = MST ∪ {(u, v, w)}
      UNION(u, v)
    if |MST| == V - 1: break

  return MST

  • Overall: O(E log E).
  • Space: O(V + E).

1. Dijkstra's Algorithm

Concept

Dijkstra's algorithm finds the shortest path from a single source vertex to all other vertices in a graph with non-negative edge weights. It greedily selects the unvisited vertex with the smallest known distance and updates its neighbours.

Paradigm: Greedy Method.

Limitation: Does NOT work with negative edge weights.

Pseudocode: Dijkstra's Algorithm
DIJKSTRA(G, source)
  dist[v] = ∞ for all v
  dist[source] = 0
  visited[v] = false for all v

  repeat V times:
    u = unvisited vertex with minimum dist[]
    visited[u] = true
    for each neighbour v of u with weight w:
      if not visited[v] and dist[u] + w < dist[v]:
        dist[v] = dist[u] + w

  return dist[]

Why Dijkstra Fails with Negative Weights

Dijkstra marks a vertex as "visited" permanently once it's picked. With negative weights, a later path through a negative edge could give a shorter distance, but Dijkstra wouldn't re-check it. This leads to incorrect results.

For negative weights, use Bellman-Ford.

2. Bellman-Ford Algorithm

Concept

Bellman-Ford computes shortest paths from a single source, even with negative edge weights. It relaxes all edges V−1 times. Additionally, it can detect negative weight cycles (a cycle whose total weight is negative — no shortest path exists in such cases).

Paradigm: Dynamic Programming.

Pseudocode: Bellman-Ford
BELLMAN-FORD(G, source)
  dist[v] = ∞ for all v
  dist[source] = 0

  // Relax all edges V-1 times
  for i = 1 to V-1:
    for each edge (u, v, w) in E:
      if dist[u] + w < dist[v]:
        dist[v] = dist[u] + w

  // Check for negative weight cycles
  for each edge (u, v, w) in E:
    if dist[u] + w < dist[v]:
      print "Negative weight cycle detected!"
      return

  return dist[]

Complexity: Bellman-Ford
  • Time: O(V · E) — V-1 passes, each scanning E edges.
  • Space: O(V).
  • Extra feature: Detects negative weight cycles in one additional pass.

3. Floyd-Warshall Algorithm

Concept

Floyd-Warshall computes shortest paths between ALL pairs of vertices. It uses Dynamic Programming on an adjacency matrix. For each intermediate vertex k, it checks if the path from i to j through k is shorter than the known path from i to j.

Paradigm: Dynamic Programming.

Handles: Negative weights (but not negative cycles).

Pseudocode: Floyd-Warshall
FLOYD-WARSHALL(W)
  // W = adjacency matrix (weight matrix)
  // W[i][j] = weight of edge i→j, ∞ if no edge, 0 if i==j
  dist[][] = copy of W

  for k = 1 to V:
    for i = 1 to V:
      for j = 1 to V:
        if dist[i][k] + dist[k][j] < dist[i][j]:
          dist[i][j] = dist[i][k] + dist[k][j]

  return dist[][]

Key Definitions

All Key Terms
  • Graph: G = (V, E); V = vertices, E = edges.
  • Directed Graph: Edges have direction (u → v).
  • Undirected Graph: Edges have no direction ({u, v}).
  • Weighted Graph: Each edge has an associated weight/cost.
  • Path: A sequence of vertices connected by edges.
  • Cycle: A path where the starting vertex equals the ending vertex.
  • DAG: Directed Acyclic Graph — a directed graph with no cycles.
  • Spanning Tree: A tree subgraph containing all vertices with V−1 edges.
  • MST: Minimum Spanning Tree — spanning tree with minimum total edge weight.
  • Topological Sort: Linear ordering of DAG vertices such that for every edge u→v, u comes before v.
  • In-degree: Number of edges coming into a vertex.
  • Relaxation: Updating the shortest distance to a vertex when a shorter path is found.
  • Prim's Algorithm: Greedy MST — grows MST from a starting vertex, adding cheapest connecting edge.
  • Kruskal's Algorithm: Greedy MST — adds edges in sorted weight order, skipping cycle-forming edges.
  • Union-Find: Data structure to track connected components; used in Kruskal's to detect cycles.
  • Dijkstra's Algorithm: Greedy single-source shortest path; only non-negative weights.
  • Bellman-Ford: DP single-source shortest path; handles negative weights; detects negative cycles.
  • Floyd-Warshall: DP all-pairs shortest path; O(V³).
  • Negative Weight Cycle: A cycle whose total weight is negative — no finite shortest path exists.
  • Adjacency Matrix: V×V matrix where entry [i][j] = weight of edge i→j (or 0/∞).
  • Adjacency List: Array of linked lists; each vertex stores its neighbours.

Multiple Choice Questions

Q 1

A spanning tree of a graph with V vertices has exactly how many edges?

  • a. V
  • b. V − 1
  • c. V + 1
  • d. 2V
Answer: b. V − 1

A tree with V vertices always has exactly V − 1 edges. A spanning tree connects all V vertices of the graph using V − 1 edges without forming any cycle.

Q 2

Topological sorting is possible only for:

  • a. Undirected graphs
  • b. Complete graphs
  • c. Directed Acyclic Graphs (DAGs)
  • d. All directed graphs
Answer: c. Directed Acyclic Graphs (DAGs)

Topological sorting requires a linear ordering where for every edge u→v, u comes before v. This is impossible if the graph has a directed cycle (e.g., A→B→C→A — who comes first?).

Q 3

Which algorithm uses Union-Find data structure?

  • a. Prim's
  • b. Dijkstra's
  • c. Kruskal's
  • d. Bellman-Ford
Answer: c. Kruskal's

Kruskal's algorithm uses Union-Find (Disjoint Set Union) to efficiently check whether adding an edge creates a cycle. FIND checks if two vertices are in the same set; UNION merges two sets.

Q 4

Dijkstra's algorithm does NOT work correctly with:

  • a. Directed graphs
  • b. Undirected graphs
  • c. Weighted graphs
  • d. Negative edge weights
Answer: d. Negative edge weights

Dijkstra's greedy approach permanently marks vertices as "visited." A negative edge weight could provide a shorter path through a visited vertex, but Dijkstra wouldn't re-check it. Use Bellman-Ford for negative weights.

Q 5

What is the time complexity of Floyd-Warshall algorithm?

  • a. O(V²)
  • b. O(V · E)
  • c. O(V³)
  • d. O(E log V)
Answer: c. O(V³)

Floyd-Warshall uses three nested loops (for k, i, j each from 1 to V), giving O(V³) time complexity. It computes shortest paths between ALL pairs of vertices.

Q 6

Prim's algorithm is better suited for:

  • a. Sparse graphs
  • b. Dense graphs
  • c. Directed graphs
  • d. Unweighted graphs
Answer: b. Dense graphs

With adjacency matrix, Prim's runs in O(V²). For dense graphs where E ≈ V², this is efficient. Kruskal's O(E log E) is better for sparse graphs where E ≪ V².

Q 7

Which algorithm can detect negative weight cycles?

  • a. Dijkstra's
  • b. Prim's
  • c. Bellman-Ford
  • d. Kruskal's
Answer: c. Bellman-Ford

After V−1 relaxation passes, Bellman-Ford performs one more pass. If any edge can still be relaxed, a negative weight cycle exists. Dijkstra cannot detect this.

Q 8

The maximum number of edges in an undirected graph with 5 vertices is:

  • a. 5
  • b. 10
  • c. 20
  • d. 25
Answer: b. 10

Maximum edges in an undirected graph = V(V−1)/2 = 5×4/2 = 10. This is a complete graph (every vertex connected to every other).

Q 9

Bellman-Ford relaxes all edges how many times?

  • a. V times
  • b. V − 1 times
  • c. E times
  • d. V + E times
Answer: b. V − 1 times

The shortest path between any two vertices in a graph with V vertices can have at most V − 1 edges. So V − 1 relaxation passes are sufficient to find shortest paths (assuming no negative cycles).

Q 10

Which MST algorithm starts by sorting all edges?

  • a. Prim's
  • b. Dijkstra's
  • c. Kruskal's
  • d. Floyd-Warshall
Answer: c. Kruskal's

Kruskal's first step is sorting all edges by weight in ascending order. Then it greedily adds edges that don't form a cycle until V−1 edges are added.

Q 11

The time complexity of topological sort is:

  • a. O(V²)
  • b. O(V + E)
  • c. O(V · E)
  • d. O(E log V)
Answer: b. O(V + E)

Both Kahn's (BFS-based) and DFS-based topological sort visit each vertex once and each edge once, giving O(V + E) time complexity.

Q 12

Which shortest path algorithm uses Dynamic Programming with three nested loops?

  • a. Dijkstra's
  • b. Bellman-Ford
  • c. Floyd-Warshall
  • d. Kruskal's
Answer: c. Floyd-Warshall

Floyd-Warshall uses three nested loops: for k (intermediate vertex), for i (source), for j (destination). It checks if path i→k→j is shorter than current i→j. This gives O(V³).

Q 13

In Prim's algorithm, the key[] array stores:

  • a. Shortest path from source
  • b. Minimum weight edge connecting vertex to MST
  • c. In-degree of the vertex
  • d. Number of neighbours
Answer: b. Minimum weight edge connecting vertex to MST

In Prim's, key[v] stores the minimum weight of any edge connecting vertex v to a vertex already in the MST. The vertex with the smallest key is picked next.

Q 14

In Floyd-Warshall, a negative weight cycle is detected when:

  • a. dist[i][j] = ∞
  • b. dist[i][i] < 0 for some i
  • c. dist[i][j] = 0
  • d. The algorithm doesn't terminate
Answer: b. dist[i][i] < 0 for some i

If after running Floyd-Warshall, any diagonal entry dist[i][i] is negative, it means there's a cycle from i back to i with negative total weight — a negative weight cycle.

Q 15

The core operation in Dijkstra's and Bellman-Ford is called:

  • a. Contraction
  • b. Relaxation
  • c. Rotation
  • d. Partitioning
Answer: b. Relaxation

Relaxation: if dist[u] + w(u,v) < dist[v], then update dist[v] = dist[u] + w(u,v). This "relaxes" the constraint on the shortest distance to v. Both Dijkstra and Bellman-Ford use this operation.

Short Answer Questions

Q 1

What is a spanning tree? How many edges does it have?

A spanning tree of a connected graph G is a subgraph that is a tree (connected and acyclic) and includes all V vertices of G. It has exactly V − 1 edges.

Example: A graph with 5 vertices has a spanning tree with exactly 4 edges.

Q 2

Differentiate between directed and undirected graphs.

Directed Graph: Edges have direction. Edge (u → v) means you can go from u to v but not necessarily from v to u. Max edges = V(V−1).

Undirected Graph: Edges have no direction. Edge {u, v} means you can go both ways. Max edges = V(V−1)/2.

Example: One-way streets → directed; Two-way roads → undirected.

Q 3

What is topological sorting? Give a real-life example.

Topological Sort: A linear ordering of vertices of a DAG such that for every edge u → v, u appears before v. It is only possible for DAGs.

Real-life example: University courses with prerequisites. If Course B requires Course A, then A must appear before B in the schedule. Topological sort gives a valid course order.

Q 4

What is a negative weight cycle? Why does it cause problems?

A negative weight cycle is a cycle in a directed graph whose total edge weight sum is negative. Example: A→B(−2), B→C(1), C→A(−1) has total weight = −2.

Problem: If a negative weight cycle is reachable from the source, we can keep going around it to reduce the distance infinitely. Therefore, no finite shortest path exists. Bellman-Ford can detect this; Dijkstra cannot.

Q 5

What is the difference between Prim's and Kruskal's algorithms?

Prim's: Vertex-based. Starts from one vertex and grows the MST by adding the cheapest edge connecting to a new vertex. Uses priority queue. Better for dense graphs O(V²).

Kruskal's: Edge-based. Sorts all edges by weight and adds them greedily, skipping cycle-forming edges. Uses Union-Find. Better for sparse graphs O(E log E).

Both produce MST with the same total weight (Greedy approach).

Q 6

Why does Dijkstra's algorithm fail with negative edge weights?

Dijkstra's is a greedy algorithm that permanently finalises the shortest distance to a vertex once it's picked (marked as visited). With negative weights, a later path through a negative edge could give a shorter distance to an already-visited vertex, but Dijkstra won't revisit it.

Example: Source S. S→A(1), S→B(10), A→B(−20). Dijkstra picks A(1), finalises it, then picks B(10). But S→A→B = 1+(−20) = −19 < 10. Dijkstra misses this.

Q 7

State the core recurrence of Floyd-Warshall algorithm.

Floyd-Warshall Recurrence:

dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])

For each intermediate vertex k (from 1 to V), check if going from i to k then k to j gives a shorter path than the current direct i→j path. This is applied for all pairs (i, j).

Q 8

What is the role of Union-Find in Kruskal's algorithm?

Union-Find (Disjoint Set Union) is used in Kruskal's to efficiently detect cycles:

  • FIND(u): Returns the representative (root) of the set containing u.
  • UNION(u, v): Merges the sets containing u and v.

Before adding edge (u, v): if FIND(u) == FIND(v), u and v are already connected → adding this edge creates a cycle → skip it. Otherwise, add the edge and UNION their sets.

Q 9

What is edge relaxation in shortest path algorithms?

Relaxation is the process of updating the shortest known distance to a vertex when a shorter path is found through another vertex.

if dist[u] + w(u,v) < dist[v]: dist[v] = dist[u] + w(u,v)

This means: if going from source to u, then taking edge u→v gives a shorter path to v than what we currently know, update the distance to v. Used in both Dijkstra and Bellman-Ford.

Q 10

Compare adjacency matrix and adjacency list representations.

Adjacency Matrix: V×V matrix. Space O(V²). Edge check O(1). Best for dense graphs. Used by Floyd-Warshall.

Adjacency List: Array of linked lists. Space O(V+E). Edge check O(degree). Best for sparse graphs. Used by BFS, DFS, Dijkstra.

Q 11

What is a DAG? Can a DAG have more than one topological order?

A DAG (Directed Acyclic Graph) is a directed graph with no directed cycles.

Yes, a DAG can have multiple valid topological orderings. For example, if vertices A and B have no dependency between them, either can come first. Only a DAG that forms a single chain (total order) has a unique topological sort.

Q 12

How many times does Bellman-Ford relax all edges? Why V−1?

Bellman-Ford relaxes all edges V − 1 times.

Why V−1? The shortest path from source to any vertex in a graph with V vertices has at most V−1 edges (since a simple path visits at most V vertices). In the i-th pass, the algorithm correctly computes shortest paths using at most i edges. After V−1 passes, all shortest paths are found.

Q 6

Explain topological sorting using Kahn's algorithm with pseudocode and a detailed example.

Kahn's Algorithm (BFS-based): Repeatedly remove vertices with in-degree 0 and add to result.

Steps
  1. Compute in-degree for every vertex.
  2. Enqueue all vertices with in-degree 0.
  3. While queue not empty: dequeue u, add to result, decrement in-degree of all neighbours of u, enqueue any that reach 0.
  4. If result size ≠ V → graph has a cycle.
Example: A→C, B→C, B→D, C→E, D→E
In-degrees: A=0, B=0, C=2, D=1, E=2
Queue: {A, B}
Dequeue A: C: 2→1. Result: [A]
Dequeue B: C: 1→0→Q, D: 1→0→Q. Result: [A,B]
Dequeue C: E: 2→1. Result: [A,B,C]
Dequeue D: E: 1→0→Q. Result: [A,B,C,D]
Dequeue E: Result: [A,B,C,D,E] ✅

Time: O(V+E). Note: [B,A,C,D,E] and [B,A,D,C,E] are also valid topological orderings.

Q 7

Define graph, path, cycle, spanning tree, and MST. Explain the relationship between them.

Graph G = (V, E): A collection of vertices V connected by edges E.

Path: A sequence of vertices where consecutive vertices are connected by edges. Length = number of edges.

Cycle: A path that starts and ends at the same vertex (v₁ = vₖ, k ≥ 3).

Spanning Tree: A subgraph of G that is a tree (connected + acyclic) containing ALL V vertices with exactly V−1 edges.

MST: The spanning tree with the minimum total edge weight among all possible spanning trees of a weighted graph.

Relationships
  • A spanning tree is a subgraph of a graph.
  • A spanning tree has no cycles (if you add any edge back, you get a cycle).
  • Removing any edge from a spanning tree disconnects it.
  • MST is a spanning tree with minimum weight — found using Prim's or Kruskal's.
  • A graph must be connected to have a spanning tree.

Quick Revision Points
  • Graph G = (V, E): Vertices + Edges. Directed or Undirected. Weighted or Unweighted.
  • Path: Sequence of vertices connected by edges. Cycle: Path starting and ending at same vertex.
  • DAG: Directed graph with NO cycles. Only DAGs have topological orderings.
  • Spanning Tree: Tree subgraph with all V vertices and V−1 edges. No cycles.
  • MST: Spanning tree with minimum total edge weight.
  • Topological Sort: O(V+E). Kahn's (BFS in-degree) or DFS-based. Only for DAGs.
  • Prim's MST: Vertex-based greedy. O(V²) matrix / O(E log V) heap. Better for dense graphs.
  • Kruskal's MST: Edge-based greedy. Sort edges + Union-Find. O(E log E). Better for sparse graphs.
  • Dijkstra: Single-source, greedy, NON-NEGATIVE weights only. O(V²) / O(E log V).
  • Bellman-Ford: Single-source, DP, handles NEGATIVE weights. Detects negative cycles. O(V·E).
  • Floyd-Warshall: ALL-PAIRS, DP, 3 nested loops. O(V³). Handles negative weights (not neg. cycles).
  • Relaxation: if dist[u]+w < dist[v] → update dist[v]. Core of Dijkstra and Bellman-Ford.
  • Undirected max edges: V(V−1)/2. Directed: V(V−1).
  • Adj Matrix: O(V²) space, O(1) edge check. Adj List: O(V+E) space, O(deg) edge check.
Must Remember for Exam
  • Spanning tree has exactly V − 1 edges.
  • Topological sort is possible ONLY for DAGs (no cycles).
  • Prim's → dense graphs (vertex-based); Kruskal's → sparse graphs (edge-based).
  • Dijkstra CANNOT handle negative weights. Use Bellman-Ford instead.
  • Bellman-Ford relaxes edges V−1 times. Extra pass detects negative cycles.
  • Floyd-Warshall: dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]).
  • Floyd-Warshall detects negative cycle if dist[i][i] < 0.
  • Kruskal's uses Union-Find for cycle detection.
  • Dijkstra uses min-heap / priority queue for finding minimum distance vertex.
  • Both MST algorithms (Prim's & Kruskal's) use Greedy paradigm.
Common Mistakes in Exams
  • Saying spanning tree has V edges — it has V − 1 edges.
  • Applying topological sort on a graph with cycles — it only works on DAGs.
  • Using Dijkstra's on a graph with negative weights — it gives wrong results.
  • Confusing Prim's (vertex-based) with Kruskal's (edge-based).
  • Saying Bellman-Ford relaxes V times — it relaxes V − 1 times.
  • Writing Floyd-Warshall as O(V²) — it is O(V³).
  • Forgetting to check for negative cycles in Bellman-Ford (the extra V-th pass).
  • Applying MST algorithms to directed graphs — MST is for undirected weighted graphs.
  • Confusing single-source (Dijkstra, Bellman-Ford) with all-pairs (Floyd-Warshall).
  • Saying Kruskal's doesn't need sorted edges — sorting is the first step.
