About This Course

Course Aim

To develop the basic concept of algorithms in computer science and prepare students with the algorithmic foundations of computing, as almost all programming involves algorithms at some level.

Course Objectives

  • Understand algorithm design and analysis fundamentals
  • Analyze time and space complexity using asymptotic notations
  • Implement and compare sorting and searching algorithms
  • Apply graph algorithms to real-world problems
  • Study string matching and data compression techniques

Learning Outcomes

  • Classify algorithms by their complexity (Big-O, Omega, Theta)
  • Implement and trace all major sorting algorithms
  • Use BST, AVL, hashing for efficient searching
  • Apply Dijkstra, Prim, Kruskal on weighted graphs
  • Implement KMP, Boyer-Moore, and Huffman coding

Prerequisites

No formal prerequisites. Basic familiarity with programming concepts (loops, arrays, functions) and elementary data structures (stacks, queues) is helpful.

Important Exam Tips
  • Unit 2 (Sorting — 16 hrs) and Unit 4 (Graph Algorithms — 14 hrs) carry the highest weightage.
  • Trace tables for sorting algorithms (Bubble, Merge, Quick, Heap) are frequently asked.
  • Dijkstra's, Prim's, and Kruskal's step-by-step traces are common 6-mark questions.
  • Complexity analysis (Big-O derivations) must be shown with proper working.
  • KMP failure function and Huffman code tree construction are important for Unit 5.
