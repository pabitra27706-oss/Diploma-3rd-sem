Linked Lists

Master Singly, Circular, Doubly, and Circular Doubly Linked Lists with complete operations and applications.

Unit Overview

What You'll Learn

This unit covers Linked Lists in complete depth — one of the most important dynamic data structures in computer science. You will learn about four types of linked lists and all operations on each.

  • Introduction: Nodes, head pointer, advantages and disadvantages over arrays
  • Singly Linked List: Insert at front, middle, end; Delete from front, middle, end
  • Circular Singly Linked List: Structure, insert, delete with circular link maintenance
  • Doubly Linked List: Bidirectional traversal, insert and delete with prev and next pointers
  • Circular Doubly Linked List: Combining circular and doubly properties
  • Applications: Linked list implementation of Stack and Queue
Why Linked Lists?
  • Dynamic size — grows and shrinks at runtime unlike arrays
  • Efficient insertion/deletion — no shifting of elements required
  • Foundation for building stacks, queues, and other complex data structures
  • Used in operating systems, compilers, file systems, and browser history

Introduction to Linked Lists

Definition

A Linked List is a linear data structure where elements (called nodes) are not stored in contiguous memory locations. Instead, each node contains data and a pointer to the next node in the sequence.

Structure of a Node

Node Components

Every node in a linked list has two parts:

  • Data: The actual value stored in the node
  • Pointer (next/link): The memory address of the next node
10 next →
→
20 next →
→
30 next →
→ NULL

The head pointer stores the address of the first node. The last node's next pointer is NULL.

Node Structure in C
struct Node {
    int data;           // Data part
    struct Node* next;  // Pointer to next node
};

// Create the head pointer
struct Node* head = NULL;
Creating a New Node
#include <stdlib.h>

struct Node* createNode(int value) {
    struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->data = value;
    newNode->next = NULL;
    return newNode;
}

Advantages vs Disadvantages

Advantages over Arrays Disadvantages
Dynamic size — grows/shrinks at runtime No random access — must traverse from head
Efficient insertion/deletion (no shifting) Extra memory for pointer in each node
Memory allocated only when needed Cache unfriendly — nodes scattered in memory
Multiple lists can share memory pool Reverse traversal not possible in singly LL
No pre-defined size limit (until RAM exhausted) More complex code compared to arrays

Array vs Linked List

Aspect Array Linked List
Memory Contiguous (sequential) Non-contiguous (scattered)
Size Fixed at compile time Dynamic (runtime)
Access Random O(1) — arr[i] Sequential O(n) — traverse from head
Insertion O(n) — shifting needed O(1) — only pointer update
Deletion O(n) — shifting needed O(1) — only pointer update
Memory Waste May waste if unused Extra memory for pointers
Searching O(log n) if sorted (binary search) O(n) — linear only

Singly Linked List

Definition

A Singly Linked List is a linked list where each node has only one pointer — next — pointing to the next node. Traversal is possible in only one direction (forward). The last node points to NULL.

Visual Representation
head →
10next
→
20next
→
30next
→ NULL

Insertion Operations

1. Insert at Beginning (Front)

Algorithm
1. Create a new node with given data
2. Set newNode->next = head
3. Update head = newNode
4. End
C Code: Insert at Beginning
void insertAtBeginning(int data) {
    struct Node* newNode = createNode(data);
    newNode->next = head;
    head = newNode;
    printf("%d inserted at beginning\n", data);
}
Trace: Insert 5 at Beginning of [10→20→30→NULL]
Before: head → 10 → 20 → 30 → NULL
Step 1: newNode = [5|next]
Step 2: newNode->next = head (points to 10)
Step 3: head = newNode
After:  head → 5 → 10 → 20 → 30 → NULL

2. Insert at End

Algorithm
1. Create a new node with given data
2. If head == NULL, set head = newNode and return
3. Traverse to the last node (where node->next == NULL)
4. Set last->next = newNode
5. newNode->next = NULL
6. End
C Code: Insert at End
void insertAtEnd(int data) {
    struct Node* newNode = createNode(data);
    if(head == NULL) {
        head = newNode;
        return;
    }
    struct Node* temp = head;
    while(temp->next != NULL) {
        temp = temp->next;
    }
    temp->next = newNode;
    printf("%d inserted at end\n", data);
}

3. Insert at Middle (After Given Position)

Algorithm
1. Create newNode with given data
2. Traverse to position (pos-1) node
3. newNode->next = current->next
4. current->next = newNode
5. End
C Code: Insert After Position
void insertAtPosition(int data, int pos) {
    struct Node* newNode = createNode(data);
    struct Node* temp = head;
    for(int i = 1; i < pos && temp != NULL; i++) {
        temp = temp->next;
    }
    if(temp == NULL) {
        printf("Position out of range\n");
        return;
    }
    newNode->next = temp->next;
    temp->next = newNode;
    printf("%d inserted at position %d\n", data, pos);
}

Deletion Operations

1. Delete First Node

Algorithm
1. If head == NULL, print "List is empty" and return
2. Store temp = head
3. Update head = head->next
4. Free(temp)
5. End
C Code: Delete First Node
void deleteFirst() {
    if(head == NULL) {
        printf("List is empty\n");
        return;
    }
    struct Node* temp = head;
    head = head->next;
    free(temp);
    printf("First node deleted\n");
}

2. Delete Last Node

Algorithm
1. If head == NULL, print "Empty list" and return
2. If head->next == NULL, free(head), head = NULL, return
3. Traverse to second-last node (where node->next->next == NULL)
4. Free(second_last->next)
5. second_last->next = NULL
6. End
C Code: Delete Last Node
void deleteLast() {
    if(head == NULL) {
        printf("List is empty\n");
        return;
    }
    if(head->next == NULL) {
        free(head);
        head = NULL;
        return;
    }
    struct Node* temp = head;
    while(temp->next->next != NULL) {
        temp = temp->next;
    }
    free(temp->next);
    temp->next = NULL;
    printf("Last node deleted\n");
}

3. Delete Middle Node (By Value)

Algorithm
1. If head == NULL, return
2. If head->data == key, call deleteFirst() and return
3. Traverse list to find node with key, keeping track of prev node
4. If found: prev->next = current->next
5. Free(current)
6. If not found, print "Node not found"
7. End
C Code: Delete by Value
void deleteByValue(int key) {
    if(head == NULL) {
        printf("List is empty\n");
        return;
    }
    if(head->data == key) {
        deleteFirst();
        return;
    }
    struct Node* prev = head;
    struct Node* curr = head->next;
    while(curr != NULL && curr->data != key) {
        prev = curr;
        curr = curr->next;
    }
    if(curr == NULL) {
        printf("Node %d not found\n", key);
        return;
    }
    prev->next = curr->next;
    free(curr);
    printf("Node %d deleted\n", key);
}

Traversal and Display

C Code: Display Linked List
void display() {
    if(head == NULL) {
        printf("List is empty\n");
        return;
    }
    struct Node* temp = head;
    printf("List: ");
    while(temp != NULL) {
        printf("%d → ", temp->data);
        temp = temp->next;
    }
    printf("NULL\n");
}

Complete Singly Linked List Program

Complete C Program
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node* next;
};

struct Node* head = NULL;

struct Node* createNode(int data) {
    struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->data = data;
    newNode->next = NULL;
    return newNode;
}

void insertAtBeginning(int data) {
    struct Node* newNode = createNode(data);
    newNode->next = head;
    head = newNode;
}

void insertAtEnd(int data) {
    struct Node* newNode = createNode(data);
    if(head == NULL) { head = newNode; return; }
    struct Node* temp = head;
    while(temp->next != NULL) temp = temp->next;
    temp->next = newNode;
}

void deleteFirst() {
    if(head == NULL) return;
    struct Node* temp = head;
    head = head->next;
    free(temp);
}

void display() {
    struct Node* temp = head;
    while(temp != NULL) {
        printf("%d → ", temp->data);
        temp = temp->next;
    }
    printf("NULL\n");
}

int main() {
    insertAtEnd(10);
    insertAtEnd(20);
    insertAtEnd(30);
    insertAtBeginning(5);
    display();         // 5 → 10 → 20 → 30 → NULL
    deleteFirst();
    display();         // 10 → 20 → 30 → NULL
    return 0;
}

Circular Singly Linked List

Definition

A Circular Singly Linked List is similar to a singly linked list, but the next pointer of the last node points back to the head node instead of NULL. This forms a circular chain.

Visual Representation
head →
10next
→
20next
→
30next
→ (back to head)

The last node (30) points back to head (10), forming a circle.

Key Difference from Singly LL
  • No NULL pointer — last node's next = head
  • Can traverse from any node and reach any other node
  • Traversal stops when we reach the head again
  • Useful in applications requiring round-robin access (Round Robin scheduling)

Insertion Operations

1. Insert at Beginning

Algorithm
1. Create newNode
2. If head == NULL:
   - head = newNode
   - newNode->next = head (point to itself)
   - return
3. Traverse to last node (where node->next == head)
4. newNode->next = head
5. last->next = newNode
6. head = newNode
7. End
C Code: Circular LL Insert at Beginning
void insertAtBeginningCL(int data) {
    struct Node* newNode = createNode(data);
    if(head == NULL) {
        head = newNode;
        newNode->next = head;
        return;
    }
    // Find last node
    struct Node* last = head;
    while(last->next != head) {
        last = last->next;
    }
    newNode->next = head;
    last->next = newNode;
    head = newNode;
}

2. Insert at End

Algorithm
1. Create newNode
2. If head == NULL:
   - head = newNode
   - newNode->next = head
   - return
3. Traverse to last node (where node->next == head)
4. last->next = newNode
5. newNode->next = head
6. End
C Code: Circular LL Insert at End
void insertAtEndCL(int data) {
    struct Node* newNode = createNode(data);
    if(head == NULL) {
        head = newNode;
        newNode->next = head;
        return;
    }
    struct Node* last = head;
    while(last->next != head) {
        last = last->next;
    }
    last->next = newNode;
    newNode->next = head;
}

Deletion Operations

1. Delete First Node

Algorithm
1. If head == NULL, return
2. If only one node (head->next == head):
   - Free head, head = NULL, return
3. Traverse to last node
4. last->next = head->next
5. Free(head)
6. head = last->next
7. End
C Code: Circular LL Delete First
void deleteFirstCL() {
    if(head == NULL) return;
    if(head->next == head) {
        free(head);
        head = NULL;
        return;
    }
    struct Node* last = head;
    while(last->next != head) {
        last = last->next;
    }
    struct Node* temp = head;
    last->next = head->next;
    head = head->next;
    free(temp);
}

2. Delete Last Node

C Code: Circular LL Delete Last
void deleteLastCL() {
    if(head == NULL) return;
    if(head->next == head) {
        free(head);
        head = NULL;
        return;
    }
    struct Node* prev = head;
    struct Node* curr = head->next;
    while(curr->next != head) {
        prev = curr;
        curr = curr->next;
    }
    prev->next = head;
    free(curr);
}

Traversal of Circular Linked List

C Code: Display Circular LL
void displayCL() {
    if(head == NULL) {
        printf("List is empty\n");
        return;
    }
    struct Node* temp = head;
    printf("Circular List: ");
    do {
        printf("%d → ", temp->data);
        temp = temp->next;
    } while(temp != head);
    printf("(back to head)\n");
}
Important Warning

When traversing a circular linked list, use a do-while loop that checks temp != head as the stopping condition — not temp != NULL, because there is no NULL in a circular list. Using while(temp != NULL) will cause an infinite loop!

Doubly Linked List

Definition

A Doubly Linked List is a linked list where each node has two pointers: prev (pointing to the previous node) and next (pointing to the next node). This allows traversal in both directions — forward and backward.

Node Structure
NULL ←
← prev 10 next →
⇌
← prev 20 next →
⇌
← prev 30 next →
→ NULL
Doubly Node Structure in C
struct DNode {
    int data;
    struct DNode* prev;  // Pointer to previous node
    struct DNode* next;  // Pointer to next node
};

struct DNode* head = NULL;

struct DNode* createDNode(int data) {
    struct DNode* newNode = (struct DNode*)malloc(sizeof(struct DNode));
    newNode->data = data;
    newNode->prev = NULL;
    newNode->next = NULL;
    return newNode;
}

Advantages over Singly LL

Doubly LL Advantages
  • Traversal in both directions (forward and backward)
  • Deletion of a given node is easier — no need to find prev separately
  • Can traverse from tail to head
  • Suitable for implementing deque (double-ended queue)
  • Useful in browser history (back/forward navigation)

Insertion Operations

1. Insert at Beginning

Algorithm
1. Create newNode
2. newNode->next = head
3. newNode->prev = NULL
4. If head != NULL, set head->prev = newNode
5. head = newNode
6. End
C Code: Doubly LL Insert at Beginning
void insertAtBeginningDL(int data) {
    struct DNode* newNode = createDNode(data);
    newNode->next = head;
    newNode->prev = NULL;
    if(head != NULL) {
        head->prev = newNode;
    }
    head = newNode;
    printf("%d inserted at beginning\n", data);
}

2. Insert at End

Algorithm
1. Create newNode
2. If head == NULL, head = newNode, return
3. Traverse to last node (where node->next == NULL)
4. last->next = newNode
5. newNode->prev = last
6. newNode->next = NULL
7. End
C Code: Doubly LL Insert at End
void insertAtEndDL(int data) {
    struct DNode* newNode = createDNode(data);
    if(head == NULL) {
        head = newNode;
        return;
    }
    struct DNode* temp = head;
    while(temp->next != NULL) {
        temp = temp->next;
    }
    temp->next = newNode;
    newNode->prev = temp;
    newNode->next = NULL;
    printf("%d inserted at end\n", data);
}

3. Insert After Given Node

C Code: Insert After Specific Node
void insertAfterDL(struct DNode* prevNode, int data) {
    if(prevNode == NULL) return;
    struct DNode* newNode = createDNode(data);
    newNode->next = prevNode->next;
    newNode->prev = prevNode;
    if(prevNode->next != NULL) {
        prevNode->next->prev = newNode;
    }
    prevNode->next = newNode;
}

Deletion Operations

1. Delete First Node

Algorithm
1. If head == NULL, return
2. temp = head
3. head = head->next
4. If head != NULL, head->prev = NULL
5. free(temp)
6. End
C Code: Doubly LL Delete First
void deleteFirstDL() {
    if(head == NULL) return;
    struct DNode* temp = head;
    head = head->next;
    if(head != NULL) {
        head->prev = NULL;
    }
    free(temp);
    printf("First node deleted\n");
}

2. Delete Last Node

Algorithm
1. If head == NULL, return
2. If head->next == NULL, free(head), head = NULL, return
3. Traverse to last node
4. second_last = last->prev
5. second_last->next = NULL
6. free(last)
7. End
C Code: Doubly LL Delete Last
void deleteLastDL() {
    if(head == NULL) return;
    if(head->next == NULL) {
        free(head);
        head = NULL;
        return;
    }
    struct DNode* temp = head;
    while(temp->next != NULL) {
        temp = temp->next;
    }
    temp->prev->next = NULL;
    free(temp);
    printf("Last node deleted\n");
}

3. Delete Middle Node (By Value)

Algorithm
1. Traverse to find node with given key
2. If not found, return
3. If node->prev != NULL: node->prev->next = node->next
4. If node->next != NULL: node->next->prev = node->prev
5. If deleting head: head = node->next
6. free(node)
7. End
C Code: Doubly LL Delete by Value
void deleteByValueDL(int key) {
    struct DNode* temp = head;
    while(temp != NULL && temp->data != key) {
        temp = temp->next;
    }
    if(temp == NULL) {
        printf("Node %d not found\n", key);
        return;
    }
    if(temp->prev != NULL)
        temp->prev->next = temp->next;
    else
        head = temp->next;  // Deleting head
    if(temp->next != NULL)
        temp->next->prev = temp->prev;
    free(temp);
    printf("Node %d deleted\n", key);
}

void displayForward() {

void displayBackward() {

    // Go to last node
    while(temp->next != NULL) {
        temp = temp->next;
    }
    printf("Backward: ");
    while(temp != NULL) {
        printf("%d → ", temp->data);
        temp = temp->prev;
    }
    printf("NULL\n");
}

Circular Doubly Linked List

Definition

A Circular Doubly Linked List combines the properties of a doubly linked list and a circular linked list. Each node has prev and next pointers. The prev of the head points to the last node, and the next of the last node points back to the head.

Visual Representation
← prev10next →
⇌
← prev20next →
⇌
← prev30next →

The prev of node 10 (head) points to node 30 (last). The next of node 30 points to node 10 (head).

Key Properties
  • head→prev always points to the last node
  • last→next always points to the head
  • No NULL pointers anywhere in the list
  • Can traverse in both directions starting from any node
  • Most flexible type of linked list
Circular Doubly Node Structure
struct CDNode {
    int data;
    struct CDNode* prev;
    struct CDNode* next;
};

struct CDNode* head = NULL;

Insert at Beginning

C Code: Circular Doubly Insert at Beginning
void insertAtBeginningCDL(int data) {
    struct CDNode* newNode = (struct CDNode*)malloc(sizeof(struct CDNode));
    newNode->data = data;
    if(head == NULL) {
        newNode->next = newNode;
        newNode->prev = newNode;
        head = newNode;
        return;
    }
    struct CDNode* last = head->prev;
    newNode->next = head;
    newNode->prev = last;
    last->next = newNode;
    head->prev = newNode;
    head = newNode;
    printf("%d inserted at beginning\n", data);
}

Insert at End

C Code: Circular Doubly Insert at End
void insertAtEndCDL(int data) {
    struct CDNode* newNode = (struct CDNode*)malloc(sizeof(struct CDNode));
    newNode->data = data;
    if(head == NULL) {
        newNode->next = newNode;
        newNode->prev = newNode;
        head = newNode;
        return;
    }
    struct CDNode* last = head->prev;
    newNode->next = head;
    newNode->prev = last;
    last->next = newNode;
    head->prev = newNode;
    printf("%d inserted at end\n", data);
}

Delete a Node

C Code: Circular Doubly Delete by Value
void deleteNodeCDL(int key) {
    if(head == NULL) return;
    struct CDNode* temp = head;
    do {
        if(temp->data == key) break;
        temp = temp->next;
    } while(temp != head);
    if(temp->data != key) {
        printf("Node not found\n");
        return;
    }
    // Only one node
    if(temp->next == temp) {
        free(temp);
        head = NULL;
        return;
    }
    temp->prev->next = temp->next;
    temp->next->prev = temp->prev;
    if(temp == head) {
        head = temp->next;
    }
    free(temp);
    printf("Node %d deleted\n", key);
}

Traversal

C Code: Circular Doubly Display
void displayCDL() {
    if(head == NULL) {
        printf("List is empty\n");
        return;
    }
    struct CDNode* temp = head;
    printf("Circular Doubly List: ");
    do {
        printf("%d ⇌ ", temp->data);
        temp = temp->next;
    } while(temp != head);
    printf("(back to head)\n");
}

Applications of Linked Lists

Overview

Linked lists are used to implement many other important data structures dynamically. The most important application for this syllabus is the implementation of Stack and Queue using linked lists.

1. Stack Using Linked List

How It Works

Instead of a fixed-size array, a linked list can implement a dynamic stack. The head of the linked list acts as the top of the stack.

  • Push: Insert new node at the beginning (head) — O(1)
  • Pop: Delete node from the beginning (head) — O(1)
  • Peek: Return head→data — O(1)
  • Overflow: Never occurs (until RAM is exhausted)
Stack Using Linked List in C
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node* next;
};

struct Node* top = NULL;

void push(int data) {
    struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->data = data;
    newNode->next = top;
    top = newNode;
    printf("%d pushed\n", data);
}

int pop() {
    if(top == NULL) {
        printf("Stack Underflow\n");
        return -1;
    }
    struct Node* temp = top;
    int val = top->data;
    top = top->next;
    free(temp);
    return val;
}

int peek() {
    if(top == NULL) return -1;
    return top->data;
}

int isEmpty() {
    return (top == NULL);
}

void display() {
    struct Node* temp = top;
    printf("Stack (top to bottom): ");
    while(temp != NULL) {
        printf("%d ", temp->data);
        temp = temp->next;
    }
    printf("\n");
}

int main() {
    push(10);
    push(20);
    push(30);
    display();
    printf("Popped: %d\n", pop());
    printf("Top: %d\n", peek());
    display();
    return 0;
}

2. Queue Using Linked List

How It Works

A queue can be implemented using a linked list with two pointers — front (for deletion/dequeue) and rear (for insertion/enqueue).

  • Enqueue: Insert new node at rear — O(1)
  • Dequeue: Delete node from front — O(1)
  • Overflow: Never occurs (until RAM is exhausted)
  • Underflow: When front == NULL (queue is empty)
Queue Using Linked List in C
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node* next;
};

struct Node* front = NULL;
struct Node* rear  = NULL;

void enqueue(int data) {
    struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->data = data;
    newNode->next = NULL;
    if(rear == NULL) {
        front = rear = newNode;
    } else {
        rear->next = newNode;
        rear = newNode;
    }
    printf("%d enqueued\n", data);
}

int dequeue() {
    if(front == NULL) {
        printf("Queue Underflow\n");
        return -1;
    }
    struct Node* temp = front;
    int val = front->data;
    front = front->next;
    if(front == NULL) rear = NULL;
    free(temp);
    return val;
}

void displayQueue() {
    struct Node* temp = front;
    printf("Queue (front to rear): ");
    while(temp != NULL) {
        printf("%d → ", temp->data);
        temp = temp->next;
    }
    printf("NULL\n");
}

int main() {
    enqueue(10);
    enqueue(20);
    enqueue(30);
    displayQueue();
    printf("Dequeued: %d\n", dequeue());
    displayQueue();
    return 0;
}
Array vs Linked List Implementation of Stack/Queue
Aspect Array Implementation Linked List Implementation
Size Fixed at compile time Dynamic (grows/shrinks at runtime)
Overflow Possible when array is full Not possible (until RAM is exhausted)
Memory Contiguous block Scattered, extra memory for pointers
Speed Slightly faster (no malloc/free) Slightly slower (dynamic allocation)
Complexity Simpler to implement Slightly more complex

Other Applications of Linked Lists

Real-World Uses
  • Browser History: Doubly linked list enables back/forward navigation
  • Music Playlist: Circular doubly linked list for looping through songs
  • Undo/Redo: Doubly linked list for undo/redo operations in editors
  • Memory Management: OS uses linked lists to manage free memory blocks
  • Polynomial Representation: Each term is a node with coefficient and exponent
  • Sparse Matrix: Store only non-zero elements using linked list

Key Formulas & Rules

Singly Linked List

Insert at front: newNode→next = head; head = newNode

Insert at end: last→next = newNode; newNode→next = NULL

Delete first: temp = head; head = head→next; free(temp)

Delete last: traverse to second-last; second_last→next = NULL

Circular Singly Linked List

Last node: last→next = head (not NULL)

Traversal stop: when temp == head again

Insert at end: last→next = newNode; newNode→next = head

Delete first: find last; last→next = head→next; head = head→next

Doubly Linked List

Insert at front: newNode→next = head; head→prev = newNode; head = newNode

Delete middle: node→prev→next = node→next; node→next→prev = node→prev

Delete first: head = head→next; head→prev = NULL

Delete last: last→prev→next = NULL

Circular Doubly Linked List

head→prev = last node always

last→next = head always

Single node: node→next = node→prev = node (itself)

Traversal stop: when temp == head again (do-while)

Stack/Queue via Linked List

Stack Push: newNode→next = top; top = newNode

Stack Pop: temp = top; top = top→next; free(temp)

Queue Enqueue: rear→next = newNode; rear = newNode

Queue Dequeue: temp = front; front = front→next; free(temp)

Key Definitions

Linked List

A linear data structure where elements (nodes) are stored in non-contiguous memory locations connected by pointers.

Node

Basic unit of a linked list containing data and one or more pointers to adjacent nodes.

Head Pointer

A pointer that stores the address of the first node in the linked list.

NULL Pointer

The next pointer of the last node in a singly or doubly linked list, indicating the end of the list.

Singly Linked List

Each node has one pointer (next). Traversal in one direction only (forward).

Doubly Linked List

Each node has two pointers (prev and next). Traversal in both directions.

Circular Linked List

Last node's next points to head instead of NULL, forming a circle.

Circular Doubly LL

Combines doubly and circular properties. head→prev = last, last→next = head.

Traversal

Visiting each node of the linked list starting from head to last node (or back to head for circular).

Dynamic Memory

Memory allocated at runtime using malloc(). Each new node gets memory from heap.

malloc()

Memory allocation function in C used to dynamically allocate a block of memory of given size.

free()

Deallocates memory previously allocated by malloc(). Used when deleting a node.

Insertion

Adding a new node at the beginning, middle, or end of a linked list by adjusting pointers.

Deletion

Removing a node from the linked list by adjusting pointers of surrounding nodes and freeing memory.

Overflow (LL)

In linked list, overflow occurs only when system RAM is completely exhausted. Unlike arrays, no fixed size limit.

Underflow (LL)

Occurs when trying to delete from an empty linked list (head == NULL).

Short Questions

Q1

Define Linked List.

A linked list is a linear data structure where elements called nodes are stored in non-contiguous memory locations. Each node contains data and a pointer to the next node. The first node is accessed through the head pointer and the last node points to NULL.

Q2

What is a node in a linked list?

A node is the basic unit of a linked list. Each node contains two parts: (1) Data — the actual value stored, and (2) Pointer (next) — the memory address of the next node in the list.

Q3

What is the difference between singly and doubly linked list?

Singly: One pointer per node (next). Traversal in forward direction only.

Doubly: Two pointers per node (prev and next). Traversal in both directions possible.

Q4

What is a Circular Linked List?

A circular linked list is a linked list where the last node's next pointer points back to the head node instead of NULL, forming a circular chain. There is no NULL pointer in the list.

Q5

State two advantages of linked list over array.

1. Dynamic Size: Linked list can grow and shrink at runtime; arrays have fixed size.

2. Efficient Insertion/Deletion: No shifting of elements required; only pointer updates needed.

Q6

State two disadvantages of linked list.

1. No Random Access: Cannot access an element directly by index; must traverse from head.

2. Extra Memory: Each node requires additional memory for storing the pointer.

Q7

How is a stack implemented using a linked list?

In a linked list stack, the head acts as the top of the stack. Push inserts a new node at the beginning (head). Pop removes the node at the beginning (head). Both operations are O(1). No overflow occurs until RAM is exhausted.

Q8

What is the role of the head pointer in a linked list?

The head pointer stores the memory address of the first node in the linked list. It is the entry point to access the list. If head == NULL, the list is empty. All traversals and operations begin from the head pointer.

Q9

How does insertion at beginning differ in singly LL vs doubly LL?

Singly LL: newNode→next = head; head = newNode (2 pointer updates)

Doubly LL: newNode→next = head; newNode→prev = NULL; head→prev = newNode; head = newNode (4 pointer updates — must also set prev of old head)

Q10

What is a Circular Doubly Linked List?

A circular doubly linked list combines doubly and circular linked list properties. Each node has prev and next pointers. The head→prev points to the last node and the last node's next points to head. No NULL pointers exist anywhere in the list.

Long Questions

Q1

Explain the structure of a singly linked list and write C code for insertion at beginning, end, and deletion of first node.

Singly Linked List

Structure: A singly linked list consists of nodes where each node has two fields: data and next pointer. The head pointer holds the address of the first node. The last node's next = NULL.

struct Node {
    int data;
    struct Node* next;
};
struct Node* head = NULL;

// Insert at beginning
void insertFront(int data) {
    struct Node* n = malloc(sizeof(struct Node));
    n->data = data;
    n->next = head;
    head = n;
}

// Insert at end
void insertEnd(int data) {
    struct Node* n = malloc(sizeof(struct Node));
    n->data = data; n->next = NULL;
    if(!head) { head = n; return; }
    struct Node* t = head;
    while(t->next) t = t->next;
    t->next = n;
}

// Delete first
void deleteFirst() {
    if(!head) return;
    struct Node* t = head;
    head = head->next;
    free(t);
}

Q2

Explain doubly linked list with insertion at beginning and end, and deletion of a node by value.

Doubly Linked List

Structure: Each node has three fields: prev pointer, data, and next pointer. The head→prev = NULL and last→next = NULL. Allows bidirectional traversal.

struct DNode { int data; struct DNode *prev, *next; };
struct DNode* head = NULL;

void insertFront(int data) {
    struct DNode* n = malloc(sizeof(struct DNode));
    n->data = data; n->prev = NULL;
    n->next = head;
    if(head) head->prev = n;
    head = n;
}

void insertEnd(int data) {
    struct DNode* n = malloc(sizeof(struct DNode));
    n->data = data; n->next = NULL;
    if(!head) { n->prev = NULL; head = n; return; }
    struct DNode* t = head;
    while(t->next) t = t->next;
    t->next = n; n->prev = t;
}

void deleteByVal(int key) {
    struct DNode* t = head;
    while(t && t->data != key) t = t->next;
    if(!t) return;
    if(t->prev) t->prev->next = t->next;
    else head = t->next;
    if(t->next) t->next->prev = t->prev;
    free(t);
}

Q5

Explain stack implementation using linked list with push, pop operations and C code.

Stack Using Linked List

The head of the linked list acts as the top of the stack. No fixed size limit exists.

struct Node { int data; struct Node* next; };
struct Node* top = NULL;

void push(int data) {
    struct Node* n = malloc(sizeof(struct Node));
    n->data = data;
    n->next = top;
    top = n;
    printf("%d pushed\n", data);
}

int pop() {
    if(!top) { printf("Underflow\n"); return -1; }
    struct Node* t = top;
    int val = t->data;
    top = top->next;
    free(t);
    return val;
}

void display() {
    struct Node* t = top;
    while(t) { printf("%d ", t->data); t = t->next; }
    printf("\n");
}

Advantages:

  • No overflow (dynamic size)
  • Memory used only as needed
  • Both push and pop are O(1)

Q6

Explain queue implementation using linked list with enqueue and dequeue operations.

Queue Using Linked List

Two pointers: front (for dequeue) and rear (for enqueue). FIFO maintained.

struct Node { int data; struct Node* next; };
struct Node *front = NULL, *rear = NULL;

void enqueue(int data) {
    struct Node* n = malloc(sizeof(struct Node));
    n->data = data; n->next = NULL;
    if(!rear) { front = rear = n; return; }
    rear->next = n;
    rear = n;
    printf("%d enqueued\n", data);
}

int dequeue() {
    if(!front) { printf("Underflow\n"); return -1; }
    struct Node* t = front;
    int val = t->data;
    front = front->next;
    if(!front) rear = NULL;
    free(t);
    return val;
}

Key Points:

  • Enqueue at rear — O(1)
  • Dequeue from front — O(1)
  • No size limit until RAM exhausted
  • When last element is dequeued, set both front and rear to NULL

Q8

Write a C program to delete a node by value from a doubly linked list.

#include <stdio.h>
#include <stdlib.h>

struct DNode {
    int data;
    struct DNode *prev, *next;
};
struct DNode* head = NULL;

void deleteByValue(int key) {
    struct DNode* temp = head;
    // Search for node
    while(temp != NULL && temp->data != key) {
        temp = temp->next;
    }
    if(temp == NULL) {
        printf("Node %d not found\n", key);
        return;
    }
    // Adjust prev pointer of next node
    if(temp->next != NULL)
        temp->next->prev = temp->prev;
    // Adjust next pointer of prev node
    if(temp->prev != NULL)
        temp->prev->next = temp->next;
    else
        head = temp->next; // Deleting head
    free(temp);
    printf("Node %d deleted\n", key);
}

Key Steps:

  1. Traverse to find the node with given key
  2. Adjust next pointer of previous node
  3. Adjust prev pointer of next node
  4. Handle special case if deleting head
  5. Free the deleted node's memory

Quick Revision

Quick Revision Points
  • Linked List: Non-contiguous nodes connected by pointers; head stores address of first node.
  • Node: Contains data + pointer(s) to adjacent nodes.
  • Singly LL: 1 pointer (next); last→next = NULL; forward traversal only.
  • Circular Singly LL: 1 pointer; last→next = head; no NULL; use do-while for traversal.
  • Doubly LL: 2 pointers (prev, next); head→prev = NULL; last→next = NULL; bidirectional.
  • Circular Doubly LL: 2 pointers; head→prev = last; last→next = head; most flexible.
  • Insert at front: newNode→next = head; head = newNode; O(1).
  • Insert at end: Traverse to last; last→next = newNode; O(n).
  • Delete first: temp = head; head = head→next; free(temp); O(1).
  • Stack via LL: head = top; push at head; pop from head; no overflow.
  • Queue via LL: front = dequeue end; rear = enqueue end; no overflow.
  • malloc(): Allocate dynamic memory; free(): Release memory.
  • Array vs LL: Array = O(1) access, O(n) insert; LL = O(n) access, O(1) insert.
Must Remember for Exams
  • Insertion at beginning: Always update head AFTER setting newNode→next = head — not before.
  • Insertion at end: Traverse until node→next == NULL (singly) or node→next == head (circular).
  • Doubly LL delete: Must update BOTH prev and next pointers of adjacent nodes.
  • Circular LL traversal: Use do-while loop with condition temp != head — never temp != NULL.
  • Circular Doubly: Single node has node→next = node and node→prev = node (points to itself).
  • Stack LL: head acts as top; push = insert at beginning; pop = delete from beginning.
  • Queue LL: rear = insertion end; front = deletion end; when last element removed, set front = rear = NULL.
  • Always call free() after deleting a node to prevent memory leaks.
  • Always check if head == NULL before any deletion operation.
Common Mistakes to Avoid
  • Setting head = newNode BEFORE setting newNode→next = head — this breaks the link!
  • Using while(temp != NULL) for circular linked list traversal — causes infinite loop!
  • Forgetting to update head→prev when inserting at front of doubly LL.
  • Not calling free() after deleting a node — causes memory leak.
  • Forgetting to handle the single-node special case in circular LL deletion.
  • In doubly LL delete, not checking if prev or next is NULL before dereferencing.
  • Forgetting to set rear = NULL when queue becomes empty in linked list queue.
  • Traversing to last node using node→next != NULL instead of node→next != head in circular LL.
