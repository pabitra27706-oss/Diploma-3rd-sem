Unit Overview

What You'll Learn

This unit introduces you to the foundational concepts of data structures — the backbone of efficient programming. You will learn how data is organized, stored, and accessed in computer memory, and understand the different types of data structures and their operations.

  • Basic Terminology: Data, Data Item, Data Type, Data Structure, Abstract Data Type (ADT)

Understanding data structures is critical for:

  • Writing efficient and optimized programs
  • Solving complex computational problems

  • Cracking technical interviews and competitive programming challenges

Basic Terminology

1. Data

Definition

Data refers to raw, unprocessed facts and figures that have no meaning on their own. Data is the basic building block of information.

Examples
  • Numbers: 42, 3.14, -7
  • Characters: 'A', 'z', '$'
  • Symbols: @, #, %
  • Text strings: "Hello", "2024"

Note: Data becomes information when it is processed and given context.

2. Data Item

Definition

A Data Item is a single unit of value. It is an elementary piece of information that cannot be divided further in a given context.

Examples
  • A single roll number: 12345
  • A single student name: "John Doe"
  • A single temperature reading: 98.6
  • A single boolean value: true or false

3. Data Type

Definition

A Data Type is a classification that specifies which type of value a variable can hold and what operations can be performed on it. It determines the size and layout of the variable's memory, the range of values that can be stored, and the set of operations that can be applied.

Common Data Types in C
Data Type Size (bytes) Range Example
int 4 -2,147,483,648 to 2,147,483,647 int age = 25;
float 4 3.4E-38 to 3.4E+38 float pi = 3.14;
char 1 -128 to 127 (ASCII) char grade = 'A';
double 8 1.7E-308 to 1.7E+308 double balance = 12345.67;

4. Data Structure

Definition

A Data Structure is a specialized way of organizing, storing, and managing data in a computer so that it can be accessed and modified efficiently. It is a collection of data values, the relationships among them, and the functions/operations that can be applied to the data.

Why Data Structures?

Data structures enable:

  • Efficient Access: Faster retrieval of data (e.g., searching in a sorted array vs unsorted)
  • Memory Management: Optimal use of memory space
  • Organization: Logical arrangement of related data
  • Reusability: Code that can be reused for different applications
Real-World Analogy

Think of a library. Books (data) are organized on shelves (data structure). You can find a book quickly if it's organized by category, author, or ISBN. Without organization, finding a book would take hours!

5. Abstract Data Type (ADT)

Definition

An Abstract Data Type (ADT) is a mathematical model for data types where the data is defined by its behavior (operations) from the point of view of a user, rather than by its implementation. ADT specifies what operations can be performed, but not how they are implemented.

Stack ADT Example

A Stack is defined by the following operations:

  • push(item) — Add an item to the top
  • pop() — Remove and return the top item
  • peek() — View the top item without removing it
  • isEmpty() — Check if the stack is empty

Key Point: Whether the stack is implemented using an array or a linked list does not matter to the user. The behavior remains the same. This is the power of abstraction.

ADT vs Data Structure
  • ADT: Logical description (what operations are available)
  • Data Structure: Physical implementation (how data is stored and accessed)

Example: Stack is an ADT. It can be implemented using an array or linked list (both are data structures).

Classification of Data Structures

Overview

Data structures can be broadly classified into two main categories:

  • Primitive Data Structures — Built-in types supported by the language
  • Non-Primitive Data Structures — Complex structures derived from primitive types

1. Primitive Data Structures

Definition

Primitive Data Structures are the fundamental data types that are directly supported and provided by the programming language itself. They represent single values and are the building blocks for more complex data structures.

Examples
  • int — Integer numbers
  • char — Single characters
  • float — Floating-point numbers
  • double — Double-precision floating-point numbers
  • pointer — Memory addresses

2. Non-Primitive Data Structures

Definition

Non-Primitive Data Structures are more complex data structures that are derived from primitive data types. They are used to store collections of data and define relationships between them.

Non-primitive data structures are further divided into two categories:

A. Linear Data Structures

Characteristics

In Linear Data Structures, elements are arranged in a sequential order. Each element is connected to its previous and next element (except the first and last). Traversal is done in a linear manner — one element after another.

Examples of Linear Data Structures
Data Structure Description
Array Fixed-size collection of elements of the same type stored in contiguous memory
Linked List Collection of nodes where each node contains data and a pointer to the next node
Stack LIFO (Last In First Out) structure — elements added/removed from the top
Queue FIFO (First In First Out) structure — elements added at rear, removed from front

B. Non-Linear Data Structures

Characteristics

In Non-Linear Data Structures, elements are not arranged in a sequential order. They are connected in a hierarchical or network manner. One element can be connected to multiple other elements. Traversal is non-linear.

Examples of Non-Linear Data Structures
Data Structure Description
Tree Hierarchical structure with a root node and child nodes (e.g., Binary Tree, AVL Tree, B-Tree)
Graph Collection of vertices (nodes) connected by edges (e.g., social networks, road maps)
Linear vs Non-Linear
Aspect Linear Non-Linear
Arrangement Sequential Hierarchical / Network
Traversal Single run (one after another) Multiple runs (recursive/iterative)
Memory Usually contiguous (arrays) or linked Non-contiguous, complex relationships
Examples Array, Stack, Queue, Linked List Tree, Graph
Complexity Easier to implement More complex to implement

Operations on Data Structures

Introduction

Operations are actions or functions that can be performed on data structures. Different data structures support different sets of operations, but there are some common operations that apply to most data structures.

1. Traversal

Definition

Traversal means visiting and accessing each element of the data structure exactly once for processing (e.g., displaying, summing, or searching).

Example: Array Traversal in C
int arr[5] = {10, 20, 30, 40, 50};
for(int i = 0; i < 5; i++) {
    printf("%d ", arr[i]);
}
// Output: 10 20 30 40 50

2. Insertion

Definition

Insertion is the process of adding a new element to the data structure at a specified position or following a specific rule.

Examples
  • Inserting an element at the end of an array
  • Pushing an element onto a stack
  • Enqueuing an element into a queue
  • Inserting a node in a linked list

3. Deletion

Definition

Deletion is the process of removing an existing element from the data structure.

Examples
  • Deleting an element from an array
  • Popping an element from a stack
  • Dequeuing an element from a queue
  • Removing a node from a linked list

4. Searching

Definition

Searching is the process of finding the location (index or address) of an element with a given key or value in the data structure.

Common Search Algorithms
  • Linear Search: Check each element one by one (O(n) time)
  • Binary Search: Efficient search in sorted arrays (O(log n) time)
Linear Search Example in C
int search(int arr[], int n, int key) {
    for(int i = 0; i < n; i++) {
        if(arr[i] == key) {
            return i;  // Element found at index i
        }
    }
    return -1;  // Element not found
}

5. Sorting

Definition

Sorting is the process of arranging elements of the data structure in a specific order — either ascending or descending.

Common Sorting Algorithms
  • Bubble Sort — Repeatedly swap adjacent elements if they are in wrong order
  • Selection Sort — Select the smallest element and place it at the beginning
  • Insertion Sort — Build the sorted array one item at a time
  • Merge Sort — Divide and conquer approach (O(n log n))
  • Quick Sort — Efficient divide and conquer (O(n log n) average)

6. Merging

Definition

Merging is the process of combining two data structures of the same type into a single data structure.

Example

Merging two sorted arrays into one sorted array is a key operation in Merge Sort algorithm.

7. Updating

Definition

Updating (or Modification) is the process of changing the value of an existing element in the data structure.

Example
int arr[5] = {10, 20, 30, 40, 50};
arr[2] = 99;  // Update element at index 2
// Array becomes: {10, 20, 99, 40, 50}

Key Formulas

Array Index Access

Element at position i: arr[i]

First element: arr[0]

Last element: arr[n-1], where n is the size

Time Complexity Notation

O(1) — Constant time (e.g., array access)

O(n) — Linear time (e.g., traversal, linear search)

O(log n) — Logarithmic time (e.g., binary search)

O(n²) — Quadratic time (e.g., bubble sort)

Memory for Array

Total memory = n × size of data type

Example: int arr[100] requires 100 × 4 = 400 bytes

Multiple Choice Questions

Q1

Which of the following is a primitive data structure?

  • a. Stack
  • b. Queue
  • c. Integer
  • d. Tree
Answer: c. Integer

Primitive data structures are basic types like int, char, float provided by the language. Stack, Queue, and Tree are non-primitive.

Q2

Which of the following is an example of a non-linear data structure?

  • a. Array
  • b. Linked List
  • c. Stack
  • d. Tree
Answer: d. Tree

Tree is a non-linear data structure where elements are arranged hierarchically. Array, Linked List, and Stack are linear.

Q3

What is the main difference between ADT and Data Structure?

  • a. ADT defines operations, Data Structure defines implementation
  • b. ADT is faster than Data Structure
  • c. They are the same thing
  • d. ADT uses less memory
Answer: a. ADT defines operations, Data Structure defines implementation

ADT is a logical model (what operations), while Data Structure is the physical implementation (how data is stored).

Q4

Which operation visits each element of a data structure exactly once?

  • a. Insertion
  • b. Traversal
  • c. Deletion
  • d. Searching
Answer: b. Traversal

Traversal is the process of visiting and processing each element exactly once.

Q5

In linear data structures, elements are arranged in:

  • a. Hierarchical order
  • b. Random order
  • c. Sequential order
  • d. Network order
Answer: c. Sequential order

Linear data structures arrange elements in a sequential manner, where each element is connected to the previous and next.

Q6

Which of the following is NOT a linear data structure?

  • a. Queue
  • b. Graph
  • c. Array
  • d. Linked List
Answer: b. Graph

Graph is a non-linear data structure. Queue, Array, and Linked List are linear.

These are fundamental data types directly supported by the programming language.

Examples: int, char, float, double, pointer

2. Non-Primitive Data Structures:

These are complex data structures derived from primitive types. They are further classified into:

A. Linear Data Structures:

  • Examples: Array, Linked List, Stack, Queue

Q2

Describe the basic operations that can be performed on data structures.

The basic operations on data structures are:

  1. Traversal: Visiting each element exactly once for processing (e.g., printing all elements).
  2. Insertion: Adding a new element to the data structure at a specified position.
  3. Deletion: Removing an existing element from the data structure.
  4. Searching: Finding the location of an element with a given key or value.
  5. Sorting: Arranging elements in ascending or descending order.
  6. Merging: Combining two data structures of the same type into one.
  7. Updating: Modifying the value of an existing element.

These operations form the foundation for working with any data structure efficiently.

Q3

What is Abstract Data Type? Explain with an example.

Abstract Data Type (ADT) is a mathematical model for data types where the data is defined by its behavior (operations) from the point of view of a user, rather than by its implementation.

Key Points:

  • ADT specifies what operations can be performed
  • It does not specify how these operations are implemented
  • The implementation details are hidden from the user

Example: Stack ADT

A Stack is an ADT that supports the following operations:

  • push(item) — Add an item to the top
  • pop() — Remove and return the top item
  • peek() — View the top item without removing
  • isEmpty() — Check if stack is empty

Implementation Independence: The Stack ADT can be implemented using either an array or a linked list. The user doesn't need to know which implementation is used — they only use the operations provided.

Practice Problems

Q1

Write a C program to traverse and print all elements of an integer array.

#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int n = 5;
    
    printf("Array elements: ");
    for(int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    
    return 0;
}

// Output: Array elements: 10 20 30 40 50

Explanation: This program uses a for loop to traverse the array from index 0 to n-1 and prints each element.

Q2

Write a C program to perform linear search in an array.

#include <stdio.h>

int linearSearch(int arr[], int n, int key) {
    for(int i = 0; i < n; i++) {
        if(arr[i] == key) {
            return i;  // Return index if found
        }
    }
    return -1;  // Return -1 if not found
}

int main() {
    int arr[] = {10, 25, 30, 45, 50};
    int n = 5;
    int key = 30;
    
    int result = linearSearch(arr, n, key);
    
    if(result != -1) {
        printf("Element %d found at index %d\n", key, result);
    } else {
        printf("Element %d not found\n", key);
    }
    
    return 0;
}

// Output: Element 30 found at index 2

Explanation: Linear search checks each element sequentially until the key is found or the array ends. Time complexity: O(n).

Q3

Write a C program to insert an element at a specific position in an array.

#include <stdio.h>

void insertElement(int arr[], int *n, int pos, int value) {
    // Shift elements to the right
    for(int i = *n; i > pos; i--) {
        arr[i] = arr[i-1];
    }
    arr[pos] = value;
    (*n)++;  // Increase array size
}

int main() {
    int arr[10] = {10, 20, 30, 40, 50};
    int n = 5;
    int pos = 2;
    int value = 99;
    
    printf("Before insertion: ");
    for(int i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");
    
    insertElement(arr, &n, pos, value);
    
    printf("After insertion: ");
    for(int i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");
    
    return 0;
}

// Output:
// Before insertion: 10 20 30 40 50
// After insertion: 10 20 99 30 40 50

Explanation: Elements from the insertion position onward are shifted right, then the new value is placed at the specified position.

Quick Revision

Quick Revision Points
  • Data: Raw facts and figures (e.g., 42, 'A', "Hello").
  • Data Item: A single unit of value.
  • Data Type: Classification specifying type and allowed operations (int, char, float).
  • Data Structure: Specialized way of organizing data for efficient access.
  • ADT: Logical model defined by operations, not implementation.
  • Primitive DS: int, char, float, double, pointer.
  • Non-Primitive DS: Array, Stack, Queue, Tree, Graph.
  • Linear DS: Sequential arrangement (Array, Stack, Queue, List).
  • Non-Linear DS: Hierarchical arrangement (Tree, Graph).
  • Operations: Traversal, Insertion, Deletion, Searching, Sorting, Merging, Updating.
Must Remember for Exams
  • Definition of Data Structure and ADT — very important for 1-mark and 2-mark questions.
  • Classification diagram: Primitive vs Non-Primitive, Linear vs Non-Linear — draw this in exams.
  • List of operations on data structures — know at least 5.
  • Difference between Linear and Non-Linear — frequently asked in comparison questions.
  • Examples of each type: Array (linear), Tree (non-linear), int (primitive).
  • Time complexity notation: O(1), O(n), O(log n), O(n²) — understand basics.
Common Mistakes to Avoid
  • Confusing ADT with Data Structure — ADT is logical, DS is physical implementation.
  • Mixing primitive and non-primitive examples — int is primitive, array is non-primitive.
  • Forgetting that Graph is non-linear, not linear.
  • Not being able to list all 7 operations — practice writing them.
  • Confusing traversal (visit all) with searching (find one).
  • Not understanding that Stack can be implemented using array OR linked list (ADT concept).
