Stacks

Introduction to Stack

Definition

A Stack is a linear data structure that follows the LIFO (Last In First Out) principle. This means the element that is inserted last is the first one to be removed.

Real-World Analogy

Think of a stack of plates in a cafeteria:

  • You can only add a plate on top (push)
  • You can only remove the top plate (pop)
  • The last plate placed is the first one taken out
  • You cannot access plates in the middle without removing the ones on top

Other examples: Stack of books, stack of trays, undo operation in text editors, browser back button.

Key Characteristics
  • Only one end is open for insertion and deletion (called the top)
  • Operations are performed only at the top
  • No random access — you cannot access the middle element directly
  • Time complexity: O(1) for push and pop operations

Array Representation of Stack

How Stack is Stored in Memory

A stack can be implemented using a static array with the following components:

  • Array: A fixed-size array to store elements (e.g., int stack[MAX])
  • top: An integer variable that keeps track of the index of the topmost element
  • MAX: The maximum capacity of the stack (e.g., 100)
Stack Structure in C
#define MAX 100

int stack[MAX];
int top = -1;  // Initialize to -1 to indicate empty stack
Understanding 'top' Variable
  • top = -1 → Stack is empty
  • top = 0 → One element in stack at index 0
  • top = MAX-1 → Stack is full
  • top always points to the last inserted element

Operations on Stack

1. push(item) — Insert Element

Definition

push(item) adds an element to the top of the stack.

Algorithm: push(item)
1. Check if stack is full (top == MAX-1)
2. If full, print "Stack Overflow" and exit
3. Otherwise, increment top by 1
4. Place item at stack[top]
5. End
C Implementation of push()
void push(int item) {
    if(top == MAX - 1) {
        printf("Stack Overflow! Cannot push %d\n", item);
        return;
    }
    top++;
    stack[top] = item;
    printf("%d pushed to stack\n", item);
}

2. pop() — Delete Element

Definition

pop() removes and returns the top element from the stack.

Algorithm: pop()
1. Check if stack is empty (top == -1)
2. If empty, print "Stack Underflow" and exit
3. Otherwise, retrieve item from stack[top]
4. Decrement top by 1
5. Return the retrieved item
6. End
C Implementation of pop()
int pop() {
    if(top == -1) {
        printf("Stack Underflow! Stack is empty\n");
        return -1;
    }
    int item = stack[top];
    top--;
    return item;
}

3. peek() / top() — View Top Element

C Implementation of peek()
int peek() {
    if(top == -1) {
        printf("Stack is empty\n");
        return -1;
    }
    return stack[top];
}

4. isEmpty() — Check if Empty

C Implementation of isEmpty()
int isEmpty() {
    return (top == -1);
}

5. isFull() — Check if Full

C Implementation of isFull()
int isFull() {
    return (top == MAX - 1);
}

Complete Stack Program

Complete Stack Implementation in C
#include <stdio.h>
#define MAX 5

int stack[MAX];
int top = -1;

void push(int item) {
    if(top == MAX - 1) {
        printf("Stack Overflow!\n");
        return;
    }
    stack[++top] = item;
    printf("%d pushed\n", item);
}

int pop() {
    if(top == -1) {
        printf("Stack Underflow!\n");
        return -1;
    }
    return stack[top--];
}

int peek() {
    if(top == -1) {
        printf("Stack is empty\n");
        return -1;
    }
    return stack[top];
}

void display() {
    if(top == -1) {
        printf("Stack is empty\n");
        return;
    }
    printf("Stack elements: ");
    for(int i = top; i >= 0; i--) {
        printf("%d ", stack[i]);
    }
    printf("\n");
}

int main() {
    push(10);
    push(20);
    push(30);
    display();
    printf("Top element: %d\n", peek());
    printf("Popped: %d\n", pop());
    display();
    return 0;
}

Applications of Stack

1. Infix to Postfix Conversion

Understanding Notations

Infix Notation: Operators are placed between operands (e.g., A + B)

Postfix Notation (Reverse Polish Notation): Operators are placed after operands (e.g., A B +)

Infix Postfix
A + BA B +
A + B * CA B C * +
(A + B) * CA B + C *
A * B + C / DA B * C D / +
Why Convert to Postfix?
  • No need for parentheses
  • No ambiguity in operator precedence
  • Easier for computers to evaluate
  • Used in compilers and calculators
Algorithm: Infix to Postfix
1. Initialize an empty stack and an empty output string
2. Scan the infix expression from left to right
3. For each character:
   a. If operand (A-Z, a-z, 0-9), add to output
   b. If '(', push to stack
   c. If ')', pop from stack and add to output until '(' is found
   d. If operator (+, -, *, /, ^):
      - Pop operators from stack with higher or equal precedence
      - Add them to output
      - Push current operator to stack
4. After scanning, pop all remaining operators from stack to output
5. Return output as postfix expression
Operator Precedence (High to Low)

1. ^ (Exponentiation) — Highest

2. * / (Multiplication, Division)

3. + - (Addition, Subtraction) — Lowest

Trace: Convert A + B * C to Postfix
Input Stack Output Action
A-AOperand, add to output
++AOperator, push to stack
B+A BOperand, add to output
*+ *A B* has higher precedence, push
C+ *A B COperand, add to output
End+A B C *Pop *, add to output
End-A B C * +Pop +, add to output

Result: A B C * +

2. Evaluating Postfix Expressions

How Postfix Evaluation Works

Postfix expressions are easier for computers to evaluate because they don't require parentheses and operator precedence rules are implicit.

Algorithm: Evaluate Postfix
1. Initialize an empty stack
2. Scan the postfix expression from left to right
3. For each character:
   a. If operand (number), push it to stack
   b. If operator (+, -, *, /, ^):
      - Pop two operands from stack (op2 = pop(), op1 = pop())
      - Perform operation: result = op1 operator op2
      - Push result back to stack
4. After scanning, the stack contains one element — the final result
5. Pop and return the result
Trace: Evaluate 5 3 + 2 *
Input Stack Action
55Push operand
35, 3Push operand
+8Pop 3, 5; compute 5+3=8; push 8
28, 2Push operand
*16Pop 2, 8; compute 8*2=16; push 16

Final Result: 16

C Code: Evaluate Postfix
#include <stdio.h>
#include <ctype.h>
#define MAX 50

int stack[MAX];
int top = -1;

void push(int x) {
    stack[++top] = x;
}

int pop() {
    return stack[top--];
}

int evaluatePostfix(char* exp) {
    for(int i = 0; exp[i] != '\0'; i++) {
        if(isdigit(exp[i])) {
            push(exp[i] - '0');  // Convert char to int
        }
        else {
            int op2 = pop();
            int op1 = pop();
            switch(exp[i]) {
                case '+': push(op1 + op2); break;
                case '-': push(op1 - op2); break;
                case '*': push(op1 * op2); break;
                case '/': push(op1 / op2); break;
            }
        }
    }
    return pop();
}

int main() {
    char exp[] = "53+2*";
    printf("Result: %d\n", evaluatePostfix(exp));
    return 0;
}

Queues

Introduction to Queue

Definition

A Queue is a linear data structure that follows the FIFO (First In First Out) principle. This means the element that is inserted first is the first one to be removed.

Real-World Analogy

Think of a queue of people at a ticket counter:

  • People join the queue at the rear (back)
  • The person at the front gets served first
  • The first person to arrive is the first to leave
  • No one can cut the line — everyone waits their turn

Other examples: Printer job queue, CPU task scheduling, call center waiting line, breadth-first search in graphs.

Key Characteristics
  • Two ends: front (for deletion) and rear (for insertion)
  • Insertion happens at the rear
  • Deletion happens at the front
  • Time complexity: O(1) for enqueue and dequeue operations

Array Representation of Queue

How Queue is Stored in Memory

A queue can be implemented using a static array with the following components:

  • Array: A fixed-size array to store elements (e.g., int queue[MAX])
  • front: Index of the first element (the one to be removed)
  • rear: Index of the last element (the one just inserted)
  • MAX: Maximum capacity of the queue
Queue Structure in C
#define MAX 100

int queue[MAX];
int front = -1;
int rear = -1;
Understanding front and rear
  • front = -1 and rear = -1 → Queue is empty
  • rear = MAX-1 → Queue is full (in linear queue)
  • front > rear → Queue has become empty after deletions

Operations on Queue

1. enqueue(item) — Insert Element

Definition

enqueue(item) adds an element to the rear of the queue.

Algorithm: enqueue(item)
1. Check if queue is full (rear == MAX-1)
2. If full, print "Queue Overflow" and exit
3. If queue is empty (front == -1), set front = 0
4. Increment rear by 1
5. Place item at queue[rear]
6. End
C Implementation of enqueue()
void enqueue(int item) {
    if(rear == MAX - 1) {
        printf("Queue Overflow!\n");
        return;
    }
    if(front == -1) {
        front = 0;  // First element
    }
    rear++;
    queue[rear] = item;
    printf("%d enqueued\n", item);
}

2. dequeue() — Delete Element

Definition

dequeue() removes and returns the front element from the queue.

Algorithm: dequeue()
1. Check if queue is empty (front == -1 or front > rear)
2. If empty, print "Queue Underflow" and exit
3. Retrieve item from queue[front]
4. Increment front by 1
5. If queue becomes empty (front > rear), reset front = rear = -1
6. Return the retrieved item
7. End
C Implementation of dequeue()
int dequeue() {
    if(front == -1 || front > rear) {
        printf("Queue Underflow!\n");
        return -1;
    }
    int item = queue[front];
    front++;
    if(front > rear) {
        front = rear = -1;  // Reset queue
    }
    return item;
}

Types of Queues

1. Circular Queue

Why Circular Queue?

Problem with Linear Queue: After several enqueue and dequeue operations, even if the queue has space at the beginning, we cannot insert new elements if rear reaches MAX-1. This is called false overflow.

Solution: Circular Queue — the last position is connected back to the first position to form a circle. We use modulo arithmetic to wrap around.

Circular Queue Formulas

rear = (rear + 1) % MAX

front = (front + 1) % MAX

Full condition: (rear + 1) % MAX == front

Empty condition: front == -1

Circular Queue enqueue()
void enqueue(int item) {
    int nextRear = (rear + 1) % MAX;
    if(nextRear == front) {
        printf("Queue is full\n");
        return;
    }
    if(front == -1) {
        front = 0;
    }
    rear = nextRear;
    queue[rear] = item;
}
Circular Queue dequeue()
int dequeue() {
    if(front == -1) {
        printf("Queue is empty\n");
        return -1;
    }
    int item = queue[front];
    if(front == rear) {
        front = rear = -1;  // Last element removed
    } else {
        front = (front + 1) % MAX;
    }
    return item;
}

2. Double Ended Queue (Deque)

Definition

A Deque (Double Ended Queue) is a queue where insertion and deletion can be performed at both ends — front and rear.

Types of Deque

1. Input Restricted Deque:

  • Insertion is allowed only at the rear
  • Deletion is allowed at both front and rear

2. Output Restricted Deque:

  • Deletion is allowed only at the front
  • Insertion is allowed at both front and rear

Application: Round Robin CPU Scheduling

What is Round Robin?

Round Robin is a CPU scheduling algorithm used in operating systems where each process is given a fixed time slice (called a quantum) to execute.

How it works:

  1. Processes are kept in a ready queue (FIFO)
  2. CPU picks the first process from the queue
  3. Process runs for the quantum time (e.g., 2 ms)
  4. If the process is not finished, it is moved to the rear of the queue
  5. Next process from the front gets CPU time
  6. This continues until all processes are complete
Advantages of Round Robin
  • Fair allocation of CPU time to all processes
  • No starvation — every process gets a turn
  • Good response time for time-sharing systems
  • Simple to implement using a circular queue

Recursion

Introduction to Recursion

Definition

Recursion is a programming technique where a function calls itself directly or indirectly. It is a powerful tool for solving problems that can be broken down into smaller, identical sub-problems.

How Recursion Works

A recursive function has two key components:

1. Base Case: The simplest instance of the problem that can be solved directly without further recursion. This is the stopping condition that prevents infinite recursion.

2. Recursive Step: The part of the function that breaks the problem down into a smaller sub-problem and calls itself with the reduced input.

Simple Recursion Example: Factorial
// Factorial: n! = n × (n-1) × (n-2) × ... × 1
// Base case: 0! = 1

int factorial(int n) {
    if(n == 0) {
        return 1;  // Base case
    }
    return n * factorial(n - 1);  // Recursive step
}

// Example: factorial(5) = 5 × 4 × 3 × 2 × 1 = 120
Trace: factorial(4)
factorial(4)
  = 4 * factorial(3)
      = 3 * factorial(2)
          = 2 * factorial(1)
              = 1 * factorial(0)
                  = 1  (base case)
              = 1 * 1 = 1
          = 2 * 1 = 2
      = 3 * 2 = 6
  = 4 * 6 = 24

Result: 24

Example 1: GCD using Euclidean Algorithm

What is GCD?

GCD (Greatest Common Divisor) of two numbers is the largest positive integer that divides both numbers without a remainder.

Example: GCD(48, 18) = 6

Euclidean Algorithm

The Euclidean algorithm is based on the principle:

gcd(a, b) = gcd(b, a % b)

Base case: gcd(a, 0) = a

Algorithm:
1. If b == 0, return a (base case)
2. Otherwise, return gcd(b, a % b) (recursive step)
C Code: GCD Recursion
int gcd(int a, int b) {
    if(b == 0) {
        return a;  // Base case
    }
    return gcd(b, a % b);  // Recursive step
}

int main() {
    int result = gcd(48, 18);
    printf("GCD = %d\n", result);
    return 0;
}

Example 2: Tower of Hanoi

The Tower of Hanoi Problem

The Tower of Hanoi is a classic mathematical puzzle with three rods and n disks of different sizes.

Rules:

  • Only one disk can be moved at a time
  • Each move consists of taking the top disk from one rod and placing it on another rod
  • No disk may be placed on top of a smaller disk

Goal: Move all disks from the source rod to the destination rod using an auxiliary rod.

Recursive Solution

To move n disks from source (A) to destination (C) using auxiliary (B):

1. Move n-1 disks from A to B using C (recursive call)
2. Move the largest disk from A to C (base operation)
3. Move n-1 disks from B to C using A (recursive call)

Base case: If n == 1, move the disk directly from source to destination
C Code: Tower of Hanoi
#include <stdio.h>

void towerOfHanoi(int n, char source, char dest, char aux) {
    if(n == 1) {
        printf("Move disk 1 from %c to %c\n", source, dest);
        return;
    }
    towerOfHanoi(n-1, source, aux, dest);
    printf("Move disk %d from %c to %c\n", n, source, dest);
    towerOfHanoi(n-1, aux, dest, source);
}

int main() {
    int n = 3;
    printf("Tower of Hanoi for %d disks:\n", n);
    towerOfHanoi(n, 'A', 'C', 'B');
    return 0;
}
Output: Tower of Hanoi (n=3)
Move disk 1 from A to C
Move disk 2 from A to B
Move disk 1 from C to B
Move disk 3 from A to C
Move disk 1 from B to A
Move disk 2 from B to C
Move disk 1 from A to C

Total moves = 7 (which is 2^3 - 1)
Number of Moves

For n disks: Total moves = 2^n - 1

Example: For 3 disks = 2³ - 1 = 7 moves

Example: For 4 disks = 2⁴ - 1 = 15 moves

Common Recursion Pitfalls
  • Missing Base Case: Leads to infinite recursion and stack overflow
  • Incorrect Base Case: Never reaches the termination condition
  • Not reducing problem size: Recursive call doesn't move toward base case
  • Stack Overflow: Too many recursive calls exhaust memory

Key Formulas

Empty: top == -1

Full: top == MAX - 1

Push: stack[++top] = item

Pop: item = stack[top--]

Empty: front == -1 or front > rear

Enqueue: queue[++rear] = item

Enqueue: rear = (rear + 1) % MAX

Multiple Choice Questions

Q1

Stack follows which principle?

  • a. FIFO
  • b. LIFO
  • c. LILO
  • d. FILO
Answer: b. LIFO

Stack follows Last In First Out (LIFO) principle — the last element inserted is the first to be removed.

Q2

Queue follows which principle?

  • a. LIFO
  • b. FIFO
  • c. Random
  • d. None of the above
Answer: b. FIFO

Queue follows First In First Out (FIFO) principle — the first element inserted is the first to be removed.

Q3

Which operation is used to insert an element into a stack?

  • a. enqueue
  • b. push
  • c. insert
  • d. add
Answer: b. push

The push operation is used to insert an element onto the top of a stack.

Q4

Which operation removes an element from a queue?

  • a. pop
  • b. dequeue
  • c. delete
  • d. remove
Answer: b. dequeue

The dequeue operation removes and returns the front element from a queue.

Q5

What is the postfix form of A + B * C?

  • a. ABC*+
  • b. AB+C*
  • c. ABC+*
  • d. A+BC*
Answer: a. ABC*+

Since * has higher precedence than +, we first write BC*, then add A: ABC*+

Q6

In a circular queue, what is the formula for the next rear position?

  • a. rear + 1
  • b. (rear + 1) % MAX
  • c. rear % MAX
  • d. (rear - 1) % MAX
Answer: b. (rear + 1) % MAX

Circular queue uses modulo arithmetic to wrap around: rear = (rear + 1) % MAX

Q7

What is the condition for an empty stack?

  • a. top == 0
  • b. top == -1
  • c. top == MAX
  • d. top == MAX-1
Answer: b. top == -1

top is initialized to -1 to indicate an empty stack.

Q8

Which data structure is used for function call management?

  • a. Queue
  • b. Stack
  • c. Array
  • d. Tree
Answer: b. Stack

Stack is used for function call management (call stack). LIFO ensures the last function called is the first to return.

Q9

In recursion, what prevents infinite recursion?

  • a. Loop condition
  • b. Base case
  • c. Recursive step
  • d. Function call
Answer: b. Base case

The base case is the termination condition that stops recursion and prevents infinite loops.

Q10

GCD(48, 18) using Euclidean algorithm equals?

  • a. 2
  • b. 6
  • c. 12
  • d. 18
Answer: b. 6

Using Euclidean algorithm: gcd(48,18) → gcd(18,12) → gcd(12,6) → gcd(6,0) = 6

Q11

How many moves are needed to solve Tower of Hanoi with 4 disks?

  • a. 7
  • b. 15
  • c. 31
  • d. 63
Answer: b. 15

Formula: 2^n - 1. For 4 disks: 2^4 - 1 = 16 - 1 = 15 moves.

Q12

Which CPU scheduling algorithm uses a queue?

  • a. Shortest Job First
  • b. Round Robin
  • c. Priority Scheduling
  • d. LIFO Scheduling
Answer: b. Round Robin

Round Robin scheduling uses a FIFO queue to manage processes with time quantum.

Short Questions

Q1

Define Stack.

A stack is a linear data structure that follows the LIFO (Last In First Out) principle. The element inserted last is removed first. Operations are performed only at one end called the top.

Q2

Define Queue.

A queue is a linear data structure that follows the FIFO (First In First Out) principle. The element inserted first is removed first. Insertion happens at the rear and deletion at the front.

Q3

What is Stack Overflow?

Stack Overflow is a condition that occurs when we try to push an element onto a stack that is already full (top == MAX-1). It indicates there is no space to insert a new element.

Q4

What is Queue Underflow?

Queue Underflow occurs when we try to dequeue an element from an empty queue (front == -1 or front > rear). It means there are no elements to remove.

Q5

What is a Circular Queue?

A circular queue is a queue where the last position is connected back to the first position to form a circle. This overcomes the limitation of linear queue's false overflow by reusing empty spaces using modulo arithmetic.

Q6

What is Recursion?

Recursion is a programming technique where a function calls itself directly or indirectly to solve a problem. It requires a base case (termination condition) and a recursive step (function calling itself with smaller input).

Q7

What is the difference between push and pop?

Push: Adds an element to the top of the stack (insertion operation).

Pop: Removes and returns the top element from the stack (deletion operation).

Q8

Convert A + B to postfix notation.

Postfix form: AB+

Operands A and B come first, followed by operator +.

Q9

What is a Deque?

Deque (Double Ended Queue) is a queue where insertion and deletion can be performed at both ends (front and rear). It can be input-restricted or output-restricted.

Q10

What is the base case in recursion?

The base case is the simplest instance of the problem that can be solved directly without further recursion. It is the termination condition that prevents infinite recursion.

Long Questions

Q1

Explain stack operations (push and pop) with algorithms and C code.

Stack Operations

1. Push Operation:

Algorithm:

1. Check if top == MAX-1 (stack full)
2. If full, print "Stack Overflow"
3. Else, increment top
4. Place item at stack[top]
void push(int item) {
    if(top == MAX - 1) {
        printf("Stack Overflow\n");
        return;
    }
    stack[++top] = item;
}

2. Pop Operation:

Algorithm:

1. Check if top == -1 (stack empty)
2. If empty, print "Stack Underflow"
3. Else, retrieve item from stack[top]
4. Decrement top
5. Return item
int pop() {
    if(top == -1) {
        printf("Stack Underflow\n");
        return -1;
    }
    return stack[top--];
}

Q2

Explain queue operations (enqueue and dequeue) with algorithms.

Queue Operations

1. Enqueue Operation:

Algorithm:

1. Check if rear == MAX-1 (queue full)
2. If full, print "Queue Overflow"
3. If front == -1, set front = 0
4. Increment rear
5. Place item at queue[rear]

2. Dequeue Operation:

Algorithm:

1. Check if front == -1 or front > rear (queue empty)
2. If empty, print "Queue Underflow"
3. Retrieve item from queue[front]
4. Increment front
5. If front > rear, reset front = rear = -1
6. Return item

Q3

Explain the algorithm for converting infix to postfix notation with an example.

Infix to Postfix Conversion

Algorithm:

1. Initialize empty stack and output string
2. Scan infix expression left to right
3. For each character:
   - If operand, add to output
   - If '(', push to stack
   - If ')', pop until '(' and add to output
   - If operator:
     * Pop operators with >= precedence
     * Add them to output
     * Push current operator to stack
4. Pop all remaining operators to output
5. Return output

Example: Convert (A + B) * C to postfix

InputStackOutput
((
A(A
+( +A
B( +A B
)A B +
**A B +
C*A B + C
EndA B + C *

Result: AB+C*

Q4

Explain the algorithm for evaluating postfix expressions with an example.

Postfix Evaluation

Algorithm:

1. Initialize empty stack
2. Scan postfix expression left to right
3. For each character:
   - If operand, push to stack
   - If operator:
     * Pop two operands (op2, op1)
     * Compute result = op1 operator op2
     * Push result to stack
4. Final stack element is the result

Example: Evaluate 5 6 + 2 *

InputStackOperation
55Push 5
65, 6Push 6
+11Pop 6,5; 5+6=11; Push 11
211, 2Push 2
*22Pop 2,11; 11*2=22; Push 22

Result: 22

Q5

What is a circular queue? Explain its advantages over a linear queue.

Circular Queue

Definition: A circular queue is a queue where the last position is connected back to the first position to form a circle. It uses modulo arithmetic to wrap around indices.

Advantages over Linear Queue:

  • Efficient Memory Use: Reuses empty spaces left after dequeue operations
  • No False Overflow: Even if rear reaches MAX-1, queue can accept elements if front has moved
  • Continuous Operation: Better for systems requiring continuous data processing (buffers, scheduling)

Key Formulas:

rear = (rear + 1) % MAX

front = (front + 1) % MAX

Full condition: (rear + 1) % MAX == front

Q6

Explain recursion with GCD example using Euclidean algorithm.

Recursion and GCD

Recursion: A technique where a function calls itself. It requires a base case and recursive step.

GCD using Euclidean Algorithm:

gcd(a, b) = gcd(b, a % b)

Base case: gcd(a, 0) = a

int gcd(int a, int b) {
    if(b == 0)
        return a;  // Base case
    return gcd(b, a % b);  // Recursive step
}

Trace: gcd(48, 18)

gcd(48, 18) → gcd(18, 12) → gcd(12, 6) → gcd(6, 0) = 6

GCD(48, 18) = 6

Q7

Explain the Tower of Hanoi problem and its recursive solution.

Tower of Hanoi

Problem: Move n disks from source rod to destination rod using an auxiliary rod, with the rule that no larger disk can be placed on a smaller disk.

Recursive Solution:

To move n disks from A to C using B:
1. Move n-1 disks from A to B using C
2. Move largest disk from A to C
3. Move n-1 disks from B to C using A

Base case: If n == 1, move directly from A to C
void hanoi(int n, char from, char to, char aux) {
    if(n == 1) {
        printf("Move disk 1 from %c to %c\n", from, to);
        return;
    }
    hanoi(n-1, from, aux, to);
    printf("Move disk %d from %c to %c\n", n, from, to);
    hanoi(n-1, aux, to, from);
}

Total moves = 2^n - 1

For 3 disks: 2³ - 1 = 7 moves

Write a C program to implement stack with push, pop, and display operations.

#include <stdio.h>
#define MAX 5

int stack[MAX];
int top = -1;

void push(int item) {
    if(top == MAX - 1) {
        printf("Stack Overflow\n");
        return;
    }
    stack[++top] = item;
    printf("%d pushed\n", item);
}

int pop() {

        printf("Stack Underflow\n");
        return -1;
    }
    return stack[top--];
}

        printf("Stack is empty\n");
        return;

    printf("\n");
}

    push(30);
    display();
    printf("Popped: %d\n", pop());

Q2

Write a C program to implement queue with enqueue and dequeue operations.

#include <stdio.h>
#define MAX 5

int queue[MAX];
int front = -1, rear = -1;

void enqueue(int item) {
    if(rear == MAX - 1) {
        printf("Queue Overflow\n");
        return;
    }
    if(front == -1) front = 0;
    queue[++rear] = item;
    printf("%d enqueued\n", item);
}

int dequeue() {
    if(front == -1 || front > rear) {
        printf("Queue Underflow\n");
        return -1;
    }
    int item = queue[front++];
    if(front > rear)
        front = rear = -1;
    return item;
}

void display() {
    if(front == -1) {
        printf("Queue is empty\n");
        return;
    }
    printf("Queue: ");
    for(int i = front; i <= rear; i++)
        printf("%d ", queue[i]);
    printf("\n");
}

int main() {
    enqueue(10);
    enqueue(20);
    enqueue(30);
    display();
    printf("Dequeued: %d\n", dequeue());
    display();
    return 0;
}

Q3

Write a C program to evaluate a postfix expression.

#include <stdio.h>
#include <ctype.h>
#define MAX 50

int stack[MAX];
int top = -1;

void push(int x) {
    stack[++top] = x;
}

int pop() {
    return stack[top--];
}

int evaluate(char* exp) {
    for(int i = 0; exp[i] != '\0'; i++) {
        if(isdigit(exp[i])) {
            push(exp[i] - '0');
        }
        else {
            int op2 = pop();
            int op1 = pop();
            switch(exp[i]) {
                case '+': push(op1 + op2); break;
                case '-': push(op1 - op2); break;
                case '*': push(op1 * op2); break;
                case '/': push(op1 / op2); break;
            }
        }
    }
    return pop();
}

int main() {
    char exp[] = "53+2*";
    printf("Result: %d\n", evaluate(exp));
    return 0;
}

Q6

Write a C program to implement circular queue.

#include <stdio.h>
#define MAX 5

int queue[MAX];
int front = -1, rear = -1;

void enqueue(int item) {
    int nextRear = (rear + 1) % MAX;
    if(nextRear == front) {
        printf("Queue is full\n");
        return;
    }
    if(front == -1) front = 0;
    rear = nextRear;
    queue[rear] = item;
    printf("%d enqueued\n", item);
}

int dequeue() {
    if(front == -1) {
        printf("Queue is empty\n");
        return -1;
    }
    int item = queue[front];
    if(front == rear) {
        front = rear = -1;
    } else {
        front = (front + 1) % MAX;
    }
    return item;
}

void display() {
    if(front == -1) {
        printf("Queue is empty\n");
        return;
    }
    printf("Queue: ");
    int i = front;
    while(1) {
        printf("%d ", queue[i]);
        if(i == rear) break;
        i = (i + 1) % MAX;
    }
    printf("\n");
}

int main() {
    enqueue(10);
    enqueue(20);
    enqueue(30);
    display();
    printf("Dequeued: %d\n", dequeue());
    display();
    return 0;
}

Write a C program to calculate factorial using recursion.

#include <stdio.h>

int factorial(int n) {

    return n * factorial(n - 1);

Quick Revision

Quick Revision Points
  • Stack: LIFO structure; operations at top only; push, pop, peek; top = -1 for empty.
  • Queue: FIFO structure; enqueue at rear, dequeue from front; front and rear pointers.
  • Stack Overflow: top == MAX-1 (full stack).
  • Queue Underflow: front == -1 or front > rear (empty queue).
  • Circular Queue: Last connects to first; uses modulo: (rear+1) % MAX; no false overflow.
  • Deque: Double ended queue; insertion/deletion at both ends; input-restricted or output-restricted.
  • Infix: A + B (operator between operands).
  • Postfix: A B + (operator after operands); no parentheses needed.
  • Recursion: Function calls itself; needs base case + recursive step.
  • GCD: gcd(a, b) = gcd(b, a % b); base: gcd(a, 0) = a.
  • Tower of Hanoi: Move n disks; 2^n - 1 moves; 3 steps: move n-1, move largest, move n-1.
  • Round Robin: CPU scheduling; uses queue; each process gets time quantum.
Must Remember for Exams
  • Push/Pop algorithms — know step-by-step for 6-mark questions.
  • Enqueue/Dequeue algorithms — frequently asked.
  • Infix to Postfix conversion — practice at least 3 examples; know operator precedence.
  • Postfix evaluation — trace with stack, show each step in table format.
  • Circular queue formulas: (rear+1) % MAX, (front+1) % MAX — very important.
  • GCD trace — show all recursive calls in table.
  • Tower of Hanoi output — for n=3, write all 7 moves.
  • Stack vs Queue comparison table — frequently asked in 2-mark questions.
  • Recursion vs Iteration differences — know at least 4 points.
  • Applications: Stack for function calls/expression eval; Queue for Round Robin.
Common Mistakes to Avoid
  • Confusing LIFO (stack) with FIFO (queue) — remember plate stack vs ticket queue analogy.
  • Forgetting to check overflow/underflow conditions in code — always check before push/pop.
  • Wrong operator precedence in infix-to-postfix (^ > * / > + -).
  • Forgetting to increment top BEFORE push: should be stack[++top], not stack[top++].
  • In circular queue, using rear+1 instead of (rear+1) % MAX — always use modulo.
  • In recursion, missing base case leads to infinite recursion and stack overflow.
  • In postfix evaluation, wrong order: pop() gives op2 first, then op1; compute op1 operator op2.
  • Tower of Hanoi: forgetting the formula 2^n - 1 for total moves.
  • Not resetting front = rear = -1 when queue becomes empty after dequeue.
