About This Course

Course Aim

  • Study structured programming concepts and their applications
  • Understand Linear Data Structures: Stacks, Queues, Linked Lists
  • Study Dynamic Memory Allocation techniques
  • Understand Non-Linear Data Structures: Trees and Graphs
  • Apply Graph theory to real-world problems
  • Study Recursion in depth with practical examples

Course Outcomes

  • Computationally formulate problems and write code to solve them
  • Gain strong understanding of Data Structures and algorithms
  • Develop structured solutions through hands-on learning
  • Implement and analyze data structure operations in C

Prerequisites

Students should have a Basic Knowledge of Computer Systems and a working understanding of C Programming — including variables, arrays, pointers, functions, and structures.

Exam Tips
  • End Semester exam carries 60 marks — focus heavily on all 4 units.
  • MCQs (1 mark), Short answers (1–2 marks), and Long answers (6 marks) are typical.
  • Algorithm traces, code writing, and definition questions are very common.
  • Practice diagrams for trees, graphs, linked lists, and stack/queue operations.
