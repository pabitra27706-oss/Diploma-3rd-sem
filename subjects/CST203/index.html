About This Course

Course Aim

To learn scripting language features and programming using Python, with a focus on practical and modern application development including graphics, GUI, and data visualization.

Course Objectives

  • Introduce Python through core language basics and program design techniques
  • Understand programming facilities — graphics, GUI, data visualization
  • Utilize high-performance constructs for practical application development

Learning Outcomes

  • Write Python programs using proper syntax and data types
  • Implement control flow and functions effectively
  • Handle files, text, and regular expressions
  • Build basic web applications using Django

Prerequisites

No formal prerequisites. Basic understanding of programming concepts (variables, loops) is helpful but not required. Python is beginner-friendly and ideal as a first scripting language.

Important Exam Tips
  • Questions are distributed across all 5 units — no unit is skipped.
  • Every unit has questions in the MCQ section.
  • Detailed subjective questions may require code writing, tracing, or diagram explanation.
  • Indentation and syntax are critically checked in code-writing answers — Python is indent-sensitive!
  • Unit 5 (Django) is often asked as a 6-mark question — know MVC, URL routing, and template syntax.
  • Regular expressions (Unit 4) are frequently tested — practice re.match(), re.search(), re.sub() patterns.
