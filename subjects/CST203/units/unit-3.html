Functions

What is a Function?

A function is a named, reusable block of code that performs a specific task. Functions help in organizing code, avoiding repetition (DRY — Don't Repeat Yourself), and making programs easier to read and maintain.

Function Definition Syntax
def function_name(parameters):
    """docstring — optional description"""
    # function body
    return value # optional
Function Examples
# Simple function — no parameters, no return
def greet():
    """Prints a greeting message."""
    print("Hello, World!")

greet()   # Calling the function → Hello, World!

# Function with parameters and return value
def add(a, b):
    """Returns the sum of a and b."""
    return a + b

result = add(5, 3)
print(result)   # 8

# Function with multiple return values
def min_max(numbers):
    return min(numbers), max(numbers)

lo, hi = min_max([4, 1, 9, 2, 7])
print(lo, hi)   # 1 9

# Calling with keyword arguments
def display(name, age):
    print(f"Name: {name}, Age: {age}")

display(age=20, name="Alice")   # Order doesn't matter with keywords
Pass by Object Reference

In Python, all arguments are passed by object reference (also called "pass by sharing"). This means:

  • If you pass an immutable object (int, str, tuple) — the function gets a copy of the reference. Modifying it inside the function does NOT affect the original.
  • If you pass a mutable object (list, dict) — the function gets the same reference. Modifying it inside DOES affect the original.
Pass by Object Reference Demo
# Immutable — original not affected
def try_modify(x):
    x = x + 10
    print("Inside:", x)

num = 5
try_modify(num)
print("Outside:", num)   # Still 5

# Mutable — original IS affected
def add_item(lst):
    lst.append(99)

my_list = [1, 2, 3]
add_item(my_list)
print(my_list)   # [1, 2, 3, 99] — modified!

Parameters and Arguments

Parameter vs Argument

Parameter: Variable listed in the function definition.
Argument: Actual value passed to the function when calling it.

Example: def add(a, b): — a and b are parameters. add(5, 3) — 5 and 3 are arguments.

Positional Parameters

Arguments are matched to parameters by their position (order). The first argument goes to the first parameter, second to second, and so on.

Positional Parameters
def describe(name, city, age):
    print(f"{name} lives in {city} and is {age} years old.")

describe("Alice", "Kolkata", 20)
# Alice lives in Kolkata and is 20 years old.

# Order matters for positional arguments
describe(20, "Alice", "Kolkata")
# Wrong — positional order matters!
Default (Optional) Parameters

Parameters can have default values. If the caller does not provide a value for that parameter, the default is used. Default parameters must come after non-default parameters.

Default Parameters
def greet(name, message="Hello"):
    print(f"{message}, {name}!")

greet("Alice")              # Hello, Alice!
greet("Bob", "Good morning")  # Good morning, Bob!

# Keyword arguments — order independent
def power(base, exponent=2):
    return base ** exponent

print(power(3))          # 9  (3^2, default exponent=2)
print(power(2, 10))      # 1024 (2^10)
print(power(exponent=3, base=4))  # 64 (keyword)
Arbitrary Arguments — *args

*args allows a function to accept any number of positional arguments. Inside the function, args is a tuple containing all the extra positional arguments.

*args Example
def sum_all(*args):
    """Accepts any number of numbers and returns their sum."""
    print(type(args))   # <class 'tuple'>
    total = 0
    for num in args:
        total += num
    return total

print(sum_all(1, 2, 3))          # 6
print(sum_all(10, 20, 30, 40))   # 100
print(sum_all(5))                # 5

# Mixing positional and *args
def display(title, *items):
    print(f"--- {title} ---")
    for item in items:
        print("-", item)

display("Fruits", "Apple", "Banana", "Mango")
# --- Fruits ---
# - Apple
# - Banana
# - Mango

# Unpacking a tuple when calling
numbers = (4, 5, 6)
print(sum_all(*numbers))   # 15 — unpacks tuple as args
Arbitrary Keyword Arguments — **kwargs

**kwargs allows a function to accept any number of keyword arguments. Inside the function, kwargs is a dictionary containing all the keyword arguments.

**kwargs Example
def print_info(**kwargs):
    """Accepts any keyword arguments."""
    print(type(kwargs))   # <class 'dict'>
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=20, city="Kolkata")
# name: Alice
# age: 20
# city: Kolkata

# Mixing all types of parameters
def mixed(a, b, *args, **kwargs):
    print("a:", a)
    print("b:", b)
    print("args:", args)
    print("kwargs:", kwargs)

mixed(1, 2, 3, 4, 5, x=10, y=20)
# a: 1
# b: 2
# args: (3, 4, 5)
# kwargs: {'x': 10, 'y': 20}

# Unpacking a dictionary when calling
data = {"name": "Bob", "age": 25}
print_info(**data)   # unpacks dict as kwargs
Parameter Order Rule

When defining a function with multiple parameter types, they must appear in this order:

def func(positional, default=value, *args, **kwargs):
  • 1. Regular positional parameters
  • 2. Default (optional) parameters
  • 3. *args
  • 4. **kwargs

Variable Scope and Binding

What is Scope?

Scope determines where a variable can be accessed in a program. Python follows the LEGB Rule to resolve variable names — it searches in this order:

L → E → G → B

L — Local    E — Enclosing    G — Global    B — Built-in

Local Scope

Variables defined inside a function. Only accessible within that function.

Enclosing Scope

Variables in the enclosing function of a nested function. Accessed using nonlocal.

Global Scope

Variables defined at the top level of a module. Accessible everywhere. Modified inside function using global keyword.

Built-in Scope

Names pre-defined in Python (print, len, range, int, etc.). Always available.

Scope Examples
# ---- Local Variable ----
def my_func():
    x = 10    # Local variable
    print(x)  # 10

my_func()
# print(x)   # NameError — x not accessible outside

# ---- Global Variable ----
count = 0    # Global variable

def increment():
    global count    # Tell Python we want the global count
    count += 1

increment()
increment()
print(count)   # 2

# ---- Nonlocal Variable ----
def outer():
    msg = "Hello"    # Enclosing variable

    def inner():
        nonlocal msg     # Access enclosing variable
        msg = "Hi"       # Modify it
        print(msg)       # Hi

    inner()
    print(msg)       # Hi — modified by inner()

outer()

Modules

What is a Module?

A module is a file containing Python code (functions, classes, variables) saved with a .py extension. Modules allow you to organize code into separate files and reuse it across multiple programs.

Importing Modules

Python provides several ways to import a module:

Import Syntax Examples
# 1. Import entire module
import math
print(math.sqrt(16))    # 4.0
print(math.pi)          # 3.141592653589793

# 2. Import specific function or variable
from math import sqrt, pi
print(sqrt(25))         # 5.0
print(pi)               # 3.141592...

# 3. Import with alias
import math as m
print(m.floor(3.7))     # 3

from datetime import datetime as dt
print(dt.now())

# 4. Import everything (not recommended)
from math import *
print(cos(0))           # 1.0

# 5. Check what's in a module
import math
print(dir(math))        # Lists all attributes and functions

# 6. __name__ special variable
# When run directly: __name__ == "__main__"
# When imported:     __name__ == "module_name"
Creating Your Own Module

Any .py file is a module. You can create your own and import it in other programs.

Creating and Using a Custom Module
# File: mymath.py  (your custom module)
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

PI = 3.14159

# ─────────────────────────────
# File: main.py  (using the module)
import mymath

print(mymath.add(5, 3))       # 8
print(mymath.subtract(10, 4)) # 6
print(mymath.PI)              # 3.14159

# Or import specific items
from mymath import add, PI
print(add(2, 7))  # 9
print(PI)         # 3.14159
External Modules — PyPI

The Python Package Index (PyPI) at pypi.org hosts thousands of third-party packages. Install them using pip:

pip install requests     # Install requests library
pip install numpy        # Install numpy
pip install django       # Install Django framework

After installation, use import requests etc. in your Python file.

Packages

What is a Package?

A package is a directory (folder) that contains multiple Python modules and a special file called __init__.py. The __init__.py file (can be empty) tells Python that this directory is a package, not just a regular folder.

Package Directory Structure
mypackage/
├── __init__.py        ← Makes this directory a package
├── module1.py         ← Module 1
├── module2.py         ← Module 2
└── subpackage/
    ├── __init__.py    ← Sub-package marker
    └── module3.py     ← Module in sub-package
Creating and Using a Package
# File: mypackage/module1.py
def hello():
    return "Hello from module1!"

# File: mypackage/module2.py
def add(a, b):
    return a + b

# File: mypackage/__init__.py
# Can be empty, or can import things to expose at package level
from .module1 import hello
from .module2 import add

# ─────────────────────────────────────────
# File: main.py (using the package)

# Method 1: Import module from package
import mypackage.module1
print(mypackage.module1.hello())   # Hello from module1!

# Method 2: Import specific function from module
from mypackage.module2 import add
print(add(3, 4))                   # 7

# Method 3: If __init__.py exposes them
import mypackage
print(mypackage.hello())           # Hello from module1!
print(mypackage.add(5, 6))        # 11

# Importing from sub-package
from mypackage.subpackage import module3

Key Definitions

Function

A named, reusable block of code that performs a specific task. Defined using the def keyword. May accept parameters and return a value.

*args

A special parameter syntax that allows a function to accept any number of positional arguments. Inside the function, args is a tuple containing all the extra positional arguments passed.

**kwargs

A special parameter syntax that allows a function to accept any number of keyword arguments. Inside the function, kwargs is a dictionary containing all the keyword arguments passed.

Scope (LEGB Rule)

The region of a program where a variable is accessible. Python resolves variable names using the LEGB rule: Local → Enclosing → Global → Built-in.

Module

A single Python file (.py) containing functions, classes, and variables that can be imported and reused in other programs.

Package

A directory containing multiple Python modules and a special __init__.py file. Packages allow large codebases to be organized into a hierarchy of modules.

Pass by Object Reference

Python's argument passing mechanism where function parameters receive a reference to the object, not a copy. Mutable objects (lists, dicts) can be modified inside the function, affecting the original.

__init__.py

A special file (can be empty) placed inside a directory to mark it as a Python package. It is executed when the package is imported and can be used to initialize package-level imports.

Multiple Choice Questions

Q 1

What data structure does *args collect arguments into inside a function?

  • a. List
  • b. Dictionary
  • c. Tuple
  • d. Set
Answer: c. Tuple

*args collects all extra positional arguments into a tuple inside the function.

Q 2

Which keyword is used to define a function in Python?

  • a. function
  • b. define
  • c. func
  • d. def
Answer: d. def

Functions in Python are defined using the def keyword followed by the function name and parentheses.

Q 3

What is the correct order of parameters in a Python function definition?

  • a. *args, positional, default, **kwargs
  • b. positional, default, *args, **kwargs
  • c. **kwargs, *args, default, positional
  • d. positional, *args, default, **kwargs
Answer: b. positional, default, *args, **kwargs

Python requires parameters in this strict order: positional → default → *args → **kwargs.

Q 4

Which file makes a directory a Python package?

  • a. __main__.py
  • b. __init__.py
  • c. __package__.py
  • d. setup.py
Answer: b. __init__.py

The __init__.py file (which can be empty) marks a directory as a Python package, allowing it to be imported.

Q 5

What does the global keyword do inside a function?

  • a. Creates a new global variable only
  • b. Deletes the global variable
  • c. Allows the function to read and modify a module-level variable
  • d. Makes all variables in the function global
Answer: c. Allows the function to read and modify a module-level variable

The global keyword tells Python that the variable name refers to the module-level (global) variable, not a new local one.

Q 6

What does **kwargs collect inside a function?

  • a. All positional arguments into a tuple
  • b. All keyword arguments into a dictionary
  • c. All arguments into a list
  • d. Only default arguments
Answer: b. All keyword arguments into a dictionary

**kwargs collects all extra keyword arguments passed to the function into a dictionary.

Q 7

Which of the following is the correct way to import only the sqrt function from the math module?

  • a. import sqrt from math
  • b. include math.sqrt
  • c. from math import sqrt
  • d. import math.sqrt
Answer: c. from math import sqrt

The correct syntax is from module_name import function_name. After this, you can use sqrt() directly without the math. prefix.

Q 8

In Python, passing a mutable object (like a list) to a function and modifying it inside the function will:

  • a. Have no effect on the original
  • b. Raise a TypeError
  • c. Modify the original object
  • d. Create a copy of the list
Answer: c. Modify the original object

Python passes mutable objects by object reference. The function receives the same reference, so modifications inside the function affect the original object.

Short Answer Questions

Q 1

What is the difference between a parameter and an argument?

A parameter is the variable listed in the function definition (e.g., def add(a, b) — a and b are parameters). An argument is the actual value passed when calling the function (e.g., add(5, 3) — 5 and 3 are arguments).

Q 2

What is the LEGB rule in Python?

LEGB is the order Python uses to resolve variable names: Local → Enclosing → Global → Built-in. Python first looks in the local scope, then enclosing function scopes, then global (module) scope, then built-in names.

Q 3

What is the purpose of __init__.py in a Python package?

The __init__.py file marks a directory as a Python package, making it importable. It can be empty or contain initialization code and package-level imports that run when the package is imported.

Q 4

What is the difference between *args and **kwargs?

*args collects extra positional arguments into a tuple. **kwargs collects extra keyword arguments into a dictionary. Both allow functions to accept a variable number of arguments.

Q 5

What does nonlocal keyword do in Python?

The nonlocal keyword is used inside a nested function to declare that a variable belongs to the enclosing (outer) function's scope, not the local scope. It allows the inner function to modify the outer function's variable.

Q 6

What is pass by object reference in Python?

In Python, function arguments receive a reference to the object, not a copy. For immutable objects (int, str, tuple), modifying inside the function does not affect the original. For mutable objects (list, dict), modifications inside the function do affect the original.

Q 7

How do you install an external Python package from PyPI?

External packages from PyPI are installed using the pip tool from the command line: pip install package_name. For example, pip install requests installs the requests library. After installation, use import requests in your program.

Q 8

What is the difference between import math and from math import sqrt?

import math imports the entire module — you must use math.sqrt() to call the function. from math import sqrt imports only the sqrt function — you can call it directly as sqrt() without the module prefix.

Long Answer Questions

Q 1

Explain functions in Python — definition, calling, parameters, return values, and pass by object reference with examples.

Function: A named, reusable block of code defined using def.

Definition syntax:

def function_name(parameters): body; return value

Calling: result = function_name(arguments)

Parameters: Variables in the definition. Arguments: values passed during call.

Return value: A function can return one or multiple values using return. Without return, function returns None.

Pass by Object Reference:

  • Immutable objects (int, str, tuple): changes inside function do NOT affect original.
  • Mutable objects (list, dict): changes inside function DO affect original because the same reference is shared.

Example:

def add(a, b): return a + b → print(add(5, 3)) → 8

Q 2

Explain *args and **kwargs in Python with syntax, examples, and how to unpack tuples and dictionaries when calling functions.

*args (Arbitrary Positional Arguments):

Allows a function to accept any number of positional arguments. Collected as a tuple.

Example: def total(*args): return sum(args)

total(1, 2, 3) → 6   total(10, 20, 30, 40) → 100

**kwargs (Arbitrary Keyword Arguments):

Allows a function to accept any number of keyword arguments. Collected as a dictionary.

Example: def info(**kwargs): print(kwargs)

info(name="Alice", age=20) → {'name': 'Alice', 'age': 20}

Unpacking when calling:

  • func(*my_tuple) → unpacks tuple as positional arguments.
  • func(**my_dict) → unpacks dictionary as keyword arguments.

Order of parameters: positional → default → *args → **kwargs.

Q 3

Explain variable scope in Python — local, nonlocal, global, and built-in scope with the LEGB rule and examples.

Scope defines where a variable is accessible. Python uses the LEGB Rule:

L — Local: Variables inside a function. Only accessible within that function.

Example: def f(): x = 10 — x is local to f.

E — Enclosing: Variables in outer function of a nested function. Use nonlocal to modify.

Example: def outer(): msg = "hi"; def inner(): nonlocal msg; msg = "hello"

G — Global: Variables at module level. Use global inside function to modify.

Example: count = 0; def inc(): global count; count += 1

B — Built-in: Python's pre-defined names like print, len, range, int. Always available.

Lookup order: Python checks L first, then E, then G, then B. If not found anywhere → NameError.

Q 4

Explain Python modules and packages — how to create, import, and use them. Include different import styles with examples.

Module: A .py file containing Python code. Used to organize and reuse code.

Creating a module: Save functions/variables in mymodule.py.

Import styles:

  • import math → use math.sqrt()
  • from math import sqrt → use sqrt() directly
  • import math as m → use m.sqrt()
  • from math import * → import everything (not recommended)

Package: A directory with __init__.py containing multiple modules.

Structure:

mypackage/__init__.py, mypackage/module1.py, mypackage/module2.py

Importing from package:

from mypackage.module1 import hello

PyPI: External packages installed using pip install package_name.

Q 5

Write a Python function that accepts a variable number of numbers using *args and returns their sum, average, minimum, and maximum.

Solution
def statistics(*args):
    """
    Accepts any number of numeric arguments.
    Returns sum, average, minimum, and maximum.
    """
    if len(args) == 0:
        print("No numbers provided.")
        return

    total = sum(args)
    average = total / len(args)
    minimum = min(args)
    maximum = max(args)

    return total, average, minimum, maximum

# Calling the function
s, avg, lo, hi = statistics(10, 25, 7, 42, 16, 33)
print(f"Sum:     {s}")
print(f"Average: {avg:.2f}")
print(f"Minimum: {lo}")
print(f"Maximum: {hi}")

# Output:
# Sum:     133
# Average: 22.17
# Minimum: 7
# Maximum: 42

# Unpacking a list as args
my_numbers = [5, 15, 25, 35, 45]
result = statistics(*my_numbers)
print(result)

Practice Problems

Q 1

Write a Python function to check whether a given number is prime or not. Call it for numbers 1 to 20 and print the primes.

Solution
def is_prime(n):
    """Returns True if n is prime, False otherwise."""
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

print("Prime numbers from 1 to 20:")
for num in range(1, 21):
    if is_prime(num):
        print(num, end=" ")

# Output: 2 3 5 7 11 13 17 19

Q 4

Write a Python function using **kwargs that accepts any number of student name–score pairs and prints the student with the highest score.

Solution
def top_student(**kwargs):
    """
    Accepts student name=score keyword pairs.
    Prints the student with the highest score.
    """
    if not kwargs:
        print("No students provided.")
        return

    print("All students:")
    for name, score in kwargs.items():
        print(f"  {name}: {score}")

    best = max(kwargs, key=kwargs.get)
    print(f"\nTop student: {best} with score {kwargs[best]}")

top_student(Alice=85, Bob=92, Charlie=78, Diana=95, Eve=88)

# Output:
# All students:
#   Alice: 85
#   Bob: 92
#   Charlie: 78
#   Diana: 95
#   Eve: 88
#
# Top student: Diana with score 95

Q 5

Write a recursive Python function to calculate the factorial of a number. Also write the iterative version and compare both.

Solution
# Recursive version
def factorial_recursive(n):
    """Calculates n! using recursion."""
    if n == 0 or n == 1:
        return 1
    return n * factorial_recursive(n - 1)

# Iterative version
def factorial_iterative(n):
    """Calculates n! using a loop."""
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

# Testing both
for n in [0, 1, 5, 7, 10]:
    r = factorial_recursive(n)
    i = factorial_iterative(n)
    print(f"{n}! = {r} (recursive) = {i} (iterative)")

# Output:
# 0! = 1 (recursive) = 1 (iterative)
# 1! = 1 (recursive) = 1 (iterative)
# 5! = 120 (recursive) = 120 (iterative)
# 7! = 5040 (recursive) = 5040 (iterative)
# 10! = 3628800 (recursive) = 3628800 (iterative)

  • global keyword: modify module-level variable inside a function.
  • nonlocal keyword: modify enclosing function's variable in a nested function.
  • A module is a .py file. Imported with import or from...import.
  • A package is a directory with __init__.py containing modules.
  • Install external packages using pip install package_name.
Must Remember for Exam
  • *args → tuple. **kwargs → dictionary. Never mix these up.
  • __init__.py makes a directory a package.
  • LEGB: Local → Enclosing → Global → Built-in.
  • global for module-level. nonlocal for enclosing function only.
  • Without return, a function returns None.
  • Immutable args → original NOT affected. Mutable args → original IS affected.
  • from math import sqrt — most efficient way to import single function.
Common Mistakes in Exams
  • Writing *args after **kwargs — wrong order causes SyntaxError.
  • Thinking *args creates a list — it creates a tuple.
  • Forgetting global when modifying a global variable inside a function — causes UnboundLocalError.
  • Using nonlocal at the module level — only valid inside nested functions.
  • Forgetting __init__.py — directory won't be recognized as package.
  • Confusing import math (needs math. prefix) with from math import sqrt (no prefix needed).
  • Default parameter after *args — causes SyntaxError in most cases.
