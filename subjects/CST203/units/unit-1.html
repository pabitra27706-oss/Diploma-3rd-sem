Introduction to Python

History of Python

Python was created by Guido van Rossum and first released in 1991. It was designed to be easy to read and write, with a focus on code readability and simplicity. The name "Python" was inspired by the British comedy show Monty Python's Flying Circus.

  • Python 1.0 — Released in 1994.
  • Python 2.0 — Released in 2000. Added list comprehensions, garbage collection.
  • Python 3.0 — Released in 2008. Not backward compatible with Python 2. Current standard.
Key Features of Python

Interpreted

Code is executed line by line. No separate compilation step needed.

High-Level

Abstracts away hardware details. Programmer focuses on logic.

Dynamically Typed

Variable types are determined at runtime. No need to declare types.

Object-Oriented

Supports classes, objects, inheritance, and polymorphism.

Extensive Libraries

Rich standard library + PyPI with thousands of third-party packages.

Cross-Platform

Runs on Windows, Linux, macOS without modification.

  3. Verify with python --version in Command Prompt.

Linux/Mac:

Variables and Data Types

Python Variables — Dynamic Typing

In Python, you do not need to declare the type of a variable. The type is automatically assigned based on the value given. This is called dynamic typing.

A variable is a name that refers to a value stored in memory. You create a variable by simply assigning a value using =.

Variable Examples
x = 10          # int
y = 3.14        # float
name = "Alice"  # str
flag = True     # bool

# Type can change dynamically
x = "Now I am a string"
print(type(x))  # <class 'str'>

# Check type using type()
print(type(10))     # <class 'int'>
print(type(3.14))   # <class 'float'>
print(type(2+3j))   # <class 'complex'>

String Data Type

What is a String?

A string is a sequence of characters enclosed in quotes. Python supports single quotes '...', double quotes "...", and triple quotes """...""" or '''...'''.

Strings in Python are immutable — once created, they cannot be changed.

Each character has an index starting from 0 (left) or -1 (right, going backwards).

String Literals and Indexing
# String literals
s1 = 'Hello'
s2 = "World"
s3 = """This is a
multi-line string"""

# Indexing
s = "Python"
print(s[0])    # P  (first char)
print(s[-1])   # n  (last char)
print(s[2])    # t

# Slicing: s[start:stop:step]
print(s[1:4])  # yth  (index 1,2,3)
print(s[:3])   # Pyt  (from start)
print(s[3:])   # hon  (to end)
print(s[::-1]) # nohtyP  (reversed)

# Concatenation and Repetition
print("Hello" + " " + "World")  # Hello World
print("Ha" * 3)                  # HaHaHa

Collections — List, Tuple, Dict, Array

Lists

A list is a mutable, ordered sequence of elements. Lists can hold elements of different types. Defined using square brackets [].

List Operations
# Defining a list
fruits = ["apple", "banana", "cherry"]
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]

# Indexing and Slicing
print(fruits[0])     # apple
print(fruits[-1])    # cherry
print(numbers[1:4])  # [2, 3, 4]
print(numbers[::-1]) # [5, 4, 3, 2, 1]

# Modifying lists (mutable)
fruits.append("mango")         # Add to end
fruits.insert(1, "grape")      # Insert at index 1
fruits.remove("banana")        # Remove by value
popped = fruits.pop()          # Remove and return last
popped2 = fruits.pop(0)        # Remove at index 0

# Other methods
numbers.sort()                 # Sort in place
numbers.reverse()              # Reverse in place
print(len(numbers))            # Length
print(numbers.index(3))        # Index of value 3
print(numbers.count(2))        # Count occurrences

# Copying Lists
import copy
original = [1, [2, 3], 4]

# Shallow copy — inner list is shared
shallow = original.copy()      # or original[:]

# Deep copy — completely independent
deep = copy.deepcopy(original)

original[1][0] = 99
print(shallow[1][0])  # 99 (affected — shallow)
print(deep[1][0])     # 2  (not affected — deep)
Shallow vs Deep Copy
  • Shallow copy: Copies the list but nested objects (inner lists) are still shared references.
  • Deep copy: Creates a fully independent copy including all nested objects.
  • Use copy.deepcopy() from the copy module for deep copy.
Tuples

A tuple is an immutable, ordered sequence. Once created, elements cannot be changed. Defined using parentheses ().

Tuple Examples
# Defining tuples
t1 = (1, 2, 3)
t2 = ("a", "b", "c")
single = (42,)      # Single element tuple needs comma!
empty = ()

# Accessing
print(t1[0])        # 1
print(t2[-1])       # c
print(t1[1:3])      # (2, 3)

# Tuples are immutable
# t1[0] = 99   # TypeError!

# Tuple packing and unpacking
packed = 1, 2, 3           # Packing
a, b, c = packed           # Unpacking
print(a, b, c)             # 1 2 3

# Swap using tuple unpacking
x, y = 10, 20
x, y = y, x
print(x, y)                # 20 10

# Tuple methods
print(t1.count(2))   # 1
print(t1.index(3))   # 2
print(len(t1))       # 3
Dictionaries

A dictionary stores data as key-value pairs. It is mutable and unordered (in Python 3.7+ insertion order is maintained). Keys must be unique and immutable. Defined using curly braces {}.

Dictionary Operations
# Defining a dictionary
student = {
    "name": "Alice",
    "age": 20,
    "grade": "A"
}

# Accessing
print(student["name"])          # Alice
print(student.get("age"))       # 20
print(student.get("marks", 0))  # 0 (default if not found)

# Adding and updating
student["email"] = "alice@mail.com"  # Add new key
student["age"] = 21                  # Update existing key

# Deleting
del student["grade"]           # Delete by key
popped = student.pop("email")  # Remove and return

# Iterating
for key in student:
    print(key, ":", student[key])

for key, value in student.items():
    print(f"{key} = {value}")

# Dictionary methods
print(student.keys())    # dict_keys(['name', 'age'])
print(student.values())  # dict_values(['Alice', 21])
print(len(student))      # 2

Coding Blocks and Indentation

Python uses indentation (whitespace at the beginning of a line) to define a block of code. All lines in the same block must have the same indentation level. The standard is 4 spaces.

Indentation Example
# Correct indentation
x = 10
if x > 5:
    print("x is greater than 5")    # block starts
    y = x * 2
    print("y =", y)                 # still in block
print("This is outside the block")  # block ends

# Wrong indentation — causes IndentationError
if x > 5:
print("Wrong!")  # IndentationError!
Common Mistake

Mixing spaces and tabs in the same file causes IndentationError or TabError. Always use 4 spaces consistently. Never mix tabs and spaces.

Key Definitions

Python

A high-level, interpreted, dynamically typed, object-oriented programming language created by Guido van Rossum in 1991. Known for readable syntax and extensive standard libraries.

Dynamic Typing

A language feature where the type of a variable is determined at runtime based on the value assigned, not at compile time. In Python, the same variable can hold different types at different times.

Interpreted Language

A language where the source code is executed line by line by an interpreter at runtime, without a separate compilation step into machine code.

Indentation

The use of whitespace (spaces or tabs) at the beginning of a line to define a block of code in Python. Python uses indentation instead of curly braces {}.

List

A mutable, ordered collection of elements in Python, defined using square brackets []. Lists allow duplicate values and elements of different types.

Tuple

An immutable, ordered collection of elements in Python, defined using parentheses (). Once created, its elements cannot be modified.

Dictionary

A mutable, unordered collection of key-value pairs in Python, defined using curly braces {}. Keys must be unique and immutable. Values can be of any type.

Operator Precedence

The order in which operators are evaluated in an expression. Higher precedence operators are evaluated before lower precedence ones. Parentheses have the highest precedence and can override default order.

Shallow Copy

A copy of a collection where only the top-level structure is duplicated. Nested objects (like inner lists) still share the same reference as the original.

Deep Copy

A completely independent copy of a collection, including all nested objects. Modifications to the deep copy do not affect the original. Created using copy.deepcopy().

Q 1

Who created the Python programming language?

  • a. Dennis Ritchie
  • b. James Gosling
  • c. Guido van Rossum
  • d. Bjarne Stroustrup
Answer: c. Guido van Rossum

Python was created by Guido van Rossum and first released in 1991.

Q 2

Which of the following is the correct way to define a single-element tuple in Python?

  • a. t = (42)
  • b. t = [42]
  • c. t = (42,)
  • d. t = {42}
Answer: c. t = (42,)

A single-element tuple requires a trailing comma. Without it, (42) is just an integer in parentheses.

Q 3

What is the output of 10 // 3 in Python?

  • a. 3.33
  • b. 1
  • c. 3
  • d. 4
Answer: c. 3

// is the floor division operator. It divides and returns the integer quotient, discarding the remainder. 10 ÷ 3 = 3 remainder 1, so result is 3.

Q 4

Which data type is immutable in Python?

  • a. List
  • b. Dictionary
  • c. Set
  • d. Tuple
Answer: d. Tuple

Tuples are immutable — once created, their elements cannot be changed. Lists, Dictionaries, and Sets are all mutable.

Q 5

What does the ** operator do in Python?

  • a. Multiply two numbers
  • b. Floor division
  • c. Exponentiation (power)
  • d. Bitwise AND
Answer: c. Exponentiation (power)

** raises the left operand to the power of the right. For example, 2 ** 8 = 256.

Q 6

What will "Python"[::-1] return?

  • a. "Pytho"
  • b. "nohtyP"
  • c. "Python"
  • d. Error
Answer: b. "nohtyP"

Slicing with step -1 reverses the string. "Python"[::-1] = "nohtyP".

Q 7

Which operator checks if two variables point to the same object in memory?

  • a. ==
  • b. !=
  • c. is
  • d. in
Answer: c. is

The is operator checks identity — whether two variables refer to the same object in memory. == checks value equality.

Q 8

What is the result of 5 & 3 in Python?

  • a. 8
  • b. 7
  • c. 1
  • d. 15
Answer: c. 1

Bitwise AND: 5 = 0101, 3 = 0011. AND: 0001 = 1.

Q 9

Which method is used to add an element to the end of a list?

  • a. .insert()
  • b. .add()
  • c. .append()
  • d. .push()
Answer: c. .append()

list.append(item) adds an element to the end of the list. .insert(index, item) adds at a specific position.

Q 10

What type does Python assign to the value 3.14?

  • a. int
  • b. double
  • c. decimal
  • d. float
Answer: d. float

In Python, decimal numbers like 3.14 are of type float. Python has no separate double type.

Short Answer Questions

Q 1

What is dynamic typing in Python?

Dynamic typing means that the type of a variable is determined at runtime based on the value assigned. You do not need to declare the type explicitly. The same variable can hold different types at different times.

Q 2

What is the difference between / and // in Python?

/ performs regular division and always returns a float (e.g., 10/3 = 3.333...). // performs floor division and returns the integer quotient (e.g., 10//3 = 3).

Q 3

What is an f-string in Python? Give an example.

An f-string (formatted string literal) is a string prefixed with f that allows embedding expressions directly inside curly braces. Example: name = "Alice"; print(f"Hello {name}") outputs Hello Alice.

Q 4

What is the difference between a list and a tuple?

A list is mutable (can be changed after creation) and uses square brackets []. A tuple is immutable (cannot be changed) and uses parentheses (). Tuples are faster than lists.

Q 5

What does the % operator do in Python?

The % operator is the modulus operator. It returns the remainder when the left operand is divided by the right operand. Example: 10 % 3 = 1 because 10 = 3×3 + 1.

Q 6

What is the purpose of indentation in Python?

In Python, indentation defines code blocks. All lines belonging to the same block (e.g., inside an if statement or loop) must be indented by the same amount. Python uses indentation instead of curly braces {}.

Q 7

What is the difference between is and == in Python?

== checks if two values are equal (value comparison). is checks if two variables point to the same object in memory (identity comparison). Two different lists with the same values will give == True but is False.

Q 8

Name any four string methods in Python with their purpose.

1. .upper() — Converts string to uppercase.
2. .lower() — Converts string to lowercase.
3. .strip() — Removes leading and trailing whitespace.
4. .split(sep) — Splits string into a list based on separator.

Long Answer Questions

Q 1

What is Python? Discuss its history, features, and the difference between interactive mode and script mode.

Python is a high-level, interpreted, dynamically typed, object-oriented programming language.

History: Created by Guido van Rossum in 1991. Python 2.0 released in 2000, Python 3.0 in 2008.

Features:

  • Interpreted: Code runs line by line without compilation.
  • High-Level: Abstracts hardware complexity.
  • Dynamically Typed: Types assigned at runtime.
  • Object-Oriented: Supports classes and objects.
  • Extensive Libraries: Rich standard library and PyPI packages.
  • Cross-Platform: Runs on Windows, Linux, macOS.

Interactive Mode: Started by typing python in terminal. Shows >>> prompt. Executes each line immediately. Used for quick testing.

Script Mode: Write code in a .py file. Run using python filename.py. Full program runs at once. Used for real applications.

Q 2

Explain all Python operators with examples — arithmetic, relational, logical, bitwise, membership, and identity operators.

1. Arithmetic Operators: Perform mathematical calculations.

+ addition, - subtraction, * multiplication, / division, // floor division, % modulus, ** exponentiation.

Example: 2 ** 8 = 256, 10 % 3 = 1

2. Relational Operators: Compare two values and return True or False.

==, !=, <, >, <=, >=

Example: 5 > 3 → True

3. Logical Operators: Combine boolean values.

and, or, not

Example: True and False → False

4. Bitwise Operators: Operate on binary bits.

& AND, | OR, ^ XOR, ~ NOT, << left shift, >> right shift.

Example: 5 & 3 → 1 (0101 AND 0011 = 0001)

5. Membership Operators: Check if a value exists in a sequence.

in, not in

Example: "a" in "cat" → True

6. Identity Operators: Check if variables point to the same object.

is, is not

Example: x = [1,2]; y = x; x is y → True

Q 3

Describe Python's collection data types — List, Tuple, and Dictionary — with their properties, operations, and examples.

List: Mutable, ordered. Defined with [].

Supports: append(), insert(), remove(), pop(), slicing.

Example: fruits = ["apple", "banana"]; fruits.append("mango")

Tuple: Immutable, ordered. Defined with ().

Cannot be modified after creation. Faster than lists.

Supports: indexing, slicing, count(), index().

Example: coords = (10, 20); x, y = coords

Dictionary: Mutable, key-value pairs. Defined with {}.

Keys must be unique and immutable. Values can be any type.

Supports: keys(), values(), items(), get(), pop().

Example: student = {"name": "Alice", "age": 20}

Key difference: Lists use integer indices, tuples are immutable, dictionaries use keys for access.

Q 4

Explain string manipulation in Python. Cover indexing, slicing, string methods, and string formatting with examples.

Strings in Python are immutable sequences of characters. They can be defined using single, double, or triple quotes.

Indexing: Each character has a position starting from 0. Negative indices count from the end.

s = "Python"; s[0] = 'P'; s[-1] = 'n'

Slicing: Extract a substring using s[start:stop:step].

s[1:4] = "yth", s[::-1] = "nohtyP"

Concatenation and Repetition:

"Hello" + " World" = "Hello World"

"Ha" * 3 = "HaHaHa"

String Methods:

  • .upper() → Uppercase
  • .lower() → Lowercase
  • .strip() → Remove whitespace
  • .split(",") → Split to list
  • ",".join(list) → Join list to string
  • .replace("a","b") → Replace characters
  • .find("sub") → Find index of substring

String Formatting:

"Hello {}".format(name) — .format() method

f"Hello {name}, age {age}" — f-string (modern, preferred)

Q 5

Explain operator precedence in Python with the complete precedence table and examples.

Operator Precedence defines the order in which operators are evaluated in an expression. Higher precedence operators are evaluated first.

Order (Highest to Lowest):

  1. () — Parentheses (highest)
  2. ** — Exponentiation
  3. ~x, +x, -x — Unary operators
  4. *, /, //, % — Multiplication group
  5. +, - — Addition/Subtraction
  6. <<, >> — Bitwise shift
  7. & — Bitwise AND
  8. ^ — Bitwise XOR
  9. | — Bitwise OR
  10. Comparison operators (==, !=, <, >, etc.)
  11. not — Logical NOT
  12. and — Logical AND
  13. or — Logical OR (lowest)

Example: 2 + 3 * 4 → 3 * 4 = 12 first (higher precedence), then 2 + 12 = 14.

Example: (2 + 3) * 4 → Parentheses first: 5 * 4 = 20.

When operators have equal precedence, they are evaluated left to right (except ** which is right to left).

Q 5

Write a Python program to demonstrate shallow copy vs deep copy using a nested list.

Solution
import copy

original = [1, [2, 3], 4]

# Shallow copy
shallow = original.copy()

# Deep copy
deep = copy.deepcopy(original)

# Modify inner list of original
original[1][0] = 99

print("Original:", original)   # [1, [99, 3], 4]
print("Shallow:", shallow)     # [1, [99, 3], 4] — affected!
print("Deep:", deep)           # [1, [2, 3], 4]  — not affected

# Conclusion
print("\nShallow copy shares inner objects — NOT safe for nested data.")
print("Deep copy is fully independent — SAFE for nested data.")
