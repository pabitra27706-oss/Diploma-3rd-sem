Keyboard Input and Output

input() Function

The input() function reads a line of text from the keyboard. It always returns a string. To use as a number, you must explicitly convert using int() or float().

input() Examples
# Basic input — always returns string
name = input("Enter your name: ")
print(f"Hello, {name}!")

# Convert to integer
age = int(input("Enter your age: "))
print(f"You are {age} years old.")

# Convert to float
price = float(input("Enter price: "))
print(f"Price with tax: {price * 1.18:.2f}")

# Multiple inputs on one line
x, y = input("Enter two numbers separated by space: ").split()
x, y = int(x), int(y)
print(f"Sum: {x + y}")

# Using map for cleaner input
a, b = map(int, input("Enter two integers: ").split())
print(f"Product: {a * b}")
print() Function

The print() function outputs data to the screen (standard output). It can print multiple values, use custom separators and end characters, and redirect output to files.

print() Examples
# Basic print
print("Hello, World!")

# Multiple values
print("Name:", "Alice", "Age:", 20)
# Name: Alice Age: 20

# Custom separator
print("A", "B", "C", sep="-")   # A-B-C

# Custom end (default is newline)
print("Hello", end=" ")
print("World")   # Hello World (on same line)

# Print nothing (just newline)
print()

# Print to a file
with open("output.txt", "w") as f:
    print("Hello, file!", file=f)

# Formatted output
pi = 3.14159
print(f"Pi is approximately {pi:.2f}")   # Pi is approximately 3.14
print("Value: {:>10.3f}".format(pi))     # Right-aligned, 3 decimal places

What is a Regular Expression?

A regular expression (regex) is a sequence of characters that defines a search pattern. It is used for pattern matching, searching, validation, and text manipulation. Python provides regex support through the built-in re module.

re.match() and re.search()
import re

text = "Hello, Python 3.11 is great!"

# re.match() — only matches at beginning
m = re.match(r"Hello", text)
if m:
    print("match found:", m.group())   # Hello
    print("Start:", m.start())         # 0
    print("End:", m.end())             # 5

# match fails if pattern not at start
m2 = re.match(r"Python", text)
print(m2)   # None — "Python" is not at start

# re.search() — searches anywhere in string
s = re.search(r"Python", text)
if s:
    print("search found:", s.group())  # Python
    print("Position:", s.start())      # 7

# Using groups
s2 = re.search(r"Python (\d+\.\d+)", text)
if s2:
    print("Full match:", s2.group())    # Python 3.11
    print("Version:", s2.group(1))      # 3.11
re.findall() and re.finditer()
import re

text = "Call 9876543210 or 8765432109 for support. Fax: 7654321098"

# re.findall() — returns list of all matches
phones = re.findall(r"\d{10}", text)
print(phones)
# ['9876543210', '8765432109', '7654321098']

# Find all words
words = re.findall(r"\w+", "Hello World Python")
print(words)   # ['Hello', 'World', 'Python']

# re.finditer() — returns iterator of match objects
for match in re.finditer(r"\d{10}", text):
    print(f"Found: {match.group()} at position {match.start()}")

# Find all email addresses
emails = "alice@example.com and bob@test.org"
found = re.findall(r"[\w.]+@[\w.]+\.\w+", emails)
print(found)   # ['alice@example.com', 'bob@test.org']
re.compile(), re.sub(), re.subn(), re.split()
import re

# re.compile() — create reusable pattern object
pattern = re.compile(r"\d+")
print(pattern.findall("abc 123 def 456"))   # ['123', '456']
print(pattern.search("abc 789").group())    # 789

# re.sub() — substitute matches
text = "Hello   World    Python"
# Replace multiple spaces with single space
cleaned = re.sub(r"\s+", " ", text)
print(cleaned)   # Hello World Python

# Replace digits with *
masked = re.sub(r"\d", "*", "Phone: 9876543210")
print(masked)    # Phone: **********

# re.subn() — substitute and return count
result, count = re.subn(r"\d", "*", "abc 123 def 456")
print(result)   # abc *** def ***
print(count)    # 6

# re.split() — split by pattern
parts = re.split(r"\s+", "one  two   three    four")
print(parts)    # ['one', 'two', 'three', 'four']

# Split by comma or semicolon
data = "apple,banana;cherry,mango"
items = re.split(r"[,;]", data)
print(items)    # ['apple', 'banana', 'cherry', 'mango']

Key Definitions

input()

A built-in Python function that reads a line of text from the keyboard (standard input) and returns it as a string. Any prompt string passed as argument is displayed to the user before reading.

File Mode

A string passed to open() that specifies how a file should be opened — for reading ('r'), writing ('w'), appending ('a'), exclusive creation ('x'), binary ('b'), or text ('t') mode.

readline()

A file method that reads and returns one complete line from the file, including the newline character \n. Returns an empty string when the end of file is reached.

readlines()

A file method that reads all lines of the file and returns them as a list of strings. Each string in the list includes the newline character at the end.

tell()

A file method that returns an integer representing the current position of the file pointer (in bytes from the beginning of the file).

seek()

A file method that moves the file pointer to a specified byte position. seek(0) moves to the beginning of the file. Used to re-read or navigate within a file.

Regular Expression (Regex)

A sequence of characters that defines a search pattern. Used for string matching, searching, validation, and substitution. Python supports regex through the re module.

re.compile()

A function that compiles a regex pattern string into a Pattern object. This compiled pattern can be reused multiple times, which is more efficient than compiling the pattern on every call.

Metacharacter

A character with a special meaning in a regular expression. Examples: . (any character), ^ (start), $ (end), * (zero or more), + (one or more), ? (optional), [] (character class), | (or).

flush()

A file method that forces any buffered data to be written to the disk immediately, without waiting for the buffer to fill or the file to be closed.

Multiple Choice Questions

Q 1

Which file mode opens a file for writing and clears its existing content?

  • a. 'r'
  • b. 'a'
  • c. 'w'
  • d. 'x'
Answer: c. 'w'

The 'w' mode opens a file for writing and truncates (clears) the file if it exists. If it does not exist, a new file is created.

Q 2

What does readlines() return?

  • a. A single string with all content
  • b. One line at a time
  • c. A list of all lines
  • d. An integer count of lines
Answer: c. A list of all lines

readlines() reads all lines from the file and returns them as a list of strings, where each string is one line including the newline character.

Q 3

Which regex function searches for a pattern anywhere in the string?

  • a. re.match()
  • b. re.search()
  • c. re.compile()
  • d. re.finditer()
Answer: b. re.search()

re.search() scans through the entire string looking for the first location where the pattern matches. re.match() only matches at the beginning.

Q 4

What does the regex metacharacter + mean?

  • a. Match zero or more times
  • b. Match exactly once
  • c. Match one or more times
  • d. Match zero or one time
Answer: c. Match one or more times

+ means the preceding element must match one or more times. Compare: * means zero or more, ? means zero or one.

Q 5

What does f.tell() return?

  • a. The file name
  • b. The number of lines in the file
  • c. The current byte position of the file pointer
  • d. The file mode
Answer: c. The current byte position of the file pointer

tell() returns an integer representing the current position (offset in bytes) of the file pointer from the beginning of the file.

Q 6

Which function returns a list of all non-overlapping matches in a string?

  • a. re.match()
  • b. re.search()
  • c. re.findall()
  • d. re.compile()
Answer: c. re.findall()

re.findall() returns a list of all non-overlapping matches of the pattern in the string, from left to right.

Q 7

What does the regex pattern ^\d{3}-\d{4}$ match?

  • a. Any string containing digits and dashes
  • b. A string that is exactly 3 digits, a dash, then 4 digits
  • c. A string starting with 3 digits
  • d. Any phone number format
Answer: b. A string that is exactly 3 digits, a dash, then 4 digits

^ anchors to start, \d{3} matches exactly 3 digits, - matches literal dash, \d{4} matches exactly 4 digits, $ anchors to end. So "123-4567" matches but not "1234-567".

Q 8

Which file mode raises an error if the file already exists?

  • a. 'w'
  • b. 'a'
  • c. 'r'
  • d. 'x'
Answer: d. 'x'

The 'x' (exclusive creation) mode creates a new file but raises FileExistsError if the file already exists. It is used when you want to ensure you are not overwriting anything.

Short Answer Questions

Q 1

What is the difference between 'w' and 'a' file modes?

'w' (write) mode opens the file and clears all existing content before writing. If the file does not exist, it creates one. 'a' (append) mode opens the file and adds new content at the end without deleting existing content.

Q 2

What is the difference between re.match() and re.search()?

re.match() matches the pattern only at the beginning of the string. If the pattern is not at the start, it returns None. re.search() scans the entire string and returns the first match found anywhere.

Q 3

Why should we use with open() instead of open() and close()?

The with statement (context manager) automatically closes the file when the block exits, even if an exception occurs. With manual open()/close(), if an error happens before close(), the file stays open, causing resource leaks.

Q 4

What does the regex \d+ match? Give an example.

\d matches any single digit (0–9). \d+ matches one or more consecutive digits. Example: in the string "abc 123 xyz 456", re.findall(r"\d+", text) returns ['123', '456'].

Q 5

What is re.compile() and why is it used?

re.compile(pattern) compiles a regex pattern string into a reusable Pattern object. It is used when the same pattern is used multiple times — compiling once and reusing is more efficient than recompiling on every function call.

Q 6

What is the difference between re.sub() and re.subn()?

Both replace matches with a replacement string. re.sub() returns only the new string after substitution. re.subn() returns a tuple of (new_string, count) where count is the number of substitutions made.

Q 7

What do tell() and seek() do in file operations?

tell() returns the current position of the file pointer as a byte offset from the beginning of the file. seek(pos) moves the file pointer to the specified byte position. Together they allow random access within a file.

Q 8

What is the difference between re.findall() and re.finditer()?

re.findall() returns a list of all matching strings. re.finditer() returns an iterator of match objects. finditer() is more memory-efficient for large texts because it yields one match at a time, and each match object provides position info via .start() and .end().

Long Answer Questions

Q 1

Explain file I/O in Python — file modes, opening, reading, writing, and closing files with examples.

File I/O allows Python programs to read data from and write data to files on disk.

Opening a file: open(filename, mode) returns a file object.

Q 3

Write a Python program to read a text file, count the number of lines, words, and characters, and write the results to another file.

Solution
def analyze_file(input_file, output_file):
    """
    Reads input_file, counts lines, words, chars.
    Writes statistics to output_file.
    """
    line_count = 0
    word_count = 0
    char_count = 0

    with open(input_file, "r") as f:
        for line in f:
            line_count += 1
            words = line.split()
            word_count += len(words)
            char_count += len(line)

    stats = f"""File Analysis: {input_file}
{'=' * 30}
Lines: {line_count}
Words: {word_count}
Characters: {char_count}
"""

    with open(output_file, "w") as f:
        f.write(stats)

    print(stats)
    print(f"Results written to {output_file}")

# Usage
analyze_file("sample.txt", "stats.txt")

import re

# Email validation
def validate_email(email):
    pattern = r"^[\w.+-]+@[\w-]+\.[a-zA-Z]{2,}$"
    if re.match(pattern, email):

    return False

emails = [

    print(f"  {e:25} → {status}")

# Phone number validation (10-digit Indian)
def validate_phone(phone):
    pattern = r"^[6-9]\d{9}$"
    return bool(re.match(pattern, phone))

phones = ["9876543210", "1234567890", "8765432109", "123"]

print("\nPhone Validation:")
for p in phones:
    status = "Valid" if validate_phone(p) else "Invalid"
    print(f"  {p:15} → {status}")

Q 5

Write a Python program demonstrating tell(), seek(), and reading a file in chunks using read(n).

Solution
# First, create a sample file
with open("demo.txt", "w") as f:
    f.write("Hello, Python File I/O is very useful!\n")
    f.write("We can read, write, seek, and tell.\n")

# Demonstrate tell() and seek()
with open("demo.txt", "r") as f:

    print("=== tell() and seek() Demo ===")
    print(f"Start position: {f.tell()}")     # 0

    chunk1 = f.read(5)
    print(f"Read 5 chars: '{chunk1}'")       # Hello
    print(f"Position after read: {f.tell()}") # 5

    f.seek(0)   # Back to beginning
    print(f"After seek(0): {f.tell()}")      # 0

    f.seek(7)   # Jump to position 7
    print(f"After seek(7): {f.tell()}")      # 7
    print(f"Read from 7: '{f.read(6)}'")     # Python

    print("\n=== Reading in chunks ===")
    f.seek(0)   # Reset
    chunk_size = 10
    while True:
        chunk = f.read(chunk_size)
        if not chunk:
            break
        print(f"Chunk: '{chunk}'")

Q 1

Write a Python program to copy the contents of one file to another file.

Solution
def copy_file(source, destination):
    """Copies content from source file to destination file."""
    try:
        with open(source, "r") as src:
            content = src.read()

        with open(destination, "w") as dst:
            dst.write(content)

        print(f"Successfully copied '{source}' to '{destination}'")

    except FileNotFoundError:

Q 3

Write a Python program to read a file and replace all occurrences of a word with another word using regex, then save the result.

Solution
import re

def replace_word_in_file(filename, old_word, new_word):
    """
    Reads file, replaces old_word with new_word,
    writes updated content back.
    """
    # Read original content
    with open(filename, "r") as f:
        content = f.read()

    # Replace using regex (case-insensitive, whole word)
    pattern = r"\b" + re.escape(old_word) + r"\b"
    new_content, count = re.subn(pattern, new_word, content,
                                  flags=re.IGNORECASE)

    # Write updated content
    with open(filename, "w") as f:
        f.write(new_content)

    print(f"Replaced '{old_word}' with '{new_word}': {count} times.")

# Create sample file
with open("story.txt", "w") as f:
    f.write("Python is great. Python is powerful. I love Python!")

replace_word_in_file("story.txt", "Python", "Java")

# Verify
with open("story.txt", "r") as f:
    print(f.read())
# Output: Java is great. Java is powerful. I love Java!

Revision

Quick Revision Points
  • input() always returns a string. Use int()/float() to convert.
  • print(sep=, end=, file=) — customize separator, end char, and output destination.
  • File modes: 'r' read, 'w' write+clear, 'a' append, 'x' exclusive create, 'b' binary.
  • 'w' clears file. 'a' preserves file and adds to end.
  • read() → whole file string. readline() → one line. readlines() → list of lines.
  • write() — does NOT add newline. writelines() — does NOT add newline.
  • Best practice: Always use with open() as f: — auto closes file.
  • tell() → current byte position. seek(n) → jump to byte n.
  • flush() → force write buffer to disk. close() → close file.
  • Regex uses raw strings r"..." to avoid backslash issues.
  • re.match() → start of string only. re.search() → anywhere in string.
  • re.findall() → returns list. re.finditer() → returns iterator of match objects.
  • re.sub(p,r,s) → new string. re.subn(p,r,s) → (new_string, count).
  • re.split(p,s) → split string by pattern. re.compile(p) → reusable pattern.
  • Key metacharacters: \d digit, \w word char, \s space, ^ start, $ end, + one or more, * zero or more, ? optional.
Must Remember for Exam
  • 'w' mode deletes existing content. 'a' mode preserves content.
  • 'x' mode raises FileExistsError if file already exists.
  • readlines() returns a list. Each element includes \n.
  • write() does NOT automatically add \n — you must add it manually.
  • re.match() fails if pattern is not at the very start.
  • re.findall() returns list of strings not match objects.
  • \d+ = one or more digits. \d* = zero or more digits.
  • Always use r"..." raw string for regex patterns.
  • re.subn() returns a tuple: (modified_string, replacement_count).
Common Mistakes in Exams
  • Using 'w' mode when you want to append — this will erase the file.
  • Forgetting that input() returns a string — not converting causes TypeError in math.
  • Confusing re.match() with re.search() — match only checks the start.
  • Forgetting that readlines() includes \n — use .strip() to remove it.
  • Not using r"..." for regex — "\d" is not the same as r"\d".
  • Using write() to write a list — it only accepts strings. Use writelines() or a loop.
  • Forgetting to check if re.match()/re.search() returned None before calling .group().
  • Using 'r' mode on a file that does not exist — causes FileNotFoundError.
