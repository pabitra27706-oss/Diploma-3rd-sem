Why there are so few formulas

3 entries are formulas. The syllabus describes topics; it prints almost no arithmetic. Where it names a quantity without printing the formula (a cache hit ratio, a worst-case comparison count) the entry says so and carries a symbol legend. No textbook page numbers are cited, because no textbook edition has been verified in this repository — inventing a chapter reference would be worse than leaving the gap visible.

How an entry becomes verified

  • The owner reads the entry against the cited syllabus topic and, where one exists, a named textbook or class note.
  • The owner adds a sign-off record with the entry ids, the citation used and an ISO date.
  • Re-running python3 scripts/build_revision_sheets.py recomputes the counts above; nothing is typed by hand.
