Start with short loop and condition problems you can dry-run on paper. Next revise collections, then functions. A Django flow diagram is a quicker first pass than learning several file and regular-expression APIs at once.

The order balances prep effort with past-paper practice. Marks are for the whole linked question, not its subparts or a future exam. Revise every unit.

  1. 1

    Start here · Unit 2 · Control Structures

    Dry-run conditions and loops

    Quick win

    Why here: Loop traces and small programs appear repeatedly. One dry-run habit transfers to range, prime checks and break/continue questions.

    Read first

    • for, while and range with a dry run
    • if–elif–else and break versus continue

    Try it: Write a prime checker and dry-run it on 1, 2 and 9. Mark exactly which condition rejects a composite number.

    Past-paper practice

    • December 2024 · Q3 · 8 marks total Explain break, continue and pass, then write a prime checker.
    • January 2024 · Q4 · 8 marks total Compare for and while and write a digit-sum program.
    Unit notes Practice questions
  2. 2

    Unit 1 · Introduction, Variables and Data Types

    Choose a type and predict the result

    Quick win

    Why here: Comparing collections and dry-running slices are short tasks with both objective and written examples in the archive.

    Read first

    • Lists versus tuples and dictionaries
    • Index, slice, split and join on small examples

    Try it: Make a list of five values. Predict two slices and try changing an element; explain how the same operation differs on a tuple.

    Past-paper practice

    • January 2026 · Q4 · 8 marks total Compare lists, tuples and dictionaries, and distinguish indexing from slicing.
    • March 2023 · Q3 · 8 marks total Show what join and split do and explain string immutability.
    Unit notes Practice questions
  3. 3

    Unit 3 · Functions, Modules and Packages

    Package small, testable functions

    Build on the basics

    Why here: Function-argument and scope questions reuse a few compact examples. Practise those before writing longer scripts or following imports.

    Read first

    • Default and variable-length arguments
    • Local/global scope and module versus package

    Try it: Write a function with one default argument, call it with and without that argument, and move it to a module that you import.

    Past-paper practice

    • January 2024 · Q5 · 8 marks total Give examples of positional, default and variable-length arguments.
    • December 2024 · Q5 · 8 marks total Compare module and package, and distinguish local, global and nonlocal scope.
    Unit notes Practice questions
  4. 4

    Unit 5 · Frameworks

    Follow a Django request

    Build on the basics

    Why here: Start with the repeatable architecture diagram and template purpose. Project setup and forms can follow as separate practice.

    Read first

    • Map URL → view → template
    • Know what templates and static files are used for

    Try it: Draw the route for a page that lists books, labelling what receives the URL and what displays the list. Add where a form would be validated.

    Past-paper practice

    • January 2026 · Q10 · 8 marks total Describe Django’s MVC/MTV architecture.
    • June 2022 · Q4(x) · 2 marks total Show how to insert a static file into a Django template.
    Unit notes Practice questions
  5. 5

    Unit 4 · File I/O, Text Processing, Regular Expressions

    Read a file and extract a match

    Longer practice

    Why here: File questions are useful, but modes, read/write methods and regex returns need separate practice. Learn them after the short reusable answers.

    Read first

    • Choose the file mode before any operation
    • Compare readline, readlines, match and findall

    Try it: Read a short text file, count its lines, and use a regular expression to pick out digit groups from the text.

    Past-paper practice

    • March 2023 · Q9 · 8 marks total Explain file access modes and show read and write methods.
    • December 2024 · Q9 · 8 marks total Compare re.match, re.split and re.findall with examples.
    Unit notes Practice questions

Last-minute checklist

Close your notes and check that you can do each of these.

  • Predict a slice and the output of a loop before you run either.
  • Show a call with a default argument and explain what the function returns.
  • Pick a file mode and a regular-expression method for a small task.
  • Sketch a Django URL, view and template flow without looking at the notes.
