Study Suggestions

Python: Easy Read

Use this study order to plan your revision, then try each task without looking at the notes.

Important Questions Subject notes 2022 syllabus

What to study first

Start by predicting the output of short snippets. Then pass a collection to a function, process text from a file, and finish by drawing how a Django page is served. This is a suggested order, not a reason to skip a syllabus unit.

  1. 1

    Unit 1 · Introduction, Variables and Data Types

    Choose a type and predict the result

    Compare lists, tuples and dictionaries. Predict slicing, indexing, string operations and the output of simple expressions.

    Try it: Make a list of five values. Predict two slices and try changing an element; explain how the same operation differs on a tuple.

    Unit notes Practice questions
  2. 2

    Unit 2 · Control Structures

    Dry-run conditions and loops

    Read indentation before tracing code. Compare for and while, then test what changes when a loop meets break, continue, pass or else.

    Try it: Write a loop that adds only the odd values in a list. Dry-run it on a mixed list and on an empty list.

    Unit notes Practice questions
  3. 3

    Unit 3 · Functions, Modules and Packages

    Package small, testable functions

    Practise arguments and scope before modules and packages. Check which names belong to the function and what its caller gets back.

    Try it: Write a function with one default argument, call it with and without that argument, and move it to a module that you import.

    Unit notes Practice questions
  4. 4

    Unit 4 · File I/O, Text Processing, Regular Expressions

    Read a file and extract a match

    Choose the correct file mode before using a read or write method. Then predict which pieces of a string the regular-expression call returns.

    Try it: Read a short text file, count its lines, and use a regular expression to pick out digit groups from the text.

    Unit notes Practice questions
  5. 5

    Unit 5 · Frameworks

    Follow a Django request

    Map a URL to a view and a template. Then revisit forms, validation, template inheritance and static files in the notes.

    Try it: Draw the route for a page that lists books, labelling what receives the URL and what displays the list. Add where a form would be validated.

    Unit notes Practice questions

Last-minute checklist

  • Predict a slice and the output of a loop before you run either.
  • Show a call with a default argument and explain what the function returns.
  • Pick a file mode and a regular-expression method for a small task.
  • Sketch a Django URL, view and template flow without looking at the notes.
