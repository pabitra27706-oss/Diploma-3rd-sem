  1. Start here · Unit 2: Control Structures

    Why first? Loop traces and small programs appear repeatedly. One dry-run habit transfers to range, prime checks and break/continue questions.

    What’s important

    • Trace if/elif/else, indentation and range bounds. Test the first, last and empty cases.
    • Explain break, continue and pass by showing which line executes next.

    What to read first

    1. Loops and range — write down each value produced by range before tracing the body.
    2. Loop control statements — compare exit, skip-to-next-iteration and no operation.

    Try it

    Write a prime checker and dry-run it on 1, 2 and 9. Mark exactly which condition rejects a composite number.

    From the papers

    • December 2024 · Q3 · 8 marks total Explain break, continue and pass, then write a prime checker.
    • January 2024 · Q4 · 8 marks total Compare for and while and write a digit-sum program.
    Unit notes Practice questions

  2. Rank 2 · Unit 1: Introduction, Variables and Data Types

    Why here? Comparing collections and dry-running slices are short tasks with both objective and written examples in the archive.

    What’s important

    • Choose among a mutable list, an immutable tuple and a dictionary keyed by a lookup value.
    • Trace indexing and slicing. Explain what split and join return on the same short string.

    What to read first

    1. Lists, tuples and dictionaries — make a tiny example of each and try changing one value.
    2. Strings and slicing — check the excluded stop index and practise split and join.

    Try it

    Make a list of five values. Predict two slices and try changing an element; explain how the same operation differs on a tuple.

    From the papers

    • January 2026 · Q4 · 8 marks total Compare lists, tuples and dictionaries, and distinguish indexing from slicing.
    • March 2023 · Q3 · 8 marks total Show what join and split do and explain string immutability.
    Unit notes Practice questions

  3. Rank 3 · Unit 3: Functions, Modules and Packages

    Why here? Function-argument and scope questions reuse a few compact examples. Practise those before writing longer scripts or following imports.

    What’s important

    • Explain positional, keyword, default and variable-length arguments with calls to a small function.
    • Distinguish a local name from a module-level name, and a module from a package.

    What to read first

    1. Parameters and arguments — compare a call that supplies a value with one that uses the default.
    2. Modules and imports — trace where an imported function is defined and how it is called.

    Try it

    Write a function with one default argument, call it with and without that argument, and move it to a module that you import.

    From the papers

    • January 2024 · Q5 · 8 marks total Give examples of positional, default and variable-length arguments.
    • December 2024 · Q5 · 8 marks total Compare module and package, and distinguish local, global and nonlocal scope.
    Unit notes Practice questions

  4. Rank 4 · Unit 5: Frameworks

    Why here? Start with the repeatable architecture diagram and template purpose. Project setup and forms can follow as separate practice.

    What’s important

    • Trace a request through the URL pattern and view to the response. Explain the role of the model and template.
    • Distinguish template data from static assets. Practise one template tag for a CSS file.

    What to read first

    1. MVC and Django’s roles — label which part stores data, which renders it and which handles the request.
    2. URLs and templates — follow a request to the view, then show where template context is used.

    Try it

    Draw the route for a page that lists books, labelling what receives the URL and what displays the list. Add where a form would be validated.

    From the papers

    • January 2026 · Q10 · 8 marks total Describe Django’s MVC/MTV architecture.
    • June 2022 · Q4(x) · 2 marks total Show how to insert a static file into a Django template.
    Unit notes Practice questions

  5. Rank 5 · Unit 4: File I/O, Text Processing, Regular Expressions

    Why here? File questions are useful, but modes, read/write methods and regex returns need separate practice. Learn them after the short reusable answers.

    What’s important

    • Choose between read, overwrite and append. Know what read, readline and readlines return.
    • Compare re.match, re.search and re.findall using input where the first match is not at the start.

    What to read first

    1. File I/O operations — read the mode table and a with-block before trying read or write.
    2. Regular expressions — trace which API returns one match and which returns a list.

    Try it

    Read a short text file, count its lines, and use a regular expression to pick out digit groups from the text.

    From the papers

    • March 2023 · Q9 · 8 marks total Explain file access modes and show read and write methods.
    • December 2024 · Q9 · 8 marks total Compare re.match, re.split and re.findall with examples.
    Unit notes Practice questions

Last-minute checklist

Close your notes and check that you can do each of these.

  • Predict a slice and the output of a loop before you run either.
  • Show a call with a default argument and explain what the function returns.
  • Pick a file mode and a regular-expression method for a small task.
  • Sketch a Django URL, view and template flow without looking at the notes.
