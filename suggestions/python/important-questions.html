Quick reference

  • Index versus slice

    An index picks one element; a slice normally excludes its stop index.

    With a = [10, 20, 30, 40], a[1] is 20 and a[1:3] is [20, 30].

  • Choose a collection

    Use a list for a mutable sequence, a tuple for a fixed sequence, or a dict for key lookup.

    scores = {"Mina": 7} lets you look up scores["Mina"] directly instead of remembering a list position.

  • Split and join

    split produces pieces; separator.join puts string pieces together.

    "a,b,c".split(",") gives ["a", "b", "c"]. "-".join of those pieces gives "a-b-c".

Quick reference

  • End of a range

    The stop value is excluded.

    range(2, 6, 2) yields 2 and 4, not 6.

  • Three loop controls

    break exits the innermost loop, continue skips the rest of this iteration, and pass does nothing.

    Over [1, 2, 3], skipping 2 with continue leaves 1 and 3 to print. Breaking at 2 prints only 1.

  • Prime check

    Reject values below 2, then look for a divisor up to and including the square root.

    For 9 the divisor 3 makes the remainder zero. For 2 there is no candidate divisor to test.

Quick reference

  • Default argument

    A parameter’s default is used when the caller leaves that argument out.

    For def scale(n, k=2): return n*k, scale(3) returns 6 and scale(3, k=4) returns 12.

  • Local versus global

    An ordinary assignment inside a function binds a local name unless declared otherwise.

    With x = 10 at module level, a function that assigns x = 3 and returns x yields 3 without changing the module’s x.

  • Module import

    A module supplies named objects. A package can group related modules.

    If tools.py defines double, import tools makes tools.double(3) available when tools.py is on the import path.

Quick reference

  • Read, write, or append

    r reads an existing file, w creates or truncates, and a creates or appends.

    To add a new line to a log without discarding earlier lines, choose a rather than w.

  • One line at a time

    readline returns the next line, while readlines returns a list of the remaining lines.

    For a file containing A\nB\n, the first readline gives "A\n"; a subsequent readlines gives ["B\n"].

  • Regex starting position

    match checks the start of a string, search looks anywhere, and findall can collect all matching spans.

    On "A12 B3", re.match(r"\d+", text) returns None; re.findall with that pattern returns ["12", "3"].

Quick reference

  • Request flow

    A URL pattern selects a view. The view returns the response and can render a template.

    For /books/, a books view could load a book list and render books.html with that list in the context.

  • Model, template and view

    A model describes the data, a template presents it, and a view coordinates the request.

    A Book model stores titles. The view supplies the books; the template loops through them to show the titles.

  • Static assets

    Static CSS and images are files; template context is per-request data.

    After {% load static %}, use {% static "css/main.css" %} to build the asset URL in a template.
