Quick reference

  • Linear or non-linear?

    A linear structure organises elements in a sequence; a tree branches.

    A queue of A, B, C has a single order. A root with two children illustrates a non-linear structure.

  • ADT and implementation

    An ADT describes operations and behaviour, not the memory representation.

    A stack promises LIFO removal. An array or linked list can implement the same push and pop behaviour.

  • Delete from an array

    With a packed array, deleting an element leaves a gap that later elements must fill.

    Delete index 1 from [4, 7, 9]: shift 9 left and reduce the logical length to get [4, 9].

Quick reference

  • Stack top

    A stack removes the most recently pushed item. In a zero-based array implementation, top = −1 denotes empty.

    Push 4, then 9: top changes −1 → 0 → 1. Pop returns 9 and leaves top at 0.

  • Postfix subtraction

    When applying a binary operator, the first popped value is the right operand.

    For 9 2 − 3 ×, pop 2 then 9 for 9 − 2 = 7. Multiply by 3 to get 21.

  • Circular queue wrap

    When space exists, an index advances to (index + 1) mod capacity.

    In four slots, rear = 3 advances to 0 on the next insertion if slot 0 is free.

Quick reference

  • Insert after a node

    Preserve the old successor before replacing the predecessor’s link.

    For A → B, set X.next = B and A.next = X to get A → X → B.

  • Doubly linked pair

    An adjacent pair needs a forward link and a matching backward link.

    Inserting X between A and B sets A.next = X, X.prev = A, X.next = B and B.prev = X.

  • Circular stop condition

    In a nonempty circular list the tail links back to the head, not to NULL.

    With A → B → A and head A, visit A and B once; stop when the next pointer returns to A.

Quick reference

  • Reconstruct from two orders

    With distinct keys, pre-order gives the root first; in-order separates its left and right subtrees.

    Pre-order B, A, C and in-order A, B, C give B at the root. Post-order is A, C, B.

  • AVL rotation

    Identify the first unbalanced node on the insertion path and the side of the imbalance.

    Inserting 30, 20, 10 creates an LL case. Rotate right at 30 to make 20 the root.

  • Compare BFS and DFS

    BFS uses a queue; DFS goes deep first using recursion or a stack.

    On edges A–B, A–C, B–D from A with alphabetical neighbours, BFS is A, B, C, D; DFS is A, B, D, C.
