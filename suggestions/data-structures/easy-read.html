  1. Start here · Unit 2: Linear Data Structures

    Why first? Push/pop, postfix and circular queues recur in full questions. One trace table helps with algorithms, boundary cases and objective items.

    What’s important

    • Trace the top index for push/pop and cover overflow and underflow. Use the stack state to check each postfix token.
    • Mark front and rear after each circular queue operation, including wraparound.

    What to read first

    1. Stack operations — check the empty and full conditions before changing top.
    2. Queue types — focus on the circular queue and draw its wraparound.

    Try it

    Evaluate the postfix expression 8 3 − 2 × with a stack. Then use a circular capacity of four and trace rear as it wraps after a dequeue.

    From the papers

    • January 2024 · Q2 · 8 marks total Write push and pop algorithms with overflow and underflow checks.
    • March 2023 · Q4 · 8 marks total Write circular-queue insertion and deletion algorithms.
    Unit notes Practice questions

  2. Rank 2 · Unit 3: Linked Lists

    Why here? Insertion and comparison questions reuse a before/after diagram. Practise singly linked lists first, then add back links or a circular tail.

    What’s important

    • Draw the head, changed link and next node for inserts and deletes. Include the empty-list case.
    • Compare a null-terminated list with a circular list, and show which back links a doubly linked list needs.

    What to read first

    1. Singly linked-list insertion — trace head, middle and tail cases before writing the code.
    2. Four list types — compare the stopping condition and the links stored per node.

    Try it

    On paper, insert into an empty list, insert in the middle, and delete the last node. Label which references change each time.

    From the papers

    • December 2024 · Q7 · 8 marks total Insert a node at the beginning of a singly linked list.
    • January 2026 · Q6 · 8 marks total Compare a linked list with an array and describe the advantage of back links.
    Unit notes Practice questions

  3. Rank 3 · Unit 1: Introduction to Data Structures

    Why here? The definitions are fast to revise, but most of the practice here is comparing and explaining. Put the reusable stack and linked-list algorithms first unless the terms are unfamiliar.

    What’s important

    • Give one linear and one non-linear example and explain how their elements are organised.
    • Describe an ADT by its behaviour before naming an implementation. Know traversal, insertion and deletion.

    What to read first

    1. Classification of data structures — compare a linear sequence with a branching structure.
    2. Abstract data types — list the permitted operations without choosing an array or links yet.

    Try it

    Pick a linear structure and a non-linear one. Sketch both and describe what it means to visit every element in each.

    From the papers

    • June 2022 · Q5(a) · 6 marks total Define a data structure and compare linear with non-linear structures.
    • December 2024 · Q3 · 8 marks total Give an example of an abstract data type.
    Unit notes Practice questions

  4. Rank 4 · Unit 4: Non-Linear Data Structures

    Why here? Trees and graph traversals have good past-paper coverage, but they need several distinct traces. Give AVL, traversal and graph work separate time.

    What’s important

    • Write pre-, in- and post-order on one tree. Reconstruct a tree with distinct keys and practise an AVL rotation separately.
    • Run BFS and DFS from a named start with a fixed neighbour order, marking visited vertices.

    What to read first

    1. Tree traversals — write the position of the root in each visit order.
    2. BFS and DFS — trace the queue or stack and mark when each vertex is first visited.

    Try it

    Take a small tree and write all three traversal orders. On a small graph, run BFS and DFS from the same vertex and compare the orders.

    From the papers

    • June 2022 · Q6(c) · 6 marks total Reconstruct the tree from in-order and pre-order and give post-order.
    • January 2026 · Q7 · 8 marks total Explain AVL rotations and construct an AVL tree from the given values.
    Unit notes Practice questions

Last-minute checklist

Close your notes and check that you can do each of these.

  • Check empty and full conditions in a stack or queue trace.
  • Draw a linked-list insertion and label the updated links.
  • Redo a tree traversal and an AVL rotation without notes.
  • State the starting vertex and neighbour order when tracing a graph.
