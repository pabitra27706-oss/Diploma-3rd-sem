Data Structures: Easy Read

Use this study order to plan your revision, then try each task without looking at the notes.

Important Questions Subject notes 2022 syllabus

What to study first

If you know the basic terms, start with stack and queue traces, then draw linked lists. If the terminology feels unfamiliar, review Unit 1 before that sequence. This is a suggested order, not a reason to skip a syllabus unit.

  1. 1

    Unit 2 · Linear Data Structures

    Trace stacks and circular queues

    Record top, front and rear after each operation. Revisit postfix evaluation and write a recursion trace with a clear base case.

    Try it: Evaluate a short postfix expression with a stack. Then trace a circular queue until rear wraps, showing its full and empty states.

    Unit notes Practice questions
  2. 2

    Unit 3 · Linked Lists

    Draw before and after each list operation

    Handle the head, tail and an interior node separately. In a doubly linked list, check the links in both directions.

    Try it: On paper, insert into an empty list, insert in the middle, and delete the last node. Label which references change each time.

    Unit notes Practice questions
  3. 3

    Unit 4 · Non-Linear Data Structures

    Separate tree and graph traces

    Write tree traversals next to the diagram and identify where an AVL rotation is needed. For graphs, label the starting vertex and visited set.

    Try it: Take a small tree and write all three traversal orders. On a small graph, run BFS and DFS from the same vertex and compare the orders.

    Unit notes Practice questions
  4. 4

    Unit 1 · Introduction to Data Structures

    Name the structure and its operations

    Organise examples by how elements are arranged. Connect each example to real operations such as insertion, deletion and traversal.

    Try it: Pick a linear structure and a non-linear one. Sketch both and describe what it means to visit every element in each.

    Unit notes Practice questions

Last-minute checklist

  • Check empty and full conditions in a stack or queue trace.
  • Draw a linked-list insertion and label the updated links.
  • Redo a tree traversal and an AVL rotation without notes.
  • State the starting vertex and neighbour order when tracing a graph.
