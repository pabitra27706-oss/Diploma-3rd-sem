Quick reference

  • Growth bounds

    O is an upper bound; Ω is a lower bound; Θ is a tight bound.

    Example: 3n + 4 grows as Θ(n).

  • Count a loop

    Write out the values before naming the time bound.

    Starting at 1 and doubling while i ≤ 16 gives 1, 2, 4, 8, 16: five iterations.

  • Divide and conquer

    Split the input, solve the subproblems, then combine the results.

    Merge sort splits in half and merges in linear time: T(n) = 2T(n/2) + Θ(n).

Quick reference

  • One pass

    Bubble compares adjacent items; selection picks the smallest remaining item.

    On [4, 3, 2, 1], the first ascending bubble pass gives [3, 2, 1, 4]. The first selection pass gives [1, 3, 2, 4].

  • Worst-case costs

    Selection and insertion take Θ(n²); merge sort and heapsort take Θ(n log n).

    Quicksort can take Θ(n²) when each pivot leaves one partition almost as large as the input.

  • Radix sort by digits

    Least-significant-digit radix sort needs a stable sort at each digit.

    Sort [16, 13, 25] by ones → [13, 25, 16], then by tens → [13, 16, 25].

Quick reference

  • Binary search

    Check the midpoint of the sorted interval and keep only the possible half.

    To find 8 in [2, 4, 6, 8, 10], check 6, keep [8, 10], then check 8 (rounding the midpoint down).

  • Hash collision

    7 mod 5 = 12 mod 5 = 2.

    Chaining stores both keys in bucket 2. Probing looks for another slot instead.

  • Search costs

    Worst-case time on arrays: linear O(n), binary O(log n).

    Binary search needs sorted input; linear search can scan an unsorted array.

Quick reference

  • Two different goals

    An MST minimizes total tree weight. A shortest path minimizes cost between vertices.

    In an undirected triangle with A–B = 2, B–C = 3, A–C = 4, the MST costs 5. The shortest A-to-C path is the direct edge of weight 4.

  • Relax an edge

    Replace d[v] if d[u] + w(u,v) is smaller. Dijkstra needs non-negative edge weights.

    If d[u] = 3, w(u,v) = 2 and d[v] = 8, update d[v] to 5.

  • All-pairs shortest paths

    Floyd–Warshall tests each vertex k as an intermediate stop.

    If i→k costs 2 and k→j costs 4, a current i→j distance of 9 drops to 6.

  • Topological order

    Only a DAG has a topological order. Every edge points from an earlier vertex to a later one.

    If A→C and B→C, put both A and B before C.
