Algorithms: Easy Read

Use this study order to plan your revision, then try each task without looking at the notes.

Important Questions Subject notes 2022 syllabus

What to study first

Start with a short complexity trace. Reuse the same small inputs to compare sorts and searches, then put graph algorithms on paper and label each intermediate choice. This is a suggested order, not a reason to skip a syllabus unit.

  1. 1

    Unit 1 · Fundamentals of Algorithms

    Count work before naming the growth rate

    Identify the input size, the operation being counted and the case you are analysing. Compare divide and conquer, greedy and dynamic programming using examples.

    Try it: Count iterations for a loop that increments by one and one that doubles its index. Show your reasoning for both before writing the asymptotic bound.

    Unit notes Practice questions
  2. 2

    Unit 2 · Sorting

    Show the intermediate sorting passes

    Practise a simple in-place sort, a divide-and-conquer sort and a linear-time sort from the syllabus. Distinguish time cost from extra space.

    Try it: Trace selection sort and merge sort on the same short list with a duplicate value. Write the array after each pass or merge.

    Unit notes Practice questions
  3. 3

    Unit 3 · Searching

    State the search assumptions

    State whether the input is sorted. For trees, trace the search path, and for hashing, show where a collision lands and how it is resolved.

    Try it: Find a present key and an absent key with binary search. Then place two keys in a small hash table so you can demonstrate one collision.

    Unit notes Practice questions
  4. 4

    Unit 4 · Graphs and Graph Algorithms

    Choose the graph algorithm for the goal

    Keep shortest paths, minimum spanning trees and topological order distinct. Check the graph type and edge assumptions before choosing an algorithm.

    Try it: Run Prim’s and Dijkstra’s algorithms on the same small undirected graph with positive weights. Record each chosen edge or updated distance and explain the different goals.

    Unit notes Practice questions

Last-minute checklist

  • Name the input size and case before writing a time bound.
  • Show passes for a sort, and test a binary search with an absent key.
  • Trace a BST update or a hash collision without notes.
  • Name the graph goal and edge assumptions before starting the trace.
