The order balances prep effort with past-paper practice. Marks are for the whole linked question, not its subparts or a future exam. Revise every unit.

  1. 1

    Start here · Unit 3 · Searching

    State the search assumptions

    Quick win

    Why here: Binary search and hash collisions have repeatable traces in written groups. Start with those before practising more involved tree updates.

    Read first

    • Binary search with a missing key and sorted input
    • One hash collision and a BST insertion/deletion

    Try it: Find a present key and an absent key with binary search. Then place two keys in a small hash table so you can demonstrate one collision.

    Past-paper practice

    • January 2024 · Q6 · 8 marks total Write recursive binary search and explain why the input must be sorted.
    • March 2023 · Q8 · 8 marks total Explain hashing and compare collision-resolution techniques.

  2. 2

    Unit 2 · Sorting

    Show the intermediate sorting passes

    Build on the basics

    Why here: Simple sorts are quick to trace and frequently tested. Start with one array and reuse it before moving to pivot selection and non-comparison methods.

    Read first

    • Write one pass each for bubble, selection and insertion
    • Compare merge/quick/heap sorts, then practise radix

    Try it: Trace selection sort and merge sort on the same short list with a duplicate value. Write the array after each pass or merge.

    Past-paper practice

    • January 2026 · Q4 · 8 marks total Write bubble sort and show the array after each pass.
    • January 2024 · Q3 · 8 marks total Trace selection sort and state its worst-case time complexity.
    Unit notes Practice questions
  3. 3

    Unit 1 · Fundamentals of Algorithms

    Count work before naming the growth rate

    Quick win

    Why here: The definitions are quick, but search and sort traces give you more chances to practise a complete procedure. If you get stuck on the notation, use this unit as a warm-up.

    Read first

    • Properties of an algorithm and common bounds
    • Distinguish time, space and the case being analysed

    Try it: Count iterations for a loop that increments by one and one that doubles its index. Show your reasoning for both before writing the asymptotic bound.

    Past-paper practice

    • December 2024 · Q2 · 8 marks total Explain algorithm characteristics and common asymptotic notations.
    • March 2023 · Q3 · 8 marks total Count iterations in a loop whose index doubles.
    Unit notes Practice questions
  4. 4

    Unit 4 · Graphs and Graph Algorithms

    Choose the graph algorithm for the goal

    Longer practice

    Why here: Graph questions provide written practice, but shortest paths, minimum spanning trees and topological order solve different problems. Keep a separate trace for each.

    Read first

    • Prim versus Kruskal on the same graph
    • Dijkstra, Bellman–Ford, Floyd–Warshall and DAG order

    Try it: Run Prim’s and Dijkstra’s algorithms on the same small undirected graph with positive weights. Record each chosen edge or updated distance and explain the different goals.

    Past-paper practice

    • January 2024 · Q4 · 8 marks total Explain and trace Prim’s algorithm for a minimum spanning tree.
    • March 2023 · Q9 · 8 marks total Write Dijkstra’s algorithm and demonstrate the distance updates.
    Unit notes Practice questions

Last-minute checklist

Close your notes and check that you can do each of these.

  • Name the input size and case before writing a time bound.
  • Show passes for a sort, and test a binary search with an absent key.
  • Trace a BST update or a hash collision without notes.
  • Name the graph goal and edge assumptions before starting the trace.
