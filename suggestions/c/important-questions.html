Quick reference

  • Group before evaluating

    Precedence determines grouping. Associativity resolves ties at the same precedence level.

    2 + 3 * 4 groups as 2 + (3 * 4) and gives 14. (2 + 3) * 4 gives 20.

  • Division and casts

    Integer division truncates toward zero. Convert an operand before dividing if you need a fractional result.

    5 / 2 gives 2; (double)5 / 2 gives 2.5. Casting the result of 5 / 2 cannot restore the fraction.

  • Bitwise AND

    A result bit is 1 only when both corresponding input bits are 1.

    For 6 & 3: 0110 AND 0011 gives 0010, or 2.

    • Mar 2021 · Q8
    • Jun 2022 · Q5(c)
    • Jan 2026 · Q4

Quick reference

  • Before or after the body?

    while tests first; do–while tests after its body.

    If x = 0 and the test is x > 0, while skips the body. A do–while with a body that leaves x unchanged runs once.

  • Trace both totals

    For a sum of running totals, update the inner total before adding it to the outer total.

    With i = 1, 2, 3, the inner totals are 1, 3, 6. Their total is 1 + 3 + 6 = 10.

  • Euclid’s remainder step

    Replace (a, b) with (b, a % b) while b is nonzero.

    For 18 and 12: (18, 12) → (12, 6) → (6, 0), so the GCD is 6.

Quick reference

  • Main diagonal

    For a square matrix, sum only positions whose row equals the column.

    In [[1, 2], [3, 4]], add a[0][0] and a[1][1]: 1 + 4 = 5.

  • Transpose

    Move an element at row i, column j to row j, column i.

    A 2 × 3 matrix becomes a 3 × 2 matrix. The element a[0][2] goes to t[2][0].

  • String storage

    A C string ends at the first null character, written \0.

    char s[] = "cat" stores c, a, t, \0 in four slots; strlen(s) is 3.

Quick reference

  • Value versus address

    C passes arguments by value. A copied pointer still points to the caller’s object.

    If a function takes int *p and executes *p = 9 after being called with &x, the caller’s x becomes 9.

  • Scope and lifetime

    Scope is where a name is visible; lifetime is how long the object exists.

    A local static counter initialised to 0 and incremented on each call retains its value between calls.

  • Recursive returns

    Specify a base case, then reduce each call toward it.

    With fact(0) = 1, fact(3) is 3 × fact(2), which unwinds to 3 × 2 × 1 × 1 = 6.

Quick reference

  • Address and dereference

    For an object x, &x is its address; *p accesses the object that p points to.

    Declare int x = 4 and int *p = &x. Assigning *p = 7 changes x to 7.

  • Array access

    Within the array, a[i] accesses the same element as *(a + i).

    For a = {5, 8, 13}, *(a + 1) reads 8. Index 3 is outside the three elements.

  • Allocate, then check

    Size a block by the element count times the size of one element. Check before use; free it when finished.

    For three int values, allocate 3 * sizeof *p bytes for an int pointer p. Do not dereference a null result.
