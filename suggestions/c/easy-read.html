If C syntax is new, skim the types and operators in Unit 1 before tracing the loops in Unit 2.

  1. Start here · Unit 2: Decision Control and Looping Statements

    Why first? Short loop templates cover written comparisons and full programs. The same dry run helps with both the running-total series and GCD.

    What’s important

    • Mark the test, body and update in a loop. Be able to explain why do–while runs its body at least once.
    • Trace a running total and a digit or GCD problem. Check one input that stops the loop early.

    What to read first

    1. Looping statements — compare where the test happens in while and do–while, then dry-run a for loop.
    2. Break and continue — explain which statements still run after each jump.

    Try it

    Trace digit sum with input 402, noting each remainder and updated value. Then write a GCD loop and test it with 18 and 12.

    From the papers

    • June 2022 · Q5(c) · 6 marks total Write the running-total series using loops.
    • January 2026 · Q3 · 8 marks total Compare while and do–while, then write a GCD program.
    Unit notes Practice questions

  2. Rank 2 · Unit 3: Subscripted Variables / Arrays

    Why here? Matrix and string questions reuse loops you already know. A clear index trace is useful across several written question forms.

    What’s important

    • Write the row and column bounds before working on a matrix diagonal or transpose.
    • Leave room for the null terminator. Distinguish measuring, comparing and editing a string.

    What to read first

    1. Two-dimensional arrays — label rows and columns, then follow a diagonal or transpose example.
    2. Strings as character arrays — draw where the terminator goes before trying a string loop.

    Try it

    Sketch a 3 × 3 matrix, mark its diagonal indices, and write a loop that adds only those elements. Then draw how a short string is stored.

    From the papers

    • December 2024 · Q5 · 8 marks total Sum the diagonal of a 4 × 4 matrix.
    • January 2026 · Q6 · 8 marks total Show string functions and check an input string for a palindrome.
    Unit notes Practice questions

  3. Rank 3 · Unit 1: Basics of C

    Why here? These short expression traces and header explanations make a useful third pass. If syntax is the thing slowing you down, do this unit as a warm-up.

    What’s important

    • Group operators before evaluating an expression. Check integer division and casts separately.
    • Recognise basic types and tokens. Know what a header such as <stdio.h> declares.

    What to read first

    1. Operators in C — parenthesise a mixed expression and check precedence and associativity.
    2. Type conversion and casting — compare integer division with a division that has a floating-point operand.

    Try it

    Predict the results of 5/2 and 5/2.0, then trace one expression that mixes multiplication and addition. Explain where parentheses would change the result.

    From the papers

    • March 2023 · ix · 1 mark total Predict the result of an expression that mixes division, multiplication and addition.
    • December 2024 · Q2 · 8 marks total Explain precedence, associativity and the difference between a header and a library.
    Unit notes Practice questions

  4. Rank 4 · Unit 4: User defined functions

    Why here? Storage-class comparisons and parameter examples are reusable. Recursion is worth practising after you can trace the same task with a loop.

    What’s important

    • Show which parameters receive copies and what the function returns. Use an address if the caller’s object must change.
    • Compare scope and lifetime, then trace a recursive base case and the return steps.

    What to read first

    1. Parameter passing — compare passing an integer with passing its address in a pointer parameter.
    2. Recursion — mark the stopping case and write the return values on the way back up.

    Try it

    Write a factorial function and trace the stack by hand for input 3. Test the base case separately.

    From the papers

    • March 2023 · Q6 · 8 marks total Compare storage classes and passing a value versus an address.
    • January 2026 · Q7 · 8 marks total Write a recursive factorial function.
    Unit notes Practice questions

  5. Rank 5 · Unit 5: Pointers in C

    Why here? Pointers turn up in written questions, but correct traversal and allocation take more careful tracing. Start them after arrays and function calls.

    What’s important

    • Draw the pointer, the address and the object separately. Check the array bound before dereferencing.
    • For dynamic memory, calculate the size, check allocation, use the block and free it once.

    What to read first

    1. Declaring and accessing pointers — explain what & and * mean in a short example.
    2. Dynamic memory allocation — compare malloc, calloc and realloc, then mark where free belongs.

    Try it

    Draw a small dynamically allocated array. Write the allocation, failure check, traversal and cleanup in that order.

    From the papers

    • January 2024 · Q6 · 8 marks total Explain address-of and dereference, then access an array using pointers.
    • March 2023 · Q10 · 8 marks total Explain malloc, calloc, realloc and free.
    Unit notes Practice questions

Last-minute checklist

Close your notes and check that you can do each of these.

  • Trace one loop on a normal input and a boundary case.
  • Explain the index bounds of a matrix and the terminator of a C string.
  • Identify the return value and base case of a recursive function.
  • Draw what a pointer refers to and say where allocated memory is freed.
