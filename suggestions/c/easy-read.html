Study Suggestions

C: Easy Read

Use this study order to plan your revision, then try each task without looking at the notes.

Important Questions Subject notes 2022 syllabus

What to study first

Trace a loop on paper, then reuse it to process an array. Once the indices make sense, move the same work into a function and revisit it using pointers. This is a suggested order, not a reason to skip a syllabus unit.

  1. 1

    Unit 1 · Basics of C

    Read a short C expression

    Start with types, formatted input and output, and operator precedence. Keep a tiny example for each operator family.

    Try it: Predict the results of integer and floating-point division with the same operands, then run both expressions and explain the difference.

    Unit notes Practice questions
  2. 2

    Unit 2 · Decision Control and Looping Statements

    Trace the branch and the loop

    Compare if–else with switch. For each loop type (for, while and do–while), note when the condition is checked and what changes each iteration.

    Try it: Trace a digit-sum loop with input 402. Include a separate test for zero and check what happens before the first iteration.

    Unit notes Practice questions
  3. 3

    Unit 3 · Subscripted Variables / Arrays

    Work through arrays and strings

    Write the valid index range before touching an array. For strings, identify the terminator and the buffer size before using a library function.

    Try it: Sketch a 3 × 3 matrix, mark its diagonal indices, and write a loop that adds only those elements. Then draw how a short string is stored.

    Unit notes Practice questions
  4. 4

    Unit 4 · User defined functions

    Turn a solution into a function

    Match the prototype, call and return type. Compare variable scope and lifetime, then practise spotting a recursion base case.

    Try it: Write a factorial function and trace the stack by hand for input 3. Test the base case separately.

    Unit notes Practice questions
  5. 5

    Unit 5 · Pointers in C

    Draw pointers before writing code

    Label each variable, address and pointed-to value. Then revise pointer-based array traversal and the allocation/free lifecycle.

    Try it: Draw a small dynamically allocated array. Write the allocation, failure check, traversal and cleanup in that order.

    Unit notes Practice questions

Last-minute checklist

  • Trace one loop on a normal input and a boundary case.
  • Explain the index bounds of a matrix and the terminator of a C string.
  • Identify the return value and base case of a recursive function.
  • Draw what a pointer refers to and say where allocated memory is freed.
