If you can read a small C program, start with branches and loops, then reuse those ideas on arrays. If syntax is new, use Unit 1 as a short warm-up and return to this order.

The order balances prep effort with past-paper practice. Marks are for the whole linked question, not its subparts or a future exam. Revise every unit.

  1. 1

    Start here · Unit 2 · Decision Control and Looping Statements

    Trace the branch and the loop

    Quick win

    Why here: Short loop templates cover written comparisons and full programs. The same dry run helps with both the running-total series and GCD.

    Read first

    • Trace while and do–while before coding
    • Rehearse one branch problem and one running-total loop

    Try it: Trace digit sum with input 402, noting each remainder and updated value. Then write a GCD loop and test it with 18 and 12.

    Past-paper practice

    • June 2022 · Q5(c) · 6 marks total Write the running-total series using loops.
    • January 2026 · Q3 · 8 marks total Compare while and do–while, then write a GCD program.
    Unit notes Practice questions
  2. 2

    Unit 3 · Subscripted Variables / Arrays

    Work through arrays and strings

    Build on the basics

    Why here: Matrix and string questions reuse loops you already know. A clear index trace is useful across several written question forms.

    Read first

    • Matrix rows, columns, diagonals and transpose
    • String terminator and basic library functions

    Try it: Sketch a 3 × 3 matrix, mark its diagonal indices, and write a loop that adds only those elements. Then draw how a short string is stored.

    Past-paper practice

    • December 2024 · Q5 · 8 marks total Sum the diagonal of a 4 × 4 matrix.
    • January 2026 · Q6 · 8 marks total Show string functions and check an input string for a palindrome.
    Unit notes Practice questions
  3. 3

    Unit 1 · Basics of C

    Read a short C expression

    Quick win

    Why here: These short expression traces and header explanations make a useful third pass. If syntax is the thing slowing you down, do this unit as a warm-up.

    Read first

    • Operator precedence and assignment versus comparison
    • Headers, common types and conversions

    Try it: Predict the results of 5/2 and 5/2.0, then trace one expression that mixes multiplication and addition. Explain where parentheses would change the result.

    Past-paper practice

    • March 2023 · ix · 1 mark total Predict the result of an expression that mixes division, multiplication and addition.
    • December 2024 · Q2 · 8 marks total Explain precedence, associativity and the difference between a header and a library.
    Unit notes Practice questions
  4. 4

    Unit 4 · User defined functions

    Turn a solution into a function

    Build on the basics

    Why here: Storage-class comparisons and parameter examples are reusable. Recursion is worth practising after you can trace the same task with a loop.

    Read first

    • Prototype, call and return value
    • Compare scopes and trace a recursive base case

    Try it: Write a factorial function and trace the stack by hand for input 3. Test the base case separately.

    Past-paper practice

    • March 2023 · Q6 · 8 marks total Compare storage classes and passing a value versus an address.
    • January 2026 · Q7 · 8 marks total Write a recursive factorial function.
    Unit notes Practice questions
  5. 5

    Unit 5 · Pointers in C

    Draw pointers before writing code

    Longer practice

    Why here: Pointers turn up in written questions, but correct traversal and allocation take more careful tracing. Start them after arrays and function calls.

    Read first

    • Draw address, pointer and value separately
    • Trace allocation, failure check, use and cleanup

    Try it: Draw a small dynamically allocated array. Write the allocation, failure check, traversal and cleanup in that order.

    Past-paper practice

    • January 2024 · Q6 · 8 marks total Explain address-of and dereference, then access an array using pointers.
    • March 2023 · Q10 · 8 marks total Explain malloc, calloc, realloc and free.
    Unit notes Practice questions

Last-minute checklist

Close your notes and check that you can do each of these.

  • Trace one loop on a normal input and a boundary case.
  • Explain the index bounds of a matrix and the terminator of a C string.
  • Identify the return value and base case of a recursive function.
  • Draw what a pointer refers to and say where allocated memory is freed.
