Quick reference

  • Three buses

    The address identifies a location, the data bus carries the value, and control coordinates the operation.

    On a CPU memory read, the CPU supplies an address and a read signal; memory supplies the data.

  • Eight-bit negative value

    For two’s complement, invert the fixed-width positive bits and add 1.

    +6 is 00000110. Inverting and adding 1 gives 11111010 for −6 in eight bits.

  • Binary32 normal numbers

    Normal IEEE binary32 values use one sign bit, eight exponent bits with bias 127, and 23 fraction bits.

    1.5 = 1.1₂ × 2⁰: sign 0, exponent field 127, and fraction starting with 1 then zeros.

Quick reference

  • Overlapping stages

    Pipelining overlaps work on different instructions; throughput and single-instruction latency are different.

    Without a stall, instruction 1 can decode in cycle 2 while instruction 2 fetches in cycle 2.

  • One Booth decision

    For the pair (Q₀, Q₋₁), 01 adds M and 10 subtracts M from A before the arithmetic shift.

    If the pair is 10, A = 0000 and M = 0011, subtract to get A = 1101 in four bits before shifting.

  • Microprogrammed control

    A microinstruction selects control actions and how to obtain the next microinstruction.

    A fetch sequence can include MAR ← PC, followed by requesting a memory read and receiving the instruction.

Quick reference

  • BIU and EU

    The BIU handles bus transfers and instruction fetch. The EU decodes and executes instructions.

    The BIU fills the instruction queue; the EU consumes instruction bytes from that queue.

  • Segment and offset

    Form an 8086 physical address from the segment value times 16 plus the offset.

    1234h:0010h gives 12340h + 0010h = 12350h.

  • Immediate or memory?

    An immediate value is encoded in the instruction; register-indirect addressing gets a memory offset from a register.

    MOV AX, 0005h loads the value 5. MOV AX, [BX] reads a word from memory using BX as the offset.

Quick reference

  • Read destination first

    In 8086 Intel syntax, MOV destination, source copies the value without changing the source.

    With AX = 2 and BX = 3, ADD AX, BX gives AX = 5; MOV CX, AX then gives CX = 5.

  • Call or jump?

    CALL saves a return address; an ordinary JMP does not.

    If CALL transfers to a procedure, RET can resume at the instruction following the CALL.

  • Zero-address expression

    On an abstract stack machine, an operator takes operands from the stack, not explicit register arguments.

    To evaluate 8 − 3, push 8, push 3, then subtract the top from the next item. The result on the stack is 5.

Quick reference

  • Direct mapping

    With L lines, block b maps to line b mod L. The tag determines whether the desired block is present.

    With eight lines, block 14 maps to line 6. Check the tag before calling it a hit.

  • Average access time

    Weight the total time for a hit and for a miss by their probabilities.

    With 90% hits at 2 ns and a total miss time of 22 ns: 0.9 × 2 + 0.1 × 22 = 4 ns.

  • Page and offset

    Translation replaces the page number with a frame number while keeping the offset.

    With 4 KiB pages, virtual 0x1234 has page 1 and offset 0x234. If page 1 maps to frame 7, the address is 0x7234.
