Computer System Organization: Easy Read

Use this study order to plan your revision, then try each task without looking at the notes.

Important Questions Subject notes 2022 syllabus

What to study first

Start with the computer block diagram and 8086 registers. Trace one short assembly sequence while the registers are fresh, then give memory and computer arithmetic their own study sessions. This is a suggested order, not a reason to skip a syllabus unit.

  1. 1

    Unit 1 · Structure of Computers; Register Transfer and Micro Operations

    Draw the path that data takes

    Label the processor, memory, I/O and buses. Use a before-and-after register diagram for transfers and shift micro-operations.

    Try it: Draw the Von Neumann block diagram without notes. Use a small register example to trace a logical shift in each direction.

    Unit notes Practice questions
  2. 2

    Unit 3 · Introduction to Microprocessor Architecture

    Label the 8086 before memorising instructions

    Identify the BIU, EU and the main registers. For an instruction, distinguish the addressing mode from the instruction’s operation.

    Try it: Draw the BIU and EU and label several registers. Explain which part of each example instruction tells you where its operand comes from.

    Unit notes Practice questions
  3. 3

    Unit 4 · Assembly Language Programming

    Track the state after each instruction

    Start with moves and arithmetic, then trace a branch or call using the values you have written down. Revisit directives, procedures and macros after the instruction trace.

    Try it: Write a short sequence that adds two register values and stores the result elsewhere. Trace what each instruction changes before adding a branch.

    Unit notes Practice questions
  4. 4

    Unit 5 · Memory and Digital Interfacing

    Keep cache, virtual memory and interfacing separate

    Draw where an address goes in each case: to a cache location, through address translation, or to a selected memory device.

    Try it: Sketch a direct-mapped cache lookup, then draw a separate RAM/ROM address-selection example from the notes.

    Unit notes Practice questions
  5. 5

    Unit 2 · Micro Programmed Control; Computer Arithmetic; Pipelining

    Trace arithmetic, control and the pipeline

    Keep separate diagrams for the control unit and instruction pipeline. For a multiplication or division algorithm, track every register update.

    Try it: Trace a small signed multiplication using the taught register format. Draw a separate pipeline timeline and mark where a dependency can delay an instruction.

    Unit notes Practice questions

Last-minute checklist

  • Draw the computer blocks and explain what moves along each bus.
  • Label the 8086 BIU and EU, and identify an instruction’s addressing mode.
  • Show the intermediate register values in an arithmetic or assembly trace.
  • Explain a pipeline hazard, a cache lookup and address translation as three separate ideas.
