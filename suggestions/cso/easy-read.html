The order balances prep effort with past-paper practice. Marks are for the whole linked question, not its subparts or a future exam. Revise every unit.

  1. 1

    Start here · Unit 3 · Introduction to Microprocessor Architecture

    Label the 8086 before memorising instructions

    Quick win

    Why here: Addressing-mode questions recur and the architecture uses repeatable diagrams. Rehearse one example per mode before studying all pin details.

    Read first

    • 8086 blocks, BIU, EU and registers
    • Addressing modes with one instruction each

    Try it: Draw the BIU and EU and label several registers. Explain which part of each example instruction tells you where its operand comes from.

    Past-paper practice

    • January 2026 · Q3 · 8 marks total Explain 8086 addressing modes with examples.
    • December 2024 · Q4 · 8 marks total Explain the 8086 internal architecture and describe interrupt types.

  2. 2

    Unit 1 · Structure of Computers; Register Transfer and Micro Operations

    Draw the path that data takes

    Quick win

    Why here: A labelled computer diagram and a short register trace are easy to rehearse. Do the floating-point exercises as a second pass within this unit.

    Read first

    • Von Neumann functional units and buses
    • Register shifts, two’s complement and bit fields

    Try it: Draw the Von Neumann block diagram without notes, then encode −6 with eight bits using two’s complement. Check which bits change in a logical right shift.

    Past-paper practice

    • January 2024 · Q2 · 8 marks total Draw the Von Neumann blocks and explain the buses.
    • December 2024 · Q7 · 8 marks total Compare fixed-point and floating-point formats, then encode −75 in eight bits.
    Unit notes Practice questions
  3. 3

    Unit 5 · Memory and Digital Interfacing

    Keep cache, virtual memory and interfacing separate

    Build on the basics

    Why here: Mapping comparisons and hit-ratio questions reuse similar worked examples. Add memory interfacing after you can distinguish cache and address translation.

    Read first

    • Cache mappings and hit/miss calculations
    • Virtual memory, TLB and where an address goes

    Try it: Sketch a direct-mapped cache lookup, then draw a separate RAM/ROM address-selection example from the notes.

    Past-paper practice

    • January 2024 · Q5 · 8 marks total Explain the cache mappings and calculate average access time.
    • January 2026 · Q6 · 8 marks total Explain direct mapping and define virtual memory.
    Unit notes Practice questions
  4. 4

    Unit 4 · Assembly Language Programming

    Track the state after each instruction

    Build on the basics

    Why here: A short register trace is a good first drill, but the archived examples here are less consistent than those for 8086 addressing or cache. Use the notes for branches, procedures and macros as well.

    Read first

    • Trace data movement and register arithmetic
    • Distinguish a normal call from an interrupt

    Try it: Write a short sequence that adds two register values and stores the result elsewhere. Trace what each instruction changes before adding a branch.

    Past-paper practice

    • December 2024 · iii · 2 marks total Choose an assembly sequence that adds two registers and saves the result.
    • January 2024 · Q3 · 8 marks total Write zero-address instructions to evaluate an arithmetic expression.
    Unit notes Practice questions
  5. 5

    Unit 2 · Micro Programmed Control; Computer Arithmetic; Pipelining

    Trace arithmetic, control and the pipeline

    Longer practice

    Why here: This unit has substantial written examples, but arithmetic traces, control sequencing and hazards are separate skills. Tackle them once the shorter diagrams are secure.

    Read first

    • Control memory and instruction pipeline
    • Booth multiplication and restoring division traces

    Try it: Trace a small signed multiplication using the taught register format. Draw a separate pipeline timeline and mark where a dependency can delay an instruction.

    Past-paper practice

    • December 2024 · Q8 · 8 marks total Explain pipelining and identify the kinds of hazards.
    • January 2026 · Q8 · 8 marks total Multiply two negative numbers using Booth’s algorithm.
    Unit notes Practice questions

Last-minute checklist

Close your notes and check that you can do each of these.

  • Draw the computer blocks and explain what moves along each bus.
  • Label the 8086 BIU and EU, and identify an instruction’s addressing mode.
  • Show the intermediate register values in an arithmetic or assembly trace.
  • Explain a pipeline hazard, a cache lookup and address translation as three separate ideas.
