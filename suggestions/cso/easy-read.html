  1. Start here · Unit 3: Introduction to Microprocessor Architecture

    Why first? Addressing-mode questions recur and the architecture uses repeatable diagrams. Rehearse one example per mode before studying all pin details.

    What’s important

    • Draw the BIU, EU and registers. Explain how instruction fetch and execution divide the work.
    • Give an example per addressing mode and tell the effective offset apart from the physical address.

    What to read first

    1. 8086 block diagram — label the BIU, EU and the instruction queue before studying the pins.
    2. 8086 addressing modes — circle the operand source in one instruction per mode.

    Try it

    Draw the BIU and EU and label several registers. Explain which part of each example instruction tells you where its operand comes from.

    From the papers

    • January 2026 · Q3 · 8 marks total Explain 8086 addressing modes with examples.
    • December 2024 · Q4 · 8 marks total Explain the 8086 internal architecture and describe interrupt types.
    Unit notes Practice questions

  2. Rank 2 · Unit 1: Structure of Computers; Register Transfer and Micro Operations

    Why here? A labelled computer diagram and a short register trace are easy to rehearse. Do the floating-point exercises as a second pass within this unit.

    What’s important

    • Label the CPU, memory and I/O, plus the address, data and control paths.
    • Practise fixed-width signed representation and register shifts. Keep the floating-point fields distinct.

    What to read first

    1. Computer structure — follow a memory read and label what travels on each bus.
    2. Data representation — work through a signed two’s-complement value before the float fields.

    Try it

    Draw the Von Neumann block diagram without notes, then encode −6 with eight bits using two’s complement. Check which bits change in a logical right shift.

    From the papers

    • January 2024 · Q2 · 8 marks total Draw the Von Neumann blocks and explain the buses.
    • December 2024 · Q7 · 8 marks total Compare fixed-point and floating-point formats, then encode −75 in eight bits.
    Unit notes Practice questions

  3. Rank 3 · Unit 5: Memory and Digital Interfacing

    Why here? Mapping comparisons and hit-ratio questions reuse similar worked examples. Add memory interfacing after you can distinguish cache and address translation.

    What’s important

    • Compare cache mappings and state what a miss time includes before calculating average access time.
    • Trace a virtual address into page and offset. Keep that separate from cache mapping and chip selection.

    What to read first

    1. Cache memory — map one block, then practise a hit/miss average.
    2. Virtual memory — separate the page number, frame number and offset.

    Try it

    Sketch a direct-mapped cache lookup, then draw a separate RAM/ROM address-selection example from the notes.

    From the papers

    • January 2024 · Q5 · 8 marks total Explain the cache mappings and calculate average access time.
    • January 2026 · Q6 · 8 marks total Explain direct mapping and define virtual memory.
    Unit notes Practice questions

  4. Rank 4 · Unit 4: Assembly Language Programming

    Why here? A short register trace is a good first drill, but the archived examples here are less consistent than those for 8086 addressing or cache. Use the notes for branches, procedures and macros as well.

    What’s important

    • Keep the destination and source straight. Record the registers a move or arithmetic instruction changes.
    • Explain the difference between a jump, a procedure call and a stack-machine expression. Do not mix their notation.

    What to read first

    1. Simple assembly programs — trace a short add-and-store example register by register.
    2. Branch and call instructions — mark the next instruction and the return point for a call.

    Try it

    Write a short sequence that adds two register values and stores the result elsewhere. Trace what each instruction changes before adding a branch.

    From the papers

    • December 2024 · iii · 2 marks total Choose an assembly sequence that adds two registers and saves the result.
    • January 2024 · Q3 · 8 marks total Write zero-address instructions to evaluate an arithmetic expression.
    Unit notes Practice questions

  5. Rank 5 · Unit 2: Micro Programmed Control; Computer Arithmetic; Pipelining

    Why here? This unit has substantial written examples, but arithmetic traces, control sequencing and hazards are separate skills. Tackle them once the shorter diagrams are secure.

    What’s important

    • Draw overlapping instruction stages and distinguish structural, data and control hazards.
    • Keep control memory and arithmetic traces separate. For Booth and restoring division, label the registers after each step.

    What to read first

    1. Pipelining and hazards — mark one dependency on a stage timeline and show why a stall can occur.
    2. Computer arithmetic — practise a Booth decision and a restoring-division iteration separately.

    Try it

    Trace a small signed multiplication using the taught register format. Draw a separate pipeline timeline and mark where a dependency can delay an instruction.

    From the papers

    • December 2024 · Q8 · 8 marks total Explain pipelining and identify the kinds of hazards.
    • January 2026 · Q8 · 8 marks total Multiply two negative numbers using Booth’s algorithm.

Last-minute checklist

Close your notes and check that you can do each of these.

  • Draw the computer blocks and explain what moves along each bus.
  • Label the 8086 BIU and EU, and identify an instruction’s addressing mode.
  • Show the intermediate register values in an arithmetic or assembly trace.
  • Explain a pipeline hazard, a cache lookup and address translation as three separate ideas.
