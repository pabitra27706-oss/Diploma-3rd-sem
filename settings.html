Backup and restore

Backups include local names, notes and answers. Keep them private. Limit: 5 MiB. Import is validated and previewed before applying. Merge keeps local conflicting values unless a supported newer timestamp exists; history is unioned by ID. Preferences are imported only when explicitly selected.

Interrupted imports keep an original-data recovery journal. Export while recovery is pending returns the pre-import data, not a partially imported state.
